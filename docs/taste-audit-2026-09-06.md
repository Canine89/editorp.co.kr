# taste-skill 재평가

평가일: 2026-09-06. 대상: 현재 로컬 개편본 http://localhost:3107. 운영 배포본의 평가가 아니다. 이번 작업에서는 화면 구현과 운영 데이터를 변경하지 않았다.

## 총평

읽기 쉬운 색상과 글꼴, 목표별 경로, 검색과 진도 저장의 기반은 갖췄다. 다만 처음 요청한 ‘완전히 새로운 사이트’와 ‘중요한 About’을 기준으로 보면, 편집자P의 전문성을 앞세우는 구성과 학습 경로의 시각적 위계를 한 번 더 다듬어야 한다. 큰 소개 문구, 넓은 여백, 비슷한 카드가 반복되어 다른 교육 사이트에도 적용할 수 있는 인상이 남아 있다.

기준: design-taste-frontend의 콘텐츠 우선 판단, 카드 사용의 목적, 반복 레이아웃 억제, 설명 문구 검수, 실제 이미지의 활용, 상태와 동작의 일치, 페이지 간 일관성. 교육 사이트의 특성상 학습 진도 막대, 순서 번호, 영상 목록의 규칙적인 그리드는 의미가 있으므로 기계적인 금지 대상으로 보지 않는다.

현재 DESIGN.md의 설정은 디자인 변화 7 / 움직임 3 / 정보 밀도 4다. 실제 화면의 변화 폭은 검토자의 판단으로 5 정도에 가깝다. 이 수치는 측정 점수가 아닌 디자인 방향의 해석이다. 움직임 3은 학습 사이트에 적합하며, 이 평가 때문에 애니메이션을 늘릴 필요는 없다.

## 먼저 수정할 사항

### 1. 편집자 소개와 전문성의 위치를 높인다

홈에서 본격적인 소개 제목은 데스크톱 문서 상단 기준 약 3,890px, 390px 모바일에서는 약 6,628px에 있다. 소개가 중요한 서비스라는 요청에 비해 노출 순서가 늦다. 상단의 ‘46권’ 숫자는 보이지만 어떤 책을 어떤 역할로 만들었는지까지 전달하지는 못한다.

홈의 첫 학습 경로 전후에 대표 도서 표지, 편집·집필 역할, 실제 강의 이력을 짧게 묶고 About으로 연결한다. 상세 이력 전체를 홈으로 복제할 필요는 없다. ‘이 순서를 누가, 어떤 경험으로 골랐는가’를 초반에 이해시키는 것이 목표다.

근거: app/page.tsx의 aboutSection과 소개 링크, 실제 홈의 제목 위치 측정.

### 2. About을 경력과 작업의 구체적인 증거가 보이는 페이지로 만든다

현재 첫 화면에서는 184×189px 캐릭터 원본을 CSS 250px로 확대하고, ‘책을 만드는 사람 / 직접 만들어보는 사람’이라는 문구를 크게 보여준다. 캐릭터는 브랜드 자산으로 유지할 가치가 있지만, 이 확대 이미지 하나가 큰 영역을 차지하는 구성은 전문성을 충분히 설명하지 못한다.

집필 도서 7권은 제목만 있는 박스로 보여준다. 실제 책 표지를 이미 보유한 사이트이므로 대표작 일부를 표지·본인 역할·관련 강의와 함께 보여줄 수 있다. 강의 이력도 최근 순서만 강조하기보다 기업·교사·공공기관의 대표 사례를 먼저 소개하고 전체 이력은 지금처럼 펼쳐보게 하는 편이 좋다. 새로운 경력이나 후기를 만들어 넣어서는 안 된다.

근거: app/about/page.tsx:41, :62, :191 및 app/about/about.module.css:55.

### 3. 추천 경로의 관계를 화면에서 바로 이해하게 한다

6개 추천 경로는 설명과 선수 지식이 있으나, 홈에서는 같은 크기의 카드에 나열된다. ‘기초’, 특정 도구, ‘업무 자동화’, ‘심화’라는 서로 다른 기준이 한 목록에 섞여 있어 앞뒤 관계를 읽어서 추론해야 한다.

공통 기초를 하나의 출발점으로 두고, 문서·업무와 웹·앱 제작으로 나뉜 뒤 심화로 이어지는 관계를 보여준다. 도구명은 선택을 돕는 보조 정보로 배치한다. 기존 전체 보기와 필터는 보존할 수 있다.

첫 경로의 총 시청 시간 105분은 정확한 정보지만 첫 시작의 부담으로 느껴질 수 있다. 총량과 함께 ‘첫 강의 약 26분’과 첫 실습 목표를 보여주는 구성이 더 적절하다. 실습 시간을 실제로 측정한 것처럼 표시해서는 안 된다.

근거: components/PathExplorer.tsx:52, data/learning-paths.json, 실제 카드 배치.

### 4. 재생 표시와 실제 동작을 일치시킨다

홈의 큰 재생 아이콘을 누르면 /learn/claude-work로 이동한다. 도착한 iframe에는 autoplay가 없다. 사용자가 예상하는 ‘영상 재생’과 실제 ‘학습 경로 열기’가 다르다. 이동을 유지하려면 ‘5개 강의로 시작하기’ 같은 경로 안내로 바꾸고 재생 아이콘을 제거한다. 재생 기능을 제공할 경우에는 재생 대상으로 표시한다.

또한 기초 첫 강의의 현재 유튜브 썸네일에는 ‘후원자 전용 도서 강의’라는 문구가 있다. 쿠키 없이 가져온 공개 페이지의 playabilityStatus는 OK, playableInEmbed는 true였다. 접근 차단으로 판정하지 않는다. 다만 사이트의 무료 학습 안내와 썸네일 문구가 충돌하므로 첫 진입에서 설명하거나 표시 이미지를 정비해야 한다.

근거: app/page.tsx:63, 실제 클릭 후 목적지와 iframe 확인, https://www.youtube.com/watch?v=lzkfJwYrKqw 의 확인된 재생 상태.

## 유지할 요소

- 녹색 중심의 밝은/어두운 테마와 한글 제목의 안정적인 가독성.
- 실제 영상·도서·경력 자료를 사용하는 방향.
- 학습 목표·선수 지식·시청 시간을 설명한 데이터 구조.
- 영상 탐색의 규칙적인 그리드. 이 페이지는 반복 구조가 자료 비교에 유리하다.
- 학습 진행률, 순서 번호, 완료 표시. 실제 학습 상태를 전달하는 기능이다.
- 과도한 모션을 추가하지 않는 방향.

## 검수 범위와 한계

현재 로컬 구현을 실제 브라우저로 확인했다. 주요 7개 화면, 홈과 학습의 390px 모바일, 밝은 테마와 학습 화면의 어두운 테마, 소개의 도서 영역, 파이썬 도서 첫 절의 모바일 본문, 링크의 실제 목적지를 확인했다. 측정한 스크롤 위치는 해당 검수 뷰포트 기준으로 다른 크기에서는 달라진다.

테마 전환 직후의 일부 캡처에서는 전환 중 색이 잡혀 대기 후 화면과 계산된 CSS 색상을 다시 확인했다. 도서 페이지의 밝은 배경에 어두운 글자는 정상이며, 이를 대비 오류로 보고하지 않는다.

이전 작업의 Lighthouse 모바일 성능 94, 접근성 100 등은 홈의 기술적 측정이다. 이번에 새로 측정한 수치가 아니며 전체 페이지의 디자인 완성도나 사용성 점수로 환산하지 않는다.

## 권장 수정 순서

1. 홈 초반의 편집자 신뢰 자료와 About 대표작·대표 강의 구성.
2. 공통 기초 → 목적별 선택 → 심화 관계와 첫 시작 경험 정리.
3. 재생 표시·목차 제목·상위 메뉴 선택 상태 개선.
4. 도서와 영상 탐색 페이지의 제목 체계·밀도·찾기 기능 통일.

전체 색상을 다시 바꾸는 작업의 우선순위는 낮다. 이번 재평가의 핵심은 편집자P의 실제 작업과 학습 결과물이 더 먼저 보이게 하는 것이다.
