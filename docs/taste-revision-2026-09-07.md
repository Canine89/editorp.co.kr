## 반영 내용

- 홈: 편집자 이름·역할·소개 링크를 첫 화면으로 이동. 대표 도서 원본 표지와 참여 역할, 46권의 도서 참여, 기업·학교·공공기관의 실제 강의 사례를 전면에 배치.
- 추천 경로: 공통 기초 → 문서·업무 / 웹·앱 제작 → 심화의 구조. 전체 보기·주제 필터·빈 결과 상태 유지. 첫 강의 시청 시간과 실습 목표 표시.
- About: 큰 캐릭터 패널을 대표 도서로 교체. 대표작의 참여 역할과 관련 영상 검색을 연결. 대표 강의 사례를 먼저 보여주고 집필·편저서 7권과 주요 강의 이력 31건을 전체 펼쳐보기로 보존.
- 학습: 원제를 보존하면서 명확한 학습용 제목 제공. 관리자 수정 제목은 자동 별칭보다 우선. 모바일 목차 열기·완료 조작, 강의 선택 후 목차 닫기와 키보드 포커스 복원. 학습 준비 정보는 펼쳐보기로 변경.
- 동작: 홈의 경로 이동에 붙었던 재생 아이콘 제거. 하위 학습·도서 페이지에서도 상위 메뉴가 선택 상태를 유지.
- 영상: 간결한 표시 제목, 원제 펼쳐보기, 포함된 학습 경로 연결, Claude/클로드·Cursor/커서·Codex/코덱스 등 한영 검색어 정규화.
- 도서: 파이썬 학습서를 전면에 배치하고 사이트 사용 예제는 보조 영역에 유지. 참여 도서 46권은 역할·출판사·제목 검색과 12권 단위 페이지 이동으로 탐색.
- 도서 본문: 내용 없이 남은 지정된 학습 표제만 읽기 화면에서 숨김. 실제 본문과 원본 원고·Firestore 오버레이는 보존.
- 질문: 로컬에서 게시판 준비 중일 때 로드맵 복귀와 오픈카톡방 링크 제공.
