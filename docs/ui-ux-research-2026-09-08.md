# UI/UX 스킬 조사와 학습 흐름 개선

## 스킬 선택

skills.sh 목록과 `skills find ux usability`의 후보를 비교한 뒤 원본 저장소·설치 이력·실제 SKILL.md를 확인했다. 키워드 검색의 소규모 후보를 바로 설치하는 대신 다음 두 스킬을 선택했다.

- [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill): 학습 진도, 선택 과정의 자율성, 탐색 상태 보존, 모바일 조작, 피드백을 다루는 로컬 지침.
- [Vercel Web Design Guidelines](https://github.com/vercel-labs/agent-skills/tree/main/skills/web-design-guidelines): URL 상태, 키보드 포커스, 폼 레이블, 로딩·오류 상태 등을 검토하는 지침. [현재 규칙 원문](https://github.com/vercel-labs/web-interface-guidelines/blob/main/command.md)을 확인했다.

두 스킬은 개인 스킬 디렉터리에 설치했다. 이번 작업에서도 설치된 문서를 직접 읽어 적용했고 다음 턴부터 자동 선택에도 사용할 수 있다. 프로젝트의 기존 색상·한국어 글꼴·Firestore 저장 구조는 유지했다.

UI/UX Pro Max에서 `learning platform progress onboarding`, `navigation back deep links`, `keyboard focus not obscured`를 UX 도메인으로, `search loading navigation`을 Next.js 스택으로 검색했다. 실제 결과 중 작업에 맞는 진도 표시·경로 선택·상태 복원·포커스·로딩 지침을 적용했다. `feedback undo`는 관련성이 낮았고 `undo action` 재검색도 일치 항목이 없어, 되돌리기는 Vercel의 실행 취소 지침과 기존 완료 기능을 근거로 구현했다.

## 확인한 문제와 수정

| 문제 | 수정 |
| --- | --- |
| 처음부터 모든 경로를 읽고 판단해야 함 | 세 가지 학습 목적을 고르면 적합한 시작 경로·결과물·첫 강의 시간이 바로 표시되는 시작점 선택 화면 |
| 이전 학습 기록이 강의실 안에서만 드러남 | 홈 상단에 미완료 경로와 마지막 학습 위치를 연결하는 이어보기 |
| 영상·설명·버튼이 분리되고 내부 스크롤에 완료 버튼이 묻힘 | 강의실을 다시 구성하고 영상 바로 아래에 이전·완료·다음 조작 배치. 목차만 필요한 범위에서 스크롤 |
| 강의별 주소가 없어 같은 위치로 공유하기 어려움 | `?lesson=강의ID` 링크, 브라우저 뒤로 가기, 직접 링크 진입 지원 |
| 실수로 완료해 다음 강의로 이동하면 되돌리기 어려움 | 완료 피드백과 실행 취소. 전체 완료 시 다음 경로 안내 |
| 필터 선택 후 새로고침하면 초기화됨 | 홈 경로 필터를 `view` URL 매개변수에 저장하고 뒤로 가기·새로고침 시 복원 |
| 검색 필드의 용도가 자리표시자에 의존함 | 검색어·주제·형식·출판사·역할의 눈에 보이는 레이블과 44px 이상 조작 영역 |
| 검색 중인지 알기 어려움 | 검색 중 버튼 상태, 목록 로딩 화면, 재시도 가능한 오류 화면 |
| 검색 후 키보드 위치가 불분명함 | 결과 개수 영역으로 포커스를 옮기고 뒤로 가기 시 검색어·필터 복원 |
| 개별 검색 조건을 해제하기 어려움 | 적용 조건 표시, 개별 해제, 전체 초기화 |

## 검증

- 프로덕션 빌드, 변경 파일 ESLint, diff 공백 검사 통과.
- 경로 추천 선택 시 경로와 링크가 바뀌는 것을 실제 브라우저에서 확인.
- 홈 필터 URL 반영 및 새로고침 복원 확인.
- 강의 직접 링크 진입, 완료 후 다음 강의, 되돌리기, 브라우저 뒤로 가기, 홈 이어보기 연결 확인.
- 데스크톱 검수 화면의 완료 버튼 하단이 약 792px로, 818px 높이의 화면 안에 들어옴. 이전에는 완료 버튼 상단이 약 980px에 있었음. 수치는 해당 뷰포트 기준이다.
- 390px 모바일 다크 모드에서 가로 넘침 없음. 주요 완료 버튼 높이 46px, 목차 선택 후 닫힘과 포커스 복원 확인.
- 네트워크 지연 600ms 조건에서 검색 중 표시 확인. 검색 후 결과 개수 영역 포커스와 뒤로 가기 시 검색어·형식 복원 확인.
- 기존 완료·마지막 강의 키 호환, 중복/삭제 ID 제거, 잘못된 저장값, 저장 차단 처리를 별도 검증.
- 홈 Lighthouse 모바일 시뮬레이션: 성능 94, 접근성 100, 권장사항 100, 검색 최적화 100. LCP 3.2초, CLS 0. 이는 로컬 기술 측정이며 사용자 테스트 점수는 아니다.
- 실제 Google 로그인·운영 Firestore 쓰기·운영 배포는 실행하지 않았다. 로컬 미리보기 인증 설정만 사용했다.

학습 기록은 기존 `completed-nodes-{id}`, `last-node-{id}`를 유지한다. `editorp-learning-activity`에는 최근 방문한 학습 경로의 시각만 기록한다. 서버나 외부 서비스로 학습 진도를 전송하지 않는다.
