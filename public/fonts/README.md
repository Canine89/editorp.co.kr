# EditorP Sans

Pretendard 1.3.9에서 이 사이트가 사용하는 문자만 추출한 가변 글꼴입니다. 원본의 Reserved Font Name을 존중하여 파생 글꼴의 내부 이름을 EditorP Sans로 변경했습니다. 라이선스와 원저작권 고지는 OFL.txt에 있습니다.

원본: https://github.com/orioncactus/pretendard/tree/v1.3.9

콘텐츠의 문자가 추가되면 `scripts/subset-font.py`로 다시 생성할 수 있습니다. 포함되지 않은 문자는 운영체제 글꼴로 표시되므로 새 글자도 읽을 수 있습니다. 외부 글꼴 CDN에 실행 시 의존하지 않습니다.
