# 코드 언어 아이콘

출처: [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0/icons), MIT 라이선스(`LICENSE.txt`).
외부 CDN 없이 이 폴더의 SVG를 사용합니다.

- Python, JavaScript, TypeScript, Bash: 각 언어의 `original` SVG.
- HTML, CSS: 각각 `html5-original.svg`, `css3-original.svg`.
- JSON: `json-original.svg`의 글리프를 유지하고 회색 그라데이션을 녹색으로 조정한 변형.

언어 이름 옆에 붙는 장식 이미지이므로 빈 대체 텍스트와 `aria-hidden`을 사용합니다.
