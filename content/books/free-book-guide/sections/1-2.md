이 사이트의 책은 한국 출판에서 익숙한 **마당 > 장 > 절** 3단계 구조를 따릅니다.

## 세 단계의 역할

| 단계 | 역할 | 예시 |
| ---- | ---- | ---- |
| 마당 | 책의 큰 흐름을 나누는 부(部) | 첫째 마당. 시작하기 |
| 장 | 하나의 주제 묶음 | 1장. 무료 도서 기능 소개 |
| 절 | 실제로 읽는 한 페이지 | 1.1 이 책의 목적 |

독자가 실제로 여는 페이지는 **절** 단위입니다. 마당과 장은 목차에서 길잡이 역할을 합니다.

## URL 구조

절 하나가 주소 하나를 가집니다.

```
/books/free-book-guide/1-2
        └── 책 id        └── 절 id
```

절 id는 책 안에서 유일하기만 하면 되고, `1-2`처럼 장-절 번호를 쓰는 것을 권합니다.
