새 책을 추가하려면 `content/books/` 아래에 폴더를 만들고 `book.json`을 작성합니다.

## 1단계. 폴더 만들기

폴더 이름이 곧 책의 URL id가 됩니다. **소문자, 숫자, 하이픈**만 사용하세요.

```
content/books/
└── my-new-book/
    ├── book.json
    └── sections/
```

## 2단계. book.json 작성

```json
{
  "title": "책 제목",
  "description": "책 소개",
  "author": "저자명",
  "publishedAt": "2026-06-10",
  "parts": [
    {
      "id": "part-1",
      "title": "첫째 마당. 마당 제목",
      "chapters": [
        {
          "id": "ch-1",
          "title": "1장. 장 제목",
          "sections": [
            { "id": "1-1", "title": "1.1 절 제목", "file": "1-1.md" }
          ]
        }
      ]
    }
  ]
}
```

저장 후 개발 서버를 새로 고치면 `/books` 목록에 바로 나타납니다. 배포 시에는 빌드 시점에 정적으로 포함됩니다.
