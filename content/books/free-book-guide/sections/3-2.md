기술서에 자주 등장하는 코드, 인용, 표를 시연합니다.

## 코드 블록

언어 이름을 붙인 펜스 코드 블록을 지원합니다.

```typescript
export function greet(name: string): string {
  return `안녕하세요, ${name}님!`;
}
```

문장 안의 `인라인 코드`도 이렇게 표시됩니다.

## 인용

> 좋은 책은 독자의 시간을 아껴 주는 책이다.
> 인용문은 여러 줄로 이어 쓸 수 있습니다.
