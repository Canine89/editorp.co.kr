## 클래스 정의하고 인스턴스 만들기

가장 기본부터 시작합니다. 반려동물을 표현하는 Pet 클래스를 정의하고 인스턴스를 2개 만들어봅시다.

```python filename="08-29-pet_class.py"
class Pet:
  def __init__(self, name, age):  # ➊ 인스턴스 변수 초기화
    self.name = name
    self.age = age

choco = Pet("초코", 3)  # ➋ 인스턴스 만들기
nabi = Pet("나비", 1)

print(choco.name)
print(nabi.age)
```

**실행 결과**

```text
초코
1
```

❶ 인스턴스를 만들 때 자동으로 실행되는 __init__( ) 메서드입니다. 전달받은 name과 age를 self에 붙여 self.name, self.age에 각각 저장해 인스턴스 변수로 만듭니다.

❷ Pet("초코", 3)으로 인스턴스를 만들어 choco 변수에 저장했습니다. 같은 설계도로 만들었지만 choco와 nabi는 서로 다른 값을 가진 별개의 인스턴스입니다.

## 인스턴스 변수를 사용하는 메서드 만들기

이번에는 Pet 클래스에 자기소개를 하는 메서드를 추가해봅시다. 메서드에서 인스턴스 변수를 사용하려면 self가 필요했죠?

```python filename="08-30-pet_method.py"
class Pet:
  def __init__(self, name, age):
    self.name = name
    self.age = age

  def introduce(self):  # ➊ 메서드 정의
    print(f"저는 {self.name}이고, {self.age}살입니다.")

choco = Pet("초코", 3)
choco.introduce()  # ➋ 메서드 호출
```

**실행 결과**

```text
저는 초코이고, 3살입니다.
```

❶ introduce( ) 메서드는 self.name과 self.age를 사용해 자기소개 문장을 출력합니다. self를 통해 인스턴스마다 자신의 값을 사용할 수 있습니다.

❷ choco.introduce( )로 호출하면 self에 choco가 전달되어 초코의 정보가 출력됩니다.

## 상속으로 자식 클래스 만들기

Pet 클래스를 상속받아 강아지 클래스를 만들어봅시다. 부모의 메서드를 그대로 물려받으면서 자식만의 메서드를 추가할 수 있습니다.

```python filename="08-31-pet_inheritance.py"
class Pet:
  def __init__(self, name, age):
    self.name = name
    self.age = age

  def introduce(self):
    print(f"저는 {self.name}이고, {self.age}살입니다.")

class Dog(Pet):  # ➊ Pet 클래스 상속
  def play(self):  # ➋ 자식 클래스만의 메서드
    print(f"{self.name}가 공을 물어옵니다!")

dog = Dog("바둑이", 2)
dog.introduce()
dog.play()
```

**실행 결과**

```text
저는 바둑이이고, 2살입니다.
바둑이가 공을 물어옵니다!
```

❶ class Dog(Pet):으로 Pet 클래스를 상속받았습니다. Dog 클래스에는 __init__( ) 메서드가 없지만 부모의 __init__( ) 메서드를 물려받아 그대로 사용합니다.

❷ play( )는 Dog에만 있는 메서드입니다. 실행 결과를 보면 부모에게 물려받은 introduce( )와 자식 클래스에 추가한 play( )가 모두 잘 동작합니다.

## 메서드 오버라이딩하고 super( ) 사용하기

이번에는 고양이 클래스에서 introduce( ) 메서드를 오버라이딩해봅시다. super( )를 사용하면 부모의 메서드도 함께 실행할 수 있습니다.

```python filename="08-32-pet_override_super.py"
class Pet:
  def __init__(self, name, age):
    self.name = name
    self.age = age

  def introduce(self):
    print(f"저는 {self.name}이고, {self.age}살입니다.")

class Cat(Pet):
  def introduce(self):  # ➊ 메서드 오버라이딩
    super().introduce()  # ➋ 부모의 introduce() 먼저 실행
    print("야옹!")

cat = Cat("나비", 1)
cat.introduce()
```

**실행 결과**

```text
저는 나비이고, 1살입니다.
야옹!
```

❶ 부모에게 물려받은 introduce( )를 자식 클래스에서 같은 이름으로 다시 정의했습니다. 이것이 오버라이딩입니다.

❷ super( ).introduce( )로 부모의 introduce( )를 먼저 실행한 다음 "야옹!"을 덧붙였습니다. 부모의 기능을 그대로 사용하면서 자식만의 동작을 더하고 싶을 때 super( )를 사용합니다.

## 클래스 변수와 __str__( ) 함께 사용하기

이번에는 클래스 변수와 __str__( ) 메서드를 함께 사용해봅시다. 인스턴스를 만들 때마다 개수를 세고, print( )로 출력할 때의 모양도 정해봅니다.

```python filename="08-33-pet_count_str.py"
class Pet:
  count = 0  # ➊ 클래스 변수

  def __init__(self, name, age):
    self.name = name
    self.age = age
    Pet.count += 1  # ➋ 인스턴스가 만들어질 때마다 1 증가

  def __str__(self):  # ➌ 출력 모양 정하기
    return f"Pet({self.name}, {self.age}살)"

choco = Pet("초코", 3)
nabi = Pet("나비", 1)

print(choco)
print(nabi)
print(f"반려동물 수: {Pet.count}")
```

**실행 결과**

```text
Pet(초코, 3살)
Pet(나비, 1살)
반려동물 수: 2
```

❶ count는 클래스 변수입니다. 인스턴스 변수와 달리 모든 인스턴스가 함께 공유합니다.

❷ __init__( ) 메서드가 실행될 때마다 Pet.count에 1을 더하므로 인스턴스가 몇 개 만들어졌는지 셀 수 있습니다.

❸ __str__( ) 메서드를 정의하면 print(choco)처럼 인스턴스를 출력할 때 원하는 모양의 문자열을 보여줄 수 있습니다.

## super( ).__init__( )으로 학생 클래스 만들기

사람 클래스를 상속받아 학교 정보까지 갖는 학생 클래스를 만들어봅시다.

```python filename="08-34-super_init_practice.py"
class Person:
  def __init__(self, name, age):
    self.name = name
    self.age = age

  def introduce(self):
    print(f"이름: {self.name}, 나이: {self.age}")

class Student(Person):
  def __init__(self, name, age, school):
    super().__init__(name, age)    # ➊ 부모의 값 이어받기
    self.school = school           # ➋ 학생만의 값 추가

  def introduce(self):
    super().introduce()
    print(f"학교: {self.school}")

baro = Student("바로", 17, "바로고등학교")
baro.introduce()
```

**실행 결과**

```text
이름: 바로, 나이: 17
학교: 바로고등학교
```

❶ super( ).__init__(...)을 사용해 부모 클래스의 __init__( ) 메서드를 실행합니다. 이 코드가 없다면 부모의 __init__( )에서 만드는 self.name과 self.age가 생성되지 않습니다.

❷ 부모가 준비해준 값 위에 학생만의 값을 더했습니다.

## 클래스 변수로 개수 세기

책 인스턴스를 만들 때마다 개수가 늘어나도록 만들어봅시다. 공유하는 클래스 변수의 값을 변경할 때는 클래스 이름으로 접근하는 것이 핵심입니다.

```python filename="08-35-class_variable_practice.py"
class Book:
  count = 0

  def __init__(self, title):
    self.title = title
    Book.count = Book.count + 1    # ➊ 클래스 이름으로 접근

book1 = Book("파이썬 입문")
book2 = Book("파이썬 중급")
book3 = Book("파이썬 실전")
print(f"만든 책: {Book.count}권")
```

**실행 결과**

```text
만든 책: 3권
```

❶ 클래스 변수 count는 모든 Book 인스턴스가 함께 사용하는 값이므로 Book.count로 접근해 책이 만들어질 때마다 1씩 증가시킵니다. 만약 self.count = self.count + 1로 바꾸면 각 인스턴스에 count라는 인스턴스 변수가 새로 만들어지고, 클래스 변수 Book.count는 0으로 유지됩니다. 따라서 출력 결과는 "만든 책: 0권"이 됩니다.

## 밑줄 두 개로 값 보호하기

지갑에 든 돈을 실수로 직접 변경하기 어렵게 만들고, 돈을 쓰는 일은 메서드를 통해 처리하도록 해봅시다.

```python filename="08-36-private_practice.py"
class Wallet:
  def __init__(self, money):
    self.__money = money           # ➊ 밑줄 두 개

  def spend(self, amount):
    if amount > self.__money:      # ➋ 가진 돈보다 많으면 거절
      print("돈이 부족합니다.")
      return
    self.__money = self.__money - amount
    print(f"남은 돈: {self.__money}원")

wallet = Wallet(5000)
wallet.spend(2000)
wallet.spend(10000)
```

**실행 결과**

```text
남은 돈: 3000원
돈이 부족합니다.
```

❶ 돈을 저장하는 인스턴스 변수 이름을 밑줄 두 개로 시작했습니다. 이렇게 하면 파이썬이 변수 이름을 내부적으로 바꾸어 저장하므로, 클래스 바깥에서 __money라는 이름으로 직접 접근하기 어려워집니다.

❷ 쓰려는 금액이 가진 돈보다 많으면 "돈이 부족합니다."를 출력하고 return으로 메서드를 바로 끝냅니다. 이를 조기 반환이라고 합니다.

## 다형성으로 여러 도형 그리기

여러 종류의 도형을 한 리스트에 담아두고 반복문으로 한 번에 그려봅시다.

```python filename="08-37-polymorphism_practice.py"
class Shape:
  def draw(self):
    print("도형을 그립니다.")

class Circle(Shape):
  def draw(self):
    print("원을 그립니다.")

class Square(Shape):
  def draw(self):
    print("사각형을 그립니다.")

shapes = [Circle(), Square()]
for shape in shapes:
  shape.draw()                     # ➊ 같은 호출
  print(isinstance(shape, Shape))  # ➋ 모두 Shape의 인스턴스
```

**실행 결과**

```text
원을 그립니다.
True
사각형을 그립니다.
True
```

❶ 반복문 안에서는 shape.draw( )라는 같은 메서드를 호출하지만 인스턴스의 종류에 따라 다른 결과가 나옵니다. 이처럼 같은 메서드 호출이 대상에 따라 다르게 동작하는 성질을 다형성이라고 합 니다.

❷ Circle과 Square 모두 Shape를 상속받았으므로 각 인스턴스를 대상으로 isinstance(인스턴스, Shape)를 실행하면 둘 다 True가 나옵니다.

아홉 개의 연습을 모두 마쳤다면 클래스의 기본기를 충분히 연습했다고 봐도 됩니다. 이제 다음 장으로 넘어가봅시다!

> **바로 핵심 요약**
>
> - 클래스를 정의하고 인스턴스를 만든 뒤 메서드를 호출하는 것이 클래스를 사용하는 기본 흐름입니다.
> - 상속과 오버라이딩, super( )를 함께 쓰면 부모의 기능을 활용하면서 자식만의 동작을 추가할 수 있습니다.
> - 클래스 변수로 인스턴스의 개수를 세고 __str__( )로 출력 모양을 정하면 클래스를 더욱 다양하게 쓸 수 있습니다.
