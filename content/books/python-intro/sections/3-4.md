이번에는 글자를 다루는 자료형인 문자열을 공부합니다. 문자열은 프로그래밍에서 숫자만큼이나 자주 쓰이는 핵심 자료형입니다. 문자열을 만들고, 자르고, 붙이고, 다듬는 방법을 차근차근 연습하다 보면 어느새 자유자재로 다루게 될 겁니다.

> **미리 알아두세요!**
>
> - 문자열은 따옴표로 감싼 글자들의 나열입니다.
> - 인덱싱과 슬라이싱으로 문자열의 일부를 꺼낼 수 있습니다.

## 문자열이란?

문자열은 쉽게 말해 텍스트를 의미합니다. 우리가 자주 사용하는 챗GPT나 클로드 같은 LLM 서비스의 텍스트, 네이버 증권 사이트에서 보는 뉴스 및 기사, 이메일 본문 등 디지털 세계의 수많은 것이 텍스트로 이루어져 있죠. 즉, 우리는 문자열에 둘러싸여 살고 있는 셈입니다. 그렇기 때문에 문자열을 다룰 줄 알면 일상이나 업무 속 다양한 문제를 해결하는 데 큰 도움이 될 겁니다.

![](/books/python-intro/p116-092.webp)

예를 들어 다음 문장에서 love라는 단어가 총 몇 번 등장하는지 찾아야 한다고 가정해봅시다.

is the most powerful emotion that makes us do incredible things for those we , and when we truly someone, we learn that isn't just about receiving but also about giving unconditionally to create a beautiful bond that lasts forever.

눈으로 일일이 세어 볼 수도 있지만 파이썬 코드를 활용하면 아주 간단하게 해결할 수 있습니다. sentence 변수에 찾아야 할 대상 문장을 큰따옴표로 감싸 저장한 뒤 sentence.lower( ). count('love')라는 구문을 실행하면 sentence에 'love'가 총 몇 번 등장하는지 알 수 있습니다.

```python filename="03-17-count_love.py"
sentence  =  "Love is the most powerful emotion that makes us do incredible things for those we love, and when we truly love someone, we learn that love isn't just about receiving love but also about giving love unconditionally to create a beautiful bond that lasts forever."
count = sentence.lower().count('love')
print(count)
```

**실행 결과**

```text
6
```

sentence 변수의 긴 문장을 제외하면 단 2줄의 코드로 love가 몇 번 등장했는지 알 수 있는 겁니다. 여러분이 워드나 구글 문서에서 `Ctrl + F`를 눌러 단어를 찾을 때 표시되는 '몇 개 중 몇 번째'와 같은 기능도 내부에서 이와 유사한 코드가 동작한 결과죠.

> **NOTE**
>
> 뒤에서 자세히 다루겠지만 .lower( )는 점 앞의 변수에 있 다만 위 코드는 glove나 lovely처럼 love가 들

는 글자를 모두 소문자로 바꾸는 함수이며, 이어 붙은 .count( )는 어간 다른 단어도 함께 세는 한계가 있습니다. 여기서소문자로 변환된 문자열에서 'love'가 몇 번 나왔는지 세어주는 함는 count( ) 함수의 사용법을 보여주는 것이 목적이므수입니다.

로 이 부분은 넘어가겠습니다.

이처럼 문자열 처리는 우리 생활과 밀접하게 연결되어 있습니다. 문자열 다루기만 능숙해져도 파이썬을 배운 의미가 충분히 있습니다. 다양한 문자열 예제를 실습하면서 문자열을 다루는 방식에 익숙해져봅시다.

## 문자열 기초 연습하기

파이썬에서 문자열을 다루는 방법은 매우 다양합니다. 문자열의 모든 기능을 이 책 한 권에 다 담기는 어렵지만, 꼭 필요한 핵심 기법들을 중심으로 기초부터 심화까지 차근차근 다뤄보겠습니다.

## 연습 01 문자열 만들기

먼저 복습 차원에서 문자열을 만드는 다양한 방법을 간단히 실습해보겠습니다. 파이썬에서는 작은따옴표(')나 큰따옴표(")로 감싸서 문자열을 만들 수 있습니다. 두 방법 모두 동일하게 작동하므로 상황에 맞춰 편한 방식을 선택하면 됩니다.

![](/books/python-intro/p118-094.webp)

에서 배운 이스케이프 문자 \n을 사용해도 문자열 중간에서 줄을 바꿀 수 있습니다. 예를 들어 "안녕하세요\n반갑습니다"는 두 줄로 출력됩니다.

```python filename="03-18-string_quotes.py"
name = '요즘이'
greeting = "안녕하세요, 파이썬 공부를 시작해볼까요?"
question = '요즘이는 "파이썬이 재미있어요"라고 말했어요'
answer = "It's a wonderful day!"
print(name)
print(greeting)
print(question)
print(answer)
```

**실행 결과**

```text
요즘이
안녕하세요, 파이썬 공부를 시작해볼까요?
요즘이는 "파이썬이 재미있어요"라고 말했어요
It's a wonderful day!
```

여러 줄로 이루어진 긴 문자열을 만들 때는 삼중따옴표 ''' 또는 """로 감싸면 됩니다.

```python filename="03-19-multiline_string.py"
요즘이_소개 = """안녕하세요, 저는 요즘이예요.
여러분과 함께 파이썬을 공부하고 있어요.
같이 즐겁게 배워봐요!"""
daily_note = '''오늘 요즘이가 배운 것:
1. 문자열 만들기
2. 따옴표 사용법'''
print(요즘이_소개)
print()
print(daily_note)
```

**실행 결과**

```text
안녕하세요, 저는 요즘이예요.
여러분과 함께 파이썬을 공부하고 있어요.
같이 즐겁게 배워봐요!
```

**실행 결과**

```text
오늘 요즘이가 배운 것:
1. 문자열 만들기
2. 따옴표 사용법
```

## 연습 02 문자열을 이어 붙이는 + 연산자

앞서 여러 번 다룬 방법입니다. 문자열은 + 연산자로 쉽게 이어 붙일 수 있습니다.

```python filename="03-20-string_concat.py"
name = "요즘이"
# 여러 문자열 연결
greeting = "안녕하세요, " + "저는 " + name + "입니다."
print(greeting)
```

**실행 결과**

```text
안녕하세요, 저는 요즘이입니다.
```

공백 역시 하나의 문자열로 취급됩니다. 따라서 중간에 공백을 넣고 싶다면 다음과 같이 공백 자체를 큰따옴표로 감싸 표현한 뒤 +로 연결하면 됩니다.

```python filename="03-21-string_space_concat.py"
# 문자열과 공백 연결
message = "Python" + " " + "Programming"
print(message)
```

**실행 결과**

```text
Python Programming
```

## 연습 03 문자열을 반복해주는 연산자

+ 연산자를 사용하다 보면 '곱하기는 어떨까?'라는 궁금증이 생길 수 있습니다. * 연산자를 숫자에 적용하면 당연히 곱셈 결과가 나오지만 문자열에 사용하면 해당 문자열을 설정한 횟수만큼 반복한 결과가 나옵니다. 예를 들어 "==============영수증=============="과 같이 입력한 내용은 다음 코드로 바꾸어 작성할 수 있습니다.

![](/books/python-intro/p120-095.webp)

```python filename="03-22-receipt_line.py"
print("=" * 14 + "영수증" + "=" * 14)
```

**실행 결과**

```text
==============영수증==============
```

이렇게 하면 = 기호를 몇 번 입력했는지 일일이 세어 볼 필요 없이 바로 * 연산자로 반복 횟수를 정할 수 있습니다. 직관적이면서도 확실한 방법이죠. 이처럼 동일한 문자열을 여러 번 반복해야 할 때 *는 유용하게 사용할 수 있습니다.

## 연습 04 문자열 안에 있는지 없는지 검사해주는 in 연산자

in 연산자는 특정 값이 지정한 문자열에 존재하는지 여부를 검사한 후 True 또는 False로 알려줍니다. 다음 코드를 입력해 실행해보면 작동 원리를 쉽게 이해할 수 있을 겁니다.

```python filename="03-23-string_contains_true.py"
message = "파이썬은 재미있는 프로그래밍 언어입니다"
print("파이썬" in message)
```

**실행 결과**

```text
True
```

실행 결과를 보면 True입니다. message 변수에 저장된 문자열 안에 "파이썬"이라는 문자열이 포함되어 있기 때문이죠. 반대로 문자열 내에 존재하지 않는 값을 찾으면 False로 나옵니다.

```python filename="03-24-string_contains_false.py"
message = "파이썬은 재미있는 프로그래밍 언어입니다"
print("이썬이" in message)
```

**실행 결과**

```text
False
```

해당 문자열 안에 "이썬이"가 없으므로 False를 출력합니다.

![](/books/python-intro/p121-096.webp)

```python
price = 1500000
message = "가격: " + price + "원"
```

**실행 결과**

```text
Traceback (most recent call last):
File "<python-input-0>", line 2, in <module>
message = "가격: " + price + "원"
TypeError: can only concatenate str (not "int") to str
```

> **바로 핵심 요약**
>
> - 문자열은 작은따옴표(')나 큰따옴표(")로 감싸서 만들고, 삼중따옴표(''' 또는 """)를 사용하면 여러 줄 문자열을 만들 수 있습니다.
> - + 연산자로 문자열을 이어 붙이고, * 연산자로 문자열을 반복할 수 있습니다.
> - in 연산자로 특정 문자열이 포함되어 있는지 확인할 수 있습니다.
