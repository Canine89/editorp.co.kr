02 다음 코드의 실행 결과로 알맞은 것을 고르세요.

```python
def twice(func):
  def wrapper():
    func()
    func()
  return wrapper
@twice
def hello():
  print("안녕")
hello()
```

① 안녕이 한 번 출력됩니다 ② 안녕이 두 번 출력됩니다

③ 아무것도 출력되지 않습니다 ④ 오류가 발생합니다
