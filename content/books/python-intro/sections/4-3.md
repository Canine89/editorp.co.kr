이번에는 리스트와 유사하면서도 뚜렷한 차이점을 지닌 튜플에 대해 알아보겠습니다. 두 자료형 모두 여러 요소를 하나로 묶어 다룬다는 공통점이 있지만 내부적으로 중요한 차이가 있습니다. 튜플을 직접 사용해보면서 하나씩 알아봅시다.

> **미리 알아두세요!**
>
> - 튜플은 소괄호로 감싸 만들며 리스트와 비슷하게 동작합니다.
> - 한 번 만든 튜플은 값을 변경할 수 없는 불변성을 가지고 있습니다.

## 튜플 사용해보기

리스트와 **튜플**(Tuple)의 가장 눈에 띄는 차이는 괄호의 모양입니다. 리스트는 요소를 대괄호로 감싸고 튜플은 소괄호를 사용합니다. 요소가 하나일 때 쉼표를 쓰는 규칙도 다릅니다. 요소가 하나뿐인 튜플을 만들 때는 ("사과",)처럼 요소 뒤에 반드시 쉼표를 붙여야 합니다. 다음은 동일한 요소를 리스트와 튜플로 각각 선언한 뒤 출력한 예입니다. 이때 type( ) 함수를 사용해 각 변수의 자료형도 함께 확인해보겠습니다.

> **NOTE**
>
> 요소가 1개인 튜플을 만들기 위해 ("사과")라고만 적으면 소괄호로 감쌌더라도

튜플이 아닌 일반 문자열 자료형으로 인식됩니다. type( ) 함수로 확인해보면 <class 'str'>이 출력되는 것을 알 수 있습니다.

```python filename="04-26-list_tuple_compare.py"
fruits_list = ["사과", "바나나", "오렌지"]
fruits_tuple = ("사과", "바나나", "오렌지")

print(f"리스트: {fruits_list}")
print(f"튜플: {fruits_tuple}")
print(f"리스트 타입: {type(fruits_list)}")
print(f"튜플 타입: {type(fruits_tuple)}")
```

**실행 결과**

```text
리스트: ['사과', '바나나', '오렌지']
튜플: ('사과', '바나나', '오렌지')
리스트 타입: <class 'list'>
튜플 타입: <class 'tuple'>
```

괄호 모양에 따라 파이썬이 서로 다른 자료형으로 취급한다는 것을 확인했습니다. 하지만 괄호 모양은 표기 방식일 뿐, 리스트와 튜플의 핵심적인 차이라고 보기는 어렵습니다. 그렇다면 두 자료형을 구분하는 본질은 무엇일까요?

## 값을 변경할 수 없는 튜플

가장 결정적인 차이는 바로 **튜플의 불변성**(Immutability)입니다. 앞서 배운 리스트는 한 번 생성한 뒤에도 요소를 추가하거나 수정, 삭제할 수 있었습니다. 반면 튜플은 한 번 생성하고 나면 내부 요소를 수정, 추가, 삭제할 수 없습니다. 다음 코드를 실행해봅시다.

```python filename="04-27-tuple_immutable.py"
fruits_list = ["사과", "바나나", "오렌지"]
fruits_tuple = ("사과", "바나나", "오렌지")

# 리스트는 요소 변경 가능
fruits_list[1] = "딸기"
print(f"변경된 리스트: {fruits_list}")

# 튜플은 요소 변경 불가능
fruits_tuple[1] = "딸기" # 여기서 오류 발생
```

**실행 결과**

```text
변경된 리스트: ['사과', '딸기', '오렌지']
Traceback (most recent call last):
  File "04-27-tuple_immutable.py", line 9, in <module>
    fruits_tuple[1] = "딸기" # 여기서 오류 발생
    ~~~~~~~~~~~~^^^
TypeError: 'tuple' object does not support item assignment
```

리스트 fruits_list의 인덱스 1번 요소를 변경하는 코드는 정상적으로 동작합니다. 하지만 튜플은 오류가 발생했습니다. 왜 그럴까요? 오류를 복사해서 인공지능에 물어보면 이렇게 답을 해줍니다.

> **NOTE**
>
> 인공지능 코딩 도구를 사용할 때는 발생한 오류 메시지를 채팅에 함께 전달하여 원인을 파악할 수 있습니다. 코드를 즉

시 수정하는 실행 모드보다 원인을 먼저 설명해주는 질문 모드를 통해 오류가 발생한 원인을 확인해보세요.

인공지능의 설명처럼 튜플은 불변 자료형이므로 값을 바꾸려고 할 때 오류를 발생시킵니다. 실제로 한 번 생성된 튜플은 요소를 다른 값으로 바꾸거나 추가 또는 삭제할 수 없습니다. 따라서 튜플은 프로그램 실행 중 절대 변해서는 안 되는 고정 데이터를 저장할 때 유용합니다.

## 튜플 기초 연습하기

리스트와 튜플은 구조가 비슷하여 다루는 방식과 결과도 거의 같습니다. 앞서 **리스트 기초 연습하기**에서 다룬 내용을 튜플로 다시 연습해보겠습니다.

## 연습 01 평균 점수 계산해보기

다음은 평균 점수를 계산하는 코드입니다. 리스트에서 튜플로 바뀌었을 뿐 전체적인 구조는 동일합니다. 다만 튜플은 불변성을 가지므로 한 번 저장된 점수를 직접 수정하거나 삭제할 수 없겠네요.

```python filename="04-28-tuple_average.py"
scores = (85, 92, 78, 90, 88)

total = sum(scores)
count = len(scores)
average = total / count

print(f"점수: {scores}")
print(f"총점: {total}점")
print(f"과목 수: {count}개")
print(f"평균: {average}점")
```

**실행 결과**

```text
점수: (85, 92, 78, 90, 88)
총점: 433점
과목 수: 5개
평균: 86.6점
```

실행 결과를 보면 sum( )과 len( ) 함수가 리스트에서와 똑같이 튜플에도 적용되는 것을 알 수 있습니다. 값을 읽어 계산하는 일에는 값을 바꿀 필요가 없으므로 튜플이어도 불편할 것이 없습니다.

## 연습 02 가장 높은 점수, 가장 낮은 점수 알아보기

이번에는 앞서 다루지 않았던 max( ) 함수와 min( ) 함수를 사용해봅시다. max( ) 함수는 이름에서도 알 수 있듯이 리스트나 튜플에서 값이 가장 큰 요소를 반환하는 함수이며, min( ) 함수는 반대로 가장 작은 요소를 반환합니다.

```python filename="04-29-tuple_score_summary.py"
student_name = "김철수"
scores = (85, 92, 78, 90, 88)

average = sum(scores) / len(scores)
highest = max(scores)
lowest = min(scores)

print(f"{student_name}의 성적 분석")
print(f"평균: {average:.1f}점")
print(f"최고점: {highest}점")
print(f"최저점: {lowest}점")
```

**실행 결과**

```text
김철수의 성적 분석
평균: 86.6점
최고점: 92점
최저점: 78점
```

실행 결과를 보면 max( )와 min( ) 함수가 어떻게 동작하는지 쉽게 알 수 있습니다. 그렇다면 두 함수와 함께 활용할 수 있는 더 유용한 사용법을 알아봅시다. 만약 튜플 내에 같은 점수가 중복되어 있다면 그 점수가 몇 개인지 어떻게 알 수 있을까요? 바로 count( ) 함수를 조합하면 됩니다.

```python filename="04-30-tuple_score_count.py"
scores = (92, 85, 92, 78, 85, 92)

print(f"최고점 {max(scores)}점이 {scores.count(max(scores))}번 나왔습니다")
print(f"최저점 {min(scores)}점이 {scores.count(min(scores))}번 나왔습니다")
```

**실행 결과**

```text
최고점 92점이 3번 나왔습니다
최저점 78점이 1번 나왔습니다
```

지금까지는 주로 함수를 하나씩 사용했지만 이렇게 함수 안에 함수를 넣어 사용할 수도 있습니다. 파이썬에서 함수를 중첩해 사용하면 가장 안쪽에 위치한 함수를 먼저 실행하고 그 결괏값을 바탕으로 바깥쪽에 위치한 함수가 실행됩니다.

![](/books/python-intro/p180-131.webp)

생각해보면 당연한 순서입니다. count( ) 함수는 소괄호 안에 전달된 값이 몇 개 들어 있는지 세어주는 함수인데, max(scores)가 먼저 실행되어 최고 점수를 구해야만 count( ) 함수가 세어야 할 대상이 무엇인지 알 수 있기 때문입니다. 이처럼 함수를 중첩하여 사용하는 방식은 앞으로도 종종 사용하겠습니다.

## 연습 03 인덱싱, 슬라이싱하기

튜플 역시 리스트와 마찬가지로 인덱싱, 슬라이싱, 더하기, 곱하기 연산을 수행할 수 있습니다. 다만 더하기와 곱하기는 기존 튜플을 바꾸는 것이 아니라 결과를 담은 새 튜플을 만들어 돌려주므로 불변성과 충돌하지 않습니다. 새 값을 다시 만드는 건 기존의 값을 변경하는 것이 아니기 때문이죠. 불변성에 대한 오해가 없기를 바랍니다. 다음 코드를 실행하며 가볍게 연습해봅시다.

```python filename="04-31-tuple_index_slice.py"
fruits = ("사과", "바나나", "오렌지", "포도", "딸기")

print(f"전체 튜플: {fruits}")
print(f"첫 번째 요소: {fruits[0]}")
print(f"세 번째 요소: {fruits[2]}")
print(f"마지막 요소: {fruits[-1]}")
print(f"뒤에서 두 번째: {fruits[-2]}")
print(f"앞의 세 개: {fruits[0:3]}")
print(f"뒤의 두 개: {fruits[3:]}")
print(fruits + ("수박",))
print(fruits[:2] * 2)
```

**실행 결과**

```text
전체 튜플: ('사과', '바나나', '오렌지', '포도', '딸기')
첫 번째 요소: 사과
세 번째 요소: 오렌지
```

```python
마지막 요소: 딸기
뒤에서 두 번째: 포도
앞의 세 개: ('사과', '바나나', '오렌지')
뒤의 두 개: ('포도', '딸기')
('사과', '바나나', '오렌지', '포도', '딸기', '수박')
('사과', '바나나', '사과', '바나나')
```

실행 결과는 리스트에서 봤던 것과 같습니다. 이처럼 튜플의 사용법은 리스트와 거의 같으므로 이 정도만 연습해도 충분합니다. 튜플은 불변성을 가진다는 핵심 특징만 잘 기억해두고, 다음으로 중요한 자료형인 딕셔너리로 넘어가봅시다.

> **바로 핵심 요약**
>
> - 튜플은 소괄호로 요소를 묶는 자료형으로, 인덱싱·슬라이싱·더하기·곱하기 등 기본적인 사용법은 리스트와 거의 같습 니다.
> - 튜플은 불변성이 있어 한 번 지정한 값을 수정하거나 삭제할 수 없으므로, 프로그램 실행 중 변하면 안 되는 고정 데이터에 적합합니다.
> - 함수를 겹쳐 쓰면 가장 안쪽 함수부터 순차적으로 실행되어 원하는 결과를 얻을 수 있습니다.
