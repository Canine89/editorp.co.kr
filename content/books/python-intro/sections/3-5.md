앞서 문자열을 만들고, 이어 붙이고, 반복하는 기본적인 방법을 알아봤습니다. 이번에는 문자열을 실제로 다룰 때 자주 쓰는 함수들을 하나씩 연습해봅니다.

> **미리 알아두세요!**
>
> - len( ), upper( ), find( ) 같은 함수로 문자열을 다양하게 다룰 수 있습니다.
> - 문자열 함수는 원본을 바꾸지 않고 처리한 결과를 새로 돌려줍니다.

문자열 처리의 기본적인 흐름을 파악했으니 이제 한 단계 더 나아가 활용도를 높여주는 방법도 알아봅시다. 대부분 문자열 함수를 사용하는 방법으로, 함수의 자세한 개념은 뒤에서 공부하겠습니다. 지금은 '문자열을 이렇게도 다룰 수 있구나' 하는 느낌으로 부담 없이 따라오면 됩 니다.

> **NOTE**
>
> 사실 .을 찍고 사용하는 함수는 메서드라고 부르지만 아직 개념을 배운 상태가

아니라서 함수로 용어를 통일했습니다.

## 문자열의 길이를 계산하는 len( ) 함수

len( ) 함수는 문자열의 전체 길이를 계산해줍니다. 길이를 계산할 문자열이나 문자열을 담고 있는 변수를 소괄호 ( ) 사이에 입력하면 됩니다.

```python filename="03-26-string_length.py"
text = "파이썬 문자열 길이 측정 연습을 해봅시다!"
print(f"len(text)의 계산 결과는? {len(text)}")
```

**실행 결과**

```text
len(text)의 계산 결과는? 23
```

"파이썬 문자열 길이 측정 연습을 해봅시다!"의 문자열 길이는 공백과 느낌표를 포함해 총 23입니다. 정말 맞는지 직접 세어 보기 바랍니다.

## 모든 문자를 대문자 또는 소문자로 바꿔주는 upper( ), lower( ) 함수

이번에는 문자열 안의 모든 문자를 대문자 또는 소문자로 바꿔주는 upper( ), lower( ) 함수를 알아보겠습니다. 이 함수들은 소괄호 안에 문자열을 넣는 방식이 아닌 text.upper( )와 같이 대상 문자열 다음에 점(.)을 붙여 사용하는 방식입니다. text 변수에 "study python"을 저장한 다음 이를 모두 대문자로 바꿔 출력해봅시다.

```python filename="03-27-string_upper.py"
text = "study python"
print(f"upper() 함수의 결과는 {text.upper()}")
```

**실행 결과**

```text
upper() 함수의 결과는 STUDY PYTHON
```

> **NOTE**
>
> 어떤 함수는 소괄호 안에 값을 넣어야 하고, 어떤 함수는 점(.)을 입력해야 동작하는지는 나중에 함수나 클래스를 설명

하며 자세히 다루겠습니다.

출력 결과를 보면 text.upper( )의 결과로 STUDY PYTHON이 나왔습니다. 이처럼 upper( ) 함수는 점(.)으로 연결한 대상 문자열을 대문자로 바꿔줍니다. lower( ) 함수는 반대로 대문자를 소문자로 바꿔줍니다. 실습을 보다 효율적으로 하기 위해 upper( ) 함수로 대문자로 바꾼 값을 새 변수에 저장한 뒤, 그 변수를 다시 소문자로 바꿔보겠습니다.

```python filename="03-28-string_lower.py"
text = "study python"
text_upper = text.upper()
print(f"lower() 함수의 결과는 {text_upper.lower()}")
```

**실행 결과**

```text
lower() 함수의 결과는 study python
```

코드가 다소 복잡해 보일 수 있지만 자세히 살펴보면 사실 구조는 간단합니다. 처음 text 변수에는 소문자가 들어 있습니다. 이를 upper( ) 함수로 모두 대문자로 변환한 뒤 text_upper 변수에 새로 저장합니다. 그러면 text_upper 변수에는 "STUDY PYTHON"이 저장됩니다. 이를 다시 lower( ) 함수를 이용하여 소문자로 바꾸어 출력한 것입니다. 지금은 변수에 저장하는 과정과 출력하는 과정이 헷갈릴 수 있으므로 차분하게 코드를 살펴보기 바랍니다.

## 문자열이 몇 번째에서 시작하는지 알려주는 find( ) 함수

find( ) 함수는 message.find("언어")와 같이 사용합니다. 대상 문자열(또는 변수 message) 뒤에 점(.)을 붙여 호출하며, 소괄호 안에 넣은 문자열이 원문의 몇 번째 글자부터 시작하는지 알려주는 함수입니다. 쉽게 말해 내가 찾으려는 구문이 전체 문자열 속 어느 위치에서 시작하는지 찾아주는 역할을 합니다. 다음 코드를 실행해봅시다.

find( ) 함수는 말 그대로 문자열 시작 위치를 찾아주네요!

```python filename="03-29-string_find.py"
message = "파이썬은 재 미있는 프로그래밍 언어입니다"
print(message.find("재미"))
```

**실행 결과**

```text
5
```

결과를 보면 5가 나옵니다. 그런데 직접 글자를 세어 보면 '재미'의 시작 위치는 띄어쓰기를 포함해 6번째처럼 보입니다.

![](/books/python-intro/p124-097.webp)

‘1, 2, 3, 4, 5, 6...’ 분명 6번째에 “재미”가 시작하는데, 왜 5라고 출력하는 걸까요? **파이썬은 문자열의 인덱스를 0부터 시작하기 때문입니다.** 여기서 **인덱스**의 개념이 등장합니다.

### 시퀀스 데이터에서 중요한 개념인 인덱스

문자열은 문자가 순서대로 나열된 데이터입니다. 이렇게 여러 값이 연속해서 나열된 형태를 시퀀스 데이터라고 합니다. 어떤 값들이 연속해 나열되어 있을 때, 특정 위치의 값을 정확히 지목해서 말할 기준 번호가 필요합니다. 이 기준 번호를 인덱스라고 합니다. **파이썬은 인덱스를 1이 아니라 0부터 시작하도록 규칙을 정했습니다.** 따라서 앞에서 살펴본 '재미'의 시작 인덱스는 6이 아니라 5로 계산됩니다. 이후에도 인덱스에 대한 설명이 필요한 시점에 적절히 다루겠습니다.

![](/books/python-intro/p124-098.webp)

인덱스의 개념을 알았으니 다시 find( ) 함수로 돌아오겠습니다. 그렇다면 찾으려는 문자열이 원문에 아예 없을 때는 어떻게 될까요? 이때 find( ) 함수는 -1을 반환합니다.

```python filename="03-30-string_find_missing.py"
message = "파이썬은 재미있는 프로그래밍 언어입니다"
print(message.find("게임"))
```

**실행 결과**

```text
-1
```

결과에서 보듯 존재하지 않는 문자열을 찾으라고 하면 -1을 반환합니다. 인덱스는 0부터 시작하므로 정상적인 위치는 항상 0 이상의 값이며, -1은 ‘찾지 못했음’을 의미하는 약속된 값입니다.

> **NOTE**
>
> 출력은 프로그램이 처리한 결과를 화면에 보여주는 것이고, 반환은 함수에서 만든 결과를 밖으로 돌려주는 것입니다.

반환된 값은 다른 곳에서 다시 사용할 수 있습니다.

## 시작과 끝을 검사하는 startswith( ), endswith( ) 함수

startswith( ), endswith( ) 함수는 문자열이 특정 문자로 시작하거나 끝나는지 검사하여 True 또는 False를 반환합니다. 예를 들어 전화번호 형식을 확인할 때 010으로 시작하는지, 02로 시작하는지 검사하고 싶다면 다음과 같이 코드를 작성하면 됩니다.

```python filename="03-31-string_startswith.py"
phone = "010-1234-5678"
print(phone.startswith('010'))
print(phone.startswith('02'))
```

**실행 결과**

```text
True
False
```

결과를 보면 startswith('010')의 결과는 True이고 startswith('02')의 결과는 False입니다. 말 그대로 입력한 문자열로 시작하는지 검사하여 True, False를 출력한 것입니다.

endswith( ) 함수도 연습해보겠습니다. 파일 이름 확장자가 무엇인지 확인하는 예제입니다.

```python filename="03-35-파일명"
filename = "report_2026.xlsx"
print(filename.endswith('.xlsx'))
print(filename.endswith('.csv'))
```

**실행 결과**

```text
True
False
결과를 보면 끝이 맞으면 True, 맞지 않으면 False를 출력해줍니다.
```

결과를 보면 끝이 맞으면 True, 맞지 않으면 False를 출력해줍니다.

## 숫자를 문자열로 변환하는 str( ) 함수

03.3의 문자열에서 숫자를 + 연산자로 문자열과 연결하면 TypeError가 발생하는 것을 보았죠. 그렇다면 숫자와 문자열을 연결하거나 숫자를 문자열처럼 다루고 싶을 때는 어떻게 해야 할까요?

> **NOTE**
>
> 사실 여기서 이야기하는 str( )은 엄밀히 말해 함수가 아니라 문자열을 만드는 자료형(클래스)입니다. 곧이어 나올 int( ),

float( )도 마찬가지로 자료형입니다. 다만 클래스라는 개념을 아직 배우기 전이므로, 이 책에서는 값의 자료형을 변환해주는 이 기능들을 편의상 '함수'로 부르겠습니다. 클래스는 뒤에서 자세히 배웁니다.

```python filename="03-36-shopping_receipt.py"
# 쇼핑몰 영수증 생성하기
product_name = "노트북"
quantity = 2
unit_price = 1500000
total_price = quantity * unit_price

# 영수증 문자열 생성
receipt = "========== 영수증 ==========\n"
receipt = receipt + "상품: " + product_name + "\n"       # 상품: 노트북
receipt = receipt + "수량: " + str(quantity) + "개\n"    # 수량: 2개
receipt = receipt + "단가: " + str(unit_price) + "원\n"  # 단가: 1500000원
receipt = receipt + "총액: " + str(total_price) + "원\n" # 총액: 3000000원
receipt = receipt + "=========================="

print(receipt)
```

**실행 결과**

```text
========== 영수증 ==========
상품: 노트북
수량: 2개
단가: 1500000원
총액: 3000000원
==========================
```

코드를 보면 숫자 계산을 하는 동안에는 quantity, unit_price, total_price를 숫자로 취급하며 사칙연산을 수행합니다. 하지만 이를 영수증 문장으로 조합해 출력하는 단계에서는 문자열로 취급하기 위해 str(quantity), str(unit_price), str(total_price)처럼 숫자 변수를 문자열로 변환한 뒤 이를 + 연산자로 연결하여 출력합니다.

## 문자열을 숫자로 바꾸는 int( ), float( ) 함수

앞서 str( ) 함수로 숫자를 문자열로 바꿔봤습니다. 반대로 문자열을 숫자로 변환해야 할 때도 있습니다. 예를 들어 "25"와 같이 따옴표로 감싸진 값은 겉보기엔 숫자 같지만 문자열이므로 연산에 바로 쓸 수 없습니다. 이때 다음과 같이 int( )와 float( ) 함수를 사용합니다.

```python filename="03-37-string_to_number.py"
age_text = "25"          # ➊ 숫자처럼 보이지만 문자열
age = int(age_text)      # ➋ 정수로 변환
print(age + 5)           # ➌ 이제 계산 가능

height = float("175.5")  # ➍ 실수로 변환
print(height + 0.5)
```

**실행 결과**

```text
30
176.0
```

❶ age_text에는 따옴표로 감싸진 "25"가 들어 있으므로 숫자가 아니라 문자열입니다. 이 상태로는 계산에 쓸 수 없습니다.

❷ int( ) 함수를 사용해 문자열 "25"를 정수 25로 바꿔 age 변수에 저장합니다.

❸ age가 정수가 되었으므로 5를 더해 30이 나왔습니다.

❹ 소수점이 있는 문자열은 float( ) 함수를 사용하여 실수로 바꿉니다.

## 문자열의 일부를 바꾸는 replace( ) 함수

문자열에서 특정 부분을 다른 문자열로 바꾸고 싶을 때는 replace( ) 함수를 사용합니다. replace("바꿀 대상", "새 문자열") 형태로 소괄호 안에 바꿀 대상과 새 문자열을 차례로 넣으면 됩니다.

```python filename="03-38-string_replace.py"
message = "파이썬은 어렵습니다"
new_message = message.replace("어렵습니다", "재미있습니다")  # ➊ 일부만 교체
print(new_message)
```

**실행 결과**

```text
파이썬은 재미있습니다
```

❶ message 안의 "어렵습니다"를 찾아 "재미있습니다"로 바꾼 결과를 new_message에 저장했습니다. 문장 전체가 아니라 지정한 단어만 변경됩니다.

전화번호의 하이픈(-)을 제거하는 것처럼 특정 문자를 지울 때도 유용합니다. 바꿀 새 문자열 자리에 빈 문자열 ""을 넣으면 해당 문자가 지워집니다.

```python filename="03-39-remove_hyphen.py"
phone = "010-1234-5678"
print(phone.replace("-", ""))   # ➊ 하이픈 제거
```

**실행 결과**

```text
01012345678
```

❶ "-"를 빈 문자열 ""로 바꾸면서 모든 하이픈이 사라졌습니다.

replace( ) 함수는 원본 문자열을 직접 수정하지 않고 바뀐 결과를 새로 반환합니다. 따라서 변경된 결과를 계속 사용하려면 위 예제처럼 새 변수에 저장하거나 바로 출력해야 합니다.

> **바로 핵심 요약**
>
> - len( ) 함수로 문자열 길이를 구하고, upper( )와 lower( ) 함수로 대소문자를 바꿀 수 있습니다.
> - find( ), startswith( ), endswith( ) 함수로 문자열의 위치와 시작과 끝 단어를 확인할 수 있습니다.
> - replace( )로 문자열 일부를 바꾸고 str( ), int( ), float( ) 함수로 자료형을 변환할 수 있습니다.
