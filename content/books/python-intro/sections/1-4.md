이제 본격적인 실습을 위한 준비를 할 차례입니다. 파이썬을 설치하고 첫 프로그램을 직접 실행해봅시다. 설치 과정은 화면을 차근차근 따라 하면 되니 전혀 어렵지 않습니다.

> **미리 알아두세요!**
>
> - 파이썬을 설치하고 실습 환경을 준비합니다.
> - 간단한 인사 프로그램을 실행하며 출력을 경험해봅니다.

먼저 파이썬 코드를 작성하고 실행하려면 파이썬을 설치해야 합니다. 파이썬이 처음이라면 파이썬을 사용하기 위해 파이썬을 설치하라는 말이 이상하게 들릴 수 있습니다. **여기서 설치하라는 파이썬은 작성한 코드를 해석하고 실행해주는 프로그램인 파이썬 인터프리터를 말합니다.** 여러분이 파이썬 코드를 입력하면 이 녀석이 파이썬을 해석하고 실행하는 역할을 합니다. 매번 파이썬 인터프리터와 프로그래밍 언어인 파이썬을 굳이 구분 짓자니 번거로워 편의상 파이썬이라고 부르는 것이죠. 그럼 지금부터 파이썬을 설치해봅시다.

## 파이썬 설치하기

공식 사이트에서 설치 프로그램을 내려받아 실행하면 되니 다음 과정을 차근차근 따라 해보세요.

01 파이썬 공식 사이트에 접속하면 파이썬 설치 프로그램을 내려받을 수 있습니다. 접속 후 위쪽 메뉴에서 [Downloads]를 누른 뒤 나타나는 [Download Python 3.x.x] 버튼을 클릭해 설치 프로그램을 내려받습니다

- **파이썬 공식 사이트 :** [python.org](https://python.org)

![](/books/python-intro/p046-013.webp)

>

인지만 확인하고 넘어가기 바랍니다.

02 다운로드한 설치 파일을 실행하여 파이썬 설치를 진행합니다.

![](/books/python-intro/p046-014.webp)

03 **설치 시에는 화면에 보이는 것처럼 [Add python.exe to PATH] 옵션을 반드시 체크하고** [Install Now]를 눌러 설치를 진행합니다. 이렇게 해야 명령 프롬프트에서 바로 python 명령어를 사용할 수 있습니다.

> **NOTE**
>

수 있는 공간입니다. 다만 명령어 기반으로 동작한다는 것이 생소해서 어렵게 느껴질 뿐 원리는 간단합니다.

05 간단한 파이썬 코드를 직접 작성해서 실행하겠습니다. 그런데 코드는 어디에 작성해야 할까요? 그냥 터미널에 바로 코드를 입력하면 될까요? 그렇지 않습니다. 파이썬 코드를 작성할 수 있는 공간으로 이동해야 합니다. ❶ 터미널에서 **python**을 입력한 뒤 `Enter`를 누릅니다. 그러면 ❷ 파이썬 코드를 작성하고 실행할 수 있는 공간인 파이썬 **인터프리터 셸**로 이동합니다.

## 인사말 프로그램을 만들며 출력 이해하기

앞서 작성했던 나에게 인사를 건네는 '인사말 프로그램'을 다시 만들어보겠습니다. 그런데 이번에는 코드를 단순히 따라 입력해서 실행하는 것보다, **출력**이라는 개념을 이해하는 데 집중해봅시다.

### name 만들기

다음과 같이 코드를 작성한 다음 `Enter`를 누릅니다. 나중에 배우겠지만 프로그래밍 언어에서 =라는 기호는 ‘같다’라는 의미가 아니라 ‘오른쪽 값을 왼쪽에 대입한다’라는 뜻입니다.

> **NOTE**
>
> 변수와 대입이라는 개념은 이어지는 2장에서 더 자세히 다룹니다.

```python
>>> name = "바로"
```

![](/books/python-intro/p049-022.webp)

이렇게 코드를 입력하고 `Enter`를 누르면 코드가 실행됩니다. 코드를 실행하면 컴퓨터는 값을 저장할 공간을 마련하고, 그 공간의 이름을 name이라 칭합니다. 그리고 거기에 "바로"라는 값을 저장해 기억합니다.

### name 출력하기

**컴퓨터가 기억한 값을 확인하는 방법은 그 값을 출력하라고 명령하는 겁니다.** 다음과 같이 코드를 작성하고 `Enter`를 누르면 값을 저장해둔 공간에 실제로 어떤 값이 들어 있는지 확인할 수 있습니다. 말 그대로 name을 프린트, 즉 출력하는 겁니다.

![](/books/python-intro/p049-023.webp)

```python
>>> print(name)
```

**실행 결과**

```text
바로
```

![](/books/python-intro/p050-024.webp)

**실행 결과**

```text
>>> print(name)
```

프로그래밍에서 **출력**은 여러 의미로 쓰이지만, 쉽게 말해 결과물을 눈으로 확인할 수 있도록 화면에 무언가를 보여주는 것을 뜻합니다.

### 문장 출력하기

이제 인사말을 출력하는 코드를 조금 변형해서 다음과 같이 작성합니다. 그리고 `Enter`를 누릅니다.

```python
>>> print("안녕하세요" + name + "님!")
```

**실행 결과**

```text
안녕하세요바로님!
```

"안녕하세요"와 name을 더하고 여기에 다시 "님!"을 더한 결과, 문장이 이어 붙어 출력되었습니다. 파이썬에서는 수학의 덧셈(+) 기호를 문자열을 연결하는 연산자로 활용하기도 합니다. 하지만 실행 결과를 보면 띄어쓰기가 적용되지 않아 다소 부자연스럽습니다. **파이썬에서는 띄어쓰기 또한 '문자'로 취급하므로 명시적으로 포함해주어야 합니다.** 그래서 문장에 띄어쓰기를 추가하려면 큰따옴표 사이에 띄어쓰기를 넣어서 다음과 같이 코드를 작성해야 합니다.

```python
>>> print("안녕하세요 " + name + " 님!")
```

**실행 결과**

```text
안녕하세요 바로 님!
```

이처럼 컴퓨터는 사람과 생각하는 방식이 다릅니다. 사람은 "안녕하세요"와 "안녕하세요 "에 큰 차이를 두지 않지만 컴퓨터는 이를 곧이곧대로 받아들입니다. "안녕하세요"는 띄어쓰기가 없고, "안녕하세요 "는 공백이 있으니 작성된 코드 그대로 출력하는 것뿐이죠. 우리는 눈치라는 게 있지만 컴퓨터는 그런 것이 없으니 이 점에 유의해서 코드를 작성해야 합니다.

![](/books/python-intro/p051-025.webp)

지금까지 파이썬을 설치하고 간단한 인사를 출력하는 코드를 입력하고 실습하면서 출력이라는 개념도 알아보았습니다. 또한 파이썬 코드를 작성할 때 덧셈(+) 기호를 활용해 문장을 연결하는 문법도 함께 살펴봤습니다.

그런데 코드를 작성하면서 ‘어두운 터미널 화면에 직접 코드를 입력하려니 불편하다’라고 느끼지는 않았나요? 실제로 여러분이 사용한 파이썬 인터프리터 셸은 실전에서는 간단한 코드를 테스트할 때 주로 사용하며, 규모가 큰 작업을 할 때는 거의 쓰이지 않습니다. 이어지는 내용부터는 실습의 편의성을 높여주며 실무에서도 자주 사용하는 다양한 파이썬 개발 환경을 하나씩 알아봅시다.

> **바로 핵심 요약**
>
> - 파이썬 코드를 실행하려면 파이썬 인터프리터를 설치해야 합니다.
> - macOS에서는 python3명령어를 사용합니다.
> - 인터프리터 셸에서 인사를 출력하는 코드를 입력하고 실행하며 출력의 개념을 이해합니다.
> - 파이썬에서는 + 기호를 사용해 문자열을 이어서 출력할 수 있으며, 공백(띄어쓰기) 역시 하나의 문자로 인식합니다.
