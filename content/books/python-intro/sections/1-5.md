파이썬 코드를 실행하는 방법은 하나만 있는 것이 아닙니다. 여기서는 **IDLE부터비주얼 스튜디오 코드**(Visual Studio Code, VS Code)까지 대표적인 도구들을 직접 사용해봅니다. 각 도구의 특징을 경험해보고 자신에게 가장 잘 맞는 도구를 골라봅시다.

> **미리 알아두세요!**
>
> - 파이썬 코드는 IDLE, 비주얼 스튜디오 코드 등 여러 도구로 실행할 수 있습니다.
> - 도구마다 특징이 다르므로 상황에 맞게 선택하면 됩니다.

먼저 파이썬 코드를 작성하고 실행할 때 자주 쓰이는 대표적인 개발 환경 3가지를 소개합니다. 모두 실무와 학습에서 유용하게 사용하는 방식입니다.

- **파이썬 기본 에디터, IDLE :** 파이썬을 설치하면 기본으로 제공되는 에디터입니다. IDLE은 구조가 가볍고 단순하여 파이썬을 처음 배우는 사람들에게 적합한 기본 개발 환경입니다.

- **무료 텍스트 편집기, 비주얼 스튜디오 코드 :** 가장 널리 사용되는 코드 에디터입니다. 다양한 확장 기능을 설치해 단순한 편집기 이상으로 활용할 수 있어 실무에서도 압도적으로 많이 쓰입니다.

- **검은색 화면에서 실행하는 인터프리터 셸 :** 터미널이나 명령 프롬프트에서 python 명령어를 입력해 파이썬 인터프리터 셸을 실행하고, 그 위에서 파이썬 코드를 작성하고 실행하는 방식입니다. 이는 앞서 실습했던 방법입니다. 실무에서는 간단한 코드를 테스트하거나, 프로그램을 빠르게 점검할 때 유용하게 활용합니다.

참고로 실습 방식에는 정답이 없으므로 모든 방법을 자세히 설명하겠습니다. 실습을 모두 따라 해보고 상황에 맞는 도구를 선택해 사용하세요. **이 책에서는 파일을 생성하거나 긴 코드를 작성할 때는 비주얼 스튜디오 코드에서 실습하고, 짧은 코드를 테스트할 때는 인터프리터 셸을 활용하겠습니다.**

## IDLE에서 파이썬 코드 작성하기

IDLE은 파이썬을 설치하면 함께 제공되는 기본 프로그램입니다. 터미널과 비슷하지만 편의 기능을 다양하게 제공하므로 한 단계 더 발전한 인터프리터 셸 기반의 실습 환경이라고 볼 수 있습니다. 그럼 IDLE 실행부터 코드 작성까지 차근차근 알아봅시다.

01 윈도우 검색창에 **idle**을 검색하고 클릭하여 실행해보세요.

![](/books/python-intro/p053-026.webp)

02 처음 실행하면 **IDLE Shell**이라는 프로그램이 실행됩니다. 화면 왼쪽에 `>>>` 표시가 눈에 띕니다. 맞습니다. 우리가 터미널에서 python을 입력했을 때 봤던 파이썬 인터프리터 셸입니다. 이제 코드를 입력하고 `Enter`를 누르면 결괏값이 바로 아래에 출력되며, 대화하듯 파이썬 코드를 입력하고 실행할 수 있습니다.

![](/books/python-intro/p053-027.webp)

다만 이 기능은 터미널에서 python을 입력하여 실행했던 모습과 거의 차이가 없습니다. 다음 두 화면을 비교해보면 쉽게 알 수 있죠. 굳이 IDLE을 따로 실행하여 학습할 이유가 없다고 생각할 수 있지만 그렇지 않습니다.

![](/books/python-intro/p053-028.webp)

03 IDLE은 코드 편집기 기능도 제공합니다. 메뉴에서 [File → New File]을 누르면 코드 편집기 창이 열립니다. IDLE의 코드 편집기에서는 원하는 만큼 코드를 입력하거나 수정한 뒤 한 번에 실행할 수 있는 장점이 있습니다. 또한 워드 프로세서를 사용하는 것처럼 마우스나 키보드로 커서를 자유롭게 이동하며 코드에서 원하는 부분을 수정하기도 쉽습니다.

![](/books/python-intro/p054-029.webp)

04 코드를 모두 작성했다면 `Ctrl + S`를 눌러 코드가 적힌 파일을 저장합니다. 파일 이름은 가급적 영문으로 생성하고, 저장 위치는 되도록 여러분이 찾기 쉬운 위치를 선택해주세요. 여기서는 바탕화면에 별도의 실습용 폴더를 만들어 저장하는 것을 추천합니다.

![](/books/python-intro/p054-030.webp)

05 파일을 저장하면 IDLE의 코드 편집기 위쪽 바에 저장한 파일 이름이 표시됩니다. 이름이 바뀐 것을 확인한 뒤 메뉴의 [Run → Run Module]을 누르거나 `F5`를 눌러서 코드를 실행해보 세요.

![](/books/python-intro/p055-031.webp)

06 그러면 실행 결과가 IDLE Shell에 나타납니다. 만약 IDLE이 마음에 든다면 앞으로의 실습은 이 방식으로 진행해도 됩니다.

![](/books/python-intro/p055-032.webp)

문서를 작성할 때 메모장보다 워드가 편리한 것처럼, 코드를 작성할 때는 비주얼 스튜디오 코드라는 대표적인 프로그램이 그런 역할을 합니다. 마이크로소프트에서 관리하므로 믿고 사용할 수 있으며, 무료라는 것도 큰 장점입니다. 이 책에서는 긴 코드나 파일을 따로 생성해야 하는 실습에 비주얼 스튜디오 코드를 사용합니다. 본격적인 학습에 앞서 비주얼 스튜디오 코드 사용법을 제대로 알아둡시다.

### 여러 줄의 코드를 파일로 저장하고 실행할 때 : 비주얼 스튜디오 코드

파이썬 코드가 여러 줄로 길어지거나 같은 코드를 여러 번 수정하며 실행해야 할 때는 비주얼 스튜디오 코드처럼 파일 단위로 작업할 수 있는 편집기를 사용하는 것이 편리합니다. 작성한 코드를 .py 파일로 저장해두면 나중에 다시 열어 수정하거나 반복 실행할 수 있고, 오류가 난 위치도 더 쉽게 확인할 수 있습니다. 앞으로 실습할 예제들은 대부분 파일로 저장해 실행하는 방식이므로, 비주얼 스튜디오 코드 사용에 조금씩 익숙해져봅시다.

파이썬 환경 설정이라는 복잡한 단계를 따라오느라 고생 많았습니다! 우리는 print( ) 코드로 출력이라는 개념을 눈으로 확인하고, 변수에 값을 대입해 문자열을 이어 붙이는 프로그래밍의 기초 동작 방식까지 간단하게 경험해봤습니다. 아직 낯설 수 있지만 괜찮습니다. 익숙해질 때까지 차근차근 반복해보세요. 시작이 반인 만큼, 본격적인 기초 문법은 훨씬 더 쉽고 재미있게 다가올 것입니다.
