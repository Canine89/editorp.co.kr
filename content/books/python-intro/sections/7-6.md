앞 절에서 함수에 값을 전달하고 결과를 돌려받는 방법을 알아봤습니다. 그런데 함수를 사용하다 보면 또 하나의 궁금증이 생깁니다. 함수 안에서 만든 변수는 함수 밖에서도 사용할 수 있을까요? 이번에는 변수가 사용될 수 있는 범위인 스코프를 알아봅시다. 스코프를 이해하면 어떤 변수는 사용할 수 있고 어떤 변수는 왜 오류가 발생하는지가 분명해집니다.

> **미리 알아두세요!**
>
> - 함수 안에서 만든 변수는 그 함수 안에서만 쓸 수 있는 지역 변수입니다.
> - 함수 밖에서 만든 전역 변수를 함수 안에서 전역 변수에 새 값을 대입하려면 global이 필요합니다.

## 스코프란?

**스코프**(scope)란 파이썬에서 이름이 유효한 범위를 말합니다. ‘요즘이’라는 이름의 학생이 각각 1학년 1반과 1학년 2반에 있다고 생각하고 출석을 부르는 상황을 떠올려봅시다.

![](/books/python-intro/p331-217.webp)

1학년 1반에서 “요즘이 왔니?”라고 출석을 부른다고 해서 1학년 2반의 요즘이가 “네! 저 왔어요!”라고 대답할 필요는 없습니다. 같은 이름이라도 서로 다른 반이라는 범위로 구분되기 때문이죠. 파이썬에서도 이처럼 이름을 구분하는 범위가 있는데, 이를 스코프라고 합니다. 함수 안에는 함수만의 지역 스코프가 만들어집니다. 따라서 함수 안에서 정의한 지역 변수는 기본적으로 그 함수 안에서만 사용할 수 있습니다.

## 함수 안에서 만든 변수 확인해보기

함수 안에서 변수를 하나 만들어보고, 그 변수를 함수 밖에서도 사용할 수 있는지 확인해봅시다.

```python filename="07-25-local_variable_scope.py"
def show_message():
  message = "함수 안에서 만든 변수"  # ➊ 함수 안에서 변수 생성
  print(message)  # ➋ 함수 안에서 출력

show_message()
print(message)  # ➌ 함수 밖에서 출력 시도
```

**실행 결과**

```text
함수 안에서 만든 변수
Traceback (most recent call last):
  File "example.py", line 6, in <module>
    print(message)
          ^^^^^^^
NameError: name 'message' is not defined
```

❶ show_message( ) 함수 안에서 message라는 변수를 만들었습니다.

❷ 함수 안에서는 message를 문제없이 출력합니다. 실행 결과 첫 줄에 “함수 안에서 만든 변수”가 나온 것을 볼 수 있습니다.

❸ 그런데 함수 밖에서 같은 message를 출력하려고 하면 NameError가 발생합니다. 현재 위치에서는 message라는 이름을 찾을 수 없다는 뜻입니다.

함수 안에서 만든 변수는 일반적으로 그 함수 안에서만 사용할 수 있습니다. ❷에서는 show_message( ) 함수가 실행 중이므로 함수 안에 만든 message를 사용할 수 있습니다. 하지만 함수의 실행이 끝나면 message의 유효 범위도 함께 끝납니다. 따라서 ❸처럼 함수 밖에서 message를 사용하려고 하면 해당 변수를 찾을 수 없어 오류가 발생합니다. 이처럼 함수와 같은 특정 범위 안에서만 사용할 수 있는 변수를 지역 변수라고 합니다.

![](/books/python-intro/p333-218.webp)

## 함수 밖에 있는 변수의 값을 함수 안에서 읽어보기

그렇다면 반대로 함수 밖에서 만든 변수는 함수 안에서 쓸 수 있을까요? 이번에는 함수 밖에 변수를 만들고 함수 안에서 읽어봅시다.

```python filename="07-26-read_global_variable.py"
title = "파이썬 입문"  # ➊ 함수 밖에서 변수 생성

def show_title():
  print(title)  # ➋ 함수 안에서 함수 밖 변수 읽기

show_title()
```

**실행 결과**

```text
파이썬 입문
```

❶ 함수 밖에서 title이라는 변수를 만들었습니다. 이렇게 함수 밖에서 만들어 어디서든 접근할 수 있는 변수를 전역 변수라고 부릅니다.

❷ show_title( ) 함수 안에서 title을 출력했습니다. 함수 안에는 title이라는 지역 변수는 없지만, 파이썬은 함수 안에서 변수를 찾지 못하면 함수 밖(전역)에서 다시 찾습니다. 그 결과 전역 변수 title을 찾아 “파이썬 입문”을 출력합니다.

![](/books/python-intro/p333-219.webp)

지금은 함수 바깥에 있는 전역 변수를 함수 안에서 읽어본 것입니다. 그렇다면 함수 안에서 전역 변수에 새로운 값을 넣으려고 하면 어떻게 될까요?

## 함수 안에서 전역 변수의 값을 바꿔보기

이번에는 함수 안에서 전역 변수에 새로운 값을 넣어봅시다.

```python filename="07-27-global_variable_error.py"
count = 0  # ➊ 전역 변수

def add_one():
  count = count + 1  # ➋ 함수 안에서 전역 변수 변경 시도
  print(count)

add_one()
```

**실행 결과**

```text
Traceback (most recent call last):
  File "example.py", line 7, in <module>
    add_one()
  File "example.py", line 4, in add_one
    count = count + 1
            ^^^^^
UnboundLocalError: cannot access local variable 'count' where it is not
associated with a value
```

오류 발생!

❶ 전역 변수 count에 0을 저장했습니다.

❷ 함수 안에서 count = count + 1로 값을 바꾸려고 했더니 UnboundLocalError가 발생합니다.

왜 이런 오류가 발생했을까요? 파이썬은 함수 안에 count = ...처럼 값을 대입하는 코드가 있으면 기본적으로 count를 그 함수의 지역 변수로 판단하기 때문입니다. 그런데 count + 1을 계산하려는 순간에는 아직 지역 변수 count에 값이 저장되어 있지 않습니다. 그래서 UnboundLocalError가 발생합니다.

함수 안에서 전역 변수 count에 새로운 값을 대입하려면 파이썬에 ‘여기서 사용하는 count는 지역 변수가 아니라 전역 변수다’라고 알려줘야 합니다. 이때 사용하는 키워드가 **global**입니다.

```python filename="07-28-modify_global_variable.py"
count = 0  # ➊ 전역 변수

def add_one():
  global count  # ➋ count를 전역 변수로 사용하겠다고 선언
  count = count + 1  # ➌ 전역 변수 count 변경
  print(count)

add_one()
add_one()
```

**실행 결과**

```text
1
2
```

❶ 함수 밖에서 초깃값 0을 저장한 전역 변수 count를 만들었습니다.

❷ global count라고 작성해 이 함수 안에서 사용하는 count가 전역 변수 count임을 알려줍니다.

❸ 이제 count = count + 1을 실행하면 전역 변수 count의 값이 변경됩니다. add_one( )을 두 번 호출하면 count가 1, 2로 증가하는 것을 확인할 수 있습니다.

다만 global 키워드는 꼭 필요한 경우에만 사용하는 것이 좋습니다. 왜냐하면 함수가 외부의 전역 변수 값을 직접 변경하면 함수만 보고는 어떤 값이 어디에서 바뀌는지 파악하기 어려워질 수 있기 때문이죠. 따라서 가능하다면 필요한 값을 매개변수로 전달받고, 계산한 결과를 return으로 반환하는 방식으로 작성하는 것이 이해하고 관리하기 쉽습니다.

이것으로 함수의 기본기를 모두 다졌습니다. 다음 절에서는 지금까지 배운 함수를 조금 더 다양하게 활용하는 방법을 알아봅니다.

> **바로 핵심 요약**
>
> - 스코프는 이름을 찾아 사용할 수 있는 범위를 뜻하며, 함수를 정의하면 그 함수 자체가 하나의 스코프를 이룹니다.
> - 함수 안에서 정의한 지역 변수는 기본적으로 함수 밖에서 사용할 수 없지만, 함수 안에서는 바깥쪽 스코프에 정의된 전역 변수의 값을 읽을 수 있습니다.
> - 함수 안에서 전역 변수에 새로운 값을 대입하려면 global로 선언할 수 있습니다. 다만 전역 변수를 직접 변경하는 방식은 꼭 필요한 경우에만 사용하고, 가능하면 매개변수와 반환값을 활용하는 것이 좋습니다.
