## format( ) 함수 사용해보기

**format() 함수는 문자열 안에 변수나 값을 보기 쉽게 채워 넣는 문자열 포매팅 도구입니다.** 중괄호 { }를 사용해 값이 들어갈 자리를 만들고, .format( ) 괄호 안에 넣을 값을 지정합니다. 앞에서 다룬 f-string과 비슷하면서도 다소 복잡하게 느껴질 수 있는 함수입니다. 하지만 format( ) 함수를 알아두면 문자열 서식을 다양하게 지정할 수 있습니다. 다음 예를 입력하고 실행해서 format( ) 함수에 대한 감을 잡아봅시다.

```python filename="03-46-format_basic.py"
name = "요즘이"
age = 25
height = 175.5
# ➊ 기본 사용법 - 순서대로 넣기
print("저는 {}입니다! 나이는 {}살이고 키는 {}cm입니다.".format(name, age, height))
# ➋ 번호로 순서 지정하기
print("제 이름은 {0}이고, {0}는 {1}살입니다.".format(name, age))
```

**실행 결과**

```text
저는 요즘이입니다! 나이는 25살이고 키는 175.5cm입니다.
제 이름은 요즘이이고, 요즘이는 25살입니다.
```

❶을 보면 문자열 "저는 { }입니다! 나이는 { }살이고 키는 { }cm입니다."에 사용된 중괄호 { }는 format( ) 함수에 쉼표로 구분하여 전달한 name, age, height 변수와 순서대로 일대일 대응합니다. 그 결과로 변수의 값이 그대로 전달되어 출력되었죠. 하나의 중괄호가 format의 하나의 변수에 대응한다고 생각하면 됩니다.

❷를 보면 중괄호 안에 0 또는 1 같은 인덱스를 전달하여 format( ) 함수에 전달한 변수의 순서와 매칭하였습니다. 파이썬의 인덱스 개념이 다시 적용되는 부분입니다. 0은 format( ) 함수에 전달한 첫 번째 인자인 name을, 1은 두 번째 인자인 age를 의미합니다. 동일한 변수의 값을 문장 안에서 여러 번 재사용할 때는 중괄호를 여닫는 것만으로는 충분하지 않으므로 이처럼 인덱스를 지정하는 방식이 유용합니다.

## format( ) 함수로 숫자 출력 다양하게 해보기

이번에는 format( ) 함수를 이용하여 숫자 출력을 다양하게 해보겠습니다. 예를 들어 1234.56789라는 실수가 있을 때 특정 소수점 자릿수까지만 출력하고 싶다면 다음과 같이 작성하면 됩니다.

```python filename="03-48-format_number.py"
number = 1234.56789

print("소수점 둘째 자리까지:", format(number, ".2f"))
print("소수점 넷째 자리까지:", format(number, ".4f"))
```

**실행 결과**

```text
소수점 둘째 자리까지: 1234.57
소수점 넷째 자리까지: 1234.5679
```

> **NOTE**
>
> format( ) 함수는 format(값, "서식")처럼 단독으로 써서 값 하나의 서식을 지정할 수도 있습니다.

만약 천 단위마다 쉼표를 넣거나, 천 단위 쉼표 구분과 소수점 자릿수 설정까지 하고 싶다면 이를 혼합하여 다음과 같이 적용할 수도 있습니다.

```python filename="03-49-format_thousands.py"
number = 1234.56789
print("천 단위 구분자 포함:", format(number, ","))
print("천 단위 구분자 + 소수점 둘째:", format(number, ",.2f"))
```

**실행 결과**

```text
천 단위 구분자 포함: 1,234.56789
천 단위 구분자 + 소수점 둘째: 1,234.57
```

조금 더 해볼까요? 숫자에 퍼센트 기호를 붙여 출력하고 싶다면 어떻게 해야 할까요? 숫자를 문자열로 변환한 뒤 + "%"를 붙이면 될까요?

```python filename="03-50-percent_string.py"
small_number = 0.123456
print("퍼센트 표시 : " + str(small_number) + "%")
```

**실행 결과**

```text
퍼센트 표시 : 0.123456%
```

숫자에 %가 붙어 출력되긴 했지만 자연스럽지 않습니다. 우선은 0.123456을 % 단위인 백분율로 환산하면 12.3456%가 되어야 하는데 0.123456%로 잘못 출력되었기 때문이죠. 이는 small_number를 str( )로 감싸 문자열로 변환한 뒤 단순히 "%"를 이어 붙였기 때문에 나온 결과입니다. 하지만 format( ) 함수를 사용하면 이 문제를 간단하게 해결할 수 있습니다.

```python filename="03-51-format_percent.py"
small_number = 0.123456
print("퍼센트 표시 :", format(small_number, ".2%"))
```

**실행 결과**

```text
퍼센트 표시 : 12.35%
```

결과를 보면 small_number의 값 0.123456에 ".2%" 형식을 적용하여 퍼센트 형식으로 바꾸면서 값을 소수점 둘째 자리까지만 출력하도록 잘 적용했습니다. 단순히 숫자에 퍼센트를 붙인 것이 아니라 완전한 비율 형식으로 전환한 것을 볼 수 있습니다. 이를 종합한 예제를 실습하면서 format( ) 함수의 사용법을 마무리하겠습니다.

```python filename="03-52-discount_format.py"
# 문자열 format() 함수 사용
price = 15000
discount_rate = 0.15
final_price = price * (1 - discount_rate)

print("원가: {:,}원".format(price))
print("할인율: {:.1%}".format(discount_rate))
print("최종 가격: {:,.0f}원".format(final_price))

# 여러 값을 한 번에 형식 지정
print("상품 가격은 {:,}원이고, {}% 할인해서 {:,.0f}원입니다.".format(price,  int(discount_rate*100), final_price))
```

**실행 결과**

```text
원가: 15,000원
할인율: 15.0%
최종 가격: 12,750원
상품 가격은 15,000원이고, 15% 할인해서 12,750원입니다.
```

format( ) 함수를 사용하면 숫자에 천 단위 구분 기호를 넣거나 소수점 자릿수와 퍼센트 형식을 지정할 수 있습니다. 또한 여러 값에 각각 다른 형식을 적용하여 하나의 문자열로 출력할 수도 있습니다.

## strip( ) 함수로 문자열 공백 처리하기

문자열 양쪽이나 한쪽에 들어간 불필요한 공백을 정리하는 작업도 자주 쓰여서 알아두면 유용합니다. 파이썬에서는 공백 제거를 위해 strip( ), lstrip( ), rstrip( ) 함수를 사용합니다.

- **strip( ) :** 문자열 양쪽 끝의 공백을 제거합니다.
- **lstrip( ) :** 문자열 왼쪽(앞쪽) 공백만 제거합니다.
- **rstrip( ) :** 문자열 오른쪽(뒤쪽) 공백만 제거합니다.

다음 코드를 작성하고 실행하여 각 함수가 문자열을 어떻게 처리하는지 확인해봅시다. 이때 제거된 공백을 명확히 표시하기 위해 repr( ) 함수로 감싸 출력했습니다.

> **NOTE**
>
> repr( ) 함수로 대상 문자열을 감싸면 작은따옴표로 감싼 형태로 결과를 출력해줍니다. 이렇게 하면 작은따옴표를 실제

문자열에 넣지 않고도 공백이 어디까지 포함되어 있는지 확인할 수 있어 유용합니다.

```python filename="03-53-strip_whitespace.py"
# 양 끝 공백 제거하기
messy_text = "   안녕하세요 파이썬!   "
left_space = "   왼쪽에만 공백"
right_space = "오른쪽에만 공백   "

print("원본:", repr(messy_text))
print("strip():", repr(messy_text.strip()))
print("lstrip():", repr(left_space.lstrip()))
print("rstrip():", repr(right_space.rstrip()))
```

**실행 결과**

```text
원본: '   안녕하세요 파이썬!   '
strip(): '안녕하세요 파이썬!'
lstrip(): '왼쪽에만 공백'
rstrip(): '오른쪽에만 공백'
```

![](/books/python-intro/p143-109.webp)

## 효율적으로 문자열을 이어 붙이는 join( ) 함수

추후 배울 내용으로, 파이썬에는 여러 데이터를 하나로 모아서 관리하는 리스트나 튜플 같은 자료구조가 있습니다. 자료구조란 어렵게 생각할 것 없이 비슷한 형태의 데이터를 모아두는 방법이라고 생각하면 됩니다. 예를 들어 문자열 3개를 모아두고 싶다면 다음과 같이 리스트를 사용하면 됩니다.

```python filename="03-54-string_list.py"
# 리스트로 3개의 문자열 보관하기
words = ["Python", "is", "awesome"]
```

이처럼 리스트는 대괄호 [ ]를 열고 닫는 방식으로 작성하며, 대괄호 안에 3개의 문자열을 쉼표로 구분해 저장합니다. 이제 리스트에 담긴 문자열을 하나로 이어 붙여보겠습니다. 이때 사용하는 것이 join( ) 함수입니다. join( ) 함수는 여러 문자열을 지정한 문자나 기호로 구분하여 하나의 문자열로 연결합니다. 다음은 띄어쓰기를 기준으로 문자열 3개를 연결하는 예제입니다.

```python filename="03-55-string_join_space.py"
# 리스트의 문자열들 연결
words = ["Python", "is", "awesome"]
sentence = " ".join(words)
print(sentence)
```

**실행 결과**

```text
Python is awesome
```

" ".join(words)와 같이 작성하면, 띄어쓰기 문자열(" ")을 기준으로 words 리스트의 문자열 요소들이 하나로 연결됩니다. 예제에서는 이 결과를 sentence 변수에 저장한 뒤 출력했습니다. 만약 띄어쓰기 대신 다른 기호나 문자로 연결하고 싶다면 " "를 원하는 것으로 바꾸면 됩니다.

```python filename="03-56-string_join_hyphen.py"
# 리스트의 문자열들 연결
words = ["Python", "is", "awesome"]
sentence = "-".join(words)
print(sentence)
```

**실행 결과**

```text
Python-is-awesome
```

+ 연산자도 문자열을 연결하는 편리한 방법이지만 join( ) 함수는 아주 많은 양의 문자열을 한꺼번에 연결할 수 있어 훨씬 유리합니다.

## split( )과 join( ) 함수로 문자열 나누고 합치기

문자열을 다루다 보면 특정 문자나 단어를 기준으로 문자열을 나누거나, 반대로 여러 개의 문자열을 특정 기호로 연결해야 하는 경우가 자주 있습니다. 예를 들어 쉼표로 구분된 데이터를 조각내어 분리하거나, 여러 단어를 하이픈(-)으로 묶어 연결하고 싶을 수도 있습니다. 파이썬에서는 split( ) 함수와 join( ) 함수를 조합하면 문자열을 나누고 연결하는 작업을 할 수 있습니다. join( ) 함수는 앞에서 이미 살펴보았으므로 여기서는 split( ) 함수와 함께 사용하면서 다양한 예시를 통해 익혀보겠습니다.

### 특정 키워드로 문자열을 나눠주는 split( ) 함수

먼저 split( ) 함수부터 알아보겠습니다. split( ) 함수는 이름 그대로 문자열을 나눌 때 사용하는 함수로, 소괄호 안에 기준이 될 문자열을 입력하면 됩니다. 나뉜 결과는 리스트라는 자료형에 담아 반환합니다. 결괏값이 대괄호로 감싸여 있고, 내부 데이터가 쉼표로 구분되어 있다면 리스트라고 이해하면 됩니다.

```python filename="03-57-split_keyword.py"
# 특정 키워드로 문자열 나누기
fruits = "사과,바나나,오렌지,포도,딸기"
sentence = "파이썬은-정말-재미있는-프로그래밍-언어입니다"

print("과일 목록:", fruits)
print("쉼표로 나누기:", fruits.split(","))
print("문장:", sentence)
print("하이픈으로 나누기:", sentence.split("-"))
```

**실행 결과**

```text
과일 목록: 사과,바나나,오렌지,포도,딸기
쉼표로 나누기: ['사과', '바나나', '오렌지', '포도', '딸기']
문장: 파이썬은-정말-재미있는-프로그래밍-언어입니다
하이픈으로 나누기: ['파이썬은', '정말', '재미있는', '프로그래밍', '언어입니다']
```

결과를 보면 "사과,바나나,오렌지,포도,딸기"를 쉼표를 기준으로 나누기 위해 fruits.split(",")를 사용했습니다. 결과는 ['사과', '바나나', '오렌지', '포도', '딸기']라는 리스트 형태로 출력됩니다. 참고로 split( )을 아무 인자 없이 호출하면 공백(스페이스, 탭, 줄바꿈)을 기준으로 문자열을 자동으로 나눠줍니다.

```python filename="03-58-split_whitespace.py"
# 공백으로 나누기
sentence = "파이썬 정말 재미있다"
print("문장 :", sentence)
print("공백으로 나누기 :", sentence.split())
```

**실행 결과**

```text
문장 : 파이썬 정말 재미있다
공백으로 나누기 : ['파이썬', '정말', '재미있다']
```

이번에는 split( )으로 나눈 결과를 join( ) 함수를 사용해 다시 하나의 문자열로 합쳐보겠습니다. 쪼갠 조각들을 원하는 구분자로 이어 붙이면 됩니다.

```python filename="03-59-split_join.py"
# split()으로 나누고 join()으로 다시 합치기
fruits = "사과,바나나,오렌지,포도,딸기"
fruit_list = fruits.split(",")
result = " / ".join(fruit_list) # 구분자로 " / " 사용
print(result)
```

**실행 결과**

```text
사과 / 바나나 / 오렌지 / 포도 / 딸기
```

split( )으로 나눈 리스트 요소들이 join( )에 의해 하나의 문자열로 다시 연결되었습니다. 이처럼 split( )과 join( )은 짝을 이루어 자주 사용되므로 함께 기억해두면 좋습니다.

## f-string으로 숫자 서식 지정하기

이미 format( ) 함수로 소수점 자릿수와 천 단위 쉼표를 지정해봤습니다. 에서 배운 f-string에서도 동일한 서식 지정 기능을 제공합니다. 방법은 간단합니다. f-string의 중괄호 안의 변수 이름 뒤에 콜론(:)을 붙이고 원하는 서식을 적어주면 됩니다. 형식은 {변수:서식} 형태입니다. 서식을 적는 규칙은 format( ) 함수에서 사용한 것과 완전히 같습니다.

```python filename="03-60-fstring_format.py"
price = 1234567.891
rate = 0.15
name = "요즘이"

print(f"가격: {price:,.2f}원")   # ➊ 천 단위 쉼표 + 소수점 둘째 자리까지
print(f"가격: {price:,.0f}원")   # ➋ 천 단위 쉼표 + 소수점 없이
print(f"할인율: {rate:.1%}")     # ➌ 백분율로 표시
print(f"[{name:^10}]")           # ➍ 10칸 안에서 가운데 정렬
```

**실행 결과**

```text
가격: 1,234,567.89원
가격: 1,234,568원
할인율: 15.0%
[   요즘이    ]
```

❶ 쉼표(,)는 천 단위마다 쉼표를 찍으라는 뜻이고, .2f는 소수점 둘째 자리까지 표시하라는 의미입니다. 두 서식을 조합해 ,.2f 형태로 함께 쓸 수 있습니다.

❷ .0f는 소수점을 출력하지 않도록 설정합니다. 이때 소수점 아래 숫자는 단순히 잘리는 것이 아니라 반올림처럼 된다는 점을 기억하세요. 1234567.891이 1,234,568이 되었습니다.

❸ %를 지정하면 값에 100을 곱한 뒤 퍼센트 기호를 붙여 줍니다. .1%로 지정했으므로 소수점 첫째 자리까지 계산되어 15.0%가 출력됩니다.

❹ ^10은 전체 10칸의 출력 공간을 확보한 다음 그 안에서 가운데 정렬을 하라는 의미입니다. 왼쪽 정렬은 <, 오른쪽 정렬은 >를 사용하며, 콘솔 화면에 표 형태로 줄을 맞춰 출력할 때 유용합니다.

정리하면 print("{:,.2f}".format(price))와 print(f"{price:,.2f}")는 완전히 같은 결과를 출력합니다. 값이 어디에 들어가는지 바로 보여 직관적이므로 실무에서는 f-string 방식을 더 많이 씁니다. format( ) 함수는 문장 서식 틀을 미리 만들어두고 값을 나중에 대입하고자 할 때 유용합니다.

> **바로 핵심 요약**
>
> - format( ) 함수로 값을 문자열에 넣고, 소수점 자릿수, 천 단위 쉼표, 퍼센트(백분율) 등 다양한 출력 형식을 지정할 수 있습니다.
> - strip( ), lstrip( ), rstrip( ) 함수로 문자열 양쪽 또는 한쪽 끝의 공백을 제거할 수 있습니다.
> - split( ) 함수로 문자열을 나누고, join( ) 함수로 나눈 문자열을 지정한 구분자로 다시 이어 붙일 수 있습니다.
