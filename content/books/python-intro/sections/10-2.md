프로그램이 갑자기 멈추고 영어로 된 긴 메시지가 나타나면 당황하기 쉽습니다. 가끔은 우리를 혼내는 것처럼 느껴지기도 합니다. 하지만 오류 메시지는 우리를 혼내는 문장이 아니라 어디에서 어떤 문제가 발생했는지 알려주는 안내문입니다. 모든 내용을 한 번에 이해하려 하지 말고 중요한 부분부터 살펴봅시다. 몇 번만 연습하면 오류 메시지도 충분히 읽을 수 있습니다!

> **미리 알아두세요!**
>
> - 오류 메시지의 마지막 줄에서 오류 종류와 원인을 확인할 수 있습니다.
> - 오류가 발생한 위치를 찾으면 문제를 해결하기 쉬워집니다.
> - SyntaxError처럼 실행되기 전에 발생하는 문법 오류도 있습니다.

## 오류 메시지는 마지막 줄부터 확인합니다

코드를 실행하다 오류가 발생하면 짧게는 몇 줄, 경우에 따라서는 수십 줄 이상의 메시지가 나타나기도 합니다. 내용이 길면 어디부터 읽어야 할지 막막할 수 있습니다. 이럴 때는 당황하지 말고 먼저 마지막 줄을 확인해보세요. 보통 마지막 줄에 발생한 오류의 종류와 원인을 파악하는 데 도움이 되는 설명이 나타나기 때문이죠. 다음 코드를 작성한 뒤 실행해봅시다.

```python filename="10-01-type_error.py"
point = "1500"
next_point = point + 500  # ➊ 문자열과 정수의 덧셈
print(next_point)
```

**실행 결과**

```text
Traceback (most recent call last):
  File "10-01-type_error.py", line 2, in <module>
    next_point = point + 500
                 ~~~~~~^~~~~
TypeError: can only concatenate str (not "int") to str
```

❶ 요즘이는 포인트 "1500"을 문자열로 저장했다는 사실을 깜빡하고 정수 500을 더했습니다. 이미 알고 있듯이 파이썬에서는 문자열과 정수를 + 연산자로 바로 더할 수 없습니다. 따라서 TypeError가 발생하고 프로그램의 실행이 중단됩니다.

오류 메시지를 보면 Traceback으로 시작하죠? 파이썬에서 오류가 발생하기까지 어떤 코드가 실행되었는지 보여주는 정보를 트레이스백(traceback)이라고 합니다. 여기서 line 2는 오류가 발생한 코드가 있는 줄을 나타내고, 그 아래에는 해당 코드가 보입니다. **이때 가장 마지막 줄을 보면 오류 종류와 원인을 확인할 수 있습니다. 마지막 줄의 TypeError는 오류 종류이고, 콜론 오른쪽에는 오류가 발생한 이유가 나타납니다.** 다음 메시지를 읽어볼까요?

**실행 결과**

```text
TypeError: can only concatenate str (not "int") to str
```

TypeError는 발생한 오류의 종류입니다. 콜론 뒤의 메시지는 문자열 str에 정수 int를 연결할 수 없다는 내용입니다. + 연산자로 문자열을 이어 붙일 때는 문자열끼리만 연결할 수 있으므로, 문자열 "1500"과 정수 500을 그대로 더하려 하자 오류가 발생한 것입니다. 그 위에는 어떤 코드에서 문제가 발생했는지도 확인할 수 있습니다.

**실행 결과**

```text
    next_point = point + 500
                 ~~~~~~^~~~~
```

point + 500 부분에 표시가 있는 것을 보면 이 연산을 처리하는 과정에서 문제가 발생했음을 알 수 있습니다. 이처럼 먼저 마지막 줄에서 오류의 종류와 설명을 확인하고, 필요한 경우 위쪽으로 올라가며 문제가 발생한 파일과 코드 위치를 살펴보면 됩니다.

파이썬에서는 상황에 따라 다양한 오류가 발생합니다. 그렇다고 오류의 이름과 메시지를 모두 미리 외울 필요는 없습니다. 오류가 생겼을 때 메시지를 직접 읽고 어떤 종류의 문제가 발생했는지 하나씩 확인하는 습관을 들이는 것이 중요합니다. 그럼 오류 메시지에 조금 더 익숙해질 수 있도록 자주 만나는 몇 가지 오류를 직접 발생시켜보겠습니다.

![](/books/python-intro/p461-281.webp)

## 자료형은 맞지만 값이 잘못됐을 때 생기는 오류, ValueError

ValueError는 함수나 연산이 요구하는 자료형의 값은 전달되었지만 그 값이 처리하기에 적절하지 않을 때 발생할 수 있습니다. 다음 코드에서 int( ) 함수에는 문자열을 전달할 수 있습니다. "20"처럼 정수로 표현할 수 있는 문자열이라면 정수 20으로 변환할 수 있습니다. 하지만 "스물"이라는 문자열은 정수로 변환할 수 없습니다.

```python filename="10-02-value_error.py"
age = "스물"
number_age = int(age)  # ➊ 변환할 수 없는 문자열
print(number_age)
```

**실행 결과**

```text
...생략...
ValueError: invalid literal for int() with base 10: '스물'
```

❶ int( ) 함수에 문자열 "스물"을 전달했습니다. 문자열이라는 자료형 자체는 문제가 없지만 "스물"은 정수로 변환할 수 있는 형태가 아닙니다. 따라서 ValueError가 발생합니다. 또한 오류 메시지의 마지막 줄을 확인하면 ValueError라는 오류 종류와 함께 어떤 값을 정수로 변환하지 못했는지 확인할 수 있습니다.

## 파일을 찾을 수 없을 때 발생하는 오류, FileNotFoundError

FileNotFoundError는 파일을 열려고 했지만 지정한 위치에서 해당 파일을 찾을 수 없을 때 발생할 수 있습니다. 다음 코드에서는 아직 만들지 않은 secret_memo.txt 파일을 읽으려고 합니다.

```python filename="10-03-file_not_found.py"
# ➊ 없는 파일 열기
with open("secret_memo.txt", "r", encoding="utf-8") as memo_file:
  memo = memo_file.read()
print(memo)
```

**실행 결과**

```text
Traceback (most recent call last):
  File "10-03-file_not_found.py", line 1, in <module>
```

```python
    with open("secret_memo.txt", "r", encoding="utf-8") as memo_file:  # ➊ 없는
파일 열기
         ~~~~^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
FileNotFoundError: [Errno 2] No such file or directory: 'secret_memo.txt'
```

❶ 현재 작업 폴더에 secret_memo.txt 파일이 없는 상태에서 읽기 모드로 열려고 했으므로 FileNotFoundError가 발생합니다. 오류 메시지를 살펴보면 open(...)을 실행하는 과정에서 문제가 발생했다는 것도 확인할 수 있습니다.

지금까지 살펴본 것처럼 파이썬은 오류가 발생하면 오류의 종류와 문제를 찾는 데 필요한 정보를 알려줍니다. 그렇다면 이런 오류가 발생했을 때 프로그램에서 직접 처리하는 방법은 무엇일까요? 그 방법을 알아보기 전에, 실행 중에 발생하는 오류와 조금 성격이 다른 문법 오류도 살펴보겠습니다.

![](/books/python-intro/p463-282.webp)

## 실행하기도 전에 나는 오류, 문법 오류

앞에서 살펴본 TypeError, ValueError, FileNotFoundError는 코드를 실행하는 과정에서 발생했습니다. 하지만 파이썬이 코드를 실행하기 전에 문법을 확인하는 단계에서 발견되는 오류도 있습니다. 파이썬 문법 규칙에 맞지 않게 코드를 작성했을 때 발생하는 SyntaxError가 대표적입니다. 예를 들어 if 문 끝에 콜론을 빠뜨려보겠습니다.

```python filename="10-04-syntax_error.py"
if 10 > 5
  print("큽니다")
```

**실행 결과**

```text
  File "10-04-syntax_error.py", line 1
    if 10 > 5
             ^
SyntaxError: expected ':'
```

오류 메시지의 마지막 부분을 보면 SyntaxError가 표시되고 expected ':'라는 설명을 통해 콜론이 필요하다는 것을 알 수 있습니다. 위쪽에는 문제가 발견된 코드의 줄과 위치도 표시됩니다. 이번에는 일부러 들여쓰기를 잘못해보겠습니다.

```python filename="10-05-indentation_error.py"
def greet():
print("안녕하세요")
```

**실행 결과**

```text
  File "10-05-indentation_error.py", line 2
    print("안녕하세요")
    ^^^^^
IndentationError: expected an indented block after function definition on line 1
```

함수를 정의한 뒤 함수의 코드 블록은 들여써야 하는데 이를 지키지 않았습니다. 이때는 IndentationError가 발생할 수 있습니다. IndentationError는 들여쓰기와 관련된 문법에 문제가 있다는 뜻으로, 예제의 메시지를 보면 함수 정의 다음에 들여쓴 코드 블록이 필요하다는 설명도 함께 확인할 수 있습니다.

> **NOTE**
>
> 현재 파일 자체의 문법 오류는 try~except 문으로 잡을 수 없

> **NOTE**
>
> 오류 메시지의 내용과 표시 방식은 파이

습니다. 코드를 읽는 단계에서 이미 막혀 프로그램이 아예 시작되지 썬 버전과 실행 환경에 따라 조금씩 달라질 수 있않기 때문입니다. 이런 문법 오류는 예외 처리로 넘기려 하기보다 오습니다. 이 책에서는 파이썬 3.13을 기준으로 설류 메시지가 가리키는 부분의 코드를 수정해야 합니다.

명합니다.

문법 오류는 메시지가 가리키는 줄과 위치를 먼저 살펴보면 비교적 쉽게 원인을 찾을 수 있습니다. 다음 코드에는 문법 오류가 있습니다. 먼저 그대로 실행해 오류 메시지를 확인한 뒤 직접 고쳐봅시다.

```python filename="10-06-fix_syntax_error.py"
scores = [80, 90, 100]
for score in scores
  print(score)
```

**실행 결과**

```text
  File "10-06-fix_syntax_error.py", line 2
    for score in scores
                       ^
SyntaxError: expected ':'
```

오류 메시지에서 콜론이 필요하다는 내용을 확인할 수 있습니다. for 문 끝에 콜론을 추가해 고쳐봅시다.

![](/books/python-intro/p464-283.webp)

```python filename="10-06-fix_syntax_error.py"
scores = [80, 90, 100]
for score in scores:    # ➊ 콜론 추가
  print(score)
```

**실행 결과**

```text
80
90
100
```

❶ 콜론 하나를 추가하니 코드가 정상적으로 실행됩니다. 이처럼 문법 오류는 콜론이나 괄호, 따옴표처럼 작은 문법 요소를 빠뜨려 발생하는 경우가 많습니다. 메시지가 가리키는 줄과 위치부터 확인하는 습관을 들여봅시다.

> **바로 핵심 요약**
>
> - 는 프로그램에 어떤 문제가 발생했는지 파악하는 데 필요한 위치, 원인 등의 정보를 알려줍니다.
> - 실행 중 발생한 오류의 트레이스백을 처음 확인할 때는 마지막 줄에 있는 오류 종류와 설명부터 살펴봅니다.
> - TypeError, ValueError, FileNotFoundError처럼 문제의 상황에 따라 여러 종류의 오류가 발생합니다.
> - 오류의 종류를 확인하면 원인을 찾거나 필요한 오류를 선택해 예외 처리하는 데 도움이 됩니다.
> - SyntaxError와 IndentationError처럼 코드의 문법 자체에 문제가 있다면 메시지가 가리키는 위치를 확인하고 코드를 수정코드를 수정해야 합니다.
