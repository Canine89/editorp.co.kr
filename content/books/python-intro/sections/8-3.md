앞에서 살펴본 것처럼 클래스는 인스턴스 변수와 메서드를 하나로 묶어 관리하고, 하나의 클래스로 여러 인스턴스를 만들어 반복해서 사용할 수 있게 해줍니다. 여기에 이미 만든 클래스를 물려받아 재사용하는 상속을 활용하면 비슷한 코드를 반복해서 작성하지 않고도 더욱 체계적으로 프로그램을 구성할 수 있습니다. 이제 상속부터 오버라이딩, super( )까지 이어지는 흐름을 예제와 함께 하나씩 따라가봅시다.

> **미리 알아두세요!**
>
> - 상속은 부모 클래스의 변수와 메서드를 자식 클래스가 물려받는 것입니다.
> - 오버라이딩으로 물려받은 메서드를 재정의하고, super( )로 부모의 메서드를 함께 쓸 수 있습니다.

## 상속은 언제 필요할까?

만약 비슷한 구조의 클래스가 필요한데, 구성이 조금씩 다르다면 어떻게 해야 할까요? 예를 들어 강아지를 표현하는 Dog 클래스가 있을 때, 고양이를 표현하는 Cat 클래스는 어떻게 만들면 좋을까요? '그냥 Dog 클래스와 Cat 클래스를 코드를 따로 작성하면 되는 것 아니야?'라는 생각이 들 수 있습니다. 이렇게 말이죠.

```python filename="08-05-dog_cat_duplicate.py"
class Dog:
  def __init__(self, name, age):
    self.name = name
    self.age = age

  def introduce(self):
    print(f"안녕! 나는 강아지 {self.name}이고, {self.age}살이야. 멍멍!")


class Cat:
  def __init__(self, name, age):
    self.name = name
    self.age = age

  def introduce(self):
    print(f"안녕! 나는 고양이 {self.name}이고, {self.age}살이야. 야옹!")


dog = Dog("초코", 3)
cat = Cat("나비", 2)

dog.introduce()
cat.introduce()
```

**실행 결과**

```text
안녕! 나는 강아지 초코이고, 3살이야. 멍멍!
안녕! 나는 고양이 나비이고, 2살이야. 야옹!
```

물론 Dog 클래스와 Cat 클래스를 각각 작성해도 프로그램은 정상적으로 동작합니다. 하지만 강아지와 고양이는 모두 '동물'이라는 공통점이 있습니다. 코드에서도 name, age와 같은 인스턴스 변수와 introduce( ) 메서드를 공통으로 가지고 있습니다. 결국 두 클래스에서 달라지는 부분은 클래스 이름과 울음소리를 표현하는 print( ) 정도입니다. 따라서 굳이 공통된 코드를 클래스마다 반복해서 작성할 필요는 없겠죠.

## 상속 이해하기

이럴 때 사용할 수 있는 방법이 바로 **상속**입니다. **상속은 한 클래스에 정의된 기능을 다른 클래스가 물려받아 사용할 수 있게 하는 문법입니다.** 공통으로 사용할 인스턴스 변수와 메서드를 하나의 클래스에 정의해두고, 다른 클래스에서 이를 물려받아 사용할 수 있습니다. 이때 **공통 기능을 제공하는 클래스를 부모 클래스 또는 상위 클래스**, **부모 클래스의 기능을 물려받는 클래스를 자식 클래스 또는 하위 클래스라고 합니다.** 상속이라는 이름 그대로 생물학의 '유전'을 떠올리면 이해하기 쉽습니다. 그럼 상속을 활용해 앞의 클래스를 다시 구성하면 다음과 같이 세 개의 클래스로 나눌 수 있습니다.

- **Animal 클래스 :** name, age라는 공통 인스턴스 변수를 가진 클래스
- **Dog 클래스 :** Animal 클래스를 상속받아 강아지에게 필요한 기능을 구현한 클래스
- **Cat 클래스 :** Animal 클래스를 상속받아 고양이에게 필요한 기능을 구현한 클래스

![](/books/python-intro/p365-231.webp)

이를 코드로 작성하면 다음과 같습니다.

```python filename="08-06-animal_inheritance.py"
class Animal:
  def __init__(self, name, age):
    self.name = name
    self.age = age


class Dog(Animal):
  def introduce(self):
    print(f"안녕! 나는 강아지 {self.name}이고, {self.age}살이야. 멍멍!")


class Cat(Animal):
  def introduce(self):
    print(f"안녕! 나는 고양이 {self.name}이고, {self.age}살이야. 야옹!")


dog = Dog("초코", 3)
cat = Cat("나비", 2)

dog.introduce()
cat.introduce()
```

**실행 결과**

```text
안녕! 나는 강아지 초코이고, 3살이야. 멍멍!
안녕! 나는 고양이 나비이고, 2살이야. 야옹!
```

코드를 보면 Dog 클래스와 Cat 클래스에는 __init__( ) 메서드가 없습니다. 그런데도 Dog("초코", 3), Cat("나비", 2)와 같이 코드를 작성해 인스턴스를 만들 수 있습니다. 그 이유는 Dog 클래스와 Cat 클래스가 __init__( ) 메서드를 가진 Animal 클래스를 상속받았기 때문입니다. 다음 코드의 일부를 살펴봅시다.

```python
class Dog(Animal):
```

클래스 A를 선언할 때 소괄호에 상속할 클래스 B를 넣어 class A(B):와 같이 입력하면 A가 B 클래스를 상속한다는 뜻입니다. 자식 클래스에 해당 메서드가 따로 정의되어 있지 않아도 상속 관계에 따라 부모 클래스에서 메서드를 찾아 사용할 수 있습니다.

이를 통해 공통 코드는 부모 클래스에 작성하고, 클래스마다 달라지는 부분만 자식 클래스에 따로 작성할 수 있습니다. 다시 말해 코드의 중복을 줄이고 클래스를 더욱 체계적으로 구성할 수 있습니다.

## 부모 클래스에 있는 메서드 재정의하기, 오버라이딩

![](/books/python-intro/p366-232.webp)

그런데 앞에서 코드를 작성하면서 혹시 이런 생각이 들지는 않았나요?

‘동물은 모두 울음소리를 내니까 introduce( ) 메서드를 아예 Animal 클래스에 한 번만 정의해두면 되지 않을까?’

충분히 합리적인 생각입니다. 하지만 한 가지 문제가 있습니다. 동물이 소리를 낸다는 점은 같아도 동물마다 내는 울음소리는 다르기 때문입니다. 강아지는 “멍멍”, 고양이는 “야옹” 하고 울죠. 그래도 ‘운다’라는 공통된 동작이 있으니 introduce( ) 메서드를 Animal 클래스에 두고 싶습니다. 정리하면 다음과 같습니다.

- 동물은 모두 우니까 공통으로 사용하는 introduce( ) 메서드를 Animal 클래스에 두고 싶다.
- 하지만 동물마다 우는 소리가 다르니 출력해야 할 내용이 다르다.

이럴 때 사용하는 방법이 **오버라이딩**(overriding)입니다. **오버라이딩은 부모 클래스에 이미 있는 메서드를 자식 클래스에서 다시 정의하여 자식 클래스에 맞게 동작을 바꾸는 방법입니다.**

![](/books/python-intro/p367-233.webp)

오버라이딩하려면 자식 클래스 안에 부모 클래스와 같은 이름의 메서드를 정의하면 됩니다. 다음 코드를 작성해봅시다.

```python filename="08-07-animal_override.py"
class Animal:
  def __init__(self, name):
    self.name = name

  def introduce(self):  # ➊ 부모 클래스에 introduce()를 한 번 정의
    print(f"저는 {self.name}입니다. 어떤 소리를 낼까요?")

class Dog(Animal):
  def introduce(self):  # ➋ 같은 이름으로 다시 작성(오버라이딩)
    print(f"저는 {self.name}입니다. 멍멍!")

class Cat(Animal):
  def introduce(self):  # ➌ Cat도 introduce()를 다시 작성
    print(f"저는 {self.name}입니다. 야옹!")

animal = Animal("이름없음")
dog = Dog("바둑이")
cat = Cat("나비")

animal.introduce()  # ➍ 부모 버전 그대로 실행
dog.introduce()
cat.introduce()
```

**실행 결과**

```text
저는 이름없음입니다. 어떤 소리를 낼까요?
저는 바둑이입니다. 멍멍!
저는 나비입니다. 야옹!
```

❶ Animal 클래스에 introduce( ) 메서드를 정의했습니다. 따라서 ❹처럼 animal.introduce( ) 를 호출하면 Animal 클래스의 introduce( ) 메서드가 실행됩니다. Animal("이름없음")으로 인스턴스를 생성했으므로 animal.introduce( )는 "저는 이름없음입니다. 어떤 소리를 낼까요?"라고 출력합니다.

❷와 ❸에서는 Dog와 Cat이 Animal을 상속받았지만 그 안에 introduce( ) 메서드를 다시 작성했습니다. **즉, Dog와 Cat 클래스는 Animal 클래스의 introduce( ) 메서드를 오버라이딩했습니다.** 따라서 dog.introduce( )를 호출하면 Animal의 introduce( ) 대신 Dog 클래스에서 다시 정의한 introduce( ) 메서드를 실행해 "멍멍!"을 출력합니다. 마찬가지로 cat.introduce( )는 "야옹!"을 출력합니다.

그리고 __init__( ) 메서드는 자식 클래스에서 다시 정의하지 않았습니다. 따라서 Dog와 Cat에서 __init__( )을 찾지 못하면 상속 관계를 따라 부모인 Animal의 __init__( ) 메서드를 찾아 호출합니다. 그 결과 전달한 이름이 self.name에 저장됩니다. 이처럼 오버라이딩을 사용하면 부모 클래스에서 물려받은 동작을 자식 클래스의 특징에 맞게 바꾸어 사용할 수 있습니다.

![](/books/python-intro/p368-234.webp)

## 오버라이딩한 메서드와 부모의 메서드를 같이 쓰고 싶다면? super( )

만약 자식 클래스에서 오버라이딩한 메서드와 부모의 메서드를 함께 쓰고 싶다면 어떻게 해야 할까요? 예를 들어 모든 동물이 "저는 OO입니다"라고 이름을 소개하는 부분은 그대로 사용하고, 동물마다 다른 울음소리만 뒤에 추가하고 싶다고 해봅시다. 이때 울음소리를 다르게 하기 위해 introduce( ) 메서드를 자식 클래스에서 오버라이딩하면 자식 메서드가 실행되므로, 부모 메서드의 기능도 쓰려면 별도로 호출해야 합니다. 따라서 부모 메서드를 호출하지 않는다면 "저는 OO입니다"라고 이름을 소개하는 코드를 자식 클래스마다 다시 작성해야 하겠죠.

이때는 super( )를 사용합니다. super( )를 사용하면 상속 관계에 따라 다음 클래스에 정의된 메서드를 찾아 호출할 수 있습니다. 지금과 같은 단순한 상속 구조에서는 부모 클래스의 메서드를 호출한다고 이해해도 좋습니다. 다음 코드를 입력해서 실행해보면 super( )가 어떤 역할을 하는지 알 수 있습니다.

```python filename="08-08-animal_super.py"
class Animal:
  def __init__(self, name):
    self.name = name

  def introduce(self):
    print(f"저는 {self.name}입니다.")

class Dog(Animal):
  def introduce(self):
    super().introduce()  # ➊ 부모 Animal의 introduce() 먼저 실행
    print("멍멍!")        # ➋ 그 뒤에 자식만의 동작을 추가

class Cat(Animal):
  def introduce(self):
    super().introduce()  # ➌ Cat도 부모 introduce()를 그대로 가져옴
    print("야옹!")

dog = Dog("바둑이")
cat = Cat("나비")

dog.introduce()
cat.introduce()
```

**실행 결과**

```text
저는 바둑이입니다.
멍멍!
저는 나비입니다.
```

❶ super( ).introduce( )를 실행하면 상속 관계에 따라 부모인 Animal 클래스의 introduce( ) 메서드가 그대로 실행됩니다.

❷ 그다음 print("멍멍!")이 실행되어 "멍멍!"이 이어서 출력됩니다.

❸ Cat 클래스도 같은 방식으로 부모 클래스인 Animal의 introduce( ) 메서드를 먼저 실행한 뒤 "야옹!"을 출력합니다. 이처럼 super( )를 사용하면 부모 클래스에 작성해둔 기능을 다시 작성하지 않고 사용할 수 있습니다.

![](/books/python-intro/p370-235.webp)

## 자식 클래스에 인스턴스 변수 더하기, super( ).__init__( )

지금까지 다룬 상속 예제에서는 자식 클래스가 부모의 __init__( ) 메서드를 그대로 물려받아 사용했습니다. 그런데 실제로 클래스를 만들다 보면 부모 클래스에서 사용하는 값은 그대로 받고, 자식 클래스만의 값을 하나 더 추가하고 싶은 상황이 생깁니다.

동물을 표현하는 클래스를 상속받아 강아지 클래스를 만든다고 해봅시다. 강아지에는 이름과 나이뿐만 아니라 견종도 저장하고 싶습니다. 그렇다면 자식 클래스에 __init__( ) 메서드를 새로 정의하면 어떻게 될까요?

```python filename="08-09-super_init_error.py"
class Animal:
  def __init__(self, name, age):
    self.name = name
    self.age = age

  def introduce(self):
    print(f"저는 {self.name}이고 {self.age}살입니다.")

class Dog(Animal):
  def __init__(self, breed):     # ➊ 자식만의 __init__() 메서드
    self.breed = breed

choco = Dog("푸들")
choco.introduce()                # ➋ 부모의 메서드 호출
```

**실행 결과**

```text
AttributeError: 'Dog' object has no attribute 'name'
```

❶ 자식 클래스에 __init__( ) 메서드를 새로 만들었습니다. 부모 클래스와 같은 이름의 메서드를 자식 클래스에 다시 정의했으므로 이 역시 오버라이딩입니다.

❷ 그런데 부모 클래스의 introduce( ) 메서드를 부르니 name이라는 인스턴스 변수가 없다는 오류가 났습니다.

이유는 간단합니다. 자식 클래스에 __init__( ) 메서드를 새로 정의하면 인스턴스를 초기화할 때 자식 클래스의 __init__( )이 호출되며, 부모 클래스의 __init__( ) 메서드는 실행되지 않습니다. 오버라이딩은 부모의 메서드를 덮어쓰는 것이니까요. 따라서 부모 클래스의 __init__( )에 작성해둔 self.name과 self.age를 설정하는 코드가 실행되지 않은 것입니다. 이럴 때는 super( )를 사용해 부모의 __init__( )을 직접 실행해주면 됩니다.

```python filename="08-10-super_init.py"
class Animal:
  def __init__(self, name, age):
    self.name = name
    self.age = age

  def introduce(self):
    print(f"저는 {self.name}이고 {self.age}살입니다.")

class Dog(Animal):
  def __init__(self, name, age, breed):
    super().__init__(name, age)  # ➊ 부모의 __init__() 먼저 실행
    self.breed = breed           # ➋ 자식만의 인스턴스 변수 추가

  def introduce(self):
    super().introduce()          # ➌ 부모의 소개를 먼저
    print(f"견종은 {self.breed}입니다.")

choco = Dog("초코", 3, "푸들")
choco.introduce()
```

**실행 결과**

```text
저는 초코이고 3살입니다.
견종은 푸들입니다.
```

❶ super( ).__init__(name, age)는 상속 관계에 따라 부모 클래스인 Animal의 __init__( ) 메서드를 실행합니다. 그 안에서 self.name과 self.age가 만들어집니다.

❷ 부모 클래스에서 설정한 값 위에 자식 클래스만의 인스턴스 변수 breed를 더했습니다.

❸ super( )로 부모 클래스의 메서드를 함께 사용하는 것과 같은 방식입니다. 부모의 introduce( )를 먼저 호출해 이름과 나이를 출력한 뒤, 자식 메서드에서 견종을 추가로 출력합니다.

정리하면 자식 클래스에서 __init__( ) 메서드를 새로 정의하면서 부모 클래스의 초기화 작업도 그대로 사용하고 싶다면, super( ).__init__( )을 호출하면 됩니다. 이렇게 해야 부모 클래스의 __init__( )에 작성해둔 초기화 코드도 함께 실행됩니다.

## 같은 호출, 다른 동작 : isinstance( )와 다형성

부모 클래스와 같은 이름의 메서드를 자식 클래스에서 다시 정의(오버라이딩)하면 자식 클래스의 메서드가 실행됩니다. 이 성질 덕분에 여러 종류의 인스턴스를 하나의 리스트에 담아두고 같은 방식으로 처리할 수 있습니다.

```python filename="08-11-polymorphism.py"
class Animal:
  def speak(self):
    print("동물이 소리를 냅니다.")

class Dog(Animal):
  def speak(self):
    print("멍멍!")

class Cat(Animal):
  def speak(self):
    print("야옹!")

animals = [Dog(), Cat(), Animal()]
for animal in animals:                 # ➊ 같은 호출, 다른 동작
  animal.speak()

print(isinstance(animals[0], Dog))     # ➋
print(isinstance(animals[0], Animal))  # ➌
```

**실행 결과**

```text
멍멍!
야옹!
동물이 소리를 냅니다.
True
True
```

❶ 반복문 안의 코드는 animal.speak( ) 하나뿐이지만, 인스턴스의 종류에 따라 다른 결과가 나옵니다. **이렇게 같은 이름의 메서드 호출이 대상에 따라 다르게 동작하는 성질을 다형성이라고 부릅니다.**

❷ isinstance( ) 함수는 어떤 값이 특정 클래스의 인스턴스인지 확인할 때 사용합니다. animals[0] 이 Dog 클래스로 만든 인스턴스라면 isinstance(animals[0], Dog)의 결과는 True입니다.

❸ Dog는 Animal을 상속받았으므로 Dog 인스턴스는 Animal의 인스턴스로도 판단됩니다. 따라서 isinstance(animals[0], Animal) 역시 True로, '강아지는 동물이기도 하다'가 성립합니다. 상속 관계를 확인할 때 유용합니다.

## 부모 클래스를 상속받아 자식 클래스 만들기

지금까지 배운 상속, 오버라이딩, super( )를 직접 연습해봅시다. 먼저 상속을 연습해보기 위해 탈것에 필요한 공통 정보를 부모 클래스인 Vehicle에 두고, 자식 클래스 Car가 그 기능을 물려받는 코드를 직접 작성해봅시다.

```python filename="08-12-vehicle_inheritance.py"
class Vehicle:                     # ➊ 부모 클래스 정의
  def __init__(self, name):
    self.name = name

class Car(Vehicle):                # ➋ 자식 클래스 정의
  def drive(self):                 # ➌ 자식 메서드 정의
    print(f"{self.name}가 달립니다.")

car = Car("자동차")                 # ➍ 인스턴스 생성
car.drive()                        # ➎ 메서드 호출
```

**실행 결과**

```text
자동차가 달립니다.
```

❶ Vehicle 클래스를 만들었습니다. 여러 탈것이 공통으로 가질 name 값을 부모 클래스의 __init__( )에서 인스턴스 변수로 저장하도록 정의했습니다.

❷ Car 클래스는 Vehicle 클래스를 상속받습니다. 따라서 Car 클래스 안에 __init__( ) 메서드를 따로 쓰지 않아도 상속 관계에 따라 Vehicle의 __init__( ) 메서드를 사용할 수 있습니다.

❸ drive( ) 메서드는 Car 클래스만의 기능입니다. 부모 클래스에서 물려받은 self.name을 사용해 문장을 출력합니다.

❹ Car("자동차")를 실행해 Car 인스턴스를 만들었습니다. 이때 Vehicle의 __init__( ) 메서드가 실행되어 self.name에 "자동차"가 저장됩니다.

❺ car.drive( )를 실행하면 car 인스턴스에 저장된 name을 사용해 결과를 출력합니다.

## 자식 클래스에서 메서드 오버라이딩하기

이번에는 부모 클래스에 있는 메서드를 자식 클래스에서 다시 정의해봅시다. 같은 introduce( ) 메서드라도 어떤 클래스의 인스턴스에서 호출하느냐에 따라 다른 결과가 나오는지 확인해보겠습니다.

```python filename="08-13-character_override.py"
class Character:                   # ➊ 부모 클래스 정의
  def __init__(self, name):
    self.name = name

  def introduce(self):             # ➋ 부모 메서드 정의
    print(f"{self.name}입니다.")

class Warrior(Character):          # ➌ 자식 클래스 정의
  def introduce(self):             # ➍ 메서드 오버라이딩
    print(f"전사 {self.name}입니다.")

class Wizard(Character):
  def introduce(self):             # ➎ 메서드 오버라이딩
    print(f"마법사 {self.name}입니다.")

warrior = Warrior("아론")
wizard = Wizard("루나")

warrior.introduce()                # ➏ 메서드 호출
wizard.introduce()
```

**실행 결과**

```text
전사 아론입니다.
마법사 루나입니다.
```

❶ Character 클래스를 만들었습니다. Warrior와 Wizard가 공통으로 사용할 name 값을 부모 클래스에서 인스턴스 변수로 저장하도록 정의했습니다.

❷ 부모 클래스에도 introduce( ) 메서드가 있습니다. 기본적으로 이름을 소개하는 기능입니다.

❸ Warrior 클래스는 Character 클래스를 상속받습니다. 그래서 __init__( ) 메서드를 따로 작성하지 않아도 Character의 __init__( ) 메서드를 사용해 name을 저장할 수 있습니다.

❹ Warrior 클래스 안에서 introduce( ) 메서드를 다시 정의했습니다. 이렇게 부모 클래스에 있는 메서드와 같은 이름의 메서드를 자식 클래스에서 다시 정의하는 것을 오버라이딩이라고 합니다.

❺ Wizard 클래스도 introduce( ) 메서드를 오버라이딩했습니다. 같은 이름의 메서드라도 자식 클래스마다 다르게 동작하게 만든 것입니다.

❻ warrior.introduce( )와 wizard.introduce( )를 실행하면 각각 자식 클래스에서 다시 정의한 introduce( ) 메서드가 실행됩니다.

## super( )로 부모 메서드 함께 사용하기

이번에는 앞에서 배운 super( )를 좀 더 확실히 이해하기 위해 자식 클래스에서 부모 클래스의 메서드를 super( )로 사용해보는 연습을 하겠습니다.

```python filename="08-14-super_practice.py"
class Animal:                      # ➊ 부모 클래스 정의
  def __init__(self, name):
    self.name = name

  def introduce(self):             # ➋ 부모 메서드 정의
    print(f"저는 {self.name}입니다.")

class Dog(Animal):                 # ➌ 자식 클래스 정의
  def introduce(self):             # ➍ 메서드 오버라이딩
    super().introduce()            # ➎ 부모 메서드 호출
    print("멍멍!")

class Cat(Animal):
  def introduce(self):
    super().introduce()            # ➏ 부모 메서드 호출
    print("야옹!")

dog = Dog("초코")
cat = Cat("나비")

dog.introduce()                    # ➐ 메서드 호출
cat.introduce()
```

**실행 결과**

```text
저는 초코입니다.
멍멍!
저는 나비입니다.
야옹!
```

❶ Animal 클래스를 만들었습니다. Dog와 Cat이 공통으로 사용할 name 값은 부모 클래스에서 인스턴스 변수로 저장하도록 했습니다.

❷ Animal 클래스의 introduce( ) 메서드는 "저는 {self.name}입니다."와 같이 인스턴스 변수 name의 값을 출력합니다.

❸ Dog 클래스는 Animal 클래스를 상속받습니다. 그래서 Animal의 __init__( ) 메서드를 그대로 사용할 수 있습니다.

❹ Dog 클래스에서 introduce( ) 메서드를 오버라이딩했습니다. 이렇게 하면 부모 클래스인 Animal의 introduce( ) 메서드가 아니라 Dog 클래스에서 재정의한 introduce( ) 메서드가 실행됩니다. 이를 통해 강아지에게 맞는 동작을 추가할 수 있습니다.

❺ Dog 클래스의 introduce( ) 메서드 안에서 super( ).introduce( )를 사용하면 상속 관계에 따라 부모 클래스인 Animal의 introduce( ) 메서드를 호출합니다. 따라서 dog.introduce( )를 실행하면 먼저 "저는 초코입니다."가 출력되고, 이어서 "멍멍!"이 출력됩니다.

❻ Cat 클래스도 같은 방식으로 super( ).introduce( )를 사용하므로 먼저 "저는 나비입니다."가 출력되고, 이어서 "야옹!"이 출력됩니다. 이렇게 하면 부모 클래스의 공통 기능을 살리면서 자식 클래스마다 다른 동작을 덧붙일 수 있습니다.

❼ 실제로 인스턴스를 만든 뒤 dog.introduce( )와 cat.introduce( )를 실행하여 서로 다른 울음소리를 출력했습니다.

> **바로 핵심 요약**
>
> - 상속을 사용하면 부모 클래스에 작성한 변수와 메서드를 자식 클래스가 그대로 물려받아 중복 코드를 줄일 수 있습 니다.
> - 부모 클래스와 같은 이름의 메서드를 자식 클래스에서 다시 정의해 동작을 바꾸는 것을 오버라이딩, 같은 이름의 메서드가 대상에 따라 다르게 동작하는 성질을 다형성이라고 합니다.
> - super( )를 사용하면 자식 클래스의 메서드 안에서 상속 관계에 있는 상위 클래스의 메서드를 활용할 수 있습니다. 자식 클래스에서 __init__( )을 새로 정의하면서 부모 클래스의 초기화 과정도 사용하려면 super( ).__init__( )을 호출합니다.
