앞에서는 read( )를 사용해 파일 전체 내용을 한꺼번에 읽었습니다. 이번에는 파일을 한 줄씩 읽어 처리하는 방법을 알아보겠습니다. 데이터를 다룰 때 자주 사용하는 방식입니다. 파일 인스턴스를 반복하는 방법부터 readline( ), readlines( ), strip( )까지 예제를 통해 하나씩 익혀봅시다.

> **미리 알아두세요!**
>
> - readline( )은 한 줄만, readlines( )는 모든 줄을 리스트로 읽어 옵니다.
> - strip( )으로 줄 끝의 줄바꿈 문자를 정리할 수 있습니다.

실제로 파일을 다룰 때는 read( ) 메서드만으로는 불편한 경우가 많습니다. read( ) 메서드는 파일의 전체 내용을 한꺼번에 읽어 하나의 긴 문자열로 가져오기 때문입니다. 파일 내용이 짧거나 전체 내용을 그대로 사용할 때는 간단하고 편리하지만, 파일이 길거나 각 줄을 따로 처리해야 한다면 다른 방법이 더 적합할 수 있습니다.

예를 들어 A4 용지 400장짜리 문서를 확인한다고 생각해봅시다. 이 문서를 한 덩어리로 통째로 보는 것보다, 한 장씩 넘기면서 필요한 내용을 확인하고 정리하는 편이 훨씬 자연스럽습니다. 파일도 비슷합니다. 여러 줄로 이루어진 파일이라면 한 줄씩 읽으면서 각 줄을 어떻게 처리할지 정하는 것이 더 편할 때가 많습니다.

![](/books/python-intro/p436-265.webp)

파이썬에서는 파일의 내용을 한 줄씩 읽을 수 있습니다. **특히 파일 인스턴스를 for 반복문에 넣으면 파일 내용을 한 줄씩 차례대로 가져올 수 있습니다.** 그러면 파일 전체를 한 번에 긴 문자열로 가져오지 않고, 한 줄을 읽을 때마다 출력하거나 번호를 붙이고 필요한 줄만 골라 처리할 수 있습니다.

## 파일을 한 줄씩 읽는다?

여러 줄의 내용이 저장된 파일이 있다고 생각해봅시다. 예를 들어 memo.txt 파일 안에 다음과 같은 내용이 들어 있다고 하겠습니다.

```python
책 반납하기
물 마시기
장보기
```

memo.txt파이썬에서는 이 파일의 내용을 다음과 같이 한 줄씩 차례대로 읽을 수 있습니다.

1. 첫 번째 줄인 **책 반납하기**를 읽고2. 두 번째 줄인 **물 마시기**를 읽고3. 세 번째 줄인 **장보기**를 읽습니다.

이처럼 파일 내용을 한꺼번에 통째로 가져오는 것이 아니라, 줄 단위로 나누어 가져오면 각 줄마다 다른 처리를 할 수 있습니다. 예를 들어 메모 앞에 번호를 붙여 출력할 수도 있고, 특정 단어가 들어 있는 줄만 찾을 수도 있습니다. 지금 당장 복잡한 검색 기능을 만들지는 않겠지만, 파일을 한 줄씩 처리하는 방법을 알아두면 이런 프로그램으로 자연스럽게 확장할 수 있습니다. 그럼 실습을 통해 그 방법을 살펴보겠습니다.

### 파일 내용을 한 줄씩 출력해보기

실습을 바로 할 수 있도록 코드 안에서 먼저 memo.txt 파일을 만들고, 이어서 같은 파일을 읽어보겠습니다. 파일을 읽을 때는 for 반복문을 사용합니다.

```python filename="09-14-memo_line_loop.py"
# ➊ 메모 파일 만들기
with open("memo.txt", "w", encoding="utf-8") as memo_file:
  memo_file.write("책 반납하기\n")
  memo_file.write("물 마시기\n")
  memo_file.write("장보기\n")

# ➋ 메모 파일 읽기
with open("memo.txt", "r", encoding="utf-8") as memo_file:
  # ➌ 파일 내용을 한 줄씩 꺼내기
  for memo in memo_file:
    print(memo)  # ➍ 읽은 줄 출력
```

**실행 결과**

```text
책 반납하기
```

**실행 결과**

```text
물 마시기
```

**실행 결과**

```text
장보기
```

❶ 실습에 사용할 메모 파일을 만드는 코드입니다. 파일을 쓰기 모드인 "w"로 열었기 때문에 같은 이름의 파일이 없다면 새로 만들고, 이미 있다면 기존 내용을 지운 뒤 새로 씁니다. 그 안에서 write( ) 메서드를 사용해 세 줄의 메모를 저장했습니다.

❷❶에서 만든 memo.txt 파일을 읽기 모드로 여는 코드입니다. 파일의 내용을 읽기만 할 것이므로 "r" 모드를 사용합니다.

❸ for memo in memo_file:이 파일 내용을 한 줄씩 꺼내는 반복문입니다. 첫 번째 반복에서는 "책 반납하기\n"가 memo 변수에 들어가고, 두 번째 반복에서는 "물 마시기\n"가 들어갑니다. 이런 식으로 마지막 줄인 "장보기\n"까지 읽고 나면 더 읽을 줄이 없으므로 반복이 끝납니다.

❹ print(memo)는 파일에서 읽어 온 한 줄을 화면에 출력합니다. 그런데 실행 결과를 보면 줄 사이가 한 줄씩 더 벌어져 있습니다. 그 이유는 파일에서 읽은 줄 끝에 이미 줄바꿈 문자 \n이 들어 있는데, print( ) 함수도 기본적으로 출력한 뒤 줄을 바꾸기 때문입니다.

정리하면 ❶ 파일을 만들고, ❷ 파일을 읽기 모드로 연 뒤, ❸ for 반복문으로 파일 내용을 한 줄씩 읽어 왔습니다. 그리고 ❹ print( )로 각 줄을 출력했습니다. 다만 파일에서 읽은 문자열에는 줄바꿈 문자가 포함될 수 있으므

![](/books/python-intro/p438-266.webp)

로, 출력 모양이 예상보다 벌어질 수 있다는 점을 기억해야 합니다.

그렇다면 각 줄 끝에 들어 있는 줄바꿈을 없애고 출력하려면 어떻게 하면 될까요?

### 줄바꿈을 정리하는 strip( )

앞의 실행 결과에서 줄 사이가 벌어진 이유는 파일에 저장된 각 줄 끝에 \n이 들어 있기 때문입니다. 우리가 파일에 내용을 쓸 때 "책 반납하기\n"처럼 줄바꿈 문자를 넣었으므로 파일에서 해당 줄을 읽어 오면 실제로는 "책 반납하기"만 들어오는 것이 아니라 "책 반납하기\n"처럼 줄바꿈 문자도 함께 포함됩니다. 이처럼 읽어 온 문자열의 앞뒤를 정리하고 싶을 때는 **기본 자료형**에서 배운 strip( )을 사용할 수 있습니다.

```python filename="09-15-memo_line_strip.py"
with open("memo.txt", "w", encoding="utf-8") as memo_file:
  memo_file.write("책 반납하기\n")
  memo_file.write("물 마시기\n")
  memo_file.write("장보기\n")

with open("memo.txt", "r", encoding="utf-8") as memo_file:
  for memo in memo_file:
    memo = memo.strip()  # ➊ 줄바꿈 제거
    print(memo)  # ➋ 정리한 줄 출력
```

**실행 결과**

```text
책 반납하기
물 마시기
장보기
```

❶ memo = memo.strip( )은 memo에 저장된 문자열의 앞뒤에 있는 공백 문자를 제거합니다. 줄바꿈 문자 \n도 공백 문자에 포함되므로 "책 반납하기\n"은 "책 반납하기"로 바뀝니다. 정리한 결과를 다시 memo 변수에 저장합니다.

❷ 그다음 print(memo)를 실행하면 끝에 있던 줄바꿈이 정리된 문자열 memo를 출력하므로 줄 사이가 불필요하게 벌어지지 않습니다.

read( )는 파일 전체 내용을 한 번에 읽어 오는 반면 for line in file:과 같은 방식은 파일 내용을 한 줄씩 읽어 옵니다. 둘 중 어느 방법이 무조건 더 좋다고 할 수는 없습니다. 파일 전체를 그대로 화면에 보여주고 싶다면 read( )가 간단합니다. 하지만 각 줄마다 번호를 붙이거나, 특정 줄만 골라 처리하거나, 줄마다 계산을 해야 한다면 한 줄씩 읽는 방식이 더 적절합니다.

![](/books/python-intro/p440-267.webp)

### readline( )으로 한 줄만 읽어보기

readline( )은 이름 그대로 현재 읽기 위치에서 한 줄을 읽어 오는 메서드입니다. 한 번 실행하면 한 줄을 읽고, 다시 실행하면 이어지는 다음 줄을 읽습니다. for 반복문이 파일의 내용을 차례대로 끝까지 반복하는 데 편리하다면, readline( )은 필요한 만큼 직접 한 줄씩 읽을 수 있다는 점이 다릅니다. 다음 코드를 실행하며 이해해봅시다.

```python filename="09-16-todo_readline.py"
# ➊ 할 일 파일 만들기
with open("todo.txt", "w", encoding="utf-8") as todo_file:
  todo_file.write("오늘의 할 일\n")
  todo_file.write("운동 30분\n")
  todo_file.write("도서관 가기\n")
  todo_file.write("방 청소하기\n")

# ➋ 파일 열기
with open("todo.txt", "r", encoding="utf-8") as todo_file:
  title = todo_file.readline().strip()  # ➌ 첫 번째 줄 읽기
  first_todo = todo_file.readline().strip()     # ➍ 두 번째 줄 읽기

print(f"제목: {title}")
print(f"첫 번째 할 일: {first_todo}")
```

**실행 결과**

```text
제목: 오늘의 할 일
첫 번째 할 일: 운동 30분
```

❶ todo.txt 파일을 만들고 네 줄의 내용을 저장합니다. 첫 번째 줄에는 "오늘의 할 일"이라는 제목을 넣고, 그 아래에는 실제 할 일을 한 줄씩 저장합니다.

❷ 파일을 읽기 모드로 열고, as todo_file을 통해 열린 파일 인스턴스를 todo_file이라는 이름으로 사용할 수 있습니다. with 문의 코드 블록이 끝나면 파일은 자동으로 닫힙니다.

❸ title = todo_file.readline( ).strip( )은 파일의 첫 번째 줄을 읽어 title 변수에 저장합니다.

readline( )으로 한 줄을 읽으면 파일에서 다음에 읽을 위치도 그만큼 앞으로 이동합니다. 따라서 다시 readline( )을 실행하면 첫 번째 줄이 아니라 그다음 내용을 이어서 읽게 됩니다.

![](/books/python-intro/p441-268.webp)

처음에는 파일을 읽을 위치가 맨 앞에 있습니다. 여기서 readline( )을 실행하면 첫 번째 줄을 읽습니다. 그 줄을 읽고 나면 다음 읽기는 그 뒤에서부터 이어집니다. 따라서 readline( )을 다시 실행하면 두 번째 줄을 읽게 됩니다.

❹ first_todo = todo_file.readline( ).strip( )은 이어지는 두 번째 줄을 읽어 first_todo 변수에 저장합니다.

정리하면 ❸ readline( )을 한 번 실행하면 현재 위치에서 한 줄을 읽고, ❹ 다시 실행하면 그다음 줄을 읽습니다. 다만 파일 전체를 끝까지 처리해야 한다면 readline( )을 여러 번 쓰기보다는 for 반복문을 사용하는 편이 더 간단합니다.

![](/books/python-intro/p441-269.webp)

한 줄씩 순서대로 처리하는 방법을 알아봤으니 이번에는 파일의 모든 줄을 리스트로 한꺼번에 가져오는 방법을 살펴보겠습니다.

### readlines( )로 모든 줄을 리스트로 읽어 오기

이번에는 readlines( ) 메서드를 알아보겠습니다. readlines( ) 메서드는 파일의 모든 줄을 읽어 각 줄을 요소로 갖는 리스트를 반환합니다. read( )가 파일 전체 내용을 하나의 문자열로 반환한다면, readlines( )는 각 줄을 나누어 리스트의 요소로 만든다는 점이 다릅니다. 예를 들어 score.txt 파일에 학생 세 명의 점수가 한 줄씩 들어 있다면 readlines( )는 다음과 같은 리스트를 반환합니다.

- ['바로: 85점\n', '요즘: 92점\n', '하나: 78점\n']

예제처럼 각 줄이 줄바꿈으로 끝난 경우에는 문자열 끝에 \n이 포함됩니다. 따라서 필요한 경우 strip( )을 사용해 문자열 앞뒤의 공백 문자를 정리할 수 있습니다.

```python filename="09-17-score_readlines.py"
# ➊ 점수 파일 만들기
with open("score.txt", "w", encoding="utf-8") as score_file:
  score_file.write("바로: 85점\n")
  score_file.write("요즘: 92점\n")
  score_file.write("하나: 78점\n")

# ➋ 모든 줄을 리스트로 읽기
with open("score.txt", "r", encoding="utf-8") as score_file:
  scores = score_file.readlines()

print(scores)   # ➌ 리스트 그대로 출력

# ➍ 리스트에 들어 있는 줄을 하나씩 출력
for score in scores:
  score = score.strip()
  print(f"점수 정보: {score}")
```

**실행 결과**

```text
['바로: 85점\n', '요즘: 92점\n', '하나: 78점\n']
점수 정보: 바로: 85점
점수 정보: 요즘: 92점
점수 정보: 하나: 78점
```

❶ score.txt 파일을 만들고 학생 세 명의 점수를 저장했습니다. 한 줄에 학생 한 명의 점수 정보가 들어 있습니다. 이렇게 정보가 줄 단위로 나뉘어 있으면 리스트로 읽어 온 뒤에도 다루기 좋습니다.

❷ readlines( )를 사용해 파일의 모든 줄을 읽어 리스트로 저장합니다.

❸ 리스트를 그대로 출력합니다. 실행 결과를 보면 각 줄 끝에 \n이 붙어 있는 것을 확인할 수 있습니다. 이는 예제 파일의 각 줄이 줄바꿈 문자로 끝나기 때문입니다.

❹ for score in scores:는 리스트에 들어 있는 줄을 하나씩 꺼내는 반복문입니다. 앞에서 파일 인스턴스 자체를 반복한 것과 모습은 비슷하지만 파일을 읽는 시점이 다릅니다.

```python
with open("memo.txt", "r", encoding="utf-8") as memo_file:
  for memo in memo_file:
    memo = memo.strip()  # 줄바꿈 제거
    print(memo)          # 정리한 줄 출력
...생략...
```

파일 인스턴스를 직접 for 문으로 반복하면 파일에서 내용을 차례대로 읽으면서 처리합니다. 반면 readlines( )를 사용하면 먼저 파일의 모든 줄을 리스트로 읽어 온 뒤, 만들어진 리스트를 반복합니다. 그런 다음 각 줄을 strip( )으로 정리한 뒤 출력하면 불필요한 줄바꿈 없이 결과를 확인할 수 있습니다.

정리하면 ❷ readlines( )는 파일의 모든 줄을 리스트로 읽어 오고, ❹ 그 리스트를 반복문으로 처리할 수 있게 해줍니다. 파일 내용을 리스트 형태로 보관해두고 여러 번 사용해야 한다면 readlines( ) 가 편할 수 있습니다. 하지만 단순히 한 번만 순서대로 처리할 거라면 for line in file: 방식이 더 간단하고, 큰 파일을 다룰 때도 유리할 수 있습니다.

이제 파일의 전체 내용을 읽는 방법부터 한 줄씩 처리하는 방법까지 알아봤습니다. 다음에는 지금까지 배운 사용자 입력과 파일 입출력을 함께 활용해 작은 프로그램을 만들어보겠습니다.

> - 파일에서 읽은 문자열의 앞뒤 공백이나 줄바꿈을 정리할 때는 strip( )을 사용할 수 있습니다.
> - readline( )은 현재 읽기 위치에서 한 줄을 읽고, 다시 호출하면 이어지는 다음 줄을 읽습니다.
> - readlines( )는 파일의 모든 줄을 읽어 각 줄을 요소로 갖는 리스트를 반환합니다.
