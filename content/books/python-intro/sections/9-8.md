## 객관식 문제

01 파일을 열 때 사용하는 모드에 대한 설명으로 옳지 않은 것을 고르세요.

① "w" 모드는 파일이 없으면 새로 만듭니다.

② "w" 모드는 파일이 이미 있으면 기존 내용을 모두 지우고 새로 씁니다.

③ "a" 모드는 기존 내용 뒤에 이어서 씁니다.

④ "r" 모드는 파일이 없으면 새로 만들어 줍니다.

02 다음 코드에 대한 설명으로 알맞은 것을 고르세요.

```python
with open("memo.txt", "w", encoding="utf-8") as file:
  file.write("첫 번째 메모")
```

① 파일을 닫는 close( ) 메서드를 따로 호출해야 합니다.

② with 문의 코드 블록이 끝나면 파일이 자동으로 닫힙니다.

③ memo.txt에 이미 내용이 있어도 그대로 남아 있습니다.

④ 터미널에 첫 번째 메모가 출력됩니다.

03 파일 전체 내용을 하나의 문자열로 읽어 오는 메서드를 고르세요.

① read( )

② readline( )

③ readlines( )

④ write( )

04 readlines( ) 메서드에 대한 설명으로 알맞은 것을 고르세요.

① 파일의 첫 줄만 문자열로 돌려줍니다.

② 파일의 모든 줄을 하나의 문자열로 이어 붙여 돌려줍니다.

③ 파일의 각 줄을 요소로 담은 리스트를 돌려줍니다.

④ 파일에 여러 줄을 한 번에 씁니다.

05 파일을 한 줄씩 읽어 출력했더니 줄 사이가 한 줄씩 더 벌어졌습니다. 그 이유로 알맞은 것을 고르세요.

① 읽어 온 줄 끝에 줄바꿈 문자 \n이 남아 있는데 print( ) 함수도 자동으로 줄을 바꾸기 때문입니다.

② 파일에 빈 줄이 함께 저장되어 있기 때문입니다.

③ encoding="utf-8"을 적지 않았기 때문입니다.

④ readline( ) 대신 read( )를 사용했기 때문입니다.

06 input( ) 함수에 대한 설명으로 옳지 않은 것을 고르세요.

① 사용자가 입력한 값을 돌려줍니다.

② 사용자가 숫자를 입력해도 문자열로 돌려줍니다.

③ 입력받은 값으로 계산하려면 int( )나 float( ) 함수로 바꿔야 합니다.

④ 사용자가 숫자를 입력하면 자동으로 정수로 바꿔 돌려줍니다.

## 주관식 문제

07 다음은 파일을 한 줄씩 읽어 줄 끝의 줄바꿈 문자를 없애고 출력하는 코드입니다. 빈칸에 들어갈 메서드 이름을 쓰세요. memo.txt에는 책 반납하기와 물 마시기가 각각 한 줄씩 저장되어 있습니다.

```python
with open("memo.txt", "r", encoding="utf-8") as file:
  for line in file:
    print(line.____())
```

with open("memo.txt", "____", encoding="utf-8") as file:
  file.write("새로운 메모\n")
