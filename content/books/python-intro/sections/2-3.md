앞서 배운 변수를 직접 손으로 연습해볼 차례입니다. 변수에 값을 저장하고, 바꾸고, 출력하는 과정을 반복하다 보면 변수의 개념을 자연스럽게 익힐 수 있을 겁니다.

> **미리 알아두세요!**
>
> - 변수에 값을 저장할 때는 = 기호를 사용합니다.
> - print() 함수와 f-str ing으로 변수에 저장된 값을 확인할 수 있습니다.

## 변수에 문자열 할당하고 출력하기

먼저 변수에 문자열을 저장(할당)하고 출력하는 연습을 해봅니다. 앞에서 자주 했고 가장 기본이 되는 코드이므로 어렵지 않을 겁니다.

```python
>>> name = "바로"
>>> print(name)
```

**실행 결과**

```text
바로
```

## 변수에 숫자 할당하고 확인하기

변수에는 문자열뿐만 아니라 숫자 값도 할당할 수 있습니다.

```python
>>> age = 20
>>> print(age)
```

## 변수에 값 저장하고 계산하기

변수에 저장된 값을 이용해 간단한 덧셈 계산을 해봅시다. 변수와 값을 활용해 계산 및 비교를 할 때 사용하는 기호를 연산자라고 합니다. 연산자에는 사칙연산 외에도 다양한 종류가 있으며, 이어지는 내용에서 차차 배우겠습니다. 지금은 변수를 사용하는 방법에만 집중합시다.

```python
>>> a = 10
>>> b = 5
>>> result = a + b
>>> print(result)
```

a와 b에 각각 값을 담은 뒤, 두 변수를 더한 결과를 result 변수에 담았습니다. 직관적인 구조라 이해하기 어렵지 않을 겁니다. 다만 코드에서 사용하는 =는 수학에서 사용하는 =와 의미가 달라 어색할 수 있습니다. 수학에서 =는 '양변이 같다'라는 뜻이지만 프로그래밍에서 **=는 오른쪽 계산 결괏값을 왼쪽 변수에 할당(대입)한다**는 의미가 있습니다.

> **NOTE**
>
> 파이썬을 비롯한 많은 프로그래밍 언어에서는 '같다'를 등호 2개인 ==로 표시합니다.

## 변수에 할당한 값 변경하고 확인하기

변수에 할당된 값은 언제든 바꿀 수 있습니다. 다음은 score 변수에 80을 할당해 출력한 뒤 다른 값을 재할당하여 출력하는 예입니다. 새로운 값을 재할당했으니 이전에 할당했던 80은 사라지고 90으로 덮어씌워집니다.

```python
>>> score = 80
>>> print(score)
```

**실행 결과**

```text
>>> score = 90
>>> print(score)
```

## 문자열과 숫자 더하기

student, grade 변수에 각각 문자열과 숫자를 저장한 후 print( ) 함수로 출력하는 예입니다. **변수에 값 저장하고 계산하기**에서는 숫자끼리 더했을 때 덧셈 결과가 나왔습니다. 그럼 문자열과 숫자를 더하면 어떻게 될까요?

```python
>>> student = "민수"
>>> grade = 85
>>> print(student + "의 점수: " + grade + "점")
```

**실행 결과**

```text
Traceback (most recent call last):
  File "<python-input-2>", line 1, in <module>
    print(student + "의 점수: " + grade + "점")
          ~~~~~~~~~~~~~~~~~~~~~~^~~~~~~
TypeError: can only concatenate str (not "int") to str
```

복잡한 결과가 보입니다. 이는 오류가 발생했다는 뜻입니다. 문자열과 숫자를 더할 수 없다는 뜻입니다. 이처럼 파이썬은 변수에 담긴 값의 종류에 따라 처리를 다르게 합니다. 만약 문자열과 숫자를 더해서 합쳐진 문자열을 만들고 싶다면 다음과 같이 작성해야 합니다.

> **NOTE**
>
> str( ) 함수는 괄호 안의 값을 문자열로 변환해주는 함수입니다. 함수의 사용 방법은 나중에 자세히 배웁니다. 지금은 그

냥 따라 입력하세요.

```python
>>> student = "민수"
>>> grade = 85
>>> print(student + "의 점수: " + str(grade) + "점")
```

**실행 결과**

```text
민수의 점수: 85점
```

이처럼 + 기호로 문자열과 숫자를 연결해서 문장을 출력하려면 앞의 코드처럼 큰따옴표 구분과 + 기호를 여러 번 사용하여 코드를 작성해야 합니다. + 기호를 세 번이나 써야 하는 불편함도 있지만 이제 막 파이썬을 시작한 초보자 입장에서는 큰따옴표를 어디서 닫고 열어야 할지 파악하기가 쉽지 않습니다. 그러면 어떻게 해야 문자열과 숫자를 편하게 합쳐서 출력할 수 있을까요?

## 변수에 할당한 값 f-string으로 출력하여 확인하기

파이썬 문법은 프로그래밍을 할 때 '불편하고 귀찮은 작업'을 줄여주는 방향으로 발전해왔습니다. 그 결과물 중 하나가 바로 **f-string**입니다. f-string은 큰따옴표로 감싼 문자열 앞에 f를 붙이고, 그 안에서 변수나 표현식을 중괄호로 감싸 표현하는 방식입니다. 처음 f-string을 접할 때는 복잡하게 느껴질 수 있지만 익숙해지면 오히려 이 방식이 직관적이고 편리하다는 걸 알 수 있습니다.

![](/books/python-intro/p079-062.webp)

```python
>>> student = "민수"
>>> grade = 85
>>> print(f"{student}의 점수: {grade}점")
```

**실행 결과**

```text
민수의 점수: 85점
```

코드를 보면 f"와 " 사이에 일반 문자 또는 {student}, {grade}와 같은 변수를 사용한 것을 알 수 있습니다. 이것들이 자연스럽게 어우러져 하나의 문자열을 이루는 겁니다. 매번 변수의 값을 문자열과 합치기 위해 + 기호나 큰따옴표로 감싼 문자열을 중간중간 넣는 것보다 이것이 훨씬 보기도 편하고 사용하기도 편합니다. 따라서 이 책에서는 f-string을 적극적으로 사용하겠습니다.

![](/books/python-intro/p079-063.webp)

> **바로 핵심 요약**
>
> - 변수에 문자열과 숫자를 각각 할당하고 print( ) 함수로 출력해보았습니다.
> - 이미 할당된 변수의 값을 새로운 값으로 바꾸거나 여러 변수를 동시에 다뤄보았습니다.
> - + 기호를 사용한 문자열 연결 방식과 f-string으로 변수 값을 문장 안에 넣어 출력하는 방법을 익히고 차이를 이해합니다.
