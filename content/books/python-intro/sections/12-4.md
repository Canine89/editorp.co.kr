for 문을 배울 때 '이터러블'이라는 말이 나왔습니다. 당시에는 '반복하면서 값을 하나씩 꺼낼 수 있는 것' 정도로만 설명하고 자세한 이야기는 뒤로 미뤄두었죠. 이제 그 약속을 지킬 차례입니다. 이번 절에서는 for 문이 내부에서 어떤 방식으로 값을 하나씩 꺼내는지 살펴보고, 값을 미리 모두 만들어두지 않고 필요할 때 하나씩 만들어 내보내는 제너레이터까지 알아보겠습니다.

> **미리 알아두세요!**
>
> - 이터러블은 값을 하나씩 꺼내 줄 수 있는 것을 말합니다.
> - yield를 쓰면 값을 미리 만들지 않는 제너레이터가 됩니다.

## 이터러블이란?

지금까지 for 문에 넣어본 것들을 떠올려봅시다. 리스트, 튜플, 문자열, 딕셔너리, 집합, range( ) 등이 있었습니다. 자료형도 다르고 생김새도 다르지만 한 가지 공통점이 있습니다. 반복하면서 값을 하나씩 꺼낼 수 있다는 것입니다. **이처럼 for 문과 같은 반복 작업에서 값을 하나씩 꺼낼 수 있는 인스턴스를 이터러블이라고 합니다.**

![](/books/python-intro/p567-346.webp)

이터러블을 우리말로 굳이 옮기면 '반복할 수 있는 것' 정도가 됩니다. 용어만 들으면 조금 막연할 수 있으니 익숙한 코드부터 다시 살펴봅시다.

```python filename="12-19-iterable.py"
numbers = [10, 20, 30]

for number in numbers:          # ➊ 리스트는 이터러블
  print(number)

for char in "파이썬":            # ➋ 문자열도 이터러블
  print(char)
```

**실행 결과**

```text
10
20
30
파
이
썬
```

❶ 리스트에서 요소를 하나씩 꺼냈습니다.

❷ 문자열에서는 글자를 하나씩 꺼냈습니다. 자료형은 서로 다르지만 for 문의 입장에서는 둘 다 값을 하나씩 꺼내 반복할 수 있는 대상입니다.

실행 결과만 보면 앞에서 반복문을 공부할 때와 달라진 것이 없어 보입니다. 실제로 작성한 코드도 이미 익숙하지요. 이번에 살펴볼 것은 결과가 아니라 그 결과가 만들어지는 내부 과정입니다. 리스트의 요소를 for 문이 어떻게 하나씩 꺼낼 수 있었던 걸까요? 지금부터 그 과정을 한 단계 더 안쪽으로 들어가 살펴보겠습니다.

## for 문 안에서 도대체 어떤 일이 벌어졌을까?

그렇다면 for 문에서는 리스트나 문자열에서 어떻게 값을 하나씩 꺼낼까요? 사실 for 문이 리스트나 문자열의 값을 직접 하나씩 꺼내는 것은 아닙니다. for 문은 먼저 반복할 대상으로부터 값을 하나씩 꺼내는 역할을 하는 인스턴스를 얻습니다. 이것이 이터레이터입니다. 직접 이터레이터를 만들어 값을 하나씩 꺼내보면 for 문의 동작을 이해하기가 훨씬 쉽습니다.

```python filename="12-20-iter_next.py"
numbers = [10, 20, 30]
it = iter(numbers)          # ➊ 값을 꺼내 줄 담당자 이터레이터 받기

print(next(it))             # ➋ 하나 꺼내기
print(next(it))
print(next(it))
```

**실행 결과**

```text
10
20
30
```

❶ iter( ) 함수에 리스트를 넣으면 이터레이터를 반환합니다. 이제부터는 이터레이터가 리스트의 값을 하나씩 꺼내줄 겁니다.

❷ next( ) 함수에 이터레이터를 전달하면 다음 값을 하나 꺼냅니다. next( )를 다시 호출할 때마다 그다음 값으로 이동합니다. 결국 for 문은 우리가 직접 iter( )와 next( )를 반복해서 호출하지 않아도 되도록 이 과정을 대신 처리해주는 셈입니다. 또한 더 꺼낼 값이 없는데 next( )를 호출하면 StopIteration이라는 예외가 발생합니다. for 문은 이를 내부적으로 처리해 반복을 자연스럽게 끝냅니다.

이처럼 이터레이터는 한 번 값을 꺼내면 그 위치를 기억하며 앞으로 이동합니다. 따라서 리스트처럼 다시 순회할 수 있는 이터러블이라면 iter( )로 새 이터레이터를 얻어 처음부터 시작할 수 있습니다. 제너레이터처럼 그 자체가 이터레이터인 대상은 새로운 이터레이터를 얻어 다시 시작해야 합니다.

![](/books/python-intro/p570-347.webp)

그림을 보면 리스트에 iter( ) 함수를 사용해서 이터레이터를 만들고 next( )를 호출해 값을 순서대로 뽑는 모습이 보입니다. 코드와 그림을 보면서 이터레이터의 콘셉트를 이해하고 넘어가기 바랍니다.

## 값을 미리 만들지 않는 함수, yield

이번에는 조금 다른 상황을 생각해봅시다. 프로그램에서 아주 많은 값을 차례대로 사용해야 한다고 가정해보겠습니다. 값을 모두 리스트에 만들어 저장하면 리스트가 커지는 만큼 메모리도 더 필요합니다. 데이터가 많아질수록 한꺼번에 모든 값을 만들어두는 방식이 부담스러워질 수도 있습니다. 꼭 모든 값을 처음부터 만들어둘 필요가 없다면 어떨까요? 필요한 순간에 값을 하나씩 만들어 사용하고 지나갈 수 있다면 한꺼번에 많은 값을 저장하지 않아도 됩니다.

![](/books/python-intro/p570-348.webp)

이러한 방식으로 값을 만들어낼 때 활용할 수 있는 것이 제너레이터 입니다. 제너레이터 함수에서는 yield라는 키워드를 사용합니다. yield가 무엇인지는 우선 코드를 작성해서 실행한 뒤에 설명하겠습니다.

```python filename="12-21-generator.py"
def countdown(n):
  print("함수 안으로 들어왔습니다")       # 함수가 실행되는 순간 확인용
  while n > 0:
    yield n                             # ➊ yield가 있으면 제너레이터가 됨
    print("멈췄던 자리에서 이어집니다")    # 이어서 실행되는지 확인용
    n = n - 1

counter = countdown(3)                  # ➋ 함수를 불렀는데 아무것도 출력되지 않음
print("제너레이터를 만들었습니다")

print(next(counter))                    # ➌ 이제야 함수 안이 실행됨
print(next(counter))
print(next(counter))
```

**실행 결과**

```text
제너레이터를 만들었습니다
함수 안으로 들어왔습니다
3
멈췄던 자리에서 이어집니다
2
멈췄던 자리에서 이어집니다
1
```

❶ 함수 안에 yield가 들어 있으면 이 함수는 제너레이터 함수가 됩니다. 제너레이터 함수를 호출하면 일반적인 함수처럼 함수 본문을 바로 끝까지 실행하는 것이 아니라 제너레이터 인스턴스를 반환합니다.

❷ 따라서 countdown(3)을 호출한 순간에는 제너레이터 인스턴스가 만들어질 뿐, 함수 본문의 코드는 아직 실행되지 않습니다.

❸ next( )를 처음 호출하면 그제야 함수 본문의 실행이 시작됩니다. 먼저 print("함수 안으로 들어왔습니다")가 실행되고, yield를 만나면 값 3을 내보낸 뒤 그 자리에서 실행을 잠시 멈춥니다. 이후 next( )를 호출할 때마다 멈췄던 자리부터 이어서 실행하다가 다음 yield에서 다시 멈춥니다. 직접 next( )를 여러 번 호출해도 되지만, 이 과정은 다음과 같이 for 문에 맡길 수 있습니다.

```python filename="12-22-generator_for.py"
def countdown(n):
  while n > 0:
    yield n
    n = n - 1

for number in countdown(3):    # ➊ for 문이 next()를 대신 불러줌
  print(number)
```

**실행 결과**

```text
3
2
1
```

❶ 코드에서는 next( )를 직접 호출하지 않았지만 값이 하나씩 나옵니다. for 문이 제너레이터에서 값을 차례대로 꺼내주기 때문입니다.

이제 값을 모두 리스트로 만들어 반환하는 함수와 제너레이터를 나란히 비교해봅시다.

```python filename="12-23-list_vs_generator.py"
def make_list(n):
  result = []
  for i in range(1, n + 1):
    result.append(i)
  return result            # ➊ 전부 만들어 한 번에 돌려주기

def make_generator(n):
  for i in range(1, n + 1):
    yield i                # ➋ 필요할 때 하나씩 내보내기

print(make_list(5))
print(make_generator(5))
print(list(make_generator(5)))   # ➌ 리스트로 바꿔 보기
```

**실행 결과**

```text
[1, 2, 3, 4, 5]
<generator object make_generator at 0x000001A2B3C4D5E0>
[1, 2, 3, 4, 5]
```

❶ make_list( )는 필요한 값을 모두 만든 뒤 하나의 리스트에 담아 반환합니다.

❷ make_generator( )를 호출하면 값을 모두 미리 만들어놓는 대신 제너레이터 인스턴스가 만들어집니다. 따라서 제너레이터 자체를 출력하면 리스트가 아니라 <generator object ...>와 같은 낯선 결과가 보입니다.

❸ 제너레이터를 list( ) 함수에 전달하면 제너레이터의 값을 끝까지 하나씩 꺼내 새로운 리스트로 만듭니다. 그제야 우리에게 익숙한 리스트 형태로 결과를 확인할 수 있습니다.

![](/books/python-intro/p573-349.webp)

> **NOTE**
>
> 제너레이터 인스턴스를 그대로 출력했을 때 보이는 0x... 형태의 값은 실행 환경이나 실행할 때마다 달라질 수 있습니

다. 책의 결과와 정확히 같지 않아도 괜찮습니다.

## 제너레이터 표현식

제너레이터를 만드는 방법은 함수와 yield만 있는 것이 아닙니다. 앞에서 배운 리스트 내포와 비슷한 형태로 간단하게 만들 수도 있습니다. 리스트 내포를 떠올려보세요. 대괄호([ ])를 사용한 리스트 내포와 비슷한 식을 소괄호(( ))로 작성하면 제너레이터 표현식이 됩니다.

```python filename="12-24-generator_expression.py"
numbers = [1, 2, 3, 4, 5]

squares_list = [n * n for n in numbers]    # ➊ 리스트 내포
squares_gen = (n * n for n in numbers)     # ➋ 제너레이터 표현식

print(squares_list)
print(squares_gen)
print(list(squares_gen))
```

**실행 결과**

```text
[1, 4, 9, 16, 25]
<generator object <genexpr> at 0x000001A2B3C4D5E0>
[1, 4, 9, 16, 25]
```

❶ 리스트 내포는 계산한 값을 모두 만들어 리스트에 담습니다.

❷ 제너레이터 표현식은 값을 모두 담은 리스트를 바로 만드는 대신, 필요할 때 값을 하나씩 만들어 내보낼 수 있는 제너레이터를 만듭니다. 괄호 모양 하나로 성격이 완전히 달라지는 셈입니다.

제너레이터는 여기까지만 알아도 충분합니다. 지금 단계에서는 '값을 미리 모두 만들어두지 않고 필요할 때 하나씩 만들어 내보낼 수 있다' 는 특징을 이해해두세요. 앞으로 다른 사람의 코드에서 yield나 제너레이터 표현식을 만났을 때 어떤 역할인지 알아볼 수 있으면 됩니다.

## 이터러블, 제너레이터, yield 연습하기

지금까지 for 문 뒤에서 동작하는 이터레이터와 필요할 때 값을 만들어내는 제너레이터를 살펴봤습니다. 짧은 코드를 직접 실행하며 각각의 특징을 다시 확인해봅시다.

## 연습 01 iter( )와 next( )로 하나씩 꺼내기

과일 목록에서 값을 하나씩 직접 꺼내봅시다. for 문이 내부에서 처리하는 과정을 직접 해보는 셈입니다.

```python filename="12-25-iter_practice.py"
fruits = ["사과", "바나나", "딸기"]
it = iter(fruits)           # ➊ 이터레이터 받기

print(next(it))             # ➋ 값 꺼내기
print(next(it))
print(next(it))
```

**실행 결과**

```text
사과
바나나
딸기
```

❶ iter( ) 함수를 사용해 리스트를 순회할 이터레이터를 얻습니다.

❷ next( ) 함수에 이터레이터를 전달해 값을 하나씩 꺼냅니다. 모든 값을 꺼낸 뒤 next( )를 한 번 더 호출하면 더 이상 꺼낼 값이 없으므로 StopIteration 예외가 발생합니다. for 문을 사용할 때 이 오류를 볼 수 없었던 것은 for 문이 이 상황을 처리하고 반복을 자동으로 끝내기 때문입니다.

## 연습 02 yield로 짝수만 내보내기

1부터 정해진 수까지 확인하면서 짝수만 내보내는 제너레이터 함수를 만들어봅시다.

```python filename="12-26-yield_practice.py"
def even_numbers(limit):
  for n in range(1, limit + 1):
    if n % 2 == 0:
      yield n               # ➊ 짝수일 때만 내보내기

for number in even_numbers(10):
  print(number)
```

**실행 결과**

```text
2
4
6
8
10
```

❶ 값이 홀수라면 yield를 실행하지 않고 다음 반복으로 넘어갑니다. 짝수일 때만 yield로 값을 하나씩 내보냅니다.

이처럼 제너레이터 함수 안에서도 조건문을 사용해 필요한 값만 골라 내보낼 수 있습니다.

## 연습 03 제너레이터는 한 번만 쓸 수 있습니다

제너레이터 인스턴스의 값을 모두 꺼낸 뒤 다시 사용하면 어떻게 되는지 확인해봅시다. 처음 제너레이터를 사용할 때 당황하기 쉬운 특징입니다.

```python filename="12-27-generator_once.py"
scores = [80, 90, 100]
bonus = (score + 5 for score in scores)   # ➊ 제너레이터 표현식

print(list(bonus))
print(list(bonus))                        # ➋ 한 번 더
```

**실행 결과**

```text
[85, 95, 105]
[]
```

❶ 점수마다 5점을 더해 내보내는 제너레이터를 만들었습니다.

❷ 첫 번째 list( )에서 제너레이터의 값을 끝까지 모두 꺼냈기 때문에 두 번째 list( )의 결과는 빈 리스트가 됩니다. 제너레이터는 한 번 꺼낸 값을 다시 꺼낼 수 없습니다.. 여러 번 써야 한다면 처음부터 리스트로 만들어두는 편이 낫습니다.

> **바로 핵심 요약**
>
> - 이터러블은 반복하면서 값을 하나씩 꺼낼 수 있는 인스턴스이며, for 문은 내부적으로 이터레이터를 이용해 값을 차례대로 꺼냅니다.
> - iter( )로 이터레이터를 얻을 수 있고, next( )를 사용하면 이터레이터에서 다음 값을 하나씩 꺼낼 수 있습니다.
> - 함수 안에 yield가 있으면 제너레이터 함수가 되며, 호출하면 제너레이터 인스턴스가 만들어집니다. 제너레이터는 실행을 멈췄다가 다시 이어가면서 값을 하나씩 내보낼 수 있습니다.
> - 리스트 내포의 대괄호를 소괄호로 바꾸면 제너레이터 표현식이 되며, 값을 한 번 꺼내면 다시 꺼낼 수 없습니다.
