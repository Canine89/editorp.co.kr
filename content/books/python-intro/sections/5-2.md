드디어 프로그램의 흐름을 다루는 제어문을 시작합니다. 우선 제어문의 기본 문법 중 하나인 if 문부터 시작해봅시다.

> **미리 알아두세요!**
>
> - if 문은 조건에 따라 코드 실행 여부를 결정하는 제어문입니다.
> - 조건이 여러 개라면 if~else 문, if~elif~else 문으로 갈래를 나눕니다.

## 트롤리 딜레마로 이해하는 if 문

if 문은 앞에서 살짝 살펴봤습니다. 그때는 if 문을 문지기처럼 설명했죠. 하지만 if 문의 역할을 이해하려면 문지기보다 열차의 선로를 바꾸는 레버를 떠올리는 것이 좋습니다. 다음은 《정의란 무엇인가》라는 도서에도 소개된 유명한 사고 실험인 트롤리 딜레마입니다. 여기서는 윤리적인 문제가 아니라 레버 하나로 이동할 길이 달라진다는 구조만 빌려오겠습니다. 이때 선로를 바꾸는 레버가 if 문과 비슷한 역할을 합니다.

![](/books/python-intro/p216-146.webp)

선로 옆에 서 있는 사람이 레버를 당겨 열차의 방향을 결정합니다. 레버를 그대로 두면 트롤리가 직진하고, 레버를 당기면 선로를 바꿔 아래로 향합니다. 이렇게 코드의 흐름을 결정하는 것이 if 문입니다. 이 개념을 머릿속에 넣어두고 기초 문법부터 응용까지 쭉 알아봅시다.

## if 문 구조 알아보기

**if 문은 조건에 따라 코드를 실행할지 말지 결정하는 제어문입니다.** if 문의 기본 구조는 다음과 같습니다.

```python
if 조건식:
  들여쓰기한 코드
  들여쓰기한 코드
  들여쓰기한 코드
```

if와 콜론 사이에 조건식을 입력하고, 콜론(:)으로 조건식의 끝을 표시한 후 다음 줄부터 일정하게 들여쓰기하여 실행할 코드를 입력합니다. 이때 들여쓰기로 묶인 코드는 코드 블록이라고 합니다. 코드 블록은 잠시 뒤에 자세히 알아보고, 먼저 조건식부터 살펴봅시다.

if 문의 조건식은 참(True) 또는 거짓(False)으로 평가됩니다. 다음 코드를 봅시다. 코드에 하이라이트로 표시한 부분이 조건식입니다. temperature 변수의 값과 25를 >= 연산자로 비교합니다. 기초적인 수학 지식이 있다면 이 조건식의 결과가 True라는 것을 직관적으로 알 수 있습니다.

> **NOTE**
>
> >=, ==, < 처럼 두 값을 비교하는 연산자를 비교 연산자라고 합니다. 비교 연산자로 두 값을 비교하면 그 결과는 True 또

는 False가 됩니다. ‘크다/작다/같다’와 같은 비교는 맞거나 틀리거나 둘 중 하나로 답이 정해지기 때문이죠. 이런 성질 덕분에 비교 연산을 if 문의 조건식에 사용할 수 있습니다.

```python filename="05-01-air_conditioner_if.py"
temperature = 35

if temperature >= 25:
  print("에어컨을 켭니다")
  print("시원하게 보내세요")
```

**실행 결과**

```text
에어컨을 켭니다
시원하게 보내세요
```

실제로 코드를 실행해봅시다. temperature의 값이 35이므로 temperature >= 25라는 조건식은 35 >= 25로 계산되며, 그 결과는 True입니다. 따라서 들여쓰기한 if 문의 코드 블록이 실행됩니다.

## 코드 블록 개념 알아보기

**앞에서 언급했듯이 : 다음 줄부터 일정하게 들여쓰기한 코드의 묶음을 코드 블록이라고 합니다.** if 문에서는 조건식의 결과에 따라 이 코드 블록을 실행할지 결정합니다.

![](/books/python-intro/p218-147.webp)

예를 들어 다음과 같이 코드를 작성하면 첫 번째 if 문의 코드 블록과 두 번째 if 문의 코드 블록은 별개입니다. 다음 코드에서는 각각의 코드 블록을 하이라이트로 표시했습니다.

```python filename="05-02-if_code_blocks.py"
x = 6
# 첫 번째 if 문의 코드 블록
if x > 0:
  print("양수입니다")  # 이 줄과
  print("0보다 큽니다")  # 이 줄이 하나의 블록

# 두 번째 if 문의 코드 블록
if x > 5:
  print(f"x의 값은 {x}입니다")  # 이 줄과
  print("5보다 큽니다")  # 이 줄이 또 하나의 블록
```

**실행 결과**

```text
양수입니다
0보다 큽니다
x의 값은 6입니다
5보다 큽니다
```

같은 코드 블록에 속하는 코드는 같은 수준으로 들여쓰기해야 합니다. 들여쓰기란 코드 앞에 삽입하는 띄어쓰기나 탭(Tab)을 말합니다. 파이썬에서는 띄어쓰기 4칸을 권장합니다. 2칸이나 3칸으로 들여쓰기해도 간격이 같으면 같은 코드 블록으로 간주하지만, 띄어쓰기 4칸을 지키는 습관을 기르기 바랍니다. 사람 눈에는 같은 수준으로 들여쓰기한 것처럼 보여도 파이썬 인터프리터는 탭과 띄어쓰기를 서로 다르게 처리하므로 오류가 발생할 수 있습니다. 앞으로 if 문을 비롯한 다양한 문법에서 들여쓰기와 코드 블록을 계속 사용하므로 자연스럽게 익숙해질 것입니다.

## if~else 문 구조 알아보기

앞에서 공부한 if 문은 조건식이 True일 때 코드 블록을 실행했습니다. if 문을 설명할 때 트롤리 딜레마 그림을 예로 들었지만, 사실 if 문만으로는 그림의 상황과 정확히 들어맞지 않습니다. if 문만 사용하면 조건식이 True일 때 실행할 코드만 지정하기 때문입니다. **만약 조건식이 False일 때 실행할 코드까지 지정하려면 else 문을 함께 사용하면 됩니다.**

```python filename="05-03-age_access_if_else.py"
age = 15

if age >= 18:
  print("성인입니다. 입장 가능합니다.")
else:
  print("미성년자입니다. 입장이 제한됩니다.")
```

**실행 결과**

```text
미성년자입니다. 입장이 제한됩니다.
```

age가 15이므로 if 문의 조건식은 False입니다. 따라서 if 문의 코드 블록은 실행하지 않고 else 문의 코드 블록을 실행합니다.

![](/books/python-intro/p219-148.webp)

```python
age = 15
if age >= 18:
    print("성인입니다. 입장 가능합니다.")
else:
    print("미성년자입니다. 입장이 제한됩니다.")
```

![](/books/python-intro/p220-149.webp)

그러면 ‘if 문만 사용하고 print("미성년자입니다. 입장이 제한됩니다.")는 if 문 바깥으로 빼면 안 될까?’라고 생각할 수도 있습니다. 좋은 질문입니다. 현재처럼 age가 15일 때는 방금 작성한 if~else 문과 같은 결과가 나옵니다.

```python filename="05-04-age_access_if_only_minor.py"
age = 15

if age >= 18:

print("미성년자입니다. 입장이 제한됩니다.")
```

**실행 결과**

```text
미성년자입니다. 입장이 제한됩니다.
```

언뜻 보면 코드를 이렇게 작성해도 될 것 같습니다. 하지만 age를 20으로 바꿔서 실행해보면 문제가 드러납니다.

```python filename="05-05-age_access_if_only_adult.py"
age = 20

if age >= 18:
```

**실행 결과**

```text
성인입니다. 입장 가능합니다.
미성년자입니다. 입장이 제한됩니다.
```

age가 20이면 조건식을 만족하므로 if 문의 코드 블록이 실행됩니다. 하지만 if 문 바깥에 있는 코드는 조건식의 결과와 관계없이 실행되므로, 결국 두 메시지가 모두 출력됩니다.

![](/books/python-intro/p221-150.webp)

```python
age = 20
if age >= 18:
    print("성인입니다. 입장 가능합니다.")
print("미성년자입니다. 입장이 제한됩니다.")
```

실행 결과를 보면 ❶ 조건식을 만족해 True가 되므로 ❷ 조건식의 코드 블록을 실행하고, ❸ 조건식과 무관한 코드도 실행됩니다.

![](/books/python-intro/p221-151.webp)

### if~else 문으로 배송비 계산 프로그램 만들기

if~else 문은 실생활의 다양한 판단 상황을 프로그램으로 만들 때 유용합니다. 이번에는 좀 더 실용적인 예제로 연습해보겠습니다. 온라인 쇼핑몰에서 쓸 수 있는 배송비 계산 프로그램을 만들어봅시다. 보통 일정 금액 이상 구매하면 무료 배송을 해주는데, 이런 조건에 따른 처리를 if~else 문으로 표현할 수 있습니다. 코드를 실행해보면 구매 금액에 따라 배송비가 자동으로 계산되는 것을 알 수 있습니다.

```python filename="05-06-shipping_fee.py"
purchase_amount = 35000
free_shipping_threshold = 50000

if purchase_amount >= free_shipping_threshold:
  shipping_fee = 0
  print(f"구매 금액: {purchase_amount:,}원")
  print("무료 배송입니다!")
else:
  shipping_fee = 3000
  print(f"구매 금액: {purchase_amount:,}원")
  print(f"배송비: {shipping_fee:,}원이 추가됩니다.")

total = purchase_amount + shipping_fee
print(f"총 결제 금액: {total:,}원")
```

**실행 결과**

```text
구매 금액: 35,000원
배송비: 3,000원이 추가됩니다.
총 결제 금액: 38,000원
```

구매 금액이 35,000원이므로 무료 배송 기준인 50,000원에 미치지 못해 배송비 3,000원이 추가되었습니다. if~else 문을 자세히 보면 shipping_fee에는 if 문의 코드 블록에서 0을, else 문의 코드 블록에서 3000을 저장합니다. 그런 다음 if~else 문 바깥에서 구매 금액과 배송비를 더해 총 결제 금액을 구합니다. 이처럼 if~else 문은 조건에 따라 서로 다른 코드를 실행해야 할 때 유용합니다.

## if~elif~else 문 구조 알아보기

if~else 문은 조건에 따라 두 가지 흐름 중 하나를 선택하는 구조였습니다. 하지만 실생활에서는 여러 조건을 차례로 확인해야 하는 경우도 많습니다. 그럴 때는 if~elif~else 문을 사용합니다. elif는 else if의 줄임말로, 쉽게 말해 ‘앞의 조건이 거짓이면 이 조건을 확인해봐’라는 의미입니다. if~elif~else 문으로 간단한 코드를 작성해 동작을 확인해봅시다. 다음은 score에 저장된 점수를 검사해 학점을 출력하는 프로그램입니다.

```python filename="05-07-score_grade.py"
score = 85

if score >= 90:
  grade = "A"
elif score >= 80:
  grade = "B"
elif score >= 70:
  grade = "C"
elif score >= 60:
  grade = "D"
else:
  grade = "F"

print(f"점수: {score}점")
print(f"학점: {grade}")
```

위에서부터 확인하다가 처음 True가 된 갈래 하나만 실행되는군요!

**실행 결과**

```text
점수: 85점
학점: B
```

점수가 85점이므로 첫 번째 조건식 score >= 90은 False로 평가됩니다. 따라서 다음 조건식인 score >= 80을 확인합니다. 이 조건식은 True이므로 grade에 "B"가 저장됩니다. **이때 if~elif~else 문은 위에서부터 조건식을 차례로 확인하다가 처음으로 True가 된 조건의 코드 블록을 실행하면 나머지 elif와 else는 확인하지 않고 넘어갑니다.** 쉽게 말해 여러 조건 중 **처음으로 만족한 조건의 코드 블록 하나만 실행하는 것**입니다. 다른 실행 결과를 확인하고 싶다면 처음 지정한 score = 85를 다른 값으로 바꿔보세요. if~elif~else 문은 구조가 단순하므로 여기서는 별도의 응용 연습 없이 넘어가겠습니다.

### if~elif~else 문에서는 else를 생략할 수도 있습니다

if~elif~else 문에서 else는 모든 조건식이 거짓일 때 실행하는 부분입니다. 때로는 특정 조건만 처리하고 나머지 경우에는 아무것도 처리하지 않아도 됩니다. 그럴 때는 else를 생략할 수 있습니다. 다음 코드를 작성해 실행해봅시다.

```python filename="05-08-scholarship_without_else.py"
score = 95

if score >= 90:
  print("우수 학생입니다!")
  print("장학금 대상자로 선정되었습니다.")
elif score >= 80:
  print("좋은 성적입니다!")
  print("성적 향상 프로그램에 참여할 수 있습니다.")

print(f"점수: {score}점")
```

**실행 결과**

```text
우수 학생입니다!
장학금 대상자로 선정되었습니다.
점수: 95점
```

점수가 95점이므로 첫 번째 조건식이 True가 되어 메시지가 출력되었습니다. 80점 미만인 경우는 특별히 처리할 필요가 없으므로 else를 생략했습니다. 점수를 75로 바꿔 실행하면 다음과 같이 결과가 나올 겁니다.

> **NOTE**
>
> 위 코드와 동일하며 점수만 바꾸어 실행했으므로, 코드는 생략했습니다.

**실행 결과**

```text
점수: 75점
```

지금까지 if 문, if~else 문, if~elif~else 문을 모두 공부했습니다. **처리해야 할 조건과 상황에 따라 알맞은 구조를 선택해서 사용하면 됩니다.** 여기까지가 조건문의 기본입니다. 마지막으로 조건문을 작성할 때 알아두면 좋은 키워드 하나를 살펴보겠습니다.

## 아무 일도 하지 않는 pass

if 문을 쓰다 보면 조건은 정했지만 그 안에 넣을 코드는 아직 정하지 못한 상황이 생길 수 있습니다. 그런데 파이썬에서는 콜론(:) 다음에 실행할 코드 없이 코드 블록을 비워둘 수 없습니다. ‘뭔가 입력은 해야겠고... 그렇다고 의미 없는 코드를 입력하기는 싫다’는 생각이 들 수 있죠. 이럴 때 코드 블록의 자리를 채워주는 키워드가 pass입니다. **pass는 이름 그대로 아무 일도 하지 않고 그냥 넘어갑니다.**

![](/books/python-intro/p224-152.webp)

```python filename="05-09-pass_keyword.py"
age = 15

if age >= 20:
  print("성인 요금 3,000원입니다")
else:
  pass                                  # ➊ 아무 일도 하지 않고 지나감

print("검사를 마쳤습니다")                # ➋ 이 줄은 정상적으로 실행됨
```

**실행 결과**

```text
검사를 마쳤습니다
```

❶ age가 15이므로 else 문의 코드 블록이 실행됩니다. 그런데 pass밖에 없으므로 아무것도 출력하지 않고 그냥 지나갑니다. 만약 pass를 지우고 else:만 남겨두면 들여쓴 코드 블록이 없으므로 IndentationError라는 오류가 발생하며 멈춥니다.

❷ pass는 아무 작업도 하지 않고 넘어가므로 프로그램의 실행은 계속됩니다. 따라서 다음 줄의 코드가 정상적으로 실행되어 메시지가 출력됩니다.

pass는 아무 작업도 하지 않으므로 ‘나중에 여기에 코드를 작성하겠다’는 표시로 사용하기 좋습니다. 조건문의 구조를 먼저 구성하고 pass로 자리를 채운 다음 하나씩 내용을 작성해 나가면 복잡한 조건문도 차근차근 완성할 수 있습니다. pass는 나중에 배울 함수나 클래스에서도 같은 방식으로 사용할 수 있습니다.

> **바로 핵심 요약**
>
> - if 문은 조건식이 True일 때만 콜론(:) 뒤 들여쓰기로 묶은 코드 블록을 실행하는 제어문입니다.
> - 조건식이 거짓일 때 실행할 코드도 필요하다면 if~else 문을 사용하고, 여러 조건을 차례로 확인해야 한다면 if~elif~else 문을 사용합니다.
> - if~elif~else 문은 위에서부터 조건식을 확인하다가 처음으로 True가 된 조건의 코드 블록만 실행하며, 나머지 경우를 따로 처리할 필요가 없다면 else를 생략할 수 있습니다.
> - 코드 블록의 내용을 아직 작성하지 않았다면 pass를 사용해 아무 작업도 하지 않고 넘어갈 수 있습니다.
