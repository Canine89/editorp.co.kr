지금까지 파이썬의 다양한 자료형을 공부하면서 각 자료형의 여러 특징을 살펴보고 코드 예제도 실행해봤습니다. 다만 정신없이 달려오느라 자료형을 바라보는 관점에 대해서는 이야기할 시간이 없었네요. 자료형을 마무리하기 전에 자료형을 어떤 관점에서 바라봐야 하는지 이야기해보겠습니다. 이미 한 번씩 설명했지만 지나가듯 살펴봤기 때문에 다시 돌아볼 만합니다.

> **미리 알아두세요!**
>
> - 자료형은 가변성, 순서, 인덱싱 같은 성질로 구분할 수 있습니다.
> - 성질을 알면 상황에 맞는 자료형을 고를 수 있습니다.

## 값을 수정할 수 있는가? 가변성, 불변성

값을 변경하는 예제를 다룰 때마다 값을 바꿀 수 있는지 없는지를 설명하면서 가변성과 불변성에 대해 여러 번 언급했습니다. 이를 영어로는 뮤터블(mutable), 이뮤터블(immutable)이라고 표현합니다. **뮤터블은 가변성, 이뮤터블은 불변성을 의미합니다.** 이 책에서는 영어 표현 대신 가변성, 불변성이라는 용어를 사용하겠습니다. 숫자, 문자열, 불리언, 튜플은 불변성을 지닙니다.

```python
# 불변
text = "hello"
text[0] = "H"  # 오류 발생! 문자열은 불변성
```

text[0]은 "h"입니다. 따라서 print(text[0])과 같이 값을 읽어 출력하는 건 괜찮습니다. 하지만 이 값을 "H"로 바꿀 수는 없습니다. 문자열은 불변성을 지니기 때문입니다. 반면 리스트, 딕셔너리, 집합은 가변성을 가집니다. 그래서 값을 추가하거나 삭제 또는 기존 값을 수정할 수 있습니다.

```python
# 가변
my_list = [1, 2, 3]
my_list[0] = 100  # OK! 리스트는 가변, [100, 2, 3]으로 바뀜
```

my_list[0]은 1이지만 my_list[0] = 100을 실행하면 1이 100으로 바뀝니다. 이처럼 파이썬의 자료형은 가변성 또는 불변성이라는 특징을 가집니다. 여러분이 나중에 프로그램을 작성할 때 데이터는 코드의 흐름을 따라 계속 이동하고 처리될 겁니다. 그때 값이 변경될 수 있는지, 변경해서는 안 되는지를 판단할 수 있어야 합니다. 어떤 값은 코드의 흐름에서 변경하지 않아야 하고, 어떤 값은 변경해야 할 수도 있습니다. 이를 결정하는 것은 여러분의 몫입니다. 자료형의 가변성과 불변성을 다시 떠올려보세요.

![](/books/python-intro/p204-138.webp)

그리고 04.1 리스트에서 확인했듯이 가변 자료형은 b = a처럼 대입하는 것만으로는 복사되지 않습니다. 같은 리스트에 이름표가 하나 더 붙을 뿐이므로 한쪽을 바꾸면 다른 쪽도 함께 바뀌죠. 서로 다른 리스트로 복사해 별도로 관리하고 싶다면 copy( ) 함수로 복사해야 한다는 점도 가변성과 함께 기억해두면 좋습니다.

## 하나만 저장할지 묶어 저장할지?

따로 길게 설명할 필요 없는 내용입니다. 파이썬의 자료형은 값을 하나씩 관리할지, 여러 값을 묶어서 관리할지에 따라 다음과 같이 구분할 수 있습니다.

- **단일한 값 :** 숫자, 불리언
- **컨테이너 :** 리스트, 딕셔너리, 튜플, 집합

이때 값을 묶어 관리하는 자료형을 컨테이너 자료형이라고 부릅니다. 말 그대로 컨테이너 박스에 여러 값을 담는 것을 상상하면 됩니다.

## 순서가 있는지 없는지?

집합을 통해 순서에 대해 이야기했습니다. 파이썬의 문자열, 리스트, 튜플은 요소의 순서를 기억하는 자료형입니다. 딕셔너리는 조금 애매합니다. 예전 파이썬에서는 딕셔너리의 순서를 보장하지 않았지만, 파이썬 3.7부터는 항목을 추가한 순서를 그대로 유지합니다. 반면 집합은 요소의 순서를 보장하지 않습니다.

이처럼 순서가 있는 자료형과 없는 자료형을 구분해야 하는 이유는 이후 배울 반복문과의 조합 때문입니다. 반복문은 컨테이너 자료형의 요소를 왼쪽부터 하나씩 순회하면서 반복하는 구조를 갖습니다. 따라서 자료형이 순서를 유지하는지 여부가 코드의 결과에 영향을 줄 수 있습니다. 어쨌든 컨테이너 자료형마다 순서 유무가 있다는 걸 다시 한 번 기억해두세요.

## 인덱싱이 있는지 없는지?

순서의 유무에 따라 인덱싱을 적용할 수 있는 자료형과 그렇지 않은 자료형을 나눌 수 있습니다. 직관적으로 생각해보면 이해하기 쉽습니다. 순서가 있어야 인덱싱으로 구성 요소를 특정할 수 있기 때문이죠. 딕셔너리 같은 경우 조금 애매합니다. 딕셔너리는 항목을 추가한 순서를 유지하지만 인덱싱은 사용할 수 없습니다. 딕셔너리에서는 키를 사용해 값을 찾으므로 student[0]은 첫 번째 항목이 아니라 정수 키 0의 값을 찾습니다. 다음 예제의 student 딕셔너리에는 키 0이 없으므로 student[0]을 실행하면 KeyError가 발생합니다. 딕셔너리는 애초에 인덱스가 아니라 키로 값을 찾도록 만들어진 자료형이기 때문입니다.

> **NOTE**
>
> 다만 딕셔너리의 키로 0을 사용하면 student[0]을 사용할 수 있습니다. 하지만 인덱싱이 아닌 키로 사용한다는 점은

여전히 같습니다.

```python
student = {"name": "Alice", "age": 20, "grade": "A"}
# 순서는 있지만 인덱스 접근은 안 됨
# print(student[0])  # 오류 발생!
```

딕셔너리에서 키만 모아 주는 keys( ) 함수와 값만 모아 주는 values( ) 함수가 돌려주는 것은 리스트가 아닌 dict_keys, dict_values라는 별도의 객체입니다. 여기서는 list( ) 함수로 감싸면 리스트로 바꿀 수 있다는 것만 알아두면 됩니다. 그런데 리스트는 인덱싱을 할 수 있죠? 그래서 keys( ), values( ) 함수에 list( ) 함수를 연이어 조합하면 딕셔너리도 인덱싱을 사용하는 것처럼 다룰 수 있습니다.

```python
student = {"name": "Alice", "age": 20, "grade": "A"}
# 키 객체를 리스트로 변환
keys = list(student.keys())
print(keys[0])  # "name"
print(student[keys[0]])  # "Alice"
```

## 참, 거짓의 성질이 있는지?

파이썬의 값은 조건문 등에서 참(True) 또는 거짓(False)으로 평가할 수 있습니다. 다만 True, False가 아닌 값까지 참과 거짓으로 판단한다는 점은 여기서 처음 다룹니다. 대표적으로 0, 빈 문자열(""), 빈 리스트([ ]) 등 **비어 있거나 0인 경우**는 거짓으로 평가됩니다. 다음 코드를 실행해봅시다. bool( ) 함수는 괄호 안의 값이 참인지 거짓인지를 판단해 True 또는 False로 반환합니다.

```python filename="04-53-falsy_values.py"
# 거짓(False)으로 평가되는 대표적인 값들
print(bool(0))
print(bool(""))
print(bool([]))
print(bool(()))
print(bool({}))
```

**실행 결과**

```text
False
False
False
False
False
```

실행 결과를 보면 알 수 있듯이 아무런 값이 없는 빈 상태이거나 숫자 0인 값 등은 모두 거짓으로 평가됩니다. 반대로 비어 있거나 0인 값을 제외한 대부분의 값은 반대로 참(True)으로 평가됩니다. 아무리 작은 숫자나 짧은 문자열이라도 값이 들어 있다면 참이 되는 것이죠.

![](/books/python-intro/p207-140.webp)

```python filename="04-54-truthy_values.py"
# 참(True)으로 평가되는 값들
print(bool(1))
print(bool(-5))
print(bool("Hello"))
print(bool([1, 2, 3]))
```

**실행 결과**

```text
True
True
True
True
```

이런 성질을 나중에 공부할 제어문과 조합하면 재미있는 작업을 할 수 있습니다. 값을 상황에 따라 참이나 거짓으로 평가할 수 있다는 것도 기억해두세요.

이처럼 파이썬 자료형은 각자의 특징에 따라 이후 프로그래밍에서 많은 것을 결정하는 가장 중요한 재료입니다. 문법을 처음 공부할 때는 코드를 한 글자씩 입력하고 print( ) 함수로 결과를 확인하느라 미처 생각하지 못하는 사실이기도 합니다. 하지만 모든 프로그램은 결국 **데이터를 처리하는 일**입니다.

그렇기에 자료형의 특성을 잘 구분하고 이해하는 것은 무엇보다 중요합니다. 자료형 이야기는 이 정도면 충분합니다. 이제 든든한 재료를 모두 챙겼으니, 다음 레벨인 **제어문**으로 이동해보겠습니다.

> **바로 핵심 요약**
>
> - 파이썬 자료형은 리스트·딕셔너리·집합과 같이 값을 바꿀 수 있는 가변 자료형과 숫자·문자열·불리언·튜플과 같이 값을 바꿀 수 없는 불변 자료형값을 바꿀 수 없는 불변 자료형으로 나뉩니다.
> - 값을 하나만 관리하는 단일 자료형과 여러 값을 묶어 관리하는 컨테이너 자료형으로 구분할 수 있으며, 자료형마다 순서 유지와 인덱싱을 지원하는지는 다릅니다.
> - 파이썬의 값은 상황에 따라 참(True) 또는 거짓(False)으로 평가될 수 있으며, 일반적으로 0과 비어 있는 값은 거짓, 그 외의 값은 참으로 평가됩니다.
