모듈이 많아지면 파일을 한 폴더에 모두 두는 것도 불편해집니다. 이럴 때는 서로 관련 있는 모듈을 폴더로 묶어 관리할 수 있습니다. 또한 다른 개발자가 만든 기능을 설치해 프로그램에 활용할 수도 있습니다. 이번 절에서는 패키지의 기본 구조와 외부 라이브러리를 사용하는 흐름을 가볍게 살펴봅시다.

> **미리 알아두세요!**
>
> - 패키지는 관련 있는 모듈을 폴더 단위로 묶은 것입니다.
> - 외부 라이브러리는 pip를 사용해 설치한 뒤 가져올 수 있습니다.

## 여러 모듈을 패키지로 묶기

예를 들어 앞에서 만든 메모장 프로그램에 메모 저장, 검색, 내용 정리 같은 기능을 계속 추가한다고 생각해봅시다. 기능마다 파일을 나누면 여러 모듈이 생기고, 관련 파일을 한곳에서 찾고 관리할 필요도 생깁니다. 이때 메모장과 관련된 모듈을 memo_tools 폴더에 모아두면 어떤 기능끼리 관련되어 있는지 한눈에 파악하기 쉬워집니다.

![](/books/python-intro/p515-318.webp)

**이처럼패키지는 서로 관련 있는 모듈을 하나의 구조로 묶어 폴더에 모아둔 것입니다.** 이번에는 메모 형식을 만드는 formatter.py와 메모 개수를 세는 counter.py를 memo_tools 패키지로 묶어보겠습니다. 폴더의 구조는 다음과 같습니다.

```python
memo_project

│  ├─ __init__.py
│  ├─ formatter.py
│  └─ counter.py
└─ 11-09-memo_tools_app.py
```

01 먼저 위의 구조대로 폴더를 만들어봅시다. memo_project 폴더를 만든 다음 비주얼 스튜디오 코드에서 해당 폴더를 엽니다.

![](/books/python-intro/p516-320.webp)

02 memo_project 폴더 안에서 마우스 오른쪽 버튼을 클릭한 다음 [New Folder]를 눌러 memo_tools 폴더를 만듭니다.

03 이제 필요한 .py 파일을 만들어 위와 같은 구조를 완성합니다. 다음 그림과 같은 구조가 되면 됩니다.

![](/books/python-intro/p516-322.webp)

__init__.py 파일은 처음 보는 파일일 겁니다. 전통적으로 파이썬에서는 이 파일을 사용해 해당 폴더를 패키지로 다뤘습니다. 요즘 파이썬에서는 경우에 따라 __init__.py가 없는 폴더도 패키지로 사용할 수 있지만, 일반적인 패키지 구조에서는 여전히 __init__.py를 두는 경우가 많습니다. 또한 나중에 패키지를 불러올 때 필요한 초기화 코드를 작성하는 곳으로 사용할 수도 있습니다. 이번 실습에서는 __init__.py에 아무 내용도 작성하지 않고 빈 파일로 두겠습니다. 그리고 formatter.py와 counter.py에는 서로 다른 역할을 하는 함수를 하나씩 작성합니다.

- **formatter.py :** 메모 내용을 보기 좋은 형식의 문자열로 만드는 함수
- **counter.py :** 현재 저장한 메모의 개수를 계산하는 함수

04 먼저 formatter.py에 메모 내용을 보기 좋은 형식으로 만드는 함수를 작성해봅시다.

```python filename="memo_tools/formatter.py"
def format_memo(content):           # ➊ 메모 형식 만들기
  return f"[메모] {content}"
```

❶ format_memo( ) 함수는 메모 내용을 전달받아 앞에 "[메모]"를 붙인 문자열을 반환합니다. 함수를 정의하기만 하고 호출하지 않았으므로 이 파일을 실행해도 출력되는 내용은 없습니다.

다음으로 counter.py에 메모 개수를 세는 함수를 작성해봅시다.

```python filename="memo_tools/counter.py"
def count_memos(memos):             # ➊ 메모 개수 세기
  return len(memos)
```

❶ count_memos( ) 함수는 메모가 들어 있는 리스트를 전달받아 len( ) 함수로 항목의 개수를 구한 뒤 반환합니다. 이 파일 역시 함수를 정의하기만 하고 호출하지 않았으므로 출력되는 내용은 없습 니다.

05 이제 11-09-memo_tools_app.py에서 memo_tools 패키지 안의 두 모듈에 있는 함수를 가져와 사용해보겠습니다.

```python filename="11-09-memo_tools_app.py"
from memo_tools.formatter import format_memo  # ➊ 서식 함수 가져오기
from memo_tools.counter import count_memos    # ➋ 개수 함수 가져오기

memos = ["장보기", "책 읽기"]

for memo in memos:
  print(format_memo(memo))                    # ➌ 메모 형식 출력

print(f"메모 개수: {count_memos(memos)}")      # ➍ 메모 개수 출력
```

**실행 결과**

```text
[메모] 장보기
[메모] 책 읽기
메모 개수: 2
```

❶ memo_tools 패키지의 formatter 모듈에서 format_memo( ) 함수를 가져옵니다.

❷ 같은 패키지의 counter 모듈에서 count_memos( ) 함수를 가져옵니다. memo_tools.formatter처럼 패키지 이름과 그 안의 모듈 이름을 점으로 연결해 위치를 나타냅니다.

❸ memos 리스트를 반복하면서 각 메모를 format_memo( ) 함수에 전달합니다. 따라서 모든 메모 앞에 "[메모]"가 붙어 출력됩니다.

❹ count_memos( ) 함수에 memos 리스트를 전달해 전체 메모 개수를 출력합니다.

앞에서 구성한 구조를 보면 memo_tools는 패키지이고, formatter와 counter는 패키지 안의 모듈입니다. 따라서 from memo_tools로 시작하는 코드를 통해 어떤 패키지에서 기능을 가져오는지 명확하게 알 수 있습니다. 이처럼 관련 기능을 하나의 패키지로 묶으면 파일이 늘어나더라도 프로그램의 구조를 쉽게 파악하고 관리할 수 있습니다.

## 파이썬 생태계의 핵심, 외부 라이브러리

표준 라이브러리는 파이썬을 설치하면 함께 사용할 수 있다는 사실을 **11.2 표준 라이브러리 활용하기**에서 알아봤습니다. 하지만 파이썬 생태계에는 다른 개발자나 단체가 만들어 공개한 다양한 외부 라이브러리와 패키지도 있습니다. 이러한 외부 라이브러리를 활용하면 필요한 기능을 처음부터 직접 만들지 않고 프로그램에 추가할 수 있습니다.

![](/books/python-intro/p519-323.webp)

다음은 널리 사용되는 외부 라이브러리의 예입니다.

- **requests 라이브러리는 웹 서버에 요청을 보내고 응답을 받을 때 유용합니다.** 특히 인터넷에서 데이터를 가져오는 작업에 자주 사용합니다. 흔히 '크롤링'이라고 부르는 작업을 하려면 먼저 웹 서버에 요청을 보내 웹 페이지의 HTML이나 필요한 데이터를 받아와야 합니다. requests는 이처럼 파이썬 프로그램이 웹 서버와 데이터를 주고받을 수 있도록 도와주는 라이브러리입니다.
- **pandas 라이브러리는 표 형태의 데이터를 정리하거나 분석할 때 유용합니다.** 예를 들어 학생 성적이나 상품 판매량처럼 행과 열로 이루어진 데이터를 불러온 뒤, 필요한 항목만 추려내고, 해당 데이터의 합계나 평균을 간편하게 계산할 수 있습니다. 반복적인 데이터 정리 작업을 파이썬 코드로 처리할 때 자주 사용합니다.
- **matplotlib 라이브러리는 숫자로 된 데이터를 그래프로 나타낼 때 유용합니다.** 예를 들어 월별 판매량의 변화를 선그래프로 나타내거나 여러 상품의 판매량을 막대그래프로 비교할 수 있습니다. 숫자로만 살펴볼 때는 알아보기 어려운 변화나 차이를 시각적으로 한눈에 확인할 수 있습니다.

이 밖에도 수많은 외부 라이브러리가 공개되어 있습니다. 그중 많은 파이썬 패키지가 PyPI(Python Package Index) 라는 사이트를 통해 배포됩니다. 다음 홈페이지에 접속하면 전 세계의 개발자와 단체가 공개한 다양한 패키지를 찾아볼 수 있습니다.

## 외부 라이브러리 설치해서 사용해보기

외부 라이브러리나 패키지는 파이썬을 설치할 때 함께 준비된 pip라는 도구로 설치할 수 있습니다. 여기서는 requests와 뷰티풀수프로 알려져 있는 beautifulsoup4(bs4) 라이브러리를 설치한 뒤 파이썬 파일에서 가져와 사용하는 과정까지 차례대로 따라 해보겠습니다.

01 터미널에 다음 명령을 입력해 현재 사용하고 있는 파이썬 환경에 requests 패키지를 설치합니다.

![](/books/python-intro/p521-327.webp)

```python
python -m pip install requests
```

> **NOTE**
>
> 운영체제와 파이썬 환경에 따라 설치 과정에서 나타나는 메시지는 다를 수 있습니다. macOS나 리눅스에서 python

명령을 찾을 수 없다면 python3 -m pip install requests처럼 python 대신 python3를 사용해보세요.

설치가 끝나면 마지막 부분에 Successfully installed라는 메시지가 나타납니다. 이미 requests가 설치되어 있다면 Requirement already satisfied라는 메시지가 나타날 수도 있습니다. 두 경우 모두 현재 파이썬 환경에서 requests를 사용할 준비가 되었다는 뜻입니다.

02 설치한 외부 라이브러리는 표준 라이브러리와 마찬가지로 import 문으로 가져와 사용할 수 있습니다. 11-10-request_test.py 파일을 만들고 다음 코드를 작성해봅시다. 참고로 requests 라이브러리는 인터넷을 통해 웹 서버에 요청을 보내므로 이 예제를 실행하려면 인터넷에 연결되어 있어야 합니다.

```python filename="11-10-request_test.py"
import requests                                     # ➊ requests 가져오기

response = requests.get("https://quotes.toscrape.com", timeout=10)  # ➋ 웹 페이지 요청
print(response.status_code)                         # ➌ 상태 코드 출력
```

**실행 결과**

```text
200
```

❶ pip로 설치한 requests 라이브러리를 현재 파일로 가져옵니다.

❷ requests.get( ) 함수로 quotes.toscrape.com 웹 서버에 요청을 보냅니다. timeout=10은 서버의 응답을 최대 10초 동안 기다리도록 제한하는 설정입니다. 서버로부터 HTTP 응답을 받으면 요청이 성공했든 404 같은 오류 상태든 그 응답이 response 변수에 저장됩니다.

❸ response의 status_code에는 서버가 보내온 HTTP 상태 코드가 들어 있습니다. 200은 웹 서버가 요청을 정상적으로 처리했다는 뜻입니다. 만약 404가 나왔다면 요청한 페이지를 서버에서 찾지 못했다는 뜻으로, 다른 사이트 주소로 테스트해보기 바랍니다.

requests는 현재 사용하는 컴퓨터의 파이썬 환경에 한 번 설치해두면 그 환경에서 실행하는 다른 파이썬 파일에서도 가져와 사용할 수 있습니다. 새로운 .py 파일을 만들 때마다 같은 라이브러리를 다시 설치할 필요는 없습니다.

![](/books/python-intro/p523-328.webp)

03 이제 웹 페이지에서 원하는 데이터만 골라내기 위해 HTML을 분석하는 도구도 사용해보겠습니다. 터미널에 다음 명령을 입력해 beautifulsoup4 라이브러리를 설치합니다.

![](/books/python-intro/p523-329.webp)

```python
python -m pip install beautifulsoup4
```

> **NOTE**
>
> 설치할 때는 beautifulsoup4라는 이름을 사용하지만, 파이썬 코드에서는 bs4라는 이름으로 가져옵니다.

04 11-11-quote_scraper.py 파일을 만들고 다음 코드를 작성해봅시다. 이 코드는 명언을 제공하는 사이트에 접속한 뒤, 첫 번째 페이지에서 명언 세 개와 작가 이름을 가져옵니다. 이때 requests는 웹 서버에 요청을 보내 HTML을 받아오는 역할을 하고, BeautifulSoup은 받아온 HTML의 구조를 분석하고 원하는 내용을 찾기 쉽게 만들어주는 역할을 합니다. 이처럼 bs4를 사용해 HTML 등의 데이터를 분석하고 필요한 구조나 내용을 찾아내는 작업을 전문 용어로 파싱이라고 합니다.

- **명언 사이트 :** [quotes.toscrape.com](https://quotes.toscrape.com)

```python filename="11-11-quote_scraper.py"
import requests
from bs4 import BeautifulSoup  # ➊ BeautifulSoup 가져오기

response = requests.get("https://quotes.toscrape.com", timeout=10)  # ➋ 웹 페이지 요청
soup = BeautifulSoup(response.text, "html.parser")  # ➌ HTML 분석
quotes = soup.select(".quote")[:3]                  # ➍ 명언 세 개 선택

for quote in quotes:                                # ➎ 명언 정보 출력
  text = quote.select_one(".text").get_text()
  author = quote.select_one(".author").get_text()
  print(f"{author}: {text[:30]}...")
```

**실행 결과**

```text
Albert Einstein: "The world as we have created ...
J.K. Rowling: "It is our choices, Harry, tha...
Albert Einstein: "There are only two ways to li...
```

❶ bs4에서 HTML을 분석할 때 사용할 BeautifulSoup을 가져옵니다.

❷ requests.get( ) 함수로 명언이 담긴 웹 페이지를 요청합니다. 서버에서 받은 응답의 본문을 response.text로 확인할 수 있습니다.

❸ BeautifulSoup(response.text, "html.parser")에서 첫 번째 인수가 서버에서 받은 웹 페이지 결과물인 HTML 문자열 덩어리이고, 두 번째 인수인 "html.parser"가 그 덩어리를 보기 좋게 정리할 bs4의 도구입니다. 쉽게 말해 response.text를 정육에 비유하자면 원육이고, "html.parser"는 원육을 가공할 방법이나 도구라고 생각하면 됩니다. 그 결과가 soup이라는 변수에 담깁니다. 이제 잘 정리된 soup에서 원하는 데이터만 찾으면 됩니다.

![](/books/python-intro/p524-330.webp)

❹ soup.select( )는 데이터를 선택하는 역할을 합니다. ".quote"는 class 속성값이 quote인 요소를 찾는 CSS 선택자이며, HTML과 CSS의 자세한 문법은 이 책의 범위를 벗어나므로 지금은 ".quote"가 명언 하나를 묶고 있는 부분을 찾는 표현이라고 이해하면 충분합니다. .quote라는 이름에서 느껴지겠지만 화면에 있는 명언 데이터 묶음을 의미합니다.

![](/books/python-intro/p525-331.webp)

.quote라는 이름을 가진 데이터는 웹 페이지 안에 여러 개가 있을 수 있으므로 슬라이싱으로 앞의 3개만 선택합니다.

❺ 선택한 각 명언 묶음에서 ".text"에 해당하는 요소의 명언과 ".author"에 해당하는 요소의 작가 이름을 찾습니다. 명언 전체를 출력하면 길어질 수 있으므로 text[:30]을 사용해 앞의 30글자만 출력합니다.

지금까지 requests로 서버에서 HTML을 받아오고, 뷰티풀수프로 HTML을 분석한 뒤 필요한 내용만 골라 사용하는 과정을 살펴봤습니다. 이처럼 여러 외부 라이브러리를 함께 사용하면 웹 페이지에 있는 정보를 프로그램에서 활용할 수도 있습니다. 이러한 과정은 흔히 이야기하는 웹 크롤링이나 웹 스크래핑에서 사용되는 작업 가운데 일부입니다. 이 책에서는 웹 크롤링 자체를 자세히 배우는 것이 목적은 아니므로 여기까지만 살펴보겠습니다. 이번 실습을 통해 외부 패키지를 설치하고, 필요한 기능을 import하여 사용하는 기본 흐름을 익혔다면 충분합니다.
