파이썬은 계산할 수 없는 식을 만나거나 필요한 파일을 찾지 못했을 때 스스로 예외를 발생시킵니다. 그러나 파이썬 문법에는 문제가 없더라도 우리가 만든 프로그램의 규칙에는 맞지 않는 값이 들어올 수 있습니다. 이럴 때는 raise를 사용해 필요한 위치에 직접 예외를 발생시킬 수 있습니다. 구체적인 예로 비밀번호의 길이를 검사하는 상황을 살펴봅시다.

> **미리 알아두세요!**
>
> - raise를 사용하면 프로그램의 규칙에 맞지 않는 값을 예외로 알릴 수 있습니다.
> - 예외 설명에는 무엇이 잘못되었는지 구체적으로 적는 것이 좋습니다.
> - Exception을 상속하면 나만의 예외를 만들 수 있습니다.

비밀번호는 일반적으로 일정한 길이 이상이어야 합니다. 그러나 파이썬은 password = "1234"라는 코드 자체를 오류로 판단하지 않습니다. 변수에 문자열 "1234"를 저장하는 것은 파이썬 문법에 맞기 때문이죠. 하지만 비밀번호를 8자 이상으로 정한 프로그램이라면 "1234"는 허용할 수 없는 값입니다. 이처럼 문법에는 맞지만 프로그램에서 정한 규칙에는 어긋나는 값을 발견했을 때 raise를 사용하여 직접 예외를 발생시킬 수 있습니다.

## 비밀번호 길이를 확인하고 예외 발생시키기

raise 뒤에는 발생시킬 예외를 작성할 수 있습니다. 이번에는 비밀번호가 8자보다 짧으면 ValueError를 직접 발생시켜봅시다.

```python filename="10-15-raise_password.py"
def check_password(password):
  if len(password) < 8:
    raise ValueError("비밀번호는 8자 이상이어야 합니다.")  # ➊ 직접 예외 발생
  return password
try:
  password = check_password("1234")      # ➋ 비밀번호 확인
except ValueError as error:
  print(f"입력 오류 : {error}")           # ➌ 예외 설명 출력
```

**실행 결과**

```text
입력 오류 : 비밀번호는 8자 이상이어야 합니다.
```

❶ 비밀번호 길이가 8자보다 짧으면 ValueError를 직접 발생시킵니다. 소괄호 안에는 무엇이 잘못되었는지 알려주는 설명을 적었습니다.

❷ check_password("1234")를 호출하여 비밀번호 길이를 확인합니다. "1234"는 문자열이라는 점에는 문제가 없지만 프로그램에서 정한 8자 이상의 조건을 만족하지 못합니다.

❸ check_password( ) 함수에서 발생한 ValueError를 처리하고, 발생한 예외 인스턴스가 error 변수에 저장되므로 이를 출력하면 raise에서 작성한 설명도 확인할 수 있습니다.

![](/books/python-intro/p481-297.webp)

이처럼 raise가 실행되면 현재 실행 중인 코드의 정상적인 흐름은 그 지점에서 멈추고 예외가 전달됩니다. 이 코드를 감싼 try 문에 해당 예외를 처리할 수 있는 except 문이 있다면 그곳에서 처리할 수 있습니다. 따라서 잘못된 값이 함수의 다음 코드에서 사용되는 것을 막을 수 있습니다.

파이썬이 미리 준비한 ValueError만 사용해야 하는 것은 아닙니다. 필요하다면 프로그램의 규칙을 나타내는 예외를 직접 만들 수도 있습니다.

## Exception을 상속해 나만의 예외 만들기

지금까지 raise로 발생시킨 예외는 ValueError처럼 파이썬이 미리 만들어둔 예외 클래스였습니다. 하지만 프로그램을 만들다 보면 파이썬 자체는 알 수 없는 우리 프로그램만의 규칙이 생길 수 있습니다. 이럴 때는 일반적인 예외의 부모 클래스인 Exception을 상속해 새로운 예외 클래스를 만들 수 있습니다. **자료형과 함수를 묶어 관리하는 클래스**에서 배운 상속을 그대로 사용합니다. 예를 들어 메모장 프로그램에 '빈 메모는 저장할 수 없다'는 규칙을 추가하면 어떻게 될까요?

```python filename="10-16-custom_exception.py"
class MemoError(Exception):        # ➊ Exception을 상속
  pass                             # ➋ 내용은 비워 둠

def save_memo(text):
  if not text.strip():
    raise MemoError("빈 메모는 저장할 수 없습니다.")   # ➌ 직접 발생
  print(f"저장 완료: {text}")

try:
  save_memo("책 반납하기")
  save_memo("   ")
except MemoError as error:         # ➍ 내가 만든 예외 잡기
  print("메모 오류:", error)
```

**실행 결과**

```text
저장 완료: 책 반납하기
메모 오류: 빈 메모는 저장할 수 없습니다.
```

❶ Exception을 상속받는 MemoError 클래스를 만들었습니다. MemoError는 파이썬이 원래 제공하던 오류 클래스가 아닙니다. 우리가 필요에 따라 직접 만든 예외 클래스입니다. 따라서 이름만 봐도 메모와 관련된 오류라는 점을 알기 쉽습니다.

❷ 이 예제에서는 별도의 기능을 추가하지 않으므로, 클래스 안에 따로 넣을 내용이 없어 pass만 적었습니다. Exception에서 물려받은 기본 기능을 그대로 사용할 수 있기 때문입니다.

❸ raise MemoError("빈 메모는 저장할 수 없습니다.")처럼 우리가 만든 예외를 직접 발생시킵니다. 괄호 안에 적은 문장이 오류 메시지가 됩니다.

❹ except MemoError:를 사용하면 우리가 만든 MemoError만 골라 처리할 수 있습니다. 파이썬이 미리 제공하는 ValueError나 FileNotFoundError와 같은 방식으로 사용하는 것입니다.

> **NOTE**
>
> 직접 만드는 예외 클래스의 이름은 일반적으로 Error로 끝내는 경우가 많습니다. 예를 들어 MemoError, AgeError처

럼 작성할 수 있습니다.

나만의 예외를 만들면 무엇이 좋을까요? 이 예제에서도 ValueError를 사용하면 프로그램 자체는 동작할 수 있습니다. 하지만 MemoError라는 별도의 예외를 만들면 ‘메모와 관련된 프로그램 규칙을 어겼다’는 의미를 코드에 더 분명하게 나타낼 수 있습니다. 또한 except MemoError:로 메모 규칙에서 발생한 문제만 따로 처리할 수도 있습니다. 프로그램의 규모가 커지고 서로 다른 규칙이 많아질수록 이런 구분이 도움이 될 수 있습니다.

### 오류 메시지를 클래스가 갖게 하기

그런데 한 가지 아쉬운 점이 있습니다. MemoError라는 예외의 이름은 클래스에 정의되어 있지만, 정작 '빈 메모는 저장할 수 없습니다.'라는 오류 메시지는 클래스 밖의 raise 줄에 적혀 있습니다. 같은 예외를 여러 곳에서 발생시키려면 그때마다 같은 메시지를 다시 적어야 하고, 그 과정에서 문구가 조금씩 달라질 수도 있습니다. 이번에는 오류 메시지까지 클래스 안에 저장해 일관되게 사용해봅시다.

```python filename="10-17-custom_exception_message.py"
class MemoError(Exception):
  def __init__(self, message="빈 메모는 저장할 수 없습니다."):
    super().__init__(message)      # ➊ 부모에게 메시지 넘기기

def save_memo(text):
  if not text.strip():
    raise MemoError()              # ➋ 메시지를 적지 않아도 됨
  if len(text) > 20:
    raise MemoError("메모는 20자를 넘을 수 없습니다.")  # ➌ 다른 메시지가 필요할 때
  print(f"저장 완료: {text}")

memos = ["책 반납하기", "   ", "도서관에 가서 책을 반납하고 새 책을 빌려오기"]

for memo in memos:
  try:
    save_memo(memo)
  except MemoError as error:
    print("메모 오류:", error)
```

**실행 결과**

```text
저장 완료: 책 반납하기
메모 오류: 빈 메모는 저장할 수 없습니다.
메모 오류: 메모는 20자를 넘을 수 없습니다.
```

❶ MemoError 클래스에 `__init__`( ) 메서드를 정의하고, message 매개변수의 기본값으로 "빈 메모는 저장할 수 없습니다."를 지정했습니다. 이어서 super( ).`__init__`(message)를 호출하여 부모 클래스인 Exception의 초기화 기능에 message를 전달합니다. 그러면 전달한 문장이 예외 인스턴스에 저장되어 오류가 발생했을 때 메시지로 표시됩니다. 따라서 별도의 메시지를 전달하지 않으면 기본 메시지가 사용되고, 필요한 경우 다른 메시지로 바꿀 수도 있습니다.

❷ 이제 raise MemoError( )처럼 별도의 메시지를 전달하지 않아도 기본값인 "빈 메모는 저장할 수 없습니다."가 사용됩니다.

❸ 상황에 따라 다른 메시지를 사용하고 싶다면 MemoError("다른 메시지")처럼 문자열을 직접 전달할 수도 있습니다. 그러면 기본값 대신 전달한 문자열이 사용됩니다.

이렇게 하면 같은 예외에서 반복해서 사용하는 기본 메시지를 클래스 안에 모아둘 수 있습니다. 나중에 기본 문구를 바꿔야 할 때도 클래스의 내용을 수정하면 됩니다.

이번에는 나이가 0보다 작으면 우리가 만든 예외를 발생시키는 예제도 살펴봅시다.

```python filename="10-18-custom_exception_practice.py"
class AgeError(Exception):       # ➊ 나이 전용 예외
  def __init__(self, message="나이는 0보다 작을 수 없습니다."):
    super().__init__(message)

def check_age(age):
  if age < 0:
    raise AgeError()             # ➋ 메시지는 클래스가 갖고 있음
  print(f"입력한 나이: {age}세")

try:
  check_age(20)
  check_age(-5)
except AgeError as error:        # ➌ 나이 오류만 골라 처리
  print("나이 오류:", error)
```

**실행 결과**

```text
입력한 나이: 20세
나이 오류: 나이는 0보다 작을 수 없습니다.
```

❶ Exception을 상속받아 나이 전용 예외를 만들었습니다. `__init__`( )에 기본 메시지를 지정했습니다.

❷ 클래스에 기본 메시지가 정의되어 있으므로 raise AgeError( )처럼 작성해 예외를 발생시킬 수 있습니다.

❸ AgeError라는 이름만 보아도 나이와 관련된 프로그램 규칙에서 문제가 발생했다는 것을 알 수 있습니다. 다른 종류의 예외와 함께 사용하더라도 except AgeError:로 나이와 관련된 문제만 따로 처리할 수 있습니다.

>

> - raise ValueError("설명")처럼 예외 클래스와 구체적인 설명을 함께 적습니다.
> - raise로 예외를 발생시키면 잘못된 값이 이후의 정상적인 코드에서 그대로 사용되는 것을 막을 수 있습니다.
