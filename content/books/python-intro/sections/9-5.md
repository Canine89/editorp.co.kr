**09.2 파일 출력 이해하기**에서는 프로그램이 만든 결과를 파일에 저장하는 방법을 배웠습니다. 그렇다면 반대로 파일에 저장된 내용을 프로그램 안으로 가져올 수도 있을까요? 물론 할 수 있습니다. 파일에 저장된 내용을 파이썬 프로그램으로 읽어 오는 것을 파일 입력이라고 합니다.

> **미리 알아두세요!**
>
> - open() 함수와 read() 로 파일의 내용을 읽을 수 있습니다.
> - 파일 입력도 with 문과 함께 쓰면 자동으로 닫혀 편리합니다.

## 파일 입력이란?

파일 입력은 우리가 이미 알고 있는 입력과 같은 흐름으로 생각하면 됩니다. input( )이 사용자가 키보드로 입력한 값을 프로그램 안으로 가져왔다면 **파일 입력은 파일에 저장된 내용을 프로그램 안으로 가져옵니다. 다시 말해 입력되는 값의 출발점이 다른 셈입니다.**

- **키보드 입력 :** 사용자가 입력한 값이 프로그램 안으로 들어옴
- **파일 입력 :** 파일에 저장된 값이 프로그램 안으로 들어옴

![](/books/python-intro/p432-264.webp)

![](/books/python-intro/p432-265.webp)

예를 들어 score.txt 파일에 다음과 같은 내용이 저장되어 있다고 해봅시다.

**실행 결과**

```text
학생 점수표
바로: 85점
요즘: 92점
하나: 78점
```

이번에는 이 파일의 내용을 파이썬으로 읽어 화면에 출력해보겠습니다.

```python filename="09-12-score_read.py"
score_file = open("score.txt", "r", encoding="utf-8")    # ➊ 점수 파일 열기
content = score_file.read()                       # ➋ 파일 내용 읽기
score_file.close()                                # ➌ 파일 닫기

print(content)                                    # ➍ 읽은 내용 출력
```

**실행 결과**

```text
학생 점수표
바로: 85점
요즘: 92점
하나: 78점
```

❶ score.txt 파일을 읽기 모드로 여는 코드입니다. 여기서 "r"은 read를 의미하며, 파일의 내용을 읽기 위한 모드입니다.

❷ 열린 파일의 내용을 read( ) 메서드로 한 번에 읽어 옵니다. 읽어 온 내용은 content 변수에 저장됩니다. 즉, 파일에 저장되어 있던 문자열이 프로그램 안으로 들어온 것입니다.

❸ 열어 둔 파일을 닫는 코드입니다. 파일 출력에서 쓰기 작업을 마친 뒤 파일을 닫았던 것처럼, 파일 입력에서도 읽기 작업이 끝나면 파일을 닫아줍니다.

❹ print(content)는 파일에서 읽어 온 내용을 화면에 출력합니다. 실행 결과를 보면 score.txt 파일 안에 있던 내용이 그대로 출력된 것을 확인할 수 있습니다.

![](/books/python-intro/p433-266.webp)

앞에서는 open( )과 close( )를 직접 사용했습니다. 하지만 파일을 쓸 때와 마찬가지로 읽을 때도 with 문을 이용하면 파일을 더 편리하게 관리할 수 있습니다.

## with 문으로 파일 읽고 자동으로 닫기

파일 출력에서 with 문을 사용하면 close( )를 직접 작성하지 않아도 된다고 했습니다. 파일 입력도 마찬가지입니다. 파일을 읽을 때 with 문을 사용하면 코드 블록을 벗어날 때 파일이 자동으로 닫힙니다.

```python filename="09-13-score_read_with.py"
# ➊ 파일 자동 닫기 방식
with open("score.txt", "r", encoding="utf-8") as score_file:
  content = score_file.read()                     # ➋ 파일 내용 읽기

print(content)                                    # ➌ 읽은 내용 출력
```

**실행 결과**

```text
학생 점수표
바로: 85점
요즘: 92점
하나: 78점
```

❶ with로 score.txt 파일을 읽기 모드로 엽니다. 그런 다음 with 문의 코드 블록을 빠져나오면서 파일은 자동으로 닫힙니다.

❷ score_file.read( )로 파일 전체 내용을 읽어 content 변수에 저장합니다.

❸ print(content)로 읽은 파일 내용, 즉 문자열을 화면에 출력합니다.

앞에서 쓴 코드와 실행 결과는 같지만, with 문을 사용하면 close( )를 직접 작성하지 않아도 됩니다. 그래서 앞으로 파일을 읽거나 쓸 때는 with 문을 사용하는 방식을 더 자주 보게 될 것입니다.

파일 입력은 단순히 파일 내용을 화면에 보여주는 데만 사용하는 것이 아닙니다. 파일에서 읽어 온 내용을 변수에 저장한 뒤, 그 값을 조건문이나 반복문으로 처리할 수도 있습니다. 예를 들어 점수표 파일을 읽어 학생 이름과 점수를 출력하거나, 메모 파일을 읽어 각 줄에 번호를 붙여 보여줄 수도 있습니다.

지금까지 입력과 출력의 기본 개념부터 파일을 읽고 쓰는 방법까지 알아봤습니다. 이제 파일 내용을 조금 더 세밀하게 다루는 방법으로 넘어가보겠습니다.

> **바로 핵심 요약**
>
> - 파일에 저장된 내용을 파이썬 코드로 읽어 오는 것을 파일 입력이라고 합니다.
> - open( ) 함수의 모드에 "r"을 넣으면 파일을 읽기 모드로 열 수 있습니다.
> - read( ) 메서드는 파일의 전체 내용을 읽어 하나의 문자열로 가져옵니다.
> - 파일 입력도 with 문과 함께 쓰면 close( )를 직접 작성하지 않아도 됩니다.
