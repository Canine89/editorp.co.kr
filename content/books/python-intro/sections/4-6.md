마지막으로 배울 자료형은 불리언 자료형입니다. 불리언 값인 True, False는 앞에서 in 연산자를 공부할 때 이미 스쳐 지나가듯 본 적이 있습니다.

> **미리 알아두세요!**
>
> - 불리언은 True와 Fal se 두 가지 값만 가지는 자료형입니다.
> - 비교나 검사의 결과로 불리언이 만들어지고, 이후 배울 if 문과 조합됩니다.

**불리언**(Boolean)은 불(Bool)이라고도 부르며, 참과 거짓을 나타내는 자료형입니다. 오직 참(True)과 거짓(False) 두 가지 값만 가지며, 파이썬 코드에서는 줄여서 bool이라고도 표기합니다.

프로그래밍에서는 어떤 조건이 참인지 거짓인지 판단한 뒤 그 결과에 따라 다르게 처리하는 일이 많습니다. 이때 불리언 자료형이 참과 거짓을 구분하는 열쇠가 됩니다.

## 불리언 기초 연습하기

이번에는 불리언 값을 직접 출력해보고, 다양한 표현식의 결과가 불리언 값으로 어떻게 나타나는지 확인하면서 불리언의 기초를 익혀봅시다.

## 연습 01 불리언 값 할당하고 자료형 확인하기

불리언은 True, False라는 키워드 그 자체가 값입니다. 글자로 되어 있어 문자열처럼 보일 수 있지만, 문자열은 큰따옴표나 작은따옴표로 감싸야 한다는 점이 다릅니다. 따옴표 없이 쓴 True, False는 문자열이 아니라 불리언 값이니 오해하지 마세요.

```python filename="04-48-boolean_values.py"
is_student = True
is_adult = False

print(is_student)
print(is_adult)
print(type(is_student))
```

**실행 결과**

```text
True
False
<class 'bool'>
```

실행 결과에서 자료형을 검사해서 알려주는 type(is_student)의 출력값은 <class 'bool'>입니다. 여기서 불리언 자료형을 나타내는 bool이라는 이름을 확인할 수 있습니다.

## 연습 02 표현식의 결과로 불리언 확인하기

불리언은 True, False로 직접 입력해 사용하는 경우도 있지만, 실제 프로그래밍에서는 다양한 표현식의 결과로 불리언 값을 얻는 경우가 많습니다. 다음은 age에 숫자를 담아서 나이를 비교하는 코드입니다. >, ==, < 연산자는 이후 다시 공부하겠습니다. 수학의 비교 기호와 비슷하므로 지금은 두 값을 비교하는 연산자라고 생각하면 됩니다.

```python filename="04-49-boolean_expressions.py"
age = 25

print(age > 20)
print(age == 30)
print(age < 18)
```

**실행 결과**

```text
True
False
False
```

실행 결과를 보면 표현식 age > 20, age == 30, age < 18이 불리언 값을 반환하는 것을 알 수 있습니다. 조건이 참이면 True, 그렇지 않으면 False를 반환하고 있네요. 만약 나이에 따라 미성년자인지 아닌지를 구분하는 프로그램을 만든다면 이후 배울 if 문과 조합하여 프로그램을 분기 처리할 수 있습니다.

```python filename="04-50-if_minor_true.py"
age = 15

if age < 18:
    print(f"{age}세는 미성년자입니다.")
    print("보호자 동의가 필요합니다.")
```

**실행 결과**

```text
15세는 미성년자입니다.
보호자 동의가 필요합니다.
```

if 문이 등장한 김에 미리 살펴보겠습니다. if 뒤에 작성한 조건식의 결과가 True인지 False인지에 따라 콜론(:) 다음 줄에 들여쓰기한 코드를 실행할지 결정합니다. age < 18 표현식의 결과가 True이므로 들여쓰기한 내용이 실행되어 바로 출력된 것입니다. 만약 age에 20을 저장하고 프로그램을 실행하면 조건식의 결과가 False가 되므로 아무것도 출력되지 않습니다.

```python filename="04-51-if_minor_false.py"
age = 20

if age < 18:
    print(f"{age}세는 미성년자입니다.")
    print("보호자 동의가 필요합니다.")
```

**실행 결과**

```text
(실행 결과 없음)
```

그림으로 이런 모습을 상상하면 됩니다.

불리언은 이 정도만 이해해도 충분합니다. 어차피 이후 문법을 공부하면서 불리언은 자연스럽게 알게 될 것입니다.

> **NOTE**
>
> 사실 이 그림은 분기를 처리하는 if 문의 동작을 설명하기에 적합하지는 않습니다. 다만 현재의 코드에서는 의미가 충분

히 전달된다고 판단해 사용했습니다. 왜 이 그림이 if 문을 설명하기에 적합하지 않은지는 if 문을 공부할 때 다시 언급하면서 설명하겠습니다.

> **바로 핵심 요약**
>
> - 불리언은 True, False 두 값을 가지는 자료형으로, type( )으로 확인하면 <class 'bool'>입니다.
> - 불리언은 직접 입력하기보다 >, ==, < 같은 비교 표현식의 결과로 얻는 경우가 많습니다.
> - if 문과 조합하면 불리언 값이 True인지 False인지에 따라 들여쓰기한 코드의 실행 여부를 결정할 수 있습니다.
