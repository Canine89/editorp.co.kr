여러분이 만들 프로그램에서 가장 중요한 것은 무엇일까요? 바로 데이터입니다. 프로그램은 이 데이터를 여러분이 정한 순서대로 처리하게 되어 있죠. 만약 여러분이 성적표를 출력하는 프로그램을 만든다면 성적 데이터가 필요할 겁니다.

![](/books/python-intro/69.png)

우리 주변의 프로그램도 마찬가지입니다. 여러분이 즐겨 사용하는 스레드도 텍스트, 이미지 데이터를 중심으로 매력적인 화면을 구성하는 SNS 서비스입니다. SNS에 아무런 글이 없고 사진도 없다면 SNS 자체가 성립하지 않겠죠?

![](/books/python-intro/70.png)

이렇게 데이터는 프로그래밍 세계에서 정말 중요한 요소라고 할 수 있습니다. 그런데 데이터는 각 성질에 따라 다르게 취급해야 할 필요가 있습니다. 예를 들어 숫자와 문자열은 서로 다르게 처리해야 이후 편의를 도모할 수 있습니다. 앞에서 숫자의 더하기와 문자열의 더하기가 다르게 처리되었던 것처럼 말이죠.

```python
# 숫자 더하기
a = 10
b = 5
print(a + b)
```

\[출력 결과\]

15

```python
# 문자열 더하기
name1 = "바로"
name2 = "바로"
print(name1 + name2)
```

\[출력 결과\]

바로바로

같은 더하기지만 다르게 취급하므로 결과가 다릅니다. 자료형은 수학으로 치면 수의 체계를 배우는 것과 같습니다. 여러분이 자연수, 실수를 배웠던 것처럼요. 앞으로 여러분이 다양한 문법을 배울 때 자료형을 제대로 알아두면 든든한 밑바탕이 될 겁니다. 그럼 파이썬의 자료형을 하나씩 알아봅시다.

#### <1:1코칭> 자료형이라고 부르지 않고 데이터 타입이라고 하는 사람도 있던데요?

프로그래밍 세계에서 개념을 영어 음차 표현으로 부르는 일도 많습니다. 그도 그럴 것이 프로그래밍은 영어권에서 먼저 발달했기 때문에 대부분 영어 표현을 많이 씁니다. 다만 저는 너무 과도한 영어 표현을 삼가기 위하여 가급적 한글 표현을 많이 사용하겠습니다. 물론 뜻을 너무 왜곡하거나 헷갈림의 소지가 있다면 영어 음차 표현, 영어 표현을 그대로 사용하겠습니다. 자료형은 이미 국내에서도 널리 퍼진 표현이므로 데이터 타입이라고 굳이 부르진 않았습니다.
