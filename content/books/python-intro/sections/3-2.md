본격적으로 파이썬을 다루기 전에 자료형과 데이터라는 개념부터 확실히 잡고 갑시다. 모든 프로그램은 결국 데이터를 다루는 일이고, 자료형은 그 데이터의 종류를 말합니다. 기본 개념만 정립하면 이후 공부가 훨씬 수월해지니 가벼운 마음으로 시작해봅시다!

> **미리 알아두세요!**
>
> - 프로그램이 다루는 모든 값은 자료형이라는 종류를 가집니다.
> - type( ) 함수로 값의 자료형을 확인할 수 있습니다.

## 프로그램은 데이터를 처리합니다

여러분이 만들 프로그램에서 가장 중요한 것은 무엇일까요? 바로 데이터입니다. 프로그램은 이 데이터를 작성자가 정한 순서대로 처리하도록 되어 있죠. 만약 여러분이 성적표를 출력하는 프로그램을 만든다면 성적 데이터가 필요할 것입니다.

![](/books/python-intro/p104-085.webp)

성적 데이터를 넣으면 프로그램이 이를 계산하여 보기 좋은 표 형태로 만들어줍니다. 우리 주변의 프로그램 대부분도 같은 방식으로 동작합니다. 여러분이 즐겨 사용하는 스레드 역시 텍스트와 이미지 데이터를 중심으로 매력적인 화면을 구성하는 SNS 서비스이죠. 만약 SNS에 글이나 사진 데이터가 전혀 없다면 서비스 자체가 성립하지 않을 겁니다.

![](/books/python-intro/p104-086.webp)

![](/books/python-intro/p105-087.webp)

이처럼 데이터는 프로그래밍 세계에서 핵심 요소 입니다. 그런데 데이터는 성질에 따라 다르게 취급해야 합니다. 이때 데이터의 성격을 구분하는 기준을 자료형이라고 부릅니다. 파이썬에는 숫자, 문자열처럼 값의 종류와 특성에 따라 다양한 자료형이 있습니다. 먼저 어떤 자료형이 있는지 다음 목록을 가볍게 살펴보고 넘어갑시다.

- **숫자 :** int(정수), float(실수), complex(복소수)

- **문자열 :** str

- **참과 거짓 :** bool

- **값이 없음을 나타낼 때 :** None

- **여러 값을 묶는 자료형 :** list(리스트), tuple(튜플), dict(딕셔너리), set(집합)

## 숫자의 더하기

데이터를 자료형으로 구분하는 이유는 성질에 따라 다르게 처리해야 오류를 줄이고 개발이 편리해지기 때문입니다. 앞서 보았듯이 숫자의 더하기와 문자열의 더하기는 서로 다르게 동작합니다. 먼저 파이썬 코드에서는 숫자를 어떻게 더하는지부터 알아보겠습니다.

![](/books/python-intro/p105-088.webp)

> **NOTE**
>
> 지금부터는 모든 코드를 파일로 작성해서 실행합니다. 비주얼 스튜디오 코드를 켜서 파일을 만들고 코드를 작성하여 저

장한 뒤 터미널에서 실행해보세요.

```python filename="03-01-number_add.py"
# 숫자 더하기
a = 10
b = 5
print(a + b)
```

**실행 결과**

```text
15
```

`10` 더하기 5의 결과는 당연히 15입니다. 그렇다면 숫자가 아닌 문자열을 더하면 어떻게 될까요?

## 문자열의 더하기

문자열을 더하는 코드를 입력하고 실행해봅시다.

```python filename="03-02-string_add.py"
# 문자열 더하기
name1 = "바로"
name2 = "바로"
print(name1 + name2)
```

**실행 결과**

```text
바로바로
```

"바로"와 "바로"를 더한 결과는 "바로바로"입니다. 사실 일상적인 언어에서 ‘문자열을 더한다’라는 개념 자체가 어색하게 느껴질 수 있습니다. 하지만 프로그래밍에서는 여러 텍스트를 이어 붙여 하나의 문장으로 만드는 일이 매우 흔합니다. 그래서 파이썬은 개발의 편의를 위해 문자열에도 더하기 연산자를 허용한다고 이해하면 됩니다. 그렇다면 곱하기 연산은 어떨까요?

## 문자열의 곱하기

이번에는 문자열을 곱하는 코드를 작성하고 실행해봅시다.

```python filename="03-03-string_repeat.py"
# 문자열 반복하기
name1 = "바로"
print(name1 * 10)
```

**실행 결과**

```text
바로바로바로바로바로바로바로바로바로바로
```

문자열에 숫자를 곱하니 해당 문자열이 곱한 숫자만큼 반복되어 출력됩니다. 앞에서 문자열 더하기 개념을 이해했다면 곱하기는 더하기의 반복이라는 맥락에서 자연스럽게 이해할 수 있을 겁니다.

이처럼 자료형을 배우는 것은 수학으로 치면 수의 체계를 배우는 것과 비슷합니다. 수의 체계에서 정수와 실수, 복소수의 성질과 처리 방식이 다른 것처럼 자료형에 따라서도 데이터를 처리하는 방식이 다르다고 생각하면 됩니다. 따라서 파이썬의 다양한 문법을 다루기 전에 자료형을 제대로 알아두면 든든한 밑바탕이 될 겁니다. 그럼 이제 파이썬의 자료형을 하나씩 알아봅시다.

![](/books/python-intro/p107-089.webp)

> **바로 핵심 요약**
>
> - 프로그램에서 가장 중요한 것은 데이터이고, 데이터의 종류를 나누는 기준이 자료형입니다.
> - 같은 더하기라도 숫자와 문자열은 자료형에 따라 다르게 처리됩니다.
