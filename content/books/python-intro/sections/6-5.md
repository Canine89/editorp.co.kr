지금까지는 반복문을 한 겹으로만 사용했습니다. 그런데 표를 만들거나 좌표를 훑는 일처럼 반복하는 과정 안에서 다시 반복해야 하는 상황도 있습니다. 이번 절에서는 반복문 안에 또 다른 반복문을 넣는 중첩 반복문을 배우고, 마지막에는 지금까지 배운 반복문을 활용하는 연습을 해보며 이 장을 마무리하겠습니다.

> **미리 알아두세요!**
>
> - 중첩 반복문은 바깥쪽 반복문이 한 번 실행될 때마다 안쪽 반복문이 처음부터 끝까지 실행됩니다.
> - 여러 단계로 구성된 데이터는 단계마다 반복문을 하나씩 두어 처리합니다.

## 중첩 반복문 기초 연습하기

**반복문 안에 또 다른 반복문을 넣어 사용하는 것을 중첩 반복문이라고 합니다.** 중첩 반복문을 쉽게 이해할 수 있는 대표적인 예가 구구단입니다. 여러분이 구구단을 외울 때를 생각해봅시다.

![](/books/python-intro/p273-181.webp)

```python
"2 x 1은 2, 2 x 2는 4, 2 x 3은 6, ..."
"3 x 1은 3, 3 x 2는 6, 3 x 3은 9, ..."
...
"7 x 1은 7, 7 x 2는 14, 7 x 3은 21, ..."
...
"9 x 1은 9, 9 x 2는 18, 9 x 3은 27, ..."
```

먼저 2단부터 시작해서 1부터 9까지 곱합니다. 그런 다음 3단, 4단, …, 9단에서도 같은 과정을 반복하죠. 결국 구구단은 각 단에서 숫자를 반복해서 곱하는 작은 반복과, 단 자체를 바꾸는 큰 반복이 겹쳐 있는 구조를 가집니다. 즉, 구구단을 외우는 구조 자체가 중첩 반복문입니다. 이 개념을 머릿속에 넣어두고 중첩 반복문을 이해해봅시다.

## 연습 01 while 문으로 중첩 반복문 사용해보기

중첩 반복문은 반복문 안에 또 다른 반복문을 넣어 사용합니다. while 문도 for 문처럼 중첩해서 사용할 수 있습니다. 기본적으로 중첩 반복문은 바깥쪽 반복문이 한 번 실행될 때마다 안쪽 반복문이 처음부터 끝까지 모두 실행됩니다. 이런 구조는 구구단이나 좌표 계산처럼 두 가지 기준을 함께 반복해야 하는 작업에서 자주 볼 수 있습니다. 코드를 실행해보면 중첩 while 문이 어떻게 동작하는지 금방 알 수 있습니다.

```python filename="06-25-nested_while.py"
i = 1
while i <= 3:
  j = 1
  while j <= 3:
    print(f"i={i}, j={j}")
    j += 1
  i += 1
```

**실행 결과**

```text
i=1, j=1
i=1, j=2
...생략...
i=3, j=2
i=3, j=3
```

결과를 보면 바깥쪽 while 문의 i가 1일 때, 안쪽 while 문이 j를 1부터 3까지 반복합니다. 안쪽 반복문이 끝난 뒤 i가 2가 되면 다시 j가 1부터 3까지 반복하는 것을 볼 수 있습니다. 안쪽 반복문이 완전히 끝나야 바깥쪽 반복문이 다음 반복으로 넘어간다는 점을 기억하세요.

## 연습 02 while 문으로 구구단 출력하는 프로그램 만들기

바깥쪽 반복문은 2단, 3단, 4단과 같이 단수를 나타내는 dan을 제어하고, 안쪽 반복문이 각 단에서 곱할 숫자인 num을 제어합니다. 예를 들어 바깥쪽 반복문이 2단, 3단, 4단을 바꾸는 역할을 한다면, 안쪽 반복문은 각 단에서 1, 2, 3처럼 곱할 숫자를 바꾸는 역할을 하는 것이죠. 이처럼 중첩 반복문은 두 가지 기준을 함께 반복해야 하는 작업에 유용합니다.

## 연습 03 숫자 카운트다운 만들기

로켓을 발사할 때 “10, 9, 8, 7... 발사!”와 같이 숫자를 거꾸로 세는 카운트다운을 본 적 있죠? 이번에는 사용자가 원하는 숫자부터 시작하는 카운트다운 프로그램을 만들어봅시다. 예를 들어 5를 입력하면 다음과 같이 출력하는 겁니다.

```python
5
4
3
2
1
발사!
```

여기서 중요한 것은 사용자에게 시작할 숫자를 입력받고, 그 숫자부터 거꾸로 출력하는 것입니다. 숫자를 거꾸로 처리하는 방법은 앞에서 연습했으므로 이번에는 input( ) 함수를 함께 사용해봅시다.

이미 공부했겠지만 복습해보자면, input( ) 함수는 사용자가 키보드로 값을 입력하고 `Enter`를 누를 때까지 입력을 기다린 뒤, 입력한 값을 문자열로 반환합니다. 따라서 숫자를 입력하더라도 문자열로 처리됩니다. 이 값을 range( ) 함수에 사용하려면 int( ) 함수로 감싸 정수로 변환해야 합니다.

> **NOTE**
>
> 만약 int( ) 함수로 감싸지 않으면 range( ) 함수에 전달해야 하는 값이 숫자가 아닌 문자열이 되어 range(0, start)에서

오류가 발생합니다.

```python filename="06-33-countdown.py"
start = int(input("몇부터 카운트다운할까요? "))

for count in range(0, start):
  print(start - count)

print("발사!   ")
```

[로켓] 이모지는 키보드에서 [~~~]를 눌러 입력할 수 있습니다

**실행 결과**

```text
몇부터 카운트다운할까요?
5
4
3
2
1
발사!
```

## 연습 04 평균 점수 계산기 만들기

이제 학생들의 시험 점수를 입력받아서 평균을 계산하는 프로그램을 만들어봅시다. 몇 명의 점수를 입력할지도 사용자가 직접 정할 수 있게 만들어보겠습니다. 예를 들어 학생이 4명이고 점수가 85, 90, 78, 92라면 프로그램이 다음과 같이 실행되면 됩니다.

```python
몇 명의 점수를 입력하시겠습니까? 4
1번 학생 점수: 85
2번 학생 점수: 90
3번 학생 점수: 78
4번 학생 점수: 92
```

**실행 결과**

```text
총점: 345점
평균: 86.25점
```

프로그램의 진행 방식을 보면 앞에서 만든 카운트다운 프로그램보다 input( ) 함수를 조금 더 적극적으로 활용한다는 것을 알 수 있습니다. 먼저 학생 수는 한 번만 입력받습니다. 반면 학생의 점수는 입력한 학생 수만큼 반복해서 받아야 합니다. 따라서 반복문 안에서 input( ) 함수를 사용해 각 학생의 점수를 차례대로 입력받으면 됩니다. 코드는 다음과 같이 작성합니다.

```python filename="06-34-student_score_average.py"
# 학생 수 입력받기
count = int(input("몇 명의 점수를 입력하시겠습니까? "))

# 총점을 저장할 변수
total = 0

# 각 학생의 점수 입력받기
for i in range(1, count + 1):
  score = int(input(f"{i}번 학생 점수: "))
  total = total + score

# 평균 계산
average = total / count

# 결과 출력
print(f"총점: {total}점")
print(f"평균: {average}점")
```

**실행 결과**

```text
몇 명의 점수를 입력하시겠습니까?
1번 학생 점수: 85
2번 학생 점수: 90
3번 학생 점수: 78
4번 학생 점수: 92
```

**실행 결과**

```text
총점: 345점
평균: 86.25점
```

> **NOTE**
>
> 이 프로그램은 사용자가 숫자를 입력한다고 가정하고 만들었습니다. 만약 “세 명”처럼 숫자가 아닌 값을 입력하면

int( ) 함수에서 오류가 발생하며 프로그램이 멈춥니다. 또 학생 수에 0을 입력하면 total / count에서 0으로 나누게 되어 ZeroDivisionError가 발생합니다. 05.3에서 배운 try~except 문을 사용하면 이런 상황에도 프로그램이 멈추지 않게 만들 수 있으니 직접 적용해보세요.

> **바로 핵심 요약**
>
> - while 문은 조건식이 True인 동안 반복하고, for 문은 리스트·튜플·딕셔너리·문자열처럼 순회할 수 있는 데이터를 하나씩 꺼내며 반복합니다.
> - break는 반복문을 즉시 빠져나오고, continue는 현재 회차의 남은 코드를 건너뛰고 다음 반복으로 넘어갑니다. range( ) 함수는 for 문과 조합해 정해진 횟수만큼 반복할 때 사용합니다.
> - 반복문 안에 또 다른 반복문을 넣는 중첩 반복문을 사용하면 여러 단계로 구성된 데이터를 처리할 수 있습니다. 리스트내포를 사용하면 반복문을 활용해 리스트를 만드는 코드를 간결하게 표현할 수 있습니다.
