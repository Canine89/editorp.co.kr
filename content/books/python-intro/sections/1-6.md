> **미리 알아두세요!**
>
> - 책에서는 실행 환경에 따라 터미널(>), 파이썬 인터프리터 셸(>>>), 비주얼 스튜디오 코드(기호 없음)로 구분해서 표시합니다.
> - 코드를 따라 칠 때 >나 >>> 기호 자체는 입력하지 않으며, 비주얼 스튜디오 코드에서는 파일 저장 여부와 작업 폴더 위치를 꼭 확인하세요.

## 터미널 명령어는 >로 표시합니다

컴퓨터에 프로그램을 설치하거나 파일·폴더를 조작하는 터미널 명령어 앞에는 `>` 기호를 표시하겠습니다. 앞으로 `>` 표시가 보이면 명령 프롬프트인 터미널에서 명령어를 입력하세요. 이때 `>` 기호는 여러분이 직접 입력하는 것이 아닙니다.

![](/books/python-intro/p066-053.webp)

```python
> mkdir newfolder
```

## 파이썬 인터프리터 셸은 >>>으로 표시합니다

한두 줄의 간단한 코드를 테스트할 때는 파이썬 인터프리터 셸을 사용하며, 코드 앞에 `>>>` 기호를 표시하겠습니다. `>>>` 표시가 보이면 '파이썬 인터프리터 셸에서 입력한다'고 이해하면 됩니다. 따라서 실습 예제에 `>>>` 표시가 있다면 터미널에서 python을 입력하고 `Enter`를 눌러 셸에 진입한 뒤, 코드를 작성해 결과를 확인해보세요.

> **NOTE**
>
> 코드 입력 시 >>> 기호 자체는 입력하지 않습니다.

![](/books/python-intro/p067-054.webp)

```python
> python
Python 3.13.5 (tags/v3.13.5:6cb20a2, Jun 11 2025, 16:15:46) ...생략...
Type "help", "copyright", "credits" or "license" for more information.
>>>
```

이 상태에서 다음 코드를 입력해봅니다. 당연히 `>>>` 표시는 입력하는 내용이 아닙니다.

```python
>>> print("안녕 파이썬?")
```

**실행 결과**

```text
안녕 파이썬?
```

## 비주얼 스튜디오 코드는 별도 기호 없이 표시합니다

마지막으로 별도 표시 없이 코드만 있다면 비주얼 스튜디오 코드에서 실행한다고 생각하면 됩니다. 이때는 적절한 폴더에 .py 파일을 만들어 코드를 작성하고, `Ctrl + S`를 눌러 저장한 다음 파일을 실행하여 결과를 확인해보기 바랍니다.

![](/books/python-intro/p068-055.webp)

비주얼 스튜디오 코드에서 실습을 할 때는 ❶ 현재 열려 있는 폴더가 여러분이 의도한 위치가 맞는지 확인하고, ❷ 탭의 파일명 옆 동그라미가 X 표시로 바뀌었는지 보고 파일이 정상적으로 저장되었는지 확인합니다. 또한 ❸ 코드를 실행할 때는 터미널 탭의 현재 폴더 위치가 ❶의 작업 폴더 위치와 같은지 확인하고 실행하세요. ❹ 명령어 입력이 번거롭다면 깃허브 코파일럿에게 파일을 실행해달라고 요청해도 됩니다.

> **바로 핵심 요약**
>
> - >는 터미널 명령어, >>>는 파이썬 인터프리터 셸에 입력하는 코드이며, 별도 기호가 없는 코드는 비주얼 스튜디오 코드에서 실행합니다.
> - 비주얼 스튜디오 코드에서는 작업 폴더와 터미널의 현재 위치가 같은지, 작성한 파일이 정상적으로 저장되었는지 확인한 뒤 실행합니다.
