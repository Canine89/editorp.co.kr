## [연습 02] 표현식을 포함한 f-string 연습하기

앞에서 표현식은 어떤 값으로 대체되는 코드 조각이라고 했습니다. f-string은 단순히 변수만 사용할 수 있는 것이 아니라 num1 + num2와 같은 표현식도 사용할 수 있습니다. num1, num2, num1 + num2 모두 표현식입니다. 표현식을 {와 }로 감싸면 f-string으로 바로 표현식의 값을 출력할 수 있습니다.

```python
# 숫자 입력
num1 = 15
num2 = 7

# 계산하고 출력
print("=== 계산 결과 ===")
print(f"{num1} + {num2} = {num1 + num2}")
print(f"{num1} - {num2} = {num1 - num2}")
print(f"{num1} × {num2} = {num1 * num2}")
print(f"{num1} ÷ {num2} = {num1 / num2}")
```

같은 방식으로 실습한 결과입니다. 이제 출력 결과는 간단하게 \[출력 결과\]라고 표시한 박스에 표시해두겠습니다.

## [연습 03] 성적표 출력 프로그램 만들기

변수를 공부하면 가장 흔하게 해보는 성적표 출력 프로그램 만들기입니다. 이때 마지막 줄에 있는 .1f는 f-string에서 사용할 수 있는 포맷 지정자입니다. 포맷 지정자는 여기서 숫자에만 사용했는데 문자열에도 사용할 수 있습니다. 포맷 지정자는 이후 자세히 공부하겠습니다. .1은 소수점 1자리까지 표현하겠다는 뜻이고 f는 실수(float)를 의미합니다. 실수는 이후 자료형에서 배울 개념인데 수학 개념을 알고 있다면 여러분이 알고 있는 그 실수가 맞습니다.

```python
# 과목별 점수
korean = 85
english = 92
math = 78

# 총점과 평균 계산
total = korean + english + math
average = total / 3

# 성적표 출력
print("=== 성적표 ===")
print("국어:", korean, "점")
print("영어:", english, "점")
print("수학:", math, "점")
print("-" * 15)
print(f"총점: {total}점")
```

print(f"평균: {average:.1f}점")  \# 소수점 1자리까지, .1는 소수점 1자리까지 표현

\[출력 결과\]

\=== 성적표 ===

국어: 85 점

영어: 92 점

수학: 78 점

\---------------

총점: 255점

평균: 85.0점

## [연습 05] 이스케이프 문자로 특수기호 출력하기

하지만 다른 방법도 있습니다. 바로 이스케이프 문자 \\를 사용하는 겁니다. 흔히 슬래시라고 부르는 /와는 다른 키로 입력해야 하는 문자입니다. 보통 \[Enter\] 키 위쪽에 위치하고 있습니다.

이스케이프 문자를 입력한 다음의 특수기호는 일반 문자로 취급합니다. 예를 들어 파이썬에서 큰따옴표는 문자열을 표현하기 위한 수단이지만 이스케이프 다음에 큰따옴표를 연이어 입력하면 일반 문자로 취급하는 것이죠. 그래서 큰따옴표로 감싼 문자열 안에서 큰따옴표를 출력하려면 다음과 같이 코드를 입력하면 됩니다.

```python
>>> print("그는 \"안녕하세요\"라고 말했다.")
```

그는 "안녕하세요"라고 말했다.

결과를 보면 큰따옴표로 감싼 문자열 안에서 큰따옴표를 그대로 출력하기 위해 이스케이프 문자를 사용하여 \\"라고 표현한 것이 바로 그겁니다. 이스케이프 문자는 생각보다 자주 사용하는 구성 요소입니다. 기억해두면 언젠가 요긴하게 써먹을 일이 있을 겁니다.

## [연습 06] \n으로 줄바꿈하기

문자열 내에 이스케이프와 n을 붙여 입력하면 줄바꿈을 출력합니다. 줄바꿈을 출력한다는 건 우리가 워드와 같은 편집기에서 \[Enter\]를 눌러 행을 띄는 것과 같습니다.

```python
>>> print("안녕하세요!\n파이썬 공부 중이에요.\n화이팅!")
```

안녕하세요\!

파이썬 공부 중이에요.

화이팅\!

실행 결과를 보면 줄바꿈이 되어 있습니다. 코드의 \\n이 \[Enter\]를 입력하는 것과 같습니다. 인식의 전환이 필요한데 컴퓨터는 \[Enter\]도 문자로 인식한다는 점이고, 바로 그 문자를 표시할 방법이 \\n이라는 겁니다. 사람은 \[Enter\]를 누르는 버튼으로 생각하지만 컴퓨터에게는 어쨌든 이것도 입력입니다.
