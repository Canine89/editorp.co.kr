## 표현식을 포함한 f-string 연습하기

표현식은 실행했을 때 하나의 값으로 평가되는 코드 조각이라고 했습니다. f-string은 단순 변수뿐만 아니라 num1 + num2와 같은 표현식도 사용할 수 있습니다. num1이나 num2 같은 변수도, num1 + num2처럼 변수를 더한 연산식도 모두 하나의 값으로 평가되는 표현식입니다. 표현식을 중괄호 { }로 감싸면 f-string 안에서 바로 그 값을 계산하여 출력할 수 있습니다.

```python filename="02-01-number.py"
# 숫자 저장
num1 = 15
num2 = 7
# 계산하고 출력
print("=== 계산 결과 ===")
print(f"{num1} + {num2} = {num1 + num2}")
print(f"{num1} - {num2} = {num1 - num2}")
print(f"{num1} × {num2} = {num1 * num2}")
print(f"{num1} ÷ {num2} = {num1 / num2}")
```

## 성적표 출력 프로그램 만들기

변수를 공부할 때 가장 흔하게 만들어보는 성적표 출력 프로그램을 작성해봅시다. 코드 마지막 줄에 있는 .1f는 f-string에서 사용하는 포맷 지정자입니다. 포맷 지정자는 숫자 외에 문자열에도 적용할 수 있으며, 이에 대한 자세한 내용은 뒤에서 다룹니다. 여기서 ‘.1f’는 값을 소수점 아래 한 자리까지 고정 소수점 형식으로 표시한다는 뜻입니다. 평균인 average처럼 소수점이 있는 수를 실수라고 합니다.

> **NOTE**
>
> 실수는 소수점이 있는 수를 다루는 자료형으로, 에서 자세히 배웁니다.

```python filename="02-02-report_card.py"
# 과목별 점수
korean = 85
english = 92
math = 78
# 총점과 평균 계산
total = korean + english + math
average = total / 3
# 성적표 출력
print("=== 성적표 ===")
print("국어:", korean, "점")
print("영어:", english, "점")
print("수학:", math, "점")
print("-" * 15)
print(f"총점: {total}점")
print(f"평균: {average:.1f}점")  # .1f는 소수점 아래 1자리까지 표시
```

**실행 결과**

```text
=== 성적표 ===
국어: 85 점
영어: 92 점
수학: 78 점
---------------
총점: 255점
평균: 85.0점
```

## 문자열 안에 따옴표를 표현하여 출력하기

파이썬에서는 문자열을 작성할 때 반드시 큰따옴표나 작은따옴표로 감싸야 합니다. 그렇다면 큰따옴표 자체를 문자열 안에 포함해 출력하고 싶다면 어떻게 해야 할까요? 큰따옴표를 출력하고 싶다면 이렇게 하면 됩니다.

```python
>>> print('그는 "안녕하세요"라고 말했다.') # 그는 "안녕하세요"라고 말했다.
```

이처럼 전체 문자열을 작은따옴표로 감싸고, 그 안에 큰따옴표를 사용하는 것이 가장 간편한 방법입니다. 반대로 작은따옴표를 출력하고 싶다면 큰따옴표 안에 작은따옴표를 사용하면 됩니다. 즉 전체 문자열을 큰따옴표로 감싸면 되죠.

```python
>>> print("It's a beautiful day!") # It's a beautiful day!
```

## 이스케이프 문자로 특수 기호 출력하기

또 다른 방법으로는 이스케이프 문자인 백슬래시 \를 사용하는 겁니다. 일반 슬래시와는 다른 키로 보통 `Enter` 키 위쪽에 위치하고 있습니다.

![](/books/python-intro/p096-080.webp)

**이스케이프 문자는 바로 뒤에 오는 문자의 본래 의미를 바꾸는 역할을 합니다. 큰따옴표나 작은따옴표 같은 특수 기호는 일반 문자로 취급하고, n과 같은 일반 문자는 ‘줄바꿈’이라는 특수 기능으로 작동하게 만듭니다.** 예를 들어 파이썬에서 큰따옴표는 문자열을 표현하기 위한 수단이지만 이스케이프 문자 다음에 큰따옴표를 연이어 입력하면 일반 문자로 취급하는 것이죠. 따라서 큰따옴표로 감싼 문자열 안에서 큰따옴표를 그대로 출력하려면 다음과 같이 작성하면 됩니다.

![](/books/python-intro/p096-081.webp)

```python
>>> print("그는 \"안녕하세요\"라고 말했다.") # 그는 "안녕하세요"라고 말했다.
```

이처럼 큰따옴표 앞에 이스케이프 문자를 붙여 \" 형태로 써주면 큰따옴표가 문자로 인식되어 출력됩니다. 이스케이프 문자는 생각보다 자주 사용하는 요소이므로, 기억해두면 언젠가 요긴하게 써먹을 일이 있을 겁니다.

## \n으로 줄바꿈하기

문자열 내에 이스케이프 문자 \와 n을 붙여 \n을 입력하면 줄바꿈으로 출력됩니다. 줄바꿈을 출력한다는 건 우리가 워드와 같은 편집기에서 `Enter`를 눌러 행을 바꾸는 것과 같습니다.

```python
>>> print("안녕하세요! \n파이썬 공부 중이에요. \n파이팅!")
```

![](/books/python-intro/p097-082.webp)

**실행 결과**

```text
안녕하세요!
파이썬 공부 중이에요.
파이팅!
```

실행 결과를 보면 줄바꿈이 되어 있는 것을 확인할 수 있습니다. 코드에 작성한 \n이 `Enter` 키를 누르는 것과 같은 방식으로 처리된 것이죠. 여기서 한 가지 생각의 전환이 필요합니다. 컴퓨터는 `Enter` 입력조차 하나의 문자로 취급한다는 점입니다. 그리고 코드 안에서 그 문자를 표현하기 위해 사용하는 약속된 기호가 \n인 거죠. 사람은 `Enter`를 단지 줄을 바꾸는 버튼으로 여기지만 컴퓨터에게는 이 또한 엄연히 전달받은 하나의 입력입니다.

## 삼중따옴표로 출력하기

만약 따옴표 종류나 줄바꿈 기호 등 이런 거 저런 거 신경 쓰고 싶지 않고 긴 내용을 한 번에 출력하고 싶다면 삼중따옴표를 활용하면 됩니다. 삼중따옴표는 큰따옴표 또는 작은따옴표를 3번 연이어 사용해 감싸는 방식으로 """ 또는 '''와 같이 사용합니다.

```python filename="02-03-triple_quote.py"
code_example = '''
"이것은 여러 줄 문자열입니다"
"삼중따옴표로 감싸면 자유롭게 텍스트를 여러 줄 표시하거나 특수 문자를 출력할 수 있습니다"
'''
print(code_example)
```

**실행 결과**

```text
"이것은 여러 줄 문자열입니다"
"삼중따옴표로 감싸면 자유롭게 텍스트를 여러 줄 표시하거나 특수 문자를 출력할 수 있습니다"
```

실행해보니 삼중따옴표로 감싼 내용이 잘 출력되었습니다. 삼중따옴표 역시 큰따옴표, 작은따옴표를 가리지 않고 모두 표현할 수 있으며, f-string도 사용할 수 있습니다.

```python filename="02-04-fstring_triple.py"
name = "바로"

'''
```
