지금까지 우리는 변수의 값을 확인하거나 조건문과 반복문의 실행 결과를 살펴볼 때 print( ) 함수를 자연스럽게 사용했습니다. 지금까지는 주로 문법을 익히고 코드의 실행 결과를 확인하기 위한 도구로 사용했다면, 이번에는 프로그램에서 '출력'이 무엇을 의미하는지 조금 더 넓게 살펴보겠습니다. 이미 익숙한 내용이니 복습하는 마음으로 시작해봅 시다.

> **미리 알아두세요!**
>
> - 출력은 프로그램이 처리한 결과를 밖으로 내보내는 것입니다.
> - 화면 출력뿐 아니라 파일 저장, 소리, 그림도 모두 출력입니다.

## 프로그램이 처리한 결과를 내보내는 출력

**프로그램이 처리한 결과를 화면이나 파일, 장치 등을 통해 바깥으로 내보내는 것을 출력이라고 합니다.** 이미 여러 번 사용했듯이 파이썬에서 값을 화면에 출력할 때는 print( ) 함수를 사용할 수 있습니다. 먼저 익숙한 print( ) 함수로 화면에 출력하는 예제를 살펴봅시다.

```python filename="09-01-show_order.py"
# ➊ 주문 출력 함수 정의
def show_order(menu, price):
  print(f"주문 메뉴: {menu}")
  print(f"결제 금액: {price}원")
  print("주문이 완료되었습니다.")

show_order("아메리카노", 3000)    # ➋ 첫 번째 주문 출력
show_order("카페라테", 4500)     # ➌ 두 번째 주문 출력
```

**실행 결과**

```text
주문 메뉴: 아메리카노
결제 금액: 3000원
주문이 완료되었습니다.
```

```python
주문 메뉴: 카페라테
결제 금액: 4500원
주문이 완료되었습니다.
```

❶ def show_order(menu, price):는 주문 정보를 화면에 보여주는 함수를 정의한 것입니다. 이 함수는 menu와 price라는 값을 받아서 주문 메뉴와 결제 금액을 출력합니다. 함수 안에 있는 세 줄의 print( )는 각각 메뉴, 금액, 주문 완료 문장을 화면에 보여줍니다.

❷ show_order("아메리카노", 3000)는 show_order( ) 함수를 첫 번째로 호출한 것입니다. 함수가 실행되면서 주문 메뉴와 결제 금액을 출력합니다. 실행 결과로 아메리카노 주문 정보와 결제 금액이 화면에 출력됩니다.

❸ show_order("카페라테", 4500)는 show_order( ) 함수를 다시 호출하며, 같은 코드 블록을 한 번 더 실행합니다. 전달하는 값만 달라졌으므로 실행 결과에는 카페라테 주문 정보와 결제 금액이 출력됩니다.

지금까지는 이처럼 print( )로 출력한 결과를 주로 터미널에서 확인했습니다. 하지만 프로그램에서 말하는 출력은 단순히 화면에 글자를 보여주는 것보다 훨씬 넓은 개념입니다. 우리 주변의 프로그램이 어떤 형태로 결과를 내보내는지 살펴봅시다.

## 현실 속 프로그램의 다양한 출력

프로그램의 출력은 결과를 내보내는 방법에 따라 다음처럼 여러 형태로 생각해볼 수 있습니다.

1. 화면에 보여주는 출력2. 소리로 들려주는 출력3. 파일로 저장하는 출력4. 종이나 장치로 내보내는 출력 가장 쉽게 떠올릴 수 있는 것은 화면 출력입니다. 쇼핑몰 웹사이트에서 물건을 주문하면 주문 번호, 결제 금액, 배송 예정일 등이 화면에 나타납니다. 은행 앱에서 이체하면 받는 사람, 보낸 금액, 이체 완료 여부가 표시되고, 날씨 앱은 오늘의 기온과 강수 확률을 글자와 아이콘으로 보여줍니다. 지도 앱에서 목적지까지 가는 길을 선과 안내 문구로 보여주는 것도 화면 출력의 한 예입니다.

![](/books/python-intro/p416-251.webp)

소리를 통해 결과를 전달하는 것도 출력으로 볼 수 있습니다. 메신저 앱에서 새 메시지가 도착했을 때 알림 소리를 내거나 음악 앱에서 음악을 재생하는 것처럼 프로그램은 스피커와 같은 장치를 통해 소리를 내보낼 수 있습니다.

![](/books/python-intro/p416-252.webp)

출력은 화면이나 소리처럼 그 순간 확인하는 형태에만 머무르지 않습니다. 프로그램이 처리한 결과를 파일로 저장하는 것도 출력의 한 형태입니다. 문서 편집 프로그램에서 작성한 내용을 저장하면 .docx 같은 문서 파일이 만들어지고, 사진 편집 프로그램에서 이미지를 내보내면 .png나 .jpg 파일이 만들어집니다. 스프레드시트 프로그램에서 표를 파일로 저장하는 것도 마찬가지입니다. 프로그램의 결과를 다른 장치로 내보낼 수도 있습니다. 대표적인 예가 프린터입니다. 문서를 프린터로 보내면 프로그램에서 처리한 내용이 종이에 인쇄되어 나옵니다.

이처럼 출력은 프로그램이 처리한 결과를 화면에 보여주는 것뿐만 아니라 소리로 들려주거나, 파일로 저장하거나, 다른 장치로 보내는 것까지 포함합니다. 이제 출력의 의미를 넓게 살펴봤으니, 다음으로는 프로그램의 결과를 파일에 직접 저장하는 파일 출력을 알아보겠습니다.

> **바로 핵심 요약**
>
> - 출력은 프로그램이 처리한 결과를 화면이나 파일처럼 바깥으로 내보내는 것을 말합니다.
> - 파이썬에서 화면에 값을 출력할 때는 print( ) 함수를 사용합니다.
> - 출력에는 화면에 보여주는 것뿐만 아니라 소리로 들려주기, 파일로 저장하기, 프린터와 같은 장치로 내보내기 등 다양한 형태가 있습니다.
