필요한 기능을 매번 처음부터 만들 필요는 없습니다. 파이썬에는 다양한 기능이 모듈로 준비되어 있고, 우리가 직접 만든 파이썬 파일도 모듈로 사용할 수 있습니다. 먼저 모듈을 공구 상자처럼 꺼내 사용하는 방법부터 알아보겠습니다.

> **미리 알아두세요!**
>
> - 모듈은 관련 있는 함수와 변수를 모아둔 파이썬 파일입니다.
> - import 문을 사용하면 다른 모듈의 기능을 가져올 수 있습니다.

## 공구 상자 같은 모듈

**모듈**(module)**은 관련 있는 함수, 변수, 클래스 등의 코드를 하나의 파이썬 파일에 모아 사용할 수 있게 만든 것입니다.** 파이썬에서는 직접 작성한 .py 파일 하나를 모듈로 사용할 수 있으며, 파이썬이 미리 제공하는 모듈도 있습니다. 마치 공구 상자에서 필요한 공구를 꺼내 쓰듯이 모듈을 가져오면 그 안에 들어 있는 기능을 사용할 수 있는 거죠. 예를 들어 수학 계산을 하고 싶을 때 import math라고 작성하면 수학 계산에 필요한 기능을 담은 math 모듈을 불러와 사용할 수 있습니다. 모듈을 불러온 다음에는 math.sqrt(81)과 같이 모듈 안에 있는 함수를 사용해 쉽게 제곱근을 계산할 수 있습니다.

![](/books/python-intro/p500-307.webp)

그럼 정말로 그런지 코드를 통해 확인해봅시다. 다음은 math 모듈에서 제곱근을 구하는 sqrt( ) 함수와 올림에 사용하는 ceil( ) 함수를 사용하는 코드입니다. **여기부터는 파일을 생성해서 코드를 작성한 뒤 터미널에서 python 명령어로 실행하는 방식으로 실습하기 바랍니다.**

```python filename="11-01-math_module.py"
import math                      # ➊ math 모듈 가져오기
print(math.sqrt(81))             # ➋ 제곱근 계산
print(math.ceil(3.2))            # ➌ 올림 계산
```

**실행 결과**

```text
9.0
4
```

❶ import 뒤에 모듈 이름을 적으면 해당 모듈을 가져와 현재 파일에서 사용할 수 있습니다. import 문은 보통 파일 맨 위쪽에 작성합니다.

❷ math.sqrt(81)은 81의 제곱근을 구합니다. 모듈 안에 있는 기능을 사용하려면 math.sqrt( )처럼 모듈 이름 뒤에 점을 찍고 사용할 이름을 작성합니다.

❸ math.ceil(3.2)는 3.2 이상인 정수 중 가장 작은 값인 4를 반환합니다.

모듈을 사용하는 과정이 바로 이해가 되었을 겁니다. 그런데 math.sqrt( ), math.ceil( )처럼 기능을 쓸 때마다 모듈 이름을 앞에 붙이다 보면 코드가 길어집니다. 그래서 모듈에서 필요한 이름만 골라 현재 파일로 가져오는 방법도 알아보겠습니다.

![](/books/python-intro/p501-308.webp)

## 모듈에서 필요한 기능만 가져오기

from 모듈 import 이름 형태로 작성하면 모듈에 정의된 이름 중 필요한 이름을 골라 현재 파일에서 직접 사용할 수 있습니다. 그러면 이후에는 모듈 이름과 점을 붙이지 않고 해당 이름을 바로 사용할 수 있으며, 이 파일에서 어떤 기능을 사용하는지도 한눈에 드러납니다. 이렇게 필요한 기능만 가져오려면 다음과 같이 from 모듈 import 이름 형태로 작성하면 됩니다.

![](/books/python-intro/p502-309.webp)

```python filename="11-02-math_from.py"
from math import pi, floor       # ➊ 필요한 이름 가져오기
print(f"원주율: {pi:.2f}")       # ➋ 원주율 출력
print(floor(7.9))               # ➌ 내림 계산
```

**실행 결과**

```text
원주율: 3.14
7
```

❶ math 모듈에서 pi와 floor를 가져왔습니다. 이제 math.pi, math.floor( )라고 작성하지 않고 pi, floor( )처럼 바로 사용할 수 있습니다.

❷ pi에는 원주율 값이 들어 있습니다. 여기서는 :.2f를 사용해 소수점 아래 둘째 자리까지 출력했습니다.

❸ floor(7.9)는 7.9 이하인 정수 중 가장 큰 값인 7을 반환합니다.

### 모듈 이름에 별명 붙이기, as

만약 모듈 이름이 길거나 자주 사용해야 한다면 as를 사용해 별명을 붙일 수도 있습니다. 예를 들어 import statistics as stats라고 작성하면 statistics 모듈의 이름을 쓰는 대신 별명인 stats를 사용할 수 있으므로 statistics.mean( ) 대신 stats.mean( )처럼 쓸 수 있습니다.

![](/books/python-intro/p502-310.webp)

```python filename="11-03-statistics_as_stats.py"
import statistics as stats
바로_점수 = [85, 90, 78, 92, 88]
평균 = stats.mean(바로_점수)
print(f"바로의 평균 점수는 {평균}점입니다.")
```

**실행 결과**

```text
바로의 평균 점수는 86.6점입니다.
```

> **바로 핵심 요약**
>
> - 모듈은 함수, 변수, 클래스 등의 코드를 하나의 단위로 묶어 사용할 수 있게 만든 것으로, 직접 작성한 .py 파일도 모듈로 사용할 수 있습니다.
> - import 모듈 형태로 모듈 전체를 가져온 뒤 모듈.함수( ) 형태로 기능을 사용합니다.
> - from 모듈 import 이름 형태로 모듈 안의 필요한 이름을 직접 가져올 수도 있습니다.
