리스트, 튜플, 딕셔너리를 지나 집합에 도착했습니다. 집합은 수학 시간에 배운 개념을 그대로 가져온 자료형입니다. **집합은 중복 없이 데이터를 묶어 관리하고 싶을 때 사용합니다.** 사실 집합은 길게 설명할 내용이 많지 않습니다. 자료형의 특징만 이해하고 적절하게 사용하면 됩니다.

> **미리 알아두세요!**
>
> - 집합은 중복을 허용하지 않는 자료형입니다.
> - 리스트, 튜플, 딕셔너리를 set( ) 함수에 넣어 집합으로 만들 수 있습니다.

## 집합 기초 연습하기

집합은 중복된 요소를 하나로 정리하여 고유한 값만 관리하는 자료형입니다. 리스트나 튜플과 달리 요소의 순서를 기준으로 관리하지 않기 때문에 인덱싱이나 슬라이싱을 사용할 수 없습니다. 대신 중복을 제거하거나 여러 데이터에서 공통된 값, 서로 다른 값 등을 찾을 때 유용합니다. 예를 들어 여러분이 어떤 데이터를 관리할 때 중복을 원하지 않는다면 어떻게 해야 할까요? 바로 집합을 사용하면 됩니다. 집합은 앞에서 배운 여러 데이터를 묶는 자료형을 set( ) 함수에 넣어 만들 수 있습니다.

## 연습 01 리스트로 집합 만들기

다음은 리스트를 집합으로 만드는 코드입니다. 중복이 제거되는 특징을 확인할 수 있도록 리스트에 중복 요소를 일부러 넣었습니다.

```python filename="04-43-set_from_list.py"
numbers = [1, 2, 2, 3, 3, 3, 4, 5]
unique_numbers = set(numbers)

print(unique_numbers)
```

set( ) 함수에 넣기만 하면 중복이 사라지네요!

**실행 결과**

```text
{1, 2, 3, 4, 5}
```

실행 결과를 보면 리스트에 있던 중복된 요소가 하나씩만 남고 대괄호로 감쌌던 내용이 중괄호로 바뀌었습니다. 이처럼 집합은 중괄호로 감싸 표현합니다.

## 연습 02 튜플로 집합 만들기

튜플을 set( ) 함수에 넣어도 집합을 만들 수 있습니다. 다만 여기서 중요한 사실이 하나 있습니다. 집합은 요소의 순서에 의존하지 않는다는 점입니다. 다음 코드를 실행해보면 지금 이야기한 '순서를 신경 쓰지 않음'의 의미를 명확하게 알 수 있습니다.

```python filename="04-44-set_from_tuple.py"
colors_tuple = ("red", "blue", "red", "green", "blue", "yellow")
colors_set = set(colors_tuple)

print(f"원본 튜플: {colors_tuple}")
print(f"집합 변환: {colors_set}")
```

**실행 결과**

```text
                             'blue', 'yellow')
집합 변환: {'yellow', 'blue', 'green', 'red'}
```

실행 결과를 보면 튜플에 있던 중복된 "red"와 "blue"가 하나씩만 남고, 원본이었던 튜플과 요소의 순서도 달라진 것을 확인할 수 있습니다. 집합은 요소의 순서를 보장하지 않으므로 출력 결과의 순서는 코드 실행 환경에 따라 달라질 수 있습니다.

## 연습 03 딕셔너리로 집합 만들기

딕셔너리도 set( ) 함수에 전달하여 집합으로 만들 수 있지만, 딕셔너리를 집합으로 변환하면 키만 집합화의 대상이 됩니다. 따라서 다음과 같이 코드를 입력하면 원본 딕셔너리는 그대로 두고 키만 모은 새 집합을 만듭니다.

```python filename="04-45-set_from_dictionary_keys.py"
student = {"name": "김철수", "age": 20, "major": "컴퓨터공학"}
keys_set = set(student)

print(keys_set)
```

**실행 결과**

```text
{'name', 'age', 'major'}
```

물론 값만 집합으로 만들고 싶다면 딕셔너리의 값만 추출해주는 values( ) 함수를 써서 student. values( )와 같이 값을 따로 뽑아 집합화하면 됩니다.

```python filename="04-46-set_from_dictionary_values.py"
student = {"name": "김철수", "age": 20, "major": "컴퓨터공학", "age2": 20}
values_set = set(student.values())

print(values_set)
```

**실행 결과**

```text
{'김철수', 20, '컴퓨터공학'}
```

실행 결과를 보면 age와 age2에 똑같이 넣었던 20이 하나만 남았습니다. 값을 모아 집합으로 만드는 과정에서 중복이 사라진 것입니다.

**딕셔너리는 이름에서 유추할 수 있듯이 사전과 비슷한 구조로 만들어졌기 때문에 하나의 키에 하나의 값을 연결하므로 중복된 키가 있을 수 없습니다. 결론적으로 딕셔너리도 집합으로 만들 수는 있지만,** 애초에 키는 중복될 수 없으므로 딕셔너리의 키를 집합으로 바꿀 필요는 없습니다. 다만 중복이 가능한 값(value)의 종류만 모아서 보고 싶을 때는 꽤 유용하게 사용할 수 있습니다.

## 설문조사 응답에서 중복 제거하기

집합을 사용하는 실용적인 예를 하나 살펴보겠습니다. 예를 들어 여러분이 사용자 설문조사 데이터를 수집했고, '어떤 과일을 좋아하나요?'라는 문항이 있다고 해봅시다. 이때 가장 먼저 파악해야 할 내용은 응답에 포함된 과일의 종류와 가짓수입니다. 이럴 때 집합이 유용합니다. 다음 코드를 작성해 중복 제거의 묘미를 느껴봅시다.

```python filename="04-47-set_remove_duplicates.py"
# 설문조사에서 응답자들이 좋아하는 과일을 수집했습니다
responses = ["사과", "바나나", "사과", "오렌지", "바나나", "사과", "포도",  "오렌지", "바나나"]

print(f"전체 응답 수: {len(responses)}")
print(f"응답 내역: {responses}")

# 중복을 제거하여 어떤 종류의 과일이 언급되었는지 확인
unique_fruits = set(responses)

print(f"\n언급된 과일 종류: {unique_fruits}")
print(f"과일 종류 개수: {len(unique_fruits)}")
```

**실행 결과**

```text
전체 응답 수: 9
응답 내역: ['사과', '바나나', '사과', '오렌지', '바나나', '사과', '포도', '오렌지', '바
나나']
```

**실행 결과**

```text
언급된 과일 종류: {'바나나', '포도', '사과', '오렌지'}
과일 종류 개수: 4
```

9개의 응답이 있었지만 실제로는 4종류의 과일만 언급된 것을 집합을 통해 금방 확인할 수 있습니다. 이처럼 집합은 중복을 제거하고 데이터의 종류를 파악하는 데 탁월합니다.

## 집합끼리 연산해보기

집합은 중복을 없애는 것 말고도 쓸모가 하나 더 있습니다. 두 집합을 놓고 '둘을 합치면?', '둘 다 가지고 있는 것은?', '나만 가지고 있는 것은?'과 같은 작업을 한 줄로 계산할 수 있다는 점입니다. 학교에서 배운 합집합, 교집합, 차집합이 그대로 파이썬 연산자로 준비되어 있습니다. 그리고 지금까지는 set( ) 함수로 집합을 만들었지만, 처음부터 값을 알고 있다면 중괄호로 바로 적어도 됩니다.

```python filename="04-48-set_operations.py"
a = {1, 2, 3, 4}       # ➊ 중괄호로 바로 집합 만들기
b = {3, 4, 5, 6}

print(a | b)           # ➋ 합집합
print(a & b)           # ➌ 교집합
print(a - b)           # ➍ 차집합

print(a.union(b))        # ➎ 연산자 대신 함수로도 가능
print(a.intersection(b))
print(a.difference(b))
```

합집합은 |, 교집합은 &, 차집합은 -

**실행 결과**

```text
{1, 2, 3, 4, 5, 6}
{3, 4}
{1, 2}
{1, 2, 3, 4, 5, 6}
{3, 4}
{1, 2}
```

❶ 중괄호 안에 값을 쉼표로 나열하면 집합이 만들어집니다. 딕셔너리도 중괄호를 사용하지만 딕셔너리는 키: 값 형태이고 집합은 값만 적는다는 점이 다릅니다. 단, 빈 중괄호 { }는 빈 딕셔너리를 의미하므로 빈 집합을 만들 때는 반드시 set( ) 함수를 써야 합니다.

❷ |는 합집합 연산자입니다. 두 집합의 모든 요소를 모으되, 중복된 요소는 한 번만 남깁니다. 3과 4가 양쪽에 있었지만 결과에는 한 번씩만 나타납니다.

❸ &는 교집합입니다. 두 집합이 공통으로 가진 값만 남깁니다.

❹ -는 차집합 연산자입니다. a에는 있지만 b에는 없는 값만 남습니다. 순서를 바꿔 b - a를 하면 {5, 6}이 나오므로 차집합에서는 두 집합의 순서가 중요합니다.

❺ 연산자가 낯설다면 union( ), intersection( ), difference( ) 함수를 써도 결과는 같습니다. 코드를 작성하는 상황이나 읽는 사람에 따라 편한 방법을 선택하면 됩니다.

예를 들어 이번 달 구매자 집합과 지난달 구매자 집합이 있다면 교집합은 두 달 연속 구매한 고객, 차집합은 이번 달에만 포함된 고객을 찾는 데 사용할 수 있습니다. 집합 연산을 이용하면 이런 비교 작업을 한 줄로 간단하게 할 수 있습니다.

> **바로 핵심 요약**
>
> - 집합은 set( ) 함수로 만들어 중괄호로 표현하며, 중복된 요소를 자동으로 제거합니다.
> - 집합은 요소의 순서를 보장하지 않으므로 순서에 의존해 데이터를 다루면 안 됩니다.
> - 합집합은 |, 교집합은 &, 차집합은 - 연산자로 구할 수 있고, union( ), intersection( ), difference( ) 함수를 써도 결과는 같습니다.
> - 리스트와 튜플은 집합으로 바꿀 수 있고, 딕셔너리를 집합으로 바꾸면 키만 대상이 됩니다. 설문 응답처럼 중복이 많은 데이터에서 종류를 파악할 때 유용합니다.
