앞에서는 클래스를 만들고 상속과 오버라이딩, super( )로 부모 클래스의 메서드를 사용하는 방법까지 배웠습니다. 이제 클래스의 기본기를 갖췄으니 한 걸음 더 나아가, 여러 인스턴스가 값을 공유하는 클래스 변수부터 출력과 비교를 담당하는 매직 메서드, 값을 보호하는 캡슐화까지 알아보겠습니다. 조금 어렵게 느껴질 수도 있지만, 다양한 예제를 따라 천천히 익혀봅시다.

> **미리 알아두세요!**
>
> - 클래스 변수는 인스턴스들이 함께 공유하는 변수입니다.
> - __str__( ), __eq __( ) 같은 매직 메서드와 캡슐화로 클래스를 더 잘 다듬을 수 있습니다.

## 인스턴스들이 공유할 수 있는 변수, 클래스 변수

지금까지 클래스에서 변수를 정의할 때는 self.name과 같이 코드를 작성했습니다. 이것을 **인스턴스 변수**라고 합니다. **인스턴스 변수는 이름에서 알 수 있듯이 인스턴스마다 서로 다른 값을 저장할 때 사용합니다.** 예를 들어 Dog 클래스에서 self.name을 정의하면 "바둑이", "짤랑이"처럼 각각의 강아지 인스턴스에 서로 다른 이름을 지어줄 수 있습니다.

![](/books/python-intro/p378-237.webp)

```python filename="08-15-dog_class_variable.py"
class Dog:
  def __init__(self, name):
    self.name = name  # ➊ 인스턴스 변수: 인스턴스마다 따로 가짐

dog1 = Dog("바둑이")  # ➋ 이름이 "바둑이"인 인스턴스
dog2 = Dog("짤랑이")  # ➌ 이름이 "짤랑이"인 인스턴스

print(dog1.name)
print(dog2.name)
```

**실행 결과**

```text
바둑이
짤랑이
```

그런데 모든 인스턴스가 함께 공유하는 값이 필요할 때가 있습니다. 예를 들어 지금까지 강아지를 몇 마리 만들었는지 기록하고 싶다고 해봅시다. 만약 강아지의 전체 수를 각 인스턴스마다 따로 가지고 있으면 제대로 관리하기 어렵겠죠. 이럴 때 사용하는 것이 클래스 변수입니다.

![](/books/python-intro/p379-238.webp)

## 연습 01 클래스 변수 사용해보기

앞에서는 인스턴스 변수를 주로 __init__( ) 메서드 안에 작성했지만 클래스 변수는 메서드 밖, 클래스의 코드 블록 바로 아래에 작성합니다. 다음 코드를 작성하면서 클래스 변수를 이해해봅시다.

```python filename="08-16-dog_count.py"
class Dog:
  count = 0  # ➊ 클래스 변수: 모든 인스턴스가 공유

  def __init__(self, name):
    self.name = name  # ➋ 인스턴스 변수: 인스턴스마다 따로 가짐
    Dog.count += 1    # ➌ 새 인스턴스가 생길 때마다 1씩 증가

dog1 = Dog("바둑이")
dog2 = Dog("뽀삐")
dog3 = Dog("초코")

print(f"강아지 이름: {dog1.name}")
print(f"강아지 이름: {dog2.name}")
print(f"지금까지 만든 강아지 수: {Dog.count}")
```

**실행 결과**

```text
강아지 이름: 바둑이
강아지 이름: 뽀삐
지금까지 만든 강아지 수: 3
```

❶ 클래스 안에 count = 0이라고 적은 것이 클래스 변수입니다. 이 변수는 Dog 클래스 자체에 정의되어 있으므로, Dog( )로 만든 모든 강아지 인스턴스가 공유합니다.

❷ self.name은 인스턴스 변수입니다. 강아지 인스턴스마다 따로 값을 가지므로, dog1.name은 "바둑이", dog2.name은 "뽀삐"가 출력됩니다.

❸ 인스턴스를 만들 때마다 Dog.count += 1을 실행하여 Dog 클래스의 count 클래스 변수의 값을 1씩 더합니다. 따라서 Dog( )로 3개의 인스턴스를 만들면 Dog.count는 3이 됩니다.

![](/books/python-intro/p380-239.webp)

이렇게 클래스 변수와 인스턴스 변수를 구분해서 쓰면, 모든 인스턴스가 공유할 값과 각 인스턴스가 따로 가질 값을 나누어 관리할 수 있습니다.

## 클래스 변수를 바꿀 때 self를 쓰면 안 되는 이유

앞에서 강아지 수를 셀 때 Dog.count처럼 클래스 이름을 앞에 붙였습니다. 그런데 인스턴스 변수를 다룰 때 항상 self를 사용했으니 여기에서도 self.count라고 쓰고 싶을 수 있습니다. 그렇게 하면 어떻게 되는지 확인해봅시다.

```python filename="08-17-class_variable_trap.py"
class Pet:
  count = 0

  def __init__(self, name):
    self.name = name
    self.count = self.count + 1    # ➊ self를 붙여서 1 더하기

pet1 = Pet("초코")
pet2 = Pet("보리")
print(f"Pet.count: {Pet.count}")
print(f"pet1.count: {pet1.count}")
print(f"pet2.count: {pet2.count}")
```

**실행 결과**

```text
Pet.count: 0
pet1.count: 1
pet2.count: 1
```

❶ 인스턴스를 두 개 만들었는데 Pet.count는 여전히 0 그대로이고, 각 인스턴스의 count에는 1이 저장되어 있습니다.

self.count = ...라고 쓰는 순간 파이썬은 해당 인스턴스에 count라는 인스턴스 변수를 새로 만듭니다. 이때 클래스 변수 Pet.count는 그대로 남아 있고, 각 인스턴스가 자신만의 count 값을 가지게 됩니다. 따라서 여러 인스턴스의 개수를 하나의 값으로 셀 수 없습니다. 그렇다면 클래스 이름으로 접근하도록 코드를 고쳐봅시다.

```python filename="08-18-class_variable.py"
class Pet:
  count = 0

  def __init__(self, name):
    self.name = name
    Pet.count = Pet.count + 1      # ➊ 클래스 이름으로 접근

pet1 = Pet("초코")
pet2 = Pet("보리")
print(f"Pet.count: {Pet.count}")
print(f"pet1.count: {pet1.count}")
```

**실행 결과**

```text
Pet.count: 2
pet1.count: 2
```

❶ Pet.count처럼 클래스 이름을 통해 값을 변경하면 클래스 변수 자체가 바뀝니다. 따라서 인스턴스를 두 개 만들면 Pet.count는 2가 됩니다.

> **NOTE**
>
> 값을 읽기만 할 때는 pet1.count처럼 인스턴스를 통해서도 클래스 변수에 접근할 수 있습니다. 문제가 되는 것은 값을

넣을 때입니다. 같은 이름으로 self.count에 값을 할당하면 인스턴스 변수가 만들어져 클래스 변수를 가리게 되므로 주의해야 합니다.

## 인스턴스를 보기 좋게 출력하는 __str__( )

지금까지 인스턴스 변수와 클래스 변수를 구분해봤습니다. 그렇다면 인스턴스 안에 든 값을 한눈에 확인하려면 어떻게 해야 할까요? 이번에는 인스턴스의 정보를 보기 좋게 출력하는 방법을 알아봅시다. print(dog)처럼 인스턴스를 그대로 출력하면 어떨지 코드를 통해 확인하겠습니다.

![](/books/python-intro/p382-240.webp)

```python filename="08-19-dog_object_print.py"
class Dog:
  def __init__(self, name, age):
    self.name = name
    self.age = age

dog = Dog("바둑이", 3)

print(dog)  # ➊ 인스턴스를 그대로 출력
```

**실행 결과**

```text
<__main__.Dog object at 0x000001A2B3C4D5E0>
```

❶ dog 인스턴스를 그대로 print( )했더니 우리가 기대한 "바둑이"나 "3살"이 아니라 <__main__. Dog object at ...> 같은 내용이 출력되었습니다. 이는 파이썬이 인스턴스를 기본 형식으로 표현한 결과로, '이 인스턴스가 어떤 클래스의 것이고 메모리 어디에 들어 있는지'와 같이 클래스 정보와 인스턴스를 구분하기 위한 값 등이 표시됩니다. 다시 말해 우리가 원하는 강아지 정보가 그대로 출력되는 것은 아닙니다.

> **NOTE**
>
> 뒤쪽에 0x로 시작하는 값은 실행할 때 달라질 수 있으므로 책의 실행 결과와 정확히 같지 않아도 괜찮습니다.

그렇다면 "바둑이(3살)"처럼 인스턴스의 정보를 보기 좋게 출력하려면 어떻게 해야 할까요? 이때 사용할 수 있는 것이 __str__( ) 메서드입니다. __str__( )은 앞에서 공부한 매직 메서드 중 하나입니다. 클래스에 __str__( )을 정의해두면 print(dog)처럼 인스턴스를 문자열로 표현할 때 자동으로 호출되어, __str__( )이 반환한 문자열이 사용됩니다. 다음 코드를 작성해서 __str__( ) 메서드의 동작 방식을 이해해봅시다.

```python filename="08-20-dog_str.py"
class Dog:
  def __init__(self, name, age):
    self.name = name
    self.age = age

  def __str__(self):  # ➊ print()할 때 보여줄 문자열을 정의
    return f"{self.name}({self.age}살)"  # ➋ 이 문자열이 출력됨

dog = Dog("바둑이", 3)

print(dog)  # ➌ __str__()이 반환한 문자열이 출력
```

**실행 결과**

```text
바둑이(3살)
```

❶ Dog 클래스에 __str__( ) 메서드를 정의했습니다.

❷ 이 메서드는 f-string으로 만든 "바둑이(3살)"를 반환합니다.

❸ 그래서 print(dog)를 실행하면 알아보기 어려운 기본 표현 대신 우리가 정한 "바둑이(3살)"가 출력됩니다. 이렇게 __str__( )을 정의해두면, 인스턴스를 원하는 형태의 문자열로 깔끔하게 보여줄 수 있습니다.

## 인스턴스를 비교해주는 __eq__( )

앞에서 살펴본 __str__( ) 외에도 매직 메서드에는 다양한 종류가 있습니다. 이번에는 두 인스턴스를 == 연산자로 비교하는 __eq__( ) 메서드를 알아보겠습니다. 예를 들어 강아지 인스턴스를 2개 만들고, dog1 == dog2와 같이 비교한다고 해봅시다. Dog 클래스에 별도의 비교 방법을 정의하지 않은 상태라면 서로 다른 두 Dog 인스턴스는 이름과 나이가 같더라도 일반적으로 False로 평가됩니다. 이름과 나이가 같아도 각각 별도로 만들어진 인스턴스이기 때문에 파이썬은 둘을 서로 다른 인스턴스로 판단합니다. 이는 쌍둥이의 생김새와 나이가 같더라도 두 사람이 서로 다른 사람인 것과 비슷합니다.

![](/books/python-intro/p384-241.webp)

하지만 특정 정보를 기준으로 두 인스턴스를 같다고 판단하고 싶을 수도 있습니다. 예를 들어 이름과 나이가 모두 같은 강아지 인스턴스는 '같다'고 평가하고 싶다고 해봅시다. 이때 __eq__( ) 메서드를 정의합니다. __eq__( ) 메서드는 인스턴스를 == 연산자로 비교할 때 자동으로 실행되어 같은지를 판단하는 데 사용합니다. 다음 코드를 입력해서 __eq__( ) 메서드를 이해해봅시다.

```python filename="08-21-dog_eq.py"
class Dog:
  def __init__(self, name, age):
    self.name = name
    self.age = age

  def __eq__(self, other):  # ➊ == 비교의 동작을 정의
    return self.name == other.name and self.age == other.age  # ➋ 이름과 나이가 모두 같으면 True

dog1 = Dog("바둑이", 3)
dog2 = Dog("바둑이", 3)
dog3 = Dog("초코", 5)

print(dog1 == dog2)  # ➌ 이름과 나이가 같음
print(dog1 == dog3)  # ➍ 이름과 나이가 다름
```

**실행 결과**

```text
True
False
```

❶ __eq__( ) 메서드를 정의했습니다.

❷ 여기서는 이름과 나이가 모두 같으면 True를 반환하도록 했습니다.

따라서 ❸의 dog1 == dog2는 두 강아지의 이름인 "바둑이"와 나이인 3이 모두 같으므로 True가 출력됩니다.

반면 ❹의 dog1 == dog3은 이름이나 나이가 다르므로 False가 출력됩니다.

> **NOTE**
>
> 지금 만든 __eq__는 상대가 Dog 객체라고 가정합니다. 다른 자료형과도 비교하려면 __eq__ 첫 부분에 if not

isinstance(other, Dog): return NotImplemented 검사를 추가합니다.

이처럼 __eq__( ) 메서드를 클래스에 정의하면 == 연산자로 인스턴스를 비교할 때 어떤 기준으로 같은지 직접 정할 수 있습니다. 이 외에도 다양한 매직 메서드가 있습니다. 더 궁금하다면 인공지능 도구나 검색창에서 '파이썬 매직 메서드' 또는 '던더 메서드'를 찾아 공부해보세요.

## 인스턴스 변수를 보호하는 방법, 캡슐화

지금까지는 주로 인스턴스 변수의 값을 저장하고 출력해봤습니다. 하지만 인스턴스를 만든 뒤에도 값을 바꿀 수 있습니다. 이를테면 dog1.name = "쿠키"와 같이 인스턴스를 생성한 이후에도 이름을 변경할 수 있습니다. 다음 그림을 보면 좀 더 쉽게 이해할 수 있을 겁니다.

![](/books/python-intro/p386-242.webp)

그런데 인스턴스를 만든 뒤 인스턴스 변수의 값을 마음대로 변경하면 곤란한 경우도 있습니다. 예를 들어 여러분이 은행 프로그램을 만들고 있다고 가정해봅시다. 잔액을 저장하기 위해 __init__( ) 메서드에서 self.balance를 만들었는데, 인스턴스를 생성한 뒤 다음과 같이 값을 바꾸면 어떻게 될 까요?’

```python filename="08-22-account_balance.py"
class Account:
  def __init__(self, owner):
    self.owner = owner
    self.balance = 0  # 보호 장치 없는 평범한 인스턴스 변수

account = Account("바둑이")
account.balance = -99999  # 외부에서 잔액을 마음대로 변경
print(f"{account.owner}님 잔액: {account.balance}원")
```

**실행 결과**

```text
바둑이님 잔액: -99999원
```

이처럼 인스턴스 변수를 바깥에서 함부로 바꾸지 못하게 하고, 정해진 메서드를 통해서만 다루도록 하는 것을 캡슐화라고 합니다. 코드에서 보듯 인스턴스 변수는 account.balance = -99999와 같이 마음대로 바꿀 수 있습니다. 하지만 은행 프로그램의 잔액을 이렇게 아무 값으로나 변경할 수 있다면 문제가 생기겠죠. 실제로 잔액을 변경하려면 여러 조건을 확인해야 합니다.

- 변경해도 되는 사람이 변경하는 상황인가?
- 현재 잔액보다 많은 금액을 출금하려는 것은 아닌가?
- 올바른 방법으로 잔액을 변경하고 있는가? 등등

그렇다면 입금이나 출금처럼 정해진 절차를 거쳐서만 잔액을 변경하도록 만들려면 어떻게 해야 할 까요?

## 연습 01 변수의 수정을 막는 @property 사용하기

이때 사용하는 것이 프로퍼티(property)입니다. @property를 사용하면 메서드를 마치 인스턴스 변수처럼 읽도록 만들고, 값을 변경하는 방법도 별도로 관리할 수 있습니다. 프로퍼티는 글로 설명하는 것보다 코드를 작성하고 실행한 뒤 하나씩 살펴보는 편이 이해하기 쉽습니다. 우선 코드를 작성해봅시다.

```python filename="08-23-account_property.py"
class Account:
  def __init__(self, owner, balance):
    self.owner = owner
    self._balance = balance

  @property
  def balance(self):
    return self._balance

  def withdraw(self, amount):
    if amount > self._balance:
      print(f"출금 실패 / 잔액 부족 (현재 잔액: {self._balance})")
      return
    self._balance -= amount
    print(f"출금 완료 / 남은 잔액: {self._balance}")

account = Account("바로", 1000)          # 계좌 생성
print(f"현재 잔액: {account.balance}")    # 잔액 조회

account.withdraw(300)                   # 정상 출금
account.withdraw(99999)                  # 잔액 초과 출금

try:
  account.balance = -99999               # 직접 대입 시도
except AttributeError:
  print("잔액은 직접 변경할 수 없습니다")

print(f"최종 잔액: {account.balance}")
```

**실행 결과**

```text
현재 잔액: 1000
출금 완료 / 남은 잔액: 700
출금 실패 / 잔액 부족 (현재 잔액: 700)
잔액은 직접 변경할 수 없습니다
최종 잔액: 700
```

코드가 꽤 길지만 중요한 내용이므로 하나씩 나누어 설명하겠습니다. 먼저 인스턴스 변수를 정의한 부분입니다. 변수 이름 앞에 밑줄을 붙인 것이 눈에 띌 겁니다.

```python
def __init__(self, owner, balance):
  self.owner = owner
  self._balance = balance
```

인스턴스 변수 이름 앞에 밑줄을 붙인 이유는 이후 @property를 사용할 때 프로퍼티의 이름과 인스턴스 변수의 이름이 겹치지 않게 하기 위해서입니다. 반드시 밑줄을 사용해야 하는 것은 아니며, 두 이름만 겹치지 않으면 됩니다. 다만 파이썬에서는 외부에서 직접 접근하지 않기를 바라는 변수의 이름 앞에 밑줄을 붙이는 관례가 있으므로, 여기서도 그 관례에 따라 _balance로 작성했습니다.

이제 balance( ) 메서드 위에 @property를 붙인 부분을 살펴봅시다.

```python
@property
def balance(self):
  return self._balance
```

평범한 메서드라도 @property를 붙이면 인스턴스에서 이 메서드를 호출하는 방식이 달라집니다. 원래 메서드는 account.balance( )처럼 소괄호를 붙여 호출합니다. 하지만 @property를 적용하면 다음과 같이 속성에 접근하듯 사용할 수 있습니다.

```python
print(f"최종 잔액: {account.balance}")
```

겉으로는 인스턴스 변수를 읽는 것처럼 보이지만, 실제로는 balance 프로퍼티의 getter(값을 읽을 때 실행되는 메서드)가 실행되고 그 안의 return self._balance가 동작하여 인스턴스 변수의 값을 반환합니다.

마지막으로 withdraw( ) 메서드를 살펴보겠습니다.

```python
def withdraw(self, amount):
  if amount > self._balance:
    print(f"출금 실패 / 잔액 부족 (현재 잔액: {self._balance})")
    return
  self._balance -= amount
  print(f"출금 완료 / 남은 잔액: {self._balance}")
```

![](/books/python-intro/p389-243.webp)

이 메서드는 매개변수 amount로 받은 금액이 현재 잔액인 self._balance보다 큰지 확인해 크면출금을 거절하고, 잔액 이하이면 출금할 수 있도록 self._balance -= amount를 실행해서 잔액을 변경합니다. 예를 들어 잔액이 1000원일 때 withdraw(300)을 실행하면, 1000에서 300을 빼서 잔액 self._balance에 700을 저장합니다. 만약 99999를 출금하려고 하면 if amount > self._balance: 조건에 걸려 출금하지 못하도록 처리할 수 있습니다. 이처럼 잔액을 직접 변경하는 대신 메서드를 통해 변경하도록 만들면 데이터를 좀 더 안전하게 관리할 수 있습니다.

![](/books/python-intro/p389-244.webp)

```python
account.balance = 99999

def balance(self, value):
```

## 밑줄 두 개로 시작하는 인스턴스 변수

앞에서 @property를 사용할 때 인스턴스 변수 이름 앞에 밑줄을 하나 붙여 _balance라고 적었습니다. 이번에는 밑줄을 두 개 붙이면 어떻게 달라지는지 알아보겠습니다.

```python filename="08-24-private_variable.py"
class Account:
  def __init__(self, balance):
    self.__balance = balance       # ➊ 밑줄 두 개로 시작

  def show(self):
    print(f"잔액: {self.__balance}원")

account = Account(1000)
account.show()
account.__balance = 99999          # ➋ 바깥에서 바꾸려고 시도
account.show()
```

**실행 결과**

```text
잔액: 1000원
잔액: 1000원
```

❶ 인스턴스 변수 이름을 밑줄 두 개로 시작했습니다.

❷ 바깥에서 account.__balance에 값을 넣어봤지만 클래스 안에서 사용하는 잔액은 그대로 1000원입니다. 밑줄 하나를 썼을 때는 _balance에 직접 접근해 값을 바꿀 수 있었지만, 이번에는 다릅니다.

밑줄 두 개로 시작하는 이름을 사용하면 파이썬은 클래스 안에서 변수 이름을 바꿔 저장합니다. 예를 들어 Account 클래스의 __balance는 내부적으로 _Account__balance와 같은 이름으로 처리됩니다. 따라서 바깥에서 account.__balance라고 작성해 값을 넣으면 클래스 안에서 사용하는 __balance가 바뀌는 것이 아니라, __balance라는 별도의 인스턴스 변수가 새로 만들어집니다. 덕분에 실수로 내부 값을 건드릴 가능성을 줄일 수 있습니다.

![](/books/python-intro/p391-246.webp)

> **NOTE**
>
> 이것도 완벽한 보호 방법은 아닙니다. 파이썬은 이름을 _Account__balance와 같은 형태로 바꿀 뿐이므로 이 이름을

사용하면 바깥에서도 접근할 수 있습니다. 따라서 보안을 위한 기능이라기보다는 실수로 접근하거나 이름이 충돌하는 일을 줄이는 기능이라고 이해하면 됩니다.

## 메서드에는 세 종류가 있습니다

지금까지 만든 메서드는 모두 첫 번째 매개변수가 self였습니다. 이런 메서드를 인스턴스 메서드라고 부릅니다. 그런데 클래스 안에는 이와 다른 방식으로 동작하는 메서드도 만들 수 있습니다. 원의 넓이를 구하는 클래스로 세 가지를 한 번에 살펴봅시다.

```python filename="08-25-method_kinds.py"
class Circle:
  pi = 3.14                        # ➊ 클래스 변수

  def __init__(self, radius):
    self.radius = radius

  def area(self):                  # ➋ 인스턴스 메서드
    return self.radius * self.radius * Circle.pi

  @classmethod
  def change_pi(cls, value):       # ➌ 클래스 메서드
    cls.pi = value

  @staticmethod
  def explain():                   # ➍ 정적 메서드
    print("원의 넓이는 반지름 × 반지름 × 원주율입니다.")

circle = Circle(10)
print(circle.area())
Circle.explain()
Circle.change_pi(3.141592)
print(Circle.pi)
```

**실행 결과**

```text
314.0
원의 넓이는 반지름 × 반지름 × 원주율입니다.
3.141592
```

❶ 모든 원이 함께 사용하는 원주율을 클래스 변수로 두었습니다.

❷ 인스턴스 메서드입니다. 첫 매개변수가 self이므로 인스턴스마다 서로 다른 radius를 사용할 수 있습니다.

❸ @classmethod를 붙이면 클래스 메서드가 됩니다. 첫 매개변수가 self가 아니라 cls이고, 이 cls는 메서드를 호출할 때 전달되는 클래스를 가리킵니다. 따라서 인스턴스가 아니라 클래스 변수처럼 클래스와 관련된 값을 다루거나 클래스 자체를 이용해야 할 때 주로 사용합니다.

❹ @staticmethod를 붙이면 정적 메서드가 됩니다. self도 cls도 받지 않습니다. 인스턴스나 클래스의 값에 직접 접근할 필요는 없지만 해당 클래스와 관련된 기능을 함께 묶어두고 싶을 때 사용합니다.

![](/books/python-intro/p392-247.webp)

> **NOTE**
>
> 입문 단계에서는 인스턴스 메서드만 쓸 줄 알아도 충분합니다. 클래스 메서드와 정적 메서드는 다른 사람의 코드에서

@classmethod나 @staticmethod를 만났을 때 '이런 역할을 하는 메서드구나' 하고 알아볼 수 있으면 됩니다. 앞에서 사용한 @property와 마찬가지로 @를 붙이는 표기라는 점도 눈여겨보세요.

## 클래스 변수로 인스턴스 수 세기

클래스 변수를 사용해 인스턴스가 몇 개 만들어졌는지 세어봅시다.

```python filename="08-26-cat_count.py"
class Cat:
  count = 0  # ➊ 클래스 변수

  def __init__(self, name):
    self.name = name  # ➋ 인스턴스 변수
    Cat.count += 1    # ➌ 클래스 변수 증가

cat1 = Cat("나비")
cat2 = Cat("초코")

print(cat1.name)
print(cat2.name)
print(f"지금까지 만든 고양이 수: {Cat.count}")
```

**실행 결과**

```text
나비
초코
지금까지 만든 고양이 수: 2
```

❶ count는 Cat 클래스 안에 만든 클래스 변수입니다. Cat 클래스로 만든 고양이 인스턴스들이 함께 공유합니다.

❷ self.name은 인스턴스 변수입니다. 따라서 cat1과 cat2가 서로 다른 이름을 가질 수 있습니다.

❸ 인스턴스가 새로 만들어질 때마다 클래스 변수 Cat.count를 1씩 증가시킵니다. 인스턴스를 2개 만들었으므로 Cat.count는 2가 되어 "지금까지 만든 고양이 수: 2"가 출력됩니다.

## _ _str__( )로 인스턴스 출력 모양 정하기

앞에서 배운 __str__( ) 메서드를 다시 실습해봅시다.

```python filename="08-27-hero_str.py"
class Hero:
  def __init__(self, name, level):
    self.name = name      # ➊ 이름 저장
    self.level = level    # ➋ 레벨 저장

  def __str__(self):      # ➌ 출력 문자열 정의
    return f"{self.name} / 레벨 {self.level}"

hero = Hero("용사", 5)

print(hero)               # ➍ 인스턴스 출력
```

**실행 결과**

```text
용사 / 레벨 5
```

❶ name 인스턴스 변수에 "용사"라는 값을 저장합니다.

❷ level 인스턴스 변수에 5라는 값을 저장합니다.

❸ __str__( ) 메서드는 인스턴스를 문자열로 출력할 때 보여줄 문자열을 반환합니다.

❹ print(hero)를 실행하면 파이썬의 기본 인스턴스 정보 대신 __str__( ) 메서드가 반환한 문자열 "용사 / 레벨 5"가 출력됩니다.

## @property로 값 조회만 허용하기

프로퍼티도 연습해봅시다. 이번에는 지갑으로 상황을 바꿔 코드를 작성해봅니다.

```python filename="08-28-wallet_property.py"
class Wallet:
  def __init__(self, owner, money):
    self.owner = owner
    self._money = money       # ➊ 보호할 값 저장

  @property
  def money(self):            # ➋ 프로퍼티 정의
    return self._money

wallet = Wallet("바로", 3000)

print(f"{wallet.owner}의 지갑: {wallet.money}원")

try:
  wallet.money = 99999        # ➌ 직접 변경 시도
except AttributeError:
  print("돈은 직접 변경할 수 없습니다")

print(f"최종 금액: {wallet.money}원")
```

**실행 결과**

```text
바로의 지갑: 3000원
돈은 직접 변경할 수 없습니다
최종 금액: 3000원
```

❶ _money 인스턴스 변수에 지갑의 초기 금액을 저장합니다.

❷ 메서드에 @property를 붙이면 wallet.money처럼 메서드를 호출하는 괄호 없이 인스턴스 변수에 접근하듯 값을 조회할 수 있습니다.

❸ money 프로퍼티에는 setter를 만들지 않았기 때문에 wallet.money = 99999처럼 직접 값을 바꾸려고 하면 오류가 발생합니다. 따라서 money 프로퍼티를 통해서는 값을 조회할 수 있지만 직접 변경할 수 없습니다.

> **바로 핵심 요약**
>
> - 클래스 변수는 클래스 안에 직접 작성하며, 그 클래스로 만든 모든 인스턴스가 함께 사용할 수 있습니다. 클래스 변수임을 명확히 하거나 값을 변경할 때는 클래스 이름을 통해 접근하는 것이 좋습니다.
> - __str__( )을 정의하면 print( )로 인스턴스를 출력할 때 문자열로 표현하는 방법을 정할 수 있고, __eq__( )를 정의하면 == 연산자로 인스턴스를 비교할 수 있습니다.
> - 인스턴스 변수 이름 앞에 밑줄을 붙이고 @property를 사용하거나 밑줄 두 개로 시작하는 이름을 쓰면 외부에서 값을 다루는 방식을 제한하거나 실수로 내부 값을 건드릴 가능성을 줄일 수 있습니다.
