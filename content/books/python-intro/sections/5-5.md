**흐름을 가르는 제어문, 조건문**에서 배운 if 문과 코드 블록, 비교 연산자와 논리 연산자, try~except 문을 문제로 확인해봅시다. 객관식 6문제와 주관식 2문제로 구성했습니다. 먼저 스스로 풀어본 다음 마지막에 있는 정답과 해설을 확인하세요. 틀린 문제가 있다면 해당 절로 돌아가 다시 읽어보면 됩니다.

### 객관식 문제

01 다음 중 두 값이 같은지 비교하는 연산자를 고르세요.

① = ② == ③ != ④ >=

02 다음 코드의 실행 결과로 알맞은 것을 고르세요.

```python
temperature = 18
if temperature >= 25:
  print("에어컨을 켭니다")
else:
  print("창문을 엽니다")
```

① 에어컨을 켭니다

② 창문을 엽니다

③ 두 문장이 모두 출력됩니다 ④ 아무것도 출력되지 않습니다

03 다음 코드의 실행 결과로 알맞은 것을 고르세요.

```python
score = 75
if score >= 90:
  print("A")
elif score >= 80:
  print("B")
elif score >= 70:
  print("C")
else:
  print("F")
```

① C ② F ③ C와 F가 모두 출력됩니다 ④ B와 C가 모두 출력됩니다

04 다음 코드가 출력하는 값을 순서대로 나열한 것을 고르세요.

```python
score = 85
attendance = 80
print(score >= 80 and attendance >= 90)
print(score >= 80 or attendance >= 90)
print(not attendance >= 90)
```

① False True True ② True False True ③ False True False ④ True True False

05 다음 코드의 실행 결과로 알맞은 것을 고르세요.

```python
user_input = "3.5"
try:
  number = int(user_input)
  print(f"변환 성공: {number}")
except:
print("숫자로 변환할 수 없습니다.")
```

① 변환 성공: 3.5 ② 변환 성공: 3 ③ 숫자로 변환할 수 없습니다. ④ 오류 메시지를 출력하며 프로그램이 멈춥니다

06 제어문에 대한 설명으로 옳지 않은 것을 고르세요.

① if~elif~else 문은 조건식 중 하나가 True로 평가되면 나머지는 모두 건너뜁니다.

② 따로 처리할 내용이 없다면 if~elif~else 문에서 else를 생략할 수 있습니다.

③ pass는 아무 일도 하지 않고 지나가므로 비어 있는 코드 블록의 자리를 채울 때 사용합니다.

④ 코드 블록의 들여쓰기는 반드시 공백 4개로 맞춰야 합니다.
