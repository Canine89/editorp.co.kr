지금까지는 함수를 만들 때 def 뒤에 함수 이름과 매개변수를 적고, 줄을 바꿔 들여쓰기한 본문에 실행할 코드를 작성했습니다. 계산 결과를 돌려주려면 그 안에서 return도 사용했죠. 다음 코드와 같은 방식으 로요.

> **미리 알아두세요!**
>
> - 람다는 이름을 따로 붙이지 않고 하나의 식으로 함수를 만드는 표현식으로, 짧은 함수를 한 줄로 정의할 수 있습니다.
> - 조건부 표현식(A if 조건 else B)을 함께 사용하면 조건에 따라 다른 값을 돌려주는 함수도 한 줄로 만들 수 있습니다.

```python filename="07-19-add_tax_function.py"
def add_tax(price):
  return price + int(price * 0.1)
```

그런데 함수의 동작이 아주 단순하다면 이렇게 여러 줄에 걸쳐 작성하는 것이 다소 길게 느껴질 수 있습니다. 이럴 때 사용할 수 있는 것이 **람다**(lambda)입니다.

## 람다 사용해보기

**람다는 이름을 따로 붙이지 않고 하나의 식으로 함수 객체를 만드는 표현식입니다.** 앞에서 작성한 짧은 함수를 람다로 바꾸면 다음과 같이 표현할 수 있습니다.

```python filename="07-20-add_tax_lambda.py"
add_tax = lambda price: price + int(price * 0.1)
```

**실행 결과**

![실행 결과](/books/python-intro/p326-216.webp)

**작성 방식은 lambda 매개변수: 식 형태로 작성합니다.** 콜론 뒤에 작성한 식의 결과가 반환값이 됩니다. 호출 방법은 일반 함수와 같습니다. 예를 들어 add_tax(3000), add_tax(5000)과 같이 호출할 수 있습니다.

![](/books/python-intro/p327-217.webp)

## 람다 제대로 쓰기

람다의 진가는 단독으로 사용할 때보다 다른 함수의 인수로 전달할 때 더 잘 드러납니다. 대표적인 예로 map( ) 함수가 있습니다. map( ) 함수는 첫 번째 매개변수로 함수를 받아 처리하는 독특한 함수입니다. 우선 코드를 작성해봅시다.

```python filename="07-21-lambda_map_double.py"
numbers = [1, 2, 3]
doubled = list(map(lambda number: number * 2, numbers))
print(doubled)
```

**실행 결과**

```text
[2, 4, 6]
```

실행 결과를 보면 numbers의 각 값이 모두 2배가 되었습니다. 어떻게 이런 결과가 나온 걸까요? map( ) 함수는 첫 번째 매개변수로 전달한 함수를 두 번째 매개변수로 전달받은 리스트의 각 요소에 적용합니다.

- lambda number: number * 2는 전달받은 숫자에 2를 곱하는 람다 함수입니다.
- numbers는 [1, 2, 3] 리스트입니다.
- map( )의 결과는 map 객체이므로 list( )로 감싸 리스트로 바꿔 출력합니다.
- 람다 함수가 리스트의 각 요소에 적용되어 모든 값이 2배가 됩니다.

![](/books/python-intro/p328-218.webp)

이렇게 람다는 짧은 계산을 함수로 잠깐 넘겨야 하는 자리에서 빛을 발합니다. 아마 이 설명만으로는 map( ) 함수가 잘 이해되지 않을 겁니다. 이 내용은 나중에 다시 자세히 공부하겠습니다.

## 람다 안에서 조건에 따라 다른 값 돌려주기

그렇다면 람다 안에서 조건에 따라 서로 다른 값을 반환하려면 어떻게 해야 할까요? 일반적인 조건문은 다음과 같이 여러 줄로 작성하므로, 람다로는 표현하기 어려워보입니다.

```python
if a > 10:
  return "10보다 크네요!"
else:
  return "10보다 작거나 같네요!"
```

하지만 조건부 표현식을 사용하면 조건에 따라 값을 선택하는 코드도 람다 안에 넣을 수 있습니다. 먼저 그 차이를 비교해볼 수 있도록 조건부 표현식을 사용하지 않고 일반 함수부터 만들어봅시다. 다음은 점수가 60점 이상이면 “합격”, 그렇지 않으면 “불합격”을 돌려주는 함수입니다.

```python filename="07-22-pass_fail_def.py"
def check(score):
  if score >= 60:
    return "합격"
  else:
    return "불합격"
print(check(85))
print(check(42))
```

**실행 결과**

```text
합격
불합격
```

이 함수가 하는 일은 조건에 따라 두 값 중 하나를 선택하여 반환하는 것입니다. 이처럼 간단한 조건은 조건부 표현식을 사용해 한 줄로 줄일 수 있습니다. 조건부 표현식은 값1 if 조건 else 값2 형태로, 조건이 참이면 값1, 거짓이면 값2가 됩니다. 이렇게 한 줄로 줄인 조건부 표현식은 람다에도 넣을 수 있습니다.

```python filename="07-23-pass_fail_lambda.py"
check = lambda score: "합격" if score >= 60 else "불합격"
print(check(85))
print(check(42))
```

**실행 결과**

```text
합격
불합격
```

실행 결과는 앞의 def 함수와 완전히 같습니다. "합격" if score >= 60 else "불합격"은 가운데에 있는 조건부터 살펴보면 이해하기 쉽습니다.

- score >= 60 조건을 먼저 확인 참이면 if 앞쪽의 "합격"을 반환 거짓이면 else 뒤쪽의 "불합격"을 반환

![](/books/python-intro/p329-219.webp)

if가 문장의 맨 앞이 아니라 가운데에 있어서 처음에는 어색하게 느껴질 수 있습니다. 에서 배운 if 문은 콜론과 들여쓰기를 사용해 코드 블록을 실행했지만, 여기서는 콜론도 들여쓰기도 없습니다. 조건에 따라 두 값 중 하나를 선택해 하나의 값을 만들어내는 조건부 표현식이기 때문입니다.

### map( ) 함수와 조건부 표현식 함께 사용해보기

이번에는 조건부 표현식을 앞에서 배운 map( ) 함수와 함께 사용해봅시다. 여러 명의 점수를 한꺼번에 합격과 불합격으로 바꾸는 코드입니다. map( ) 함수에 조건부 표현식으로 만든 람다를 전달하면, 각 점수를 판정해 그 결과에 맞는 값으로 바꿀 수 있습니다.

```python filename="07-24-map_pass_fail.py"
scores = [85, 42, 77, 30]
results = list(map(lambda score: "합격" if score >= 60 else "불합격", scores))
print(results)
```

**실행 결과**

```text
['합격', '불합격', '합격', '불합격']
```

scores의 값이 하나씩 람다의 score에 전달되고, 조건부 표현식은 점수에 따라 그 값을 "합격" 또는 "불합격"으로 반환합니다. 이렇게 표현식을 넣은 람다는 짧은 판단을 함수 자리에 끼워 넣어야 할 때 유용하게 사용할 수 있습니다.

> **NOTE**
>
> 조건부 표현식은 두 값 중 하나를 고르는 단순한 상황에서만 쓰는 것이 좋습니다. 조건이 여러 단계로 늘어난다면 한 줄

에 억지로 밀어 넣기보다 에서 배운 if~elif~else 문으로 작성하는 편이 훨씬 읽기 좋습니다.

> **바로 핵심 요약**
>
> - 람다는 lambda 매개변수: 식 형태로 함수를 한 줄에 정의하는 표현식이며, 콜론 뒤 식의 결과가 그대로 반환값이 됩니다. map( )처럼 함수를 인수로 받는 자리에 전달할 때 특히 유용합니다.
> - 람다를 사용하면 하나의 식으로 이루어진 함수를 한 줄로 정의할 수 있으며, 조건부 표현식(A if 조건 else B)을 넣어 조건에 따라 서로 다른 값을 반환할 수도 있습니다.
