지금까지는 조건에 따라 흐름을 가르는 방법을 배웠습니다. 이제 같은 코드를 여러 번 실행하는 반복문을 배울 차례입니다. 반복문에는 while 문과 for 문 두 가지가 있으며, 여기서는 while 문부터 차례대로 알아보겠습니다.

> **미리 알아두세요!**
>
> - while 문은 조건식이 True인 동안 코드 블록을 반복합니다.
> - break는 반복을 끝내고, continue는 다음 반복으로 건너뜁니다.

## while 문 기초 연습하기

while 문은 조건이 참(True)인 동안 같은 코드를 반복해서 실행하는 문법입니다. 간단한 예제 코드를 통해 while 문의 기본 구조와 반복이 어떻게 이루어지는지 알아보겠습니다.

## 연습 01 while 문 기본 구조 사용해보기

while 문은 조건식이 True인 동안 코드 블록을 계속 반복해서 실행합니다. 조건식은 앞에서 if 문을 공부할 때 이미 살펴봤습니다. 우선 while 문의 예제 코드를 입력해 실행한 다음 동작 원리를 알아보겠습니다.

```python filename="06-01-while_count.py"
count = 1

while count <= 5:
  print(f"{count}번째 반복입니다.")
  count = count + 1
```

**실행 결과**

```text
1번째 반복입니다.
2번째 반복입니다.
3번째 반복입니다.
4번째 반복입니다.
5번째 반복입니다.
```

코드에서 하이라이트한 부분이 조건식입니다. 그럼 while 문은 어떻게 동작할까요? 다음 순서를 살펴봅시다.

![](/books/python-intro/p243-159.webp)

while 문은 먼저 조건식을 확인하고 그 결과에 따라 코드 블록의 실행 여부를 결정합니다. True이면 while 문의 코드 블록을 실행한 뒤 다시 조건식으로 돌아갑니다. 이 과정을 반복하다가 조건식이 False가 되면 while 문을 종료합니다.

**이때 조건식이 언젠가는 False가 될 수 있도록 코드 블록을 설계하는 것이 중요합니다. 이 예제에서는 코드 블록의 count = count + 1이 바로 그런 역할을 합니다.** count = count + 1은 현재 count의 값에 1을 더한 다음 그 결과를 다시 count에 저장하는 코드입니다. 처음 count가 1이었다면 한 번 실행한 뒤에는 2가 됩니다. 이후 코드 블록이 실행될 때마다 3, 4, 5처럼 값이 하나씩 증가하게 되죠. 결국 count가 6이 되는 시점이 옵니다. 이때 6 <= 5라는 조건식은 False로 평가되므로 while 문의 실행이 종료됩니다. 정리하면 작성한 코드는 다음과 같이 동작합니다.

1. count는 1이므로 조건식이 True, 코드 블록 실행(print( ) 함수 실행, count를 2로 만들기) 2. count는 2이므로 조건식이 True, 코드 블록 실행(print( ) 함수 실행, count를 3으로 만들기) ... 6. count는 6이므로 조건식이 False, while 문 종료

![](/books/python-intro/p244-160.webp)

while 문의 동작 방식을 이해하는 것은 크게 어렵지 않을 겁니다. **다만 반복을 끝내야 할 때 조건식이 False가 되도록 코드 블록 안에 종료 조건을 제대로 만들어두는 것이 매우 중요합니다.** 그렇다면 조건식이 계속 True로 유지되면 어떻게 될까요?

## 연습 02 while 문의 무한 루프

while 문을 사용할 때 주의해야 할 것 중 하나가 바로 **무한 루프**입니다. while 문의 조건식이 True로 유지되면 프로그램이 멈추지 않고 계속 실행되기 때문입니다. 다음은 count 변수에 1을 저장한 다음 while 문의 코드 블록에서 count의 값을 변경하지 않는 코드입니다. 조건식 count <= 5가 계속 True로 평가되므로 반복이 끝나지 않고 무한 실행됩니다.

## break 기초 연습하기

while 문의 기본 동작을 익혔으니 이제 반복의 흐름을 바꾸는 두 키워드를 차례로 알아보겠습니다. 먼저 반복을 즉시 멈추고 빠져나오는 break입니다.

## 연습 01 break로 반복문 빠져나오기

앞에서는 while 문을 종료하려면 조건식이 False가 되도록 만들면 된다고 이야기했습니다. 하지만 반복문을 끝내는 방법이 하나 더 있습니다. 바로 break입니다. break는 ‘깨다, 중단하다’라는 뜻으로, 현재 실행 중인 반복문을 즉시 종료하는 키워드입니다. 특정 조건을 만족했을 때 반복을 끝내는 형태로 자주 사용하므로 if 문과 함께 사용하는 모습을 많이 볼 수 있습니다. 다음 코드를 살펴봅시다.

```python filename="06-03-break_at_five.py"
count = 1

while count <= 10:
  print(f"{count}번째 반복")

  if count == 5:
    print("5에 도달했습니다. 반복을 중단합니다.")
    break

  count = count + 1

print("반복문이 종료되었습니다.")
```

**실행 결과**

```text
1번째 반복
2번째 반복
3번째 반복
4번째 반복
5번째 반복
5에 도달했습니다. 반복을 중단합니다.
반복문이 종료되었습니다.
```

코드를 실행하면 count 변수의 값이 1로 시작하고, 반복할 때마다 count = count + 1을 실행해 count 변수의 값이 1씩 증가합니다. 이때 if 문의 조건식 count == 5가 True가 되면, 즉 count의 값이 5가 되면 "5에 도달했습니다. 반복을 중단합니다."를 출력하고 break를 실행하여 반복의 흐름을 깨고 나옵니다. 반복문 자체의 조건식은 count <= 10으로 count가 11이 되어야 False가 되어 반복이 끝납니다. 하지만 이 코드에서는 count가 5일 때 break가 실행되므로 조건식이 False가 되기 전에 반복문을 종료합니다. 코드 흐름을 그림으로 나타내면 다음과 같습니다.

![](/books/python-intro/p247-165.webp)

그림을 보면 count를 출력한 다음 count가 5인지 검사하고, 5라면 break를 만나 반복문을 종료하는 모습을 확인할 수 있습니다. 이처럼 break 키워드는 반복문 안에서 사용하며, break를 만나면 현재 실행 중인 반복문은 즉시 종료됩니다.

## continue 기초 연습하기

break를 익혔으니 이번에는 함께 알아두면 좋은 키워드인 continue를 살펴봅니다. 둘 다 반복문의 흐름을 바꾸는 키워드이지만 동작 방식은 다르니 코드를 통해 그 차이를 확인해봅시다.

## 연습 01 continue로 다음 반복으로 건너뛰기

**continue 키워드는 현재 반복에서 남은 코드를 실행하지 않고 다음 반복으로 바로 넘어갈 때 사용합니다.** break는 반복문 자체를 완전히 빠져나오지만, continue는 반복문을 종료하지 않습니다. while 문에서 continue를 만나면 조건식으로 돌아가 다음 반복을 계속할지 다시 확인합니다. 코드를 실행해 결과를 확인해봅시다.

```python filename="06-04-continue_skip_five.py"
count = 0

while count < 10:
  count += 1

  if count == 5:
    print(f"{count}번은 건너뜁니다.")
    continue

  print(f"{count}번째 반복 실행")

print("반복문 종료")
```

**실행 결과**

```text
1번째 반복 실행
2번째 반복 실행
3번째 반복 실행
4번째 반복 실행
```

```python
5번은 건너뜁니다.
6번째 반복 실행
7번째 반복 실행
8번째 반복 실행
9번째 반복 실행
10번째 반복 실행
반복문 종료
```

코드를 실행해보면 5번째 반복에서 continue를 만나서 "5번째 반복 실행" 메시지는 출력하지 않고, 다시 처음인 조건식으로 돌아갑니다. 이후 조건식이 계속 True로 평가되므로 반복을 이어가고, 10번째까지 실행한 뒤 종료합니다. 참고로 이번 코드에서는 count = count + 1 대신 count += 1이라는 표현을 사용했습니다. 두 코드는 같은 동작을 합니다. count += 1은 ‘현재 count 값에 1을 더한 뒤 다시 count에 저장한다’는 코드를 짧게 표현한 것입니다. 파이썬에서는 이처럼 자기 자신을 기준으로 값을 더하거나 뺄 때 +=, -=와 같은 연산자를 자주 사용하므로 눈에 익혀두면 좋습니다.

## continue 응용 연습하기

continue를 활용하면 반복 작업 중 특정 조건에 해당하는 경우만 건너뛰고 나머지 작업을 계속 처리할 수 있습니다. 실제 상황을 간단하게 구현한 예제를 통해 continue가 언제 유용하게 사용되는지 알아봅시다.

## 연습 01 재고 처리 프로그램 만들기

continue는 처음 공부하면 어디서 사용하면 좋을지 감을 잡기 어려운 키워드입니다. 이번에는 재고 처리 프로그램을 통해 감을 잡아봅시다.

> **NOTE**
>
> 여기서 딕셔너리를 요소로 가지는 리스트를 사용합니다. 개념이 가물가물하다면

로 돌아가 다시 살펴보고 와도 좋습니다.

```python filename="06-05-product_stock.py"
products = [
  {"name": "사과", "stock": 10},
  {"name": "바나나", "stock": 0},
  {"name": "오렌지", "stock": 5},
  {"name": "포도", "stock": 0},
  {"name": "수박", "stock": 3}
]

print("판매 가능한 상품:")

index = 0
while index < len(products):
  product = products[index]
  index += 1

  if product["stock"] == 0:
    continue

  print(f"- {product['name']}: {product['stock']}개")
```

**실행 결과**

```text
판매 가능한 상품:
- 사과: 10개
- 오렌지: 5개
- 수박: 3개
```

조건식은 while index < len(products):입니다. len( ) 함수는 04.1 리스트에서 알아본 것처럼 데이터의 길이를 반환합니다. products 리스트에는 총 5개의 딕셔너리가 들어 있으므로 len(products)는 5를 반환합니다. 따라서 index가 0부터 시작해 4가 될 때까지 반복문을 실행하고 5가 되면 조건식이 False가 되어 반복문을 종료합니다.

이때 반복문 안에서 if product["stock"] == 0:로 딕셔너리의 키가 "stock"인 값이 0인지 확인합니다. 만약 0이면 continue를 실행해 이후 코드를 건너뛰고 while 문의 조건식으로 돌아갑니다. 한마디로 products 리스트의 내용물을 하나씩 확인하면서 재고가 있는 상품만 출력하는 프로그램입니다. 다음 그림을 보며 프로그램의 구조를 다시 이해해봅시다.

## 연습 01 ATM기 시뮬레이션 프로그램 만들기

while 문을 이용해 ATM기 시뮬레이션 프로그램을 만들어봅시다. 다음 코드는 잔액이 5만 원이고, 인출할 때 수수료 1천 원이 발생한다고 가정한 ATM기 시뮬레이션 프로그램입니다. 메뉴에서 1, 2, 3, 4 중 하나를 선택해 ATM기의 동작을 간단하게 구현했습니다.

> **NOTE**
>
> 이번 코드는 좀 깁니다. 혹시라도 파이썬 인터프리터 셸에서 실습하고 있었다면 이번에는 비주얼 스튜디오 코드나 커서

에서 실습해보세요.

```python filename="06-06-atm_withdrawal.py"
balance = 50000
fee = 1000

print(f"잔액: {balance:,}원 (수수료: {fee:,}원)")

while True:
  print("\n[인출 금액 선택]")
  print("1. 5,000원")
  print("2. 10,000원")
  print("3. 50,000원")
  print("4. 취소")

  choice = input("선택하세요 (1/2/3/4): ")

  if choice == "1":
    amount = 5000
  elif choice == "2":
    amount = 10000
  elif choice == "3":
    amount = 50000
  elif choice == "4":
    print("거래를 취소합니다.")
    break
  else:
    print("잘못된 선택입니다.")
    continue

  print(f"\n{amount:,}원 선택")

  if amount + fee <= balance:
    balance -= (amount + fee)
    print(f"인출 완료! 남은 잔액: {balance:,}원")
  else:
    print(f"잔액 부족 (필요: {amount + fee:,}원)")
```

프로그램을 실행하면 [인출 금액 선택]이라는 메시지와 함께 '선택하세요 (1/2/3/4):'를 화면에 띄운 상태로 사용자의 입력을 기다립니다. 이는 input( ) 함수가 실행되었기 때문입니다. 앞에서 input( ) 함수를 자세히 다루지 않았으므로 여기서 간단히 알아보겠습니다.

### 사용자의 키보드 입력을 기다리는 input( ) 함수

input( ) 함수는 괄호 안에 전달한 문자열을 화면에 출력하고 사용자가 키보드로 값을 입력한 뒤 `Enter`를 누를 때까지 기다립니다. 그리고 사용자가 값을 입력하고 `Enter`를 누르면 입력한 내용을 문자열로 반환합니다. 코드와 실행 상태를 연결해보면 다음 그림과 같이 생각할 수 있습니다.

![](/books/python-intro/p253-168.webp)

그림을 보면 직관적으로 'input( ) 함수는 메시지를 출력한 상태에서 키보드 입력을 기다리고, 입력한 값을 코드에서 다시 사용할 수 있게 해주는 거구나'라고 이해할 수 있습니다. 이 정도면 input( ) 함수의 동작 방식은 충분히 이해되었을 겁니다. 다시 ATM기 코드 설명으로 돌아가보죠.

while 문의 조건식을 True로 고정했으므로 의도적으로 계속 반복하는 무한 루프 구조입니다. 따라서 이 반복을 언제 끝낼지 종료 조건을 정하는 것이 중요하겠죠? 이 프로그램에서는 if~elif~else 문 안에 종료 조건이 있습니다. 해당 부분을 다시 살펴봅시다.

```python
...생략...
while True:
  ...생략...
  if choice == "1":
    amount = 5000
  elif choice == "2":
    amount = 10000
  elif choice == "3":
    amount = 50000
  elif choice == "4":
    print("거래를 취소합니다.")
    break
  else:
    print("잘못된 선택입니다.")
    continue
...생략...
```

코드를 보면 choice 변수에 input( ) 함수로 입력받은 값이 무엇인지에 따라 다르게 처리하고 있습니다. 하이라이트로 표시한 부분이 반복문을 종료하는 조건입니다. choice의 값이 "4"가 되면 break를 실행해 반복문을 빠져나옵니다. 또한 사용자가 값을 잘못 입력하거나 메뉴에 없는 값을 입력하는 상황도 대비했습니다. "1", "2", "3", "4" 이외의 값을 입력하면 else 문의 코드 블록이 실행되고, continue를 만나 현재 반복의 남은 코드를 건너뛴 뒤 다시 while 문의 조건식으로 돌아갑니다. 따라서 메뉴가 다시 출력되고 사용자의 입력을 기다리는 무한 루프를 유지할 수 있는 것이죠.

코드의 길이가 길어서 프로그램이 어떻게 돌아가는지 한눈에 파악하기 어려울 수 있습니다. 침착하게 다음 그림과 함께 프로그램의 흐름을 살펴봅시다.

![](/books/python-intro/p255-169.webp)

그림을 살펴보면 먼저 프로그램에서 사용할 잔액과 수수료의 초깃값을 설정하고 메뉴를 출력해 사용자의 입력을 기다립니다.

이후 반복문은 다음과 같이 동작하며, 사용자가 4를 입력했을 때 종료됩니다.

1. **사용자가 1~3을 입력했을 때 :** 인출 로직 실행 **━ 잔액이 충분하다면 :** 인출 메시지 출력 **━ 잔액이 충분하지 않다면 :** 부족 메시지 출력2. **사용자가 1~4 이외의 값을 입력했을 때 :** 다시 메뉴 출력3. **사용자가 4를 입력했을 때 :** break로 반복문 종료이로써 while 문, break, continue의 기본적인 사용 방법을 충분히 익혔을 겁니다. 사용자의 입력을 받는 input( ) 함수도 꼭 기억해두세요. 앞으로 여러 예제에서 다루겠습니다.

> **바로 핵심 요약**
>
> - while 문은 조건식이 True인 동안 코드 블록을 반복하고, 조건식이 False가 되면 반복을 종료합니다. 따라서 반복을 끝내야 한다면 조건식이 False가 되게 하거나 break를 실행하는 종료 조건을 마련해야 합니다.
> - 조건식이 계속 True로 유지되면 반복이 끝나지 않는 무한 루프가 됩니다. 실행 중인 무한 루프는 + `C`로 멈출 수 있으며, 서버처럼 계속 실행되어야 하는 프로그램에서는 while True:를 의도적으로 사용하기도 합니다.
> - break는 실행 중인 반복문을 즉시 종료하고, continue는 현재 회차의 남은 코드를 건너뛴 뒤 조건식으로 돌아갑니다. 두 키워드는 보통 if 문과 함께 사용합니다. 사용자에게 값을 입력받을 때는 input( ) 함수를 사용하며, 입력한 값은 문자열로 반환됩니다.
