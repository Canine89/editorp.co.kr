## 평균과 중앙값 구하기, statistics

여러 점수의 평균을 구하려면 합계를 개수로 나누면 됩니다. 하지만 통계 계산을 자주 한다면 statistics 모듈을 사용하는 편이 낫습니다. 모듈의 이름과 기능 이름 덕분에 코드만 읽어도 어떤 연산을 할지 알 수 있기 때문입니다.

```python filename="11-04-score_statistics.py"
import statistics                   # ➊ 통계 모듈 가져오기
scores = [80, 90, 100, 70]
print(statistics.mean(scores))     # ➋ 평균 계산
print(statistics.median(scores))   # ➌ 중앙값 계산
```

**실행 결과**

```text
85
85.0
```

❶ statistics 모듈을 가져옵니다.

❷ mean( ) 함수를 사용해 평균을 계산합니다.

❸ median( ) 함수를 사용해 중앙값을 계산하면 85.0을 반환합니다. 점수를 정렬하면 [70, 80, 90, 100]이 되는데, 값의 개수가 짝수이므로 가운데 두 값인 80과 90의 평균 85.0을 중앙값으로 반환 합니다.

## 날짜 다루고 계산하기, datetime

'오늘부터 시험까지 며칠 남았지?', '100일 뒤는 며칠이지?'와 같은 날짜 계산을 하려면 어떻게 해야 할까요? 문자열 "2026-08-20"에서 "2026-07-13"을 빼는 방법을 떠올릴 수도 있지만 문자열끼리는 이런 날짜 계산을 할 수 없습니다. 이럴 때 활용할 수 있는 것이 datetime 모듈입니다. datetime 모듈에서 제공하는 date 클래스를 사용하면 연·월·일로 날짜를 만들고 날짜끼리 계산할 수 있습니다. 바로 코드를 실행하며 알아봅시다.

> **NOTE**
>
> date는 date(연, 월, 일) 형태로 날짜를 만들 때 사용합니다. 날짜의 차이나 ‘며칠 뒤’와 같은 기간 계산에는 timedelta

도 함께 사용할 수 있습니다.

```python filename="11-05-study_date.py"
from datetime import date, timedelta   # ➊ date와 timedelta 가져오기
study_day = date(2026, 7, 13)          # ➋ 날짜 만들기
exam_day = date(2026, 8, 20)
print(study_day)
# ➌ 날짜 정보 꺼내기print(f"{study_day.year}년 {study_day.month}월 {study_day.day}일")
left = exam_day - study_day            # ➍ 날짜끼리 빼기
print(f"시험까지 {left.days}일 남음")
after_100 = study_day + timedelta(days=100)  # ➎ 100일 뒤 계산
print(f"100일 뒤 : {after_100}")
```

**실행 결과**

```text
2026-07-13
2026년 7월 13일
시험까지 38일 남음
100일 뒤 : 2026-10-21
```

❶ datetime 모듈에서 date와 timedelta를 가져왔습니다. date는 특정 날짜를 나타내고, timedelta는 일정한 기간(시간 간격)을 나타냅니다.

❷ date(2026, 7, 13)은 2026년 7월 13일을 나타내는 date 인스턴스를 만듭니다. 공부를 시작한 날과 시험 날을 각각 만들었습니다.

❸ year, month, day 속성을 사용해 날짜에서 연도·월·일을 각각 꺼냈습니다. 여기까지는 문자열로도 흉내 낼 수 있는 부분입니다.

❹ 두 date 인스턴스를 빼면 며칠 차이인지 계산됩니다. 여기에 .days를 붙여 날짜 사이의 차이를 일수로 꺼내면 38을 얻을 수 있습니다. 문자열이었다면 직접 계산해야 할 부분을 뺄셈 한 번으로 해결했습니다.

❺ date에 timedelta(days=100)을 더하면 해당 날짜에서 100일 뒤 날짜가 나옵니다.

이처럼 date와 timedelta를 활용하면 날짜를 표현하는 것뿐 아니라 날짜 사이의 차이나 며칠 뒤의 날짜도 편리하게 계산할 수 있습니다.

![](/books/python-intro/p506-314.webp)

> **NOTE**
>
> date끼리 뺀 결과는 숫자가 아니라 timedelta입니다. 따라서 날짜 사이가 며칠인지 확인하려면 위 예제 코드처럼

.days를 붙여 값을 꺼내야 합니다.

## 파일 이름 살펴보기, pathlib

파일을 다루다 보면 전체 경로에서 파일 이름이나 확장자만 확인해야 할 때가 있습니다. pathlib 모듈의 Path 클래스를 사용하면 파일과 폴더의 경로를 문자열보다 편리하게 다룰 수 있습니다.

```python filename="11-06-file_path.py"
from pathlib import Path           # ➊ Path 클래스 가져오기
file_path = Path("memo.txt")       # ➋ 파일 경로 만들기
print(file_path.stem)              # ➌ 확장자를 뺀 이름
print(file_path.suffix)            # ➍ 확장자
```

**실행 결과**

```text
memo
.txt
```

❶ pathlib 모듈에서 Path 클래스를 가져왔습니다.

❷ 문자열 "memo.txt"를 사용해 해당 경로를 나타내는 Path 인스턴스를 만들었습니다.

❸ stem 속성은 확장자를 제외한 파일 이름인 "memo"를 반환합니다.

❹ suffix 속성은 점을 포함한 확장자인 ".txt"를 반환합니다.

이 밖에도 자주 쓰는 표준 라이브러리에는 다양한 모듈이 있습니다. random 모듈은 무작위 값을 선택하거나 만들 때 사용할 수 있고, time 모듈은 프로그램의 실행을 일정 시간 동안 멈추는 등의 작업에 활용할 수 있습니다. 또 앞에서 살펴본 Path에는 파일 이름을 확인하는 기능뿐 아니라 glob( ) 메서드를 사용해 조건에 맞는 파일이나 폴더를 찾는 기능도 있습니다. 이 기능들은 **11.6 모듈과 라이브러리**에서 직접 사용해보겠습니다.

## 필요한 표준 라이브러리 찾아보기

파이썬으로 어떤 기능을 만들고 싶은데 어떤 모듈을 사용해야 할지 모를 때는 ‘하고 싶은 일’을 ‘파이썬 표준 라이브러리’라는 키워드와 함께 검색해볼 수 있습니다. 예를 들어 숫자들의 중앙값을 구하고 싶다면 ‘파이썬 중앙값 표준 라이브러리’라고 검색해보세요.

![](/books/python-intro/p508-315.webp)

검색 결과 또는 파이썬 공식 문서를 살펴보면 statistics 모듈의 median( ) 함수를 사용할 수 있다는 것을 알 수 있습니다. 이제부터는 인공지능의 차례입니다. 사용해야 할 기능을 찾았다면 인공지능에게 사용 방법이나 간단한 예제를 물어볼 수도 있습니다. 여기서는 클로드에게 물어봤습니다.

![](/books/python-intro/p508-316.webp)

공식 문서나 인공지능을 통해 사용 방법을 확인했다면 짧은 코드를 직접 작성하고 실행해보는 것이 중요합니다. 여러분이 직접 코드를 입력하고 결과를 확인하는 과정에서 해당 기능을 어떻게 사용하는지 훨씬 분명하게 익힐 수 있습니다.

```python filename="11-07-median_check.py"
from statistics import median    # ➊ median() 함수 가져오기

점수 = [70, 90, 80]
print(median(점수))              # ➋ 함수 동작 확인
```

**실행 결과**

```text
80
```

지금까지 파이썬의 표준 라이브러리를 살펴보고 필요한 기능을 찾아 사용하는 방법도 알아봤습니다. ‘바퀴를 재발명하지 말라’는 말처럼 이미 만들어져 있는 좋은 도구가 있다면 직접 처음부터 다시 만들기보다 적절하게 활용하는 것도 중요합니다.
