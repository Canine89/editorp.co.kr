**컬렉션 자료형과 불리언**에서 배운 리스트, 튜플, 딕셔너리, 집합, 불리언 자료형의 특징과 사용 방법을 문제로 확인해봅시다. 객관식 7문제와 주관식 2문제로 구성했습니다. 먼저 스스로 풀어본 다음 마지막에 있는 정답과 해설을 확인하세요. 틀린 문제가 있다면 해당 절로 돌아가 다시 읽어보면 됩니다.

### 객관식 문제

01 다음 코드의 실행 결과로 알맞은 것을 고르세요.

```python
nums = [10, 20, 30]
nums[0] = 100
print(nums)
```

① [10, 20, 30]

② [100, 20, 30]

③ [100]

④ 오류가 발생합니다

02 튜플에 대한 설명으로 옳지 않은 것을 고르세요.

① 소괄호 ( )로 값을 묶어 만듭니다.

② 인덱스로 값을 꺼낼 수 있습니다.

③ 한 번 만들면 값을 수정할 수 없습니다.

④ 리스트처럼 append( ) 함수로 값을 추가할 수 있습니다.

03 다음 코드의 실행 결과로 알맞은 것을 고르세요.

```python
person = {"name": "바로", "age": 25}
print(person["name"])
```

① name ② 바로 ③ {"name": "바로"} ④ 오류가 발생합니다

04 다음 코드의 실행 결과로 알맞은 것을 고르세요.

```python
numbers = {1, 2, 2, 3, 3, 3}
print(len(numbers))
```

① 6 ② 3 ③ 2 ④ 1

05 다음 중 불리언으로 판단했을 때 참(True)으로 취급하는 값을 고르세요.

① 0 ② "" ③ [ ]

④ "0"

06 자료형에 대한 설명으로 옳지 않은 것을 고르세요.

① 리스트는 값을 수정할 수 있는 가변 자료형입니다.

② 튜플은 값을 수정할 수 없는 불변 자료형입니다.

③ 딕셔너리는 키로 값을 찾아 쓰는 자료형입니다.

④ 집합은 순서가 있어 인덱스로 값을 꺼낼 수 있습니다.

07 다음 코드의 실행 결과로 알맞은 것을 고르세요.

```python
person = {"name": "바로", "age": 25}
print(person.get("phone", "없음"))
```

① None ② 없음 ③ phone ④ 오류가 발생합니다

### 주관식 문제

08 다음은 리스트 끝에 값을 추가한 뒤 리스트와 값의 개수를 함께 출력하는 코드입니다. 빈칸 두 곳에 들어갈 함수 이름을 쓰세요.

```python
scores = [90, 85]
scores.____(100)
print(scores, ____(scores))
```

**실행 결과**

```text
[90, 85, 100] 3
```

09 다음은 리스트에서 중복을 없앤 뒤 오름차순으로 정렬해 출력하는 코드입니다. 빈칸 두 곳에 들어갈 함수 이름을 쓰세요.

```python
numbers = [3, 1, 3, 2, 1]
unique_numbers = ____(numbers)
print(____(unique_numbers))
```

**실행 결과**

```text
[1, 2, 3]
```
