이번에는 코드에서 오류가 발생했을 때 프로그램이 갑자기 멈추지 않도록 처리하는 try~except 문을 공부해보겠습니다. try~except 문은 영어 표현을 떠올리면 역할을 이해하기 쉽습니다. try는 ‘일단 실행해본다’, except는 ‘실행 중 발생한 예외를 처리한다’ 정도로 생각하면 됩니다.

> **미리 알아두세요!**
>
> - try~except 문은 오류가 나도 프로그램이 멈추지 않게 해줍니다.
> - 일단 실행해보고(try), 문제가 생기면 예외를 처리(except)하는 구조입니다.

## try~except 문 기초 연습하기

try~except 문은 코드를 실행하는 과정에서 예외가 발생했을 때 프로그램이 멈추지 않고, 해당 상황에 맞게 대응할 수 있도록 해주는 문법입니다. 간단한 예제 코드 실습을 통해 예외를 처리하는 기본적인 방법부터 알아보겠습 니다.

## 연습 01 try~except 문 기본 형태 사용해보기

그러면 try~except 문의 기본 형태를 살펴볼 겸 간단한 코드를 입력해 실행해보겠습니다. user_input 변수에 "abc"라는 문자열을 저장한 다음 이 값을 int( ) 함수에 전달해 숫자형으로 변환하려는 코드입니다.

```python filename="05-15-try_except_conversion.py"
user_input = "abc"

try:
  number = int(user_input)
  print(f"변환 성공: {number}")
except:
  print("숫자로 변환할 수 없습니다.")
```

**실행 결과**

```text
숫자로 변환할 수 없습니다.
```

실행 결과를 보면 알 수 있듯이 "abc"라는 문자열은 정수로 변환할 수 없습니다. 따라서 하이라이트한 코드에서 오류가 발생합니다. 그렇다면 프로그램이 여기서 바로 멈추면서 오류 메시지를 출력할까요? 실행 결과를 보면 그렇지 않습니다. **왜냐하면 try~except 문은 try 문의 코드 블록을 실행하다가 오류가 발생하면 그 지점에서 try 블록의 실행을 멈추고 except 문의 코드 블록으로 이동하기 때문입니다.** except 문에서 예외를 처리한 뒤에는 try~except 문 다음에 있는 코드부터 계속 실행합니다. 따라서 예외가 발생해도 프로그램 전체가 중단되지 않습니다.

![](/books/python-intro/p233-156.webp)

### 왜 이 경우 if~else 문보다 try~except 문이 편리할까?

그렇다면 같은 상황을 if~else 문으로 처리하면 어떨까요? 그건 좀 어렵습니다. 왜냐하면 if~else 문을 사용하려면 오류가 발생할 상황을 미리 조건식으로 판단할 수 있어야 하기 때문입니다. 앞에서 작성한 코드를 if~else 문으로 처리한다면 다음과 같이 작성해볼 수 있습니다.

```python filename="05-16-digit_check_input.py"
user_input = "abc"

# if~else로 억지로 처리하기
if user_input.isdigit():
  number = int(user_input)
  print(f"변환 성공: {number}")
else:
  print("숫자로 변환할 수 없습니다.")
```

**실행 결과**

```text
숫자로 변환할 수 없습니다.
```

실행 결과를 보면 문제없어 보입니다. isdigit( ) 함수는 문자열의 모든 문자가 숫자인지 확인하므로 user_input.isdigit( )은 False로 평가됩니다. 따라서 else 문의 코드 블록이 실행됩니다. 그렇다면 잘 처리된 걸까요? 그렇지 않습니다. 이번에는 다음과 같은 값을 사용해봅시다.

```python filename="05-17-digit_check_negative.py"
user_input = "-123"

if user_input.isdigit():
  number = int(user_input)
  print(f"변환 성공: {number}")
else:
  print("숫자로 변환할 수 없습니다.")
```

**실행 결과**

```text
숫자로 변환할 수 없습니다.
```

실행 결과가 예상과 다릅니다. isdigit( ) 함수는 말 그대로 문자열의 각 문자가 숫자인지를 확인하며, -가 음수 표시인지 아닌지는 검사할 수 없습니다. 코드를 보면 "-123"에는 숫자가 아닌 "-" 문자가 포함되어 있습니다. 따라서 -는 문자로 확인되어 else 문의 코드 블록을 실행합니다. 하지만 int("-123")은 정상적으로 정수 -123으로 변환됩니다. 따라서 isdigit( )으로 미리 검사하지 말고 try~except 문으로 바로 변환을 시도하는 편이 낫습니다.

```python filename="05-18-try_except_negative.py"
user_input = "-123"

try:
  number = int(user_input)
  print(f"변환 성공: {number}")
except:
  print("숫자로 변환할 수 없습니다.")
```

**실행 결과**

```text
변환 성공: -123
```

try~except 문은 먼저 try 문의 코드 블록을 실행하고, 처리할 수 있는 예외가 발생했을 때 except 문의 코드 블록을 실행합니다. "-123"은 int( ) 함수를 통해 정수로 잘 변환되므로 예외가 발생하지 않고 try 문의 코드 블록이 실행됩니다. 언뜻 보면 if~else 문과 try~except 문이 비슷하게 동작하는 것처럼 보이지만 오류가 예상되는 상황에서는 역할이 다릅니다. if~else 문은 조건에 따라 실행할 코드를 선택하고, try~except 문은 코드를 실행하는 과정에서 발생하는 예외를 처리합니다. 상황에 맞는 문법을 선택해서 사용하면 됩니다. try~except 문의 기본 원리는 이 정도만 이해해도 충분합니다. 오류가 발생할 수 있는 상황을 처리하는 방법까지 익혔으니, 이제 같은 일을 여러 번 시키는 반복문으로 넘어가봅시다.

> **바로 핵심 요약**
>
> - try~except 문은 먼저 try 문의 코드 블록을 실행하고, 처리할 예외가 발생하면 프로그램을 멈추는 대신 except 문의 코드 블록을 실행합니다.
> - if~else 문은 조건에 따라 실행할 코드를 선택하고, try~except 문은 코드 실행 중 발생한 예외를 처리할 때 사용합니다.
> - try~except 문은 문자열을 정수로 바꾸는 int( ) 함수처럼 오류가 발생할 수 있는 코드에 사용하면 프로그램이 중간에 멈추는 일 없이 예외 상황에 적절하게 대응할 수 있습니다.
