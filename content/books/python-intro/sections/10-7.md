이번 장에서 배운 오류 메시지 읽는 방법, 예외 종류를 지정한 except 문, else와 finally, raise, 나만의 예외를 문제로 확인해봅시다. 객관식 7문제와 주관식 2문제로 구성했습니다. 먼저 스스로 풀어본 다음 마지막에 있는 정답과 해설을 확인하세요. 틀린 문제가 있다면 해당 절로 돌아가 다시 살펴보면 됩니다.

### 객관식 문제

01 오류 메시지를 읽는 방법으로 알맞은 것을 고르세요.

① 첫 줄부터 차례대로 읽는 것이 가장 빠릅니다.

② 마지막 줄에 오류의 종류와 원인이 나오므로 마지막 줄부터 확인합니다.

③ 오류의 종류는 모두 외워두어야 읽을 수 있습니다.

④ 오류 메시지는 파이썬이 알아서 처리하므로 읽지 않아도 됩니다.

02 다음 코드의 실행 결과로 알맞은 것을 고르세요.

```python
try:
  print(10 / 0)
except ZeroDivisionError:
  print("0으로 나눌 수 없습니다.")
finally:
  print("계산을 마쳤습니다.")
```

① '0으로 나눌 수 없습니다.'만 출력됩니다

② '계산을 마쳤습니다.'만 출력됩니다

③ '0으로 나눌 수 없습니다.'와 '계산을 마쳤습니다.'가 차례대로 출력됩니다

④ 오류 메시지가 출력되며 프로그램이 종료됩니다

03 다음 코드를 실행할 때 발생하는 오류의 종류를 고르세요.

```python
number = int("스물")
```

① TypeError ② ValueError ③ FileNotFoundError ④ ZeroDivisionError

04 다음 코드를 실행할 때 발생하는 오류의 종류를 고르세요. secret_memo.txt 파일은 없다고 가정합니다.

```python
with open("secret_memo.txt", "r", encoding="utf-8") as file:
  print(file.read())
```

① NameError ② KeyError ③ FileNotFoundError ④ IndexError

05 except 문에 예외의 종류를 지정하는 이유로 알맞은 것을 고르세요.

① 코드를 더 짧게 쓸 수 있기 때문입니다.

② 어떤 오류가 발생했는지 구분해 상황에 맞는 안내를 할 수 있기 때문입니다.

③ 예외를 지정하지 않으면 프로그램이 실행되지 않기 때문입니다.

④ 예외를 지정하면 오류가 아예 발생하지 않기 때문입니다.

06 else 문과 finally 문에 대한 설명으로 옳은 것을 고르세요.

① else 문은 오류가 발생했을 때 실행됩니다.

② finally 문은 오류가 발생했을 때만 실행됩니다.

③ else 문은 try 문의 코드 블록에서 오류가 발생하지 않았을 때 실행됩니다.

④ else 문과 finally 문은 함께 사용할 수 없습니다.

07 예외에 대한 설명으로 옳지 않은 것을 고르세요.

① 파이썬의 일반적인 예외는 Exception을 상속합니다.

② Exception을 상속하면 나만의 예외를 만들 수 있습니다.

③ raise로 예외를 직접 발생시킬 수 있습니다.

④ 현재 파일의 SyntaxError는 try~except 문으로 잡을 수 있습니다.
