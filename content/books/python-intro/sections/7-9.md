```python
>>> def add(a, b):
```

03 다음 코드의 실행 결과로 알맞은 것을 고르세요.

```python
>>> def greet():

>>> result = greet()
>>> print(result)
```

① 안녕하세요만 출력됩니다

② 안녕하세요가 출력된 다음 줄에 None이 출력됩니다

④ 오류가 발생합니다

04 다음 코드의 실행 결과로 알맞은 것을 고르세요.
