문자열에서 원하는 부분만 꺼내 쓰고 싶을 때가 많습니다. 이번 절에서는 글자 하나를 꺼내는 **인덱싱**과 여러 글자를 잘라내는 **슬라이싱**을 공부합니다. 번호를 세는 규칙만 익숙해지면 크게 어렵지 않으니 천천히 따라 해봅시다.

> **미리 알아두세요!**
>
> - 인덱싱은 문자열에서 글자 하나를 꺼내는 방법이고, 인덱스는 0부터 시작합니다.
> - 슬라이싱은 [시작:끝] 형태로 문자열의 일부를 잘라내는 방법입니다.

먼저 문자열 인덱싱에 대해 알아봅시다. **문자열 인덱싱은 문자의 위치 번호인 인덱스를 이용해 문자 하나를 꺼내는 방법입니다.** 앞에서 잠깐 살펴봤던 그림을 다시 가져왔습니다.

![](/books/python-intro/p130-100.webp)

“파이썬은 재미있는 프로그래밍 언어입니다”라는 문자열에서 공백을 포함해 0부터 위치를 세는 것이 파이썬의 문자열 인덱싱 규칙입니다.

## 인덱싱 알아보기

앞에서 find( ) 함수가 5를 알려준 것처럼 인덱스는 어떤 문자가 몇 번째 자리에 있는지를 나타냅니다. 하지만 인덱스는 단순히 위치를 알려주는 데만 쓰이지 않습니다. 반대로 인덱스를 지정해 알려주면 그 자리에 있는 문자를 꺼내올 수도 있습니다. **이렇게 인덱스로 문자 하나를 추출하는 것을 인덱싱이라고 합니다.** 방법은 간단합니다. 문자열이 저장된 변수 뒤에 대괄호를 붙이고 그 안에 원하는 인덱스 번호를 적으면 됩니다. 다음 코드를 입력해 실행해봅시다.

```python filename="03-36-string_index.py"
sayhello = "안녕하세요 파이썬!"
print(sayhello[0])
print(sayhello[3])
```

**실행 결과**

```text
안
세
```

sayhello[0]은 0번 인덱스에 있는 문자, 즉 첫 글자인 '안'을 꺼냅니다. sayhello[3]은 3번 인덱스이므로 '세'를 꺼냅니다. 손가락으로 직접 세어 보면 '세'는 네 번째 글자이지만 인덱스는 3입니다. 0부터 세기 때문에 인덱스는 우리가 일상적으로 세는 순번보다 항상 1이 작다고 생각하면 편합니다.

### 인덱싱 좀 더 알아보기 : 음수 인덱스

그렇다면 마지막 글자를 꺼내고 싶을 때는 어떻게 할까요? "안녕하세요 파이썬!"은 공백을 포함해 총 10글자이므로 마지막 인덱스는 9입니다. 하지만 문자열이 길어질 경우, 마지막 인덱스가 몇인지 매번 세어 봐야 한다면 번거로울 것입니다. 그래서 파이썬은 뒤에서부터 세는 음수 인덱스 기능을 제공합니다. 마지막 문자가 -1이고 그 앞 문자가 -2가 됩니다.

![](/books/python-intro/p131-101.webp)

```python filename="03-37-string_index_negative.py"
sayhello = "안녕하세요 파이썬!"
print(sayhello[-1])
print(sayhello[-2])
```

**실행 결과**

```text
!
썬
```

앞에서부터 셀 때는 0부터 시작하고, 뒤에서부터 셀 때는 -1부터 시작합니다. 0은 이미 첫 글자를 가리키고 있으므로 뒤에서 셀 때는 -0이 아니라 -1부터 시작하는 것입니다. 이 음수 인덱스는 잠시 뒤에 배울 슬라이싱에서도 그대로 쓰이니 잘 기억해두기 바랍니다.

### 인덱싱 좀 더 알아보기 : 없는 인덱스를 사용하면?

인덱스는 문자열에 실제로 있는 위치만 가리킬 수 있습니다. 그렇다면 없는 인덱스를 지정하면 어떻게 될까요? "안녕하세요 파이썬!"은 공백을 포함해 총 10글자이고, 인덱스는 0부터 9까지입니다. 만약 10번 인덱스에 있는 문자를 꺼내라고 하면 어떻게 될까요? 파이썬은 없는 자리를 조용히 넘어가지 않고 오류를 발생시킵니다.

```python filename="03-38-string_index_error.py"
sayhello = "안녕하세요 파이썬!"
print(sayhello[10])
```

**실행 결과**

```text
Traceback (most recent call last):
  File "<python-input-0>", line 2, in <module>
    print(sayhello[10])
IndexError: string index out of range
```

오류 발생!

IndexError는 ‘인덱스 오류’라는 뜻이며, string index out of range는 ‘문자열 인덱스가 허용 범위를 벗어났다’라는 뜻입니다. 코드를 작성하다가 이 오류를 만나면 전체 문자열의 길이 이상인 인덱스를 입력한 것은 아닌지 확인해보면 됩니다.

## 슬라이싱 알아보기

그렇다면 슬라이싱은 무엇일까요? **슬라이싱은 방금 배운 인덱싱 규칙을 이용해 문자열을 자르는 문법입니다.** 마치 빵을 원하는 두께로 썰어내듯 문자열에서 원하는 구간만큼 잘라낼 수 있습니다. **슬라이싱은 대괄호 안에 시작 인덱스와 끝 인덱스를 콜론(:)으로 구분해서 사용합니다.** [시작:끝] 형태로 작성하면 시작 위치부터 끝 위치 직전까지의 데이터를 가져옵니다. 시작 이상, 끝 미만으로 외워두면 기억하기 쉽겠죠? 다음 코드를 입력하고 실행해보면 문자열에서 원하는 부분을 어떻게 추출하는지 알 수 있을 겁니다.

```python filename="03-39-string_slice_start.py"
sayhello = "안녕하세요 파이썬!"
print(sayhello[0:3])
```

**실행 결과**

```text
안녕하
```

![](/books/python-intro/p133-102.webp)

[0:3]이라고 입력했으므로 0 이상 3 미만 구간의 텍스트를 슬라이싱합니다. '안'이 0번 인덱스이고, '세'가 3번 인덱스이므로, '안녕하'까지만 출력된 것입니다. 한 번 더 해볼까요?

```python filename="03-40-string_slice_middle.py"
sayhello = "안녕하세요 파이썬!"
print(sayhello[3:7])
```

**실행 결과**

```text
세요파
```

3번 인덱스는 '세'이고, 7번 인덱스는 '이'이므로 7번 직전까지인 '세요 파'가 출력되었습니다. 만약 특정 위치부터 문자열 끝까지 출력하고 싶다면 시작 인덱스만 입력하고 끝 인덱스는 생략하면 됩니다.

```python filename="03-41-string_slice_end.py"
sayhello = "안녕하세요 파이썬!"
print(sayhello[5:])
```

**실행 결과**

```text
파이썬!
```

여기서 눈여겨볼 점은 5번 인덱스가 공백(" ")이므로, 해당 위치인 공백부터 끝까지 출력했다는 점입니다. 여기까지 잘 이해했다면 슬라이싱의 기초는 뗀 셈입니다.

### 슬라이싱 좀 더 알아보기 : 음수 인덱스

슬라이싱에서 구간을 정할 때 음수 인덱스를 사용할 수도 있습니다. 앞에서 배운 것처럼 음수 인덱스는 뒤에서부터 세므로 -1은 문자열의 마지막 위치를 의미합니다. 만약 "안녕하세요 파이썬!"에서 "파이썬!"만 추출할 때 음수를 활용해서 슬라이싱하려면 어떻게 하는 것이 좋을까요? 다음 그림을 보면서 고민해봅시다.

![](/books/python-intro/p134-103.webp)

언뜻 생각하면 sayhello[-4:-1]이라고 작성해야 할 것 같습니다. 하지만 슬라이싱은 시작 인덱스 이상, 끝 인덱스 미만인 규칙을 따르므로, 마지막 인덱스인 -1은 추출 범위에서 제외됩니다. 이럴 때는 앞에서 배운 대로 끝 인덱스를 생략해 끝까지 슬라이싱하면 됩니다. 실행 결과를 보면 -4번 인덱스 이상부터 끝까지 슬라이싱한 것을 알 수 있습니다.

```python filename="03-42-string_slice_negative.py"
sayhello = "안녕하세요 파이썬!"
print(sayhello[-4:])
```

**실행 결과**

```text
파이썬!
```

![](/books/python-intro/p134-104.webp)

### 슬라이싱 좀 더 알아보기 : 건너뛰며 슬라이싱

원하는 간격으로 건너뛰며 문자열을 추출하는 방법도 있습니다. 지금까지 우리가 배운 기본 슬라이싱은 [시작:끝] 형태였습니다. 여기에 콜론을 하나 더 붙여 [시작:끝:간격]과 같이 간격 옵션을 추가하면 일정한 간격으로 건너뛰며 슬라이싱할 수 있습니다. 다음 코드를 실행해봅시다.

```python filename="03-43-string_slice_step.py"
sayhello = "안녕하세요 파이썬!"
print(sayhello[0:6:2])
```

**실행 결과**

```text
안하요
```

![](/books/python-intro/p135-105.webp)

결과를 보면 인덱스 0 이상 6 미만의 범위에서 인덱스를 2씩 더해가며 슬라이싱을 수행했습니다. 여기서 ‘건너뛴다’라는 표현 때문에 2칸을 비워야 한다고 오해하기 쉬운데, 그냥 현재 인덱스에 +2를 하면서 문자를 가져온다고 이해하면 됩니다. 따라서 간격을 1로 설정하면 인덱스에 +1을 하면서 순차적으로 슬라이싱을 진행하므로 간격을 생략했을 때와 동일한 결과를 얻을 수 있습니다.

```python filename="03-44-string_slice_default_step.py"
sayhello = "안녕하세요 파이썬!"
print(sayhello[0:5:1])
```

**실행 결과**

```text
안녕하세요
```

![](/books/python-intro/p136-106.webp)

### 슬라이싱 좀 더 알아보기 : 음수로 건너뛰며 슬라이싱

이번에는 음수로 건너뛰며 슬라이싱하는 방법을 알아보겠습니다. 음수로 간격을 지정하면 어떤 결과가 나올까요? 전체 문자열을 선택한 뒤 간격을 -1로 설정해보겠습니다. 이를 사용하면 데이터의 순서를 거꾸로 뒤집을 수 있습니다.

```python filename="03-45-string_reverse.py"
sayhello = "안녕하세요 파이썬!"
print(sayhello[::-1])
```

**실행 결과**

```text
!썬이파 요세하녕안
```

![](/books/python-intro/p136-107.webp)

문자열이 거꾸로 출력되는 재미있는 결과가 나타났네요. 원리를 이해하고 보니 직관적이고 당연한 결과입니다. 전체 문자열 범위에서 반대 방향으로 인덱스를 -1씩 더하고 이동하면서 문자를 가져왔기 때문에 이런 결과가 나온 것입니다. 이 정도면 문자열을 다루는 핵심 방법을 대부분 설명한 것 같습니다.

지금까지 배운 문자열 다루기 개념은 이후 리스트와 같은 자료구조를 공부할 때 다시 등장합니다. 혹시나 ‘문자열을 다룰 일이 이렇게까지 많은가?’라는 생각을 했다면, 이후 동일한 개념을 마주할 때 ‘아! 이래서 그때 문자열 관련해서 다양한 개념과 원리를 배웠구나’ 하는 생각이 들 겁니다.

> **바로 핵심 요약**
>
> - 문자열의 인덱스는 0부터 시작하며, 음수 인덱스 -1은 맨 마지막 문자를 가리킵니다.
> - 슬라이싱은 [시작:끝] 형태로 작성하며, 시작 인덱스 이상, 끝 인덱스 미만의 문자열을 잘라냅니다.
> - [시작:끝:간격]을 사용하면 특정 간격으로 문자를 건너뛰며 추출할 수 있고, [::-1]을 입력하면 문자열을 거꾸로 뒤집을 수 있습니다.
