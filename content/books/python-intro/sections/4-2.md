**리스트**(List)는 여러 값을 하나로 묶어 저장하는 자료형입니다. 이미 몇 번 본 적 있는 대괄호로 감싸고 쉼표로 값을 구분해 만든 자료형이 바로 리스트입니다. 다음은 숫자형 데이터만 담은 리스트를 만들고 출력하는 코드입니다.

> **미리 알아두세요!**
>
> - 리스트는 여러 값을 대괄호로 감싸 한 바구니에 담는 자료형입니다.
> - 요소를 추가·수정·삭제하고 정렬할 수 있는 가변 자료형입니다.

```python filename="04-01-list_scores.py"
# 숫자로 이루어진 리스트
scores = [85, 92, 78, 96, 88]
print("수학 점수 :", scores)
```

**실행 결과**

```text
수학 점수 : [85, 92, 78, 96, 88]
```

![](/books/python-intro/p154-113.webp)

실행 결과를 보면 입력한 값이 대괄호로 감싸인 형태 그대로 출력됩니다. **이처럼 대괄호 안에 값을 쉼표로 구분해 나열한 것이 리스트입니다.** 리스트 안에 쉼표로 구분한 각각의 값을 **요소**(Element)라고 합니다. 즉, 리스트는 여러 요소를 하나로 묶어 놓은 데이터라고 생각하면 됩니다. 그렇다면 리스트를 왜 사용할까요?

## 리스트 기초 연습하기

리스트가 왜 필요한지는 여러 값을 다뤄보면 금방 이해할 수 있습니다. 예를 들어 여러분이 숫자 5개의 평균을 계산해야 한다면 어떻게 할 수 있을까요? 점수 평균을 계산하는 예제를 통해 리스트의 기초와 필요성을 알아보겠습니다.

## 연습 01 점수 평균 계산해보기

만약 리스트를 사용하지 않고 숫자형 데이터 5개를 변수에 저장한다면 이렇게 코드를 작성해야 할 겁니다.

```python filename="04-02-score_variables.py"
score1 = 85
score2 = 92
score3 = 78
score4 = 96
score5 = 88
```

틀린 코드는 아닙니다. 그렇다면 평균 점수를 구하려면 어떻게 해야 할까요? 다음과 같이 작성하면 됩니다.

```python filename="04-03-score_average.py"
score1 = 85
score2 = 92
score3 = 78
score4 = 96
score5 = 88

print("평균 점수:", (score1 + score2 + score3 + score4 + score5) / 5)
```

**실행 결과**

```text
평균 점수: 87.8
```

하지만 항상 이런 방식으로 작성할 수는 없습니다. 예를 들어 점수가 100개라면 어떻게 해야 할까요? 변수도 100개가 필요하고, 평균을 구하는 식에도 100개의 변수를 모두 입력해야 합니다. 생각만 해도 불편합니다.

이럴 때 리스트가 필요합니다. 다음 코드를 작성해서 실행해봅시다.

```python filename="04-04-list_average.py"
scores = [85, 92, 78, 96, 88]
print("리스트로 관리 :", scores)
print("평균 점수 :", sum(scores) / len(scores))
```

**실행 결과**

```text
리스트로 관리 : [85, 92, 78, 96, 88]
평균 점수 : 87.8
```

코드를 보면 scores 변수 하나에 모든 값을 담아 저장했습니다. 그래서 score1, score2와 같은 개별 변수를 만들 필요가 없습니다. 또한 리스트에는 합계나 길이를 구하는 sum( ), len( ) 함수를 바로 적용할 수 있습니다. 만약 점수가 추가되더라도 scores 리스트에 숫자를 쉼표로 구분하여 더 입력하면 됩니다. 프로그램을 크게 수정할 필요가 없으니 편리합니다.

> **NOTE**
>
> 개별 변수로 관리했다면 변수 이름을 추가로 만들어야 하고, 평균을 구하는 식에도 추가한 변수를 하나씩 더해야 했을

겁니다.

## 연습 02 인덱싱, 슬라이싱하기

에서는 문자열의 인덱싱, 슬라이싱을 배웠습니다. 문자열은 여러 문자가 모인 데이터라고 했었죠? 리스트도 여러 값이 모여 있는 데이터입니다. 따라서 리스트도 문자열과 마찬가지로 인덱싱과 슬라이싱을 할 수 있습니다. 다음은 리스트에서 인덱싱을 사용하는 예시 코드로, 특정 요소에 접근해서 해당 요소의 값을 출력합니다.

> **NOTE**
>
> 여기서는 출력문에 f-string을 사용했습니다.

```python filename="04-05-list_indexing.py"
# 리스트의 각 요소에 접근하기
colors = ["빨강", "파랑", "노랑", "초록"]
print(f"첫 번째 색깔 : {colors[0]}")
print(f"두 번째 색깔 : {colors[1]}")
print(f"마지막 색깔 : {colors[-1]}")
```

**실행 결과**

```text
첫 번째 색깔 : 빨강
두 번째 색깔 : 파랑
마지막 색깔 : 초록
```

실행 결과를 보면 colors[0]은 첫 번째 요소인 빨강을, colors[1]은 두 번째 요소인 파랑을 가져옵니다. colors[-1]처럼 음수를 쓰면 뒤에서부터 세어 마지막 요소인 초록이 나옵니다. 문자열에서 쓰던 인덱스 규칙이 리스트에도 그대로 적용된 것이죠.

슬라이싱도 이어서 알아봅니다. 슬라이싱 역시 문자열에서 배운 내용과 크게 다르지 않으므로 별도의 설명 없이 코드를 입력해보면 바로 이해할 수 있을 것입니다.

> **NOTE**
>
> 여기서는 출력문에서 값을 쉼표로 구분해 출력하는 방식을 사용했습니다.

```python filename="04-06-list_slicing.py"
numbers = [10, 20, 30, 40, 50, 60, 70, 80]

# 슬라이싱: [시작:끝] 형태로 사용
print("처음부터 3번 인덱스 전까지:", numbers[0:3])
print("5번 인덱스부터 끝까지:", numbers[5:])
```

**실행 결과**

```text
처음부터 3번 인덱스 전까지: [10, 20, 30]
5번 인덱스부터 끝까지: [60, 70, 80]
```

실행 결과를 보면 문자열의 슬라이싱과 같은 방식으로 동작합니다. 0:3으로 지정하면 인덱스 0부터 2까지 잘라 [10, 20, 30]을 출력하고, 5:로 지정하면 인덱스 5부터 마지막 요소까지 출력합니다.

## 연습 03 리스트로 더하거나 곱하기

이번에는 리스트에 +와 * 연산자를 사용해 연결과 반복을 해봅시다. 리스트는 더하기, 곱하기 연산을 지원합니다. 이 두 가지 연산만 알아도 리스트를 훨씬 자유롭게 다룰 수 있습니다. 다음 코드를 실행해 결과를 확인해봅시다.

```python filename="04-07-list_concatenate.py"
fruits = ["apple", "banana"]
vegetables = ["carrot", "cucumber"]

cart = fruits + vegetables
print(f"장바구니: {cart}")

repeated_fruits = fruits * 3
print(f"과일 3번 반복: {repeated_fruits}")
```

**실행 결과**

```text
장바구니: ['apple', 'banana', 'carrot', 'cucumber']
과일 3번 반복: ['apple', 'banana', 'apple', 'banana', 'apple', 'banana']
```

실행 결과를 보면 문자열의 더하기와 곱하기 연산과 비슷하게 동작한다는 것을 알 수 있습니다. 더하기는 말 그대로 두 리스트를 순서대로 합친 것이고, 곱하기는 리스트를 지정한 횟수만큼 반복해 이어 붙인 것입니다. 빼기나 나누기는 사용할 수 없습니다. 이후 예제를 실습하며 리스트 연산자는 필요할 때 종종 사용하겠습니다.

## 연습 01 리스트의 요소 수정하기

리스트는 요소를 자유롭게 수정할 수 있는 자료형입니다. 특정 위치의 요소를 다른 값으로 바꾸거나, 여러 요소를 한 번에 수정할 수도 있습니다. 요소를 수정하려면 인덱스로 위치를 지정한 뒤 새로운 값을 할당하면 됩니다. 변수에 값을 저장하는 것처럼 **리스트[인덱스] = 값** 형태로 작성하면 됩니다.

```python filename="04-09-list_element_update.py"
fruits = ["apple", "banana", "cherry"]
print(f"원본 리스트: {fruits}")

# 두 번째 항목 수정 (인덱스 1)
fruits[1] = "blueberry"
print(f"수정 후: {fruits}")
```

**실행 결과**

```text
원본 리스트: ['apple', 'banana', 'cherry']
수정 후: ['apple', 'blueberry', 'cherry']
```

실행 결과를 보면 인덱스 1에 있던 "banana"가 "blueberry"로 바뀐 것을 알 수 있습니다.

## 연습 02 슬라이싱으로 리스트 수정하기

슬라이싱을 이용하면 원하는 범위의 요소를 한꺼번에 수정할 수도 있습니다. 다음은 numbers 리스트에서 인덱스 1 이상, 4 미만(인덱스 1, 2, 3)의 요소를 수정하는 코드입니다.

```python filename="04-10-list_slice_update.py"
numbers = [1, 2, 3, 4, 5]
print(f"원본: {numbers}")

# 중간 세 개를 한꺼번에 수정 (인덱스 1부터 3까지)
numbers[1:4] = [20, 30, 40]
print(f"범위 수정: {numbers}")
```

**실행 결과**

```text
원본: [1, 2, 3, 4, 5]
범위 수정: [1, 20, 30, 40, 5]
```

![](/books/python-intro/p161-117.webp)

numbers[1:4]를 지정하여 인덱스 1부터 4 미만(1~3) 범위에 있는 [2, 3, 4]를 [20, 30, 40]으로 수정했습니다.

## 연습 03 요소 개수 바꾸며 리스트 값 교체하기

리스트의 값은 다른 리스트로 교체할 수도 있습니다. 슬라이싱과 함께 사용하면 특정 범위를 지정해 여러 값을 한 번에 바꿀 수 있습니다. 이때 선택한 범위와 새로 넣을 요소의 개수가 꼭 같지 않아도 됩니다.

```python filename="04-11-list_slice_resize.py"
# 일부 범위를 더 적은 개수로 교체 (인덱스 1 이상 4 미만)
colors = ["red", "green", "blue", "yellow", "purple"]
colors[1:4] = ["orange"]
print(f"축소 수정: {colors}")

# 일부 범위를 더 많은 개수로 교체 (인덱스 1 이상 2 미만)
animals = ["cat", "dog", "bird"]
animals[1:2] = ["rabbit", "hamster", "turtle"]
print(f"확장 수정: {animals}")
```

**실행 결과**

```text
축소 수정: ['red', 'orange', 'purple']
확장 수정: ['cat', 'rabbit', 'hamster', 'turtle', 'bird']
```

이때 중요한 점은 교체할 곳이 리스트이므로 준비할 데이터도 리스트여야 합니다. 다시 말해 리스트 대 리스트로 교체해야 합니다. 예를 들어 colors[1:4] = ["orange"]와 같이 작성해야 colors[1:4]도 리스트, ["orange"]도 리스트이므로 의도한 결과를 확인할 수 있습니다.

> **NOTE**
>
> 사실은 ‘리스트 대 리스트’로 교체한다는 표현보다는 슬라이스에 대입하는 값은 ‘반복할 수 있는 객체’여야 한다고 하는

것이 더 정확합니다. 하지만 아직 반복할 수 있는 객체의 개념을 배우지 않아 ‘리스트 대 리스트’와 같은 표현을 사용했습니다.

## 연습 04 리스트를 교체할 때 문자열을 그냥 넣으면 어떻게 될까?

리스트를 교체할 때 좌우를 대등하게 맞추지 않으면 어떻게 될까요? 예를 들어 colors[1:4] = "orange"와 같이 문자열을 그대로 대입하면 어떻게 되는지 살펴봅시다.

```python filename="04-12-list_slice_string.py"
colors = ["red", "green", "blue", "yellow", "purple"]
colors[1:4] = "orange"
print(f"문자열 대입 결과: {colors}")
```

**실행 결과**

```text
문자열 대입 결과: ['red', 'o', 'r', 'a', 'n', 'g', 'e', 'purple']
```

결과를 보면 문자열 "orange"를 ['o', 'r', 'a', 'n', 'g', 'e']와 같이 한 글자씩 쪼갠 뒤 리스트화하고 지정한 colors[1:4] 위치의 요소들을 이 글자들로 통째로 바꿨습니다. 이렇게 된 이유는 파이썬이 문자열의 각 문자를 순서대로 가져와 넣기 때문입니다. 오류가 발생하지는 않았지만 우리가 의도한 것과는 다른 결과가 나왔네요.

리스트의 요소를 삭제할 때는 remove( )와 pop( ) 함수를 사용합니다. remove( ) 함수는 지정한 값을 리스트에서 삭제합니다. 반면 pop( ) 함수는 인덱스를 지정하면 해당 위치의 요소를, 지정하지 않으면 마지막 요소를 삭제하고 그 값을 반환합니다.

## 연습 05 지정한 요소를 지우는 remove( ) 함수

먼저 remove( ) 함수부터 알아봅시다.

```python filename="04-13-list_remove.py"
fruits = ["apple", "banana", "orange", "grape", "banana"]

# remove()로 값을 지정해서 삭제
fruits.remove("banana")
print("remove() 후:", fruits)
```

**실행 결과**

```text
remove() 후: ['apple', 'orange', 'grape', 'banana']
```

실행 결과를 보면 리스트 내에서 "banana"라는 값을 찾아 삭제합니다. 만약 리스트에 동일한 값이 여러 개 존재하더라도 왼쪽부터 찾아 가장 먼저 나오는 요소 하나만 지웁니다. 이때 remove( ) 함수는 값을 지우기만 할 뿐 지운 값을 돌려주지는 않습니다. 또한 리스트에 없는 값을 지우려고 하면 오류가 발생하므로 지우려는 값이 리스트에 있는지 먼저 확인하는 것이 안전합니다.

## 연습 06 지정한 인덱스의 요소를 지우는 pop( ) 함수

remove( ) 함수가 값을 보고 지운다면, pop( ) 함수는 위치를 보고 지웁니다. 먼저 괄호를 비워 둔 채로 그냥 사용해보겠습니다.

```python filename="04-14-list_pop_last.py"
numbers = [10, 20, 30, 40, 50]
print("원래 리스트:", numbers)
last_value = numbers.pop()
print("pop() 후:", numbers)
print("꺼낸 값:", last_value)
```

**실행 결과**

```text
원래 리스트: [10, 20, 30, 40, 50]
pop() 후: [10, 20, 30, 40]
꺼낸 값: 50
```

pop( ) 함수는 요소를 삭제함과 동시에 그 값을 리스트 밖으로 'pop' 즉, 튕겨내 돌려주는 역할도 합니다. 그래서 last_value = numbers.pop( )과 같이 튀어나간 값을 변수에 저장하여 재활용할 수도 있습니다.

이번에는 마지막에 위치한 요소를 지워보겠습니다. 괄호 안에 인덱스를 전달하면 그 자리의 요소를 꺼냅니다.

```python filename="04-15-list_pop_index.py"
fruits = ["apple", "orange", "grape", "banana"]
# pop()으로 인덱스를 지정해서 삭제
removed_fruit = fruits.pop(3)
print("pop() 후:", fruits)
print("삭제된 값:", removed_fruit)
```

**실행 결과**

```text
pop() 후: ['apple', 'orange', 'grape']
삭제된 값: banana
```

실행 결과를 보면 인덱스 3에 있던 "banana"가 삭제되고 그 값이 removed_fruit 변수에 저장되었습니다. 이 리스트에서 "banana"는 인덱스 3에 있으므로 pop(3)으로 꺼냈습니다. 이처럼 괄호 안에 인덱스를 전달하면 마지막이 아닌 원하는 위치의 요소도 골라 꺼낼 수 있습니다.

## 연습 07 append( ), insert( ) 함수로 리스트에 요소 추가하기

지금까지 인덱싱이나 슬라이싱으로 요소를 수정하고 삭제하는 방법을 알아봤습니다. 그렇다면 새로운 요소를 추가하려면 어떻게 해야 할까요? 바로 append( ) 함수나 insert( ) 함수를 사용하면 됩니다. append( ) 함수는 리스트 맨 끝에 요소를 추가할 수 있고, insert( ) 함수는 지정한 인덱스 위치에 요소를 추가할 수 있습니다. 다음 코드를 통해 어떻게 다르게 동작하는지 살펴봅시다.

```python filename="04-16-list_append.py"
fruits = ["apple", "banana"]
print("원래 리스트:", fruits)

# append()로 맨 끝에 추가
fruits.append("orange")
print("append() 후:", fruits)

fruits.append("grape")
print("한 번 더 append():", fruits)
```

**실행 결과**

```text
원래 리스트: ['apple', 'banana']
append() 후: ['apple', 'banana', 'orange']
한 번 더 append(): ['apple', 'banana', 'orange', 'grape']
```

실행 결과를 보면 append("orange")로 리스트의 맨 끝에 "orange"를 추가하여 ['apple', 'banana']가 ['apple', 'banana', 'orange']로 바뀌었습니다. 한 번 더 append("grape")를 하여 ['apple', 'banana', 'orange', 'grape']가 되었네요.

만약 리스트의 중간에 요소를 추가하고 싶다면 다음과 같이 insert( ) 함수를 사용하면 됩니다. insert( ) 함수는 요소를 추가할 위치의 인덱스와 추가할 값을 함께 전달해야 합니다. 예를 들어 insert(1, "yellow")와 같이 작성하면 인덱스 1 위치에 "yellow"가 추가됩니다.

```python filename="04-17-list_insert.py"
colors = ["red", "blue", "green"]
print("원래 리스트:", colors)

# insert(인덱스, 값)으로 특정 위치에 추가
colors.insert(1, "yellow")
print("insert(1, 'yellow') 후:", colors)

colors.insert(0, "purple")
print("insert(0, 'purple') 후:", colors)
```

**실행 결과**

```text
원래 리스트: ['red', 'blue', 'green']
insert(1, 'yellow') 후: ['red',    , ,'blue', 'green']'yellow'
insert(0, 'purple') 후: ['purple', 'red', 'yellow', 'blue', 'green']
```

실행 결과를 보면 colors.insert(1, "yellow")를 실행했을 때 원래 1번 인덱스에 있던 "blue" 자리에 "yellow"가 들어가고, "blue"를 포함한 뒤쪽 요소들은 한 칸씩 뒤로 밀려난 것을 알 수 있습니다. 즉, insert(인덱스, 값)에서 인덱스는 '새로운 값이 들어갈 방 번호'를 지정하는 것입니다. 기존에 그 방을 쓰고 있던 데이터는 자연스럽게 다음 방으로 옮겨가게 됩니다. insert(0, "purple") 역시 원래 0번 방에 있던 "red"를 뒤로 밀어내고 맨 앞자리를 차지한 모습을 확인할 수 있습니다.

## 리스트 요소의 개수를 세거나 정렬해보기

값이 여러 개 있는 리스트를 보면 요소가 얼마나 들어 있는지, 정렬할 수 있는 방법은 없는지 궁금해질 겁니다. 실제로 많이 사용하는 len( ), sort( )와 같은 함수를 사용해보면서 리스트에 들어 있는 요소의 개수를 세거나 정렬해보는 방법을 알아봅니다.

## 연습 01 len( ) 함수로 리스트에 포함되어 있는 요소 개수 세기

리스트에 몇 개의 요소가 들어 있는지 알고 싶을 때는 len( ) 함수를 사용합니다. len( ) 함수는 리스트를 괄호 안에 넣어주기만 하면 그 리스트가 가지고 있는 요소의 개수를 정수로 돌려줍니다. 빈 리스트라면 0을 반환하고, 요소가 있다면 그 개수만큼의 숫자를 알려주죠.

```python filename="04-18-list_length.py"
fruits = ["사과", "바나나", "오렌지"]
count = len(fruits)
print(f"과일 리스트에는 {count}개의 요소가 있습니다")
```

**실행 결과**

```text
과일 리스트에는 3개의 요소가 있습니다
```

리스트 fruits에는 세 개의 문자열이 요소로 들어 있으므로 len( ) 함수가 3을 반환했습니다.

## 연습 02 sort( ), sorted( ) 함수로 리스트 정렬하기

리스트에 담긴 여러 값을 순서대로 정렬할 수 있습니다. 파이썬에서는 sort( ) 함수 또는 sorted( ) 함수를 사용해서 리스트를 쉽게 정렬할 수 있습니다. 두 함수에는 각각 다음과 같은 차이가 있습니다.

- **sort( ) 함수 :** 원본 리스트 자체를 정렬하고 None을 반환합니다.
- **sorted( ) 함수 :** 원본은 그대로 유지하고 정렬을 마친 새로운 리스트를 만들어 반환합니다.

두 함수 모두 기본적으로 오름차순(작은 값부터 큰 값 순서)으로 정렬합니다. 만약 내림차순으로 정렬하고 싶다면 reverse=True 옵션을 사용하면 됩니다.

아직 함수를 배우기 전이라 설명이 한 번에 와닿지 않을 수 있습니다. 하지만 동작 원리만 놓고 보면 어렵지 않습니다. sort( ) 함수는 정렬 대상인 원본 리스트를 직접 수정하는 방식이고, sorted( ) 함수는 원본을 건드리지 않고 사본을 만들어서 정렬하는 방식입니다. 다음 코드를 입력해 실행해보면 더 쉽게 이해할 수 있습니다.

![](/books/python-intro/p167-121.webp)

```python filename="04-19-list_sort.py"
# 숫자 리스트 만들기
numbers = [85, 90, 78, 92, 88]
print(f"원본 리스트: {numbers}")

# sort() 함수로 정렬(원본 변경)
numbers.sort()
print(f"sort() 후: {numbers}")

# 내림차순 정렬
numbers.sort(reverse=True)
print(f"내림차순 정렬: {numbers}")
```

**실행 결과**

```text
원본 리스트: [85, 90, 78, 92, 88]
sort() 후: [78, 85, 88, 90, 92]
내림차순 정렬: [92, 90, 88, 85, 78]
```

numbers 변수 뒤에 점(.)을 찍고 sort( ) 함수를 붙여 리스트에 적용했습니다. 기본값이 오름차순이므로 [85, 90, 78, 92, 88]이 [78, 85, 88, 90, 92]로 정렬됩니다. reverse 옵션을 적용하는 방식도 함께 보겠습니다. numbers.sort(reverse=True)처럼 괄호 안에 reverse=True 옵션을 넣으면 기본 정렬 순서의 반대인 내림차순으로 정렬되어 [92, 90, 88, 85, 78]로 바뀝니다.

이번에는 원본을 건드리지 않는 sorted( ) 함수를 사용해보겠습니다.

```python filename="04-20-sorted_list.py"
# 숫자 리스트 만들기
numbers = [85, 90, 78, 92, 88]
print(f"처음 원본 리스트: {numbers}")

# sorted() 함수로 정렬(원본은 그대로 두고 새 리스트 생성)
new_numbers = sorted(numbers)
print(f"sorted() 결과   : {new_numbers}")
print(f"sorted() 후 원본: {numbers}") # 원본이 그대로 유지됨

# sorted()로 내림차순 정렬
new_numbers = sorted(numbers, reverse=True)
print(f"내림차순 정렬   : {new_numbers}")
```

**실행 결과**

```text
처음 원본 리스트: [85, 90, 78, 92, 88]
sorted() 결과   : [78, 85, 88, 90, 92]
sorted() 후 원본: [85, 90, 78, 92, 88]
내림차순 정렬   : [92, 90, 88, 85, 78]
```

코드를 보면 sorted( )는 sort( )와 문법적 쓰임새가 조금 다릅니다. numbers.sort( )처럼 리스트 뒤에 점(.)을 붙여 호출하는 방식과 달리, sorted(numbers)는 소괄호 안에 정렬하고 싶은 리스트를 넣어 전달하는 방식으로 사용합니다.

실행 결과를 살펴보면 흥미로운 점이 있습니다. sorted(numbers)를 실행한 결과는 오름차순으로 정렬되어 new_numbers에 담겼지만, 정작 원본인 numbers를 다시 출력해보면 처음 입력했던 순서 그대로 전혀 바뀌지 않았습니다. 앞서 설명했듯이 원본을 직접 수정하지 않고 복사본으로 정렬된 새 리스트를 만들어 반환했기 때문입니다.

## 연습 01 리스트 복사하기 : 별칭

앞에서 sorted( ) 함수는 원본을 변경하지 않고 새 리스트를 만들어 반환한다고 했습니다. 그렇다면 리스트를 단순히 복사하고 싶을 때는 어떻게 해야 할까요? 변수에 대입하면 복사가 될까요? 예상이 맞는지 코드로 직접 확인해봅시다.

```python filename="04-21-list_assign_share.py"
a = [1, 2, 3]
b = a                     # ➊ 복사한 것처럼 보이지만
b.append(4)               # ➋ b에만 값을 추가했는데
print(f"b: {b}")
print(f"a: {a}")         # ➌ a까지 바뀌어 있습니다
```

**실행 결과**

```text
b: [1, 2, 3, 4]
a: [1, 2, 3, 4]
```

❶ b = a로 리스트를 복사했다고 생각하기 쉽습니다.

❷ 그래서 b에만 4를 추가했습니다.

❸ 그런데 손대지 않은 a까지 [1, 2, 3, 4]로 바뀌었습니다.

왜 이런 일이 벌어질까요? 변수를 상자에 비유했던 것을 떠올려봅시다. b = a라고 하면 b에 a의 내용을 통째로 복사한 뒤 담을 것 같지만 실제로는 그렇지 않습니다. 파이썬은 데이터(값)를 메모리에 따로 저장해두고, 변수는 그 값을 가리키는 이름표 역할만 수행하기 때문입니다.

이건 메모리 구조를 알아야 이해할 수 있으므로 그림과 함께 최대한 쉽게 설명하겠습니다. 여러분이 코드로 뭔가를 작성하고 실행할 수 있는 건 메모리가 있기 때문입니다. 대부분의 작업은 이 메모리에서 벌어집니다. 쉽게 말해 변수에 값을 저장해두고 다시 꺼내 쓸 수 있는 것도 그 값을 메모리에 기록해두기 때문입니다. 그런데 [1, 2, 3]이라는 리스트를 만들고 변수 a에 저장하면 파이썬은 실제로 이것을 메모리에 다음과 같이 저장합니다.

![](/books/python-intro/p170-123.webp)

그림을 보면 a라는 상자에 [1, 2, 3]을 담는 것이 아니라 a가 메모리상의 [1, 2, 3]이 저장된 위치를 가리킵니다. 파이썬의 변수는 실제로 이처럼 값이 있는 위치를 가리키는 방식으로 동작합니다. 그래서 b = a를 실행하면 [1, 2, 3]을 메모리에 새로 복사하여 b가 그 복사한 [1, 2, 3]을 가리키는 것이 아니라 b와 a가 같은 리스트를 가리키게 됩니다.

![](/books/python-intro/p170-124.webp)

**다시 말해 [1, 2, 3]의 값은 그대로 둔 채, a와 b라는 두 이름표가 동일한 값을 함께 가리키도록 설정한 것입니다.** 이런 행위를 **별칭**(aliasing)이라고 부릅니다. 쉽게 말해 리스트 [1, 2, 3]에 이름표를 2개 붙인 겁니다.

![](/books/python-intro/p170-125.webp)

## 연습 02 리스트 복사하기 : 얕은 복사

그렇다면 a에 담은 [1, 2, 3]의 값을 완전히 독립된 새로운 리스트로 복사하려면 어떻게 해야 할까요? 이럴 때 바로 copy( ) 함수를 사용합니다.

```python filename="04-22-list_copy.py"
a = [1, 2, 3]
b = a.copy()         # ➊ 내용물을 베껴 새 리스트 만들기
b.append(4)
print(f"b: {b}")
print(f"a: {a}")     # ➋ 원본은 그대로
```

**실행 결과**

```text
b: [1, 2, 3, 4]
a: [1, 2, 3]
```

❶ a.copy( )는 a의 요소를 그대로 복사한 새 리스트를 만들어 돌려줍니다. 이제 b는 a와 별개의 리스트입니다.

❷ 따라서 b에 새로운 값을 추가해도 a는 [1, 2, 3]을 그대로 유지합니다.

비로소 우리가 원하던 독립적인 복사가 되었습니다. a에 담긴 요소를 새 리스트에 복사해 담아 b에 저장했기 때문에, b에 4라는 요소를 추가하더라도 a에는 영향을 주지 않고 복사한 b의 [1, 2, 3]에만 요소가 추가됩니다.

> **NOTE**
>
> 이것으로 리스트 복사의 개념이 끝난 것은 아닙니다. 얕은 복사, 깊은 복사, 중첩 리스트 복사처럼 더 알아두어야 할 내

용이 있습니다. 다만 한꺼번에 너무 많은 내용을 다루면 혼란스러울 수 있으니, 심화 내용은 에서 이야기하겠습니다.

## 연습 03 리스트 비교하기

리스트는 단순히 이름표만 새로 붙였는지(별칭) 아니면 독립된 새 리스트를 만들었는지(얕은 복사)에 따라 비교 연산의 결과가 달라집니다. == 연산자는 내부 값이 같은지를 비교하고, is 연산자는 두 변수가 완전히 동일한 객체를 가리키고 있는지를 비교합니다.

```python filename="04-23-equal_vs_is.py"
a = [1, 2, 3]
b = a          # 같은 리스트에 이름표를 하나 더
c = a.copy()   # 내용물을 베낀 새 리스트
print(a == b, a is b)   # ➊
print(a == c, a is c)   # ➋
```

**실행 결과**

```text
True True
True False
```

❶ b는 a와 값도 같고 동일한 리스트를 가리키고 있으므로 둘 다 True입니다.

❷ c는 내부 값은 같지만 a와 다른 독립된 리스트이므로 ==는 True, is는 False입니다.

평소에 두 리스트의 값을 비교할 때는 ==를 사용하면 됩니다. is 연산자는 ‘값이 같은가’가 아니라 ‘진짜로 같은 것인가’를 따져야 하는 특수한 상황에서만 사용합니다.

## 리스트 안에 리스트가 들어가는 중첩 리스트

지금까지 살펴본 리스트는 값이 한 줄로 나열된 형태였습니다. **하지만 리스트의 요소로 또 다른 리스트를 넣을 수도 있습니다.** 이렇게 하면 엑셀 시트처럼 행과 열을 갖춘 표 형태의 데이터를 표현할 수 있죠. 이를 **2차원 리스트** 또는 **중첩 리스트**라고 부릅니다. 이 책에서는 중첩 리스트라고 하겠습니다. 중첩 리스트에서 특정 값을 꺼낼 때는 대괄호 두 개를 연달아 사용해 **[행][열] 순서로 지정합니다**. 표 형식(엑셀)의 데이터를 상상하면 쉽게 이해할 수 있습니다.

![](/books/python-intro/p172-126.webp)

그림처럼 [["사과", "배"], ["포도", "귤"]] 형태의 중첩 리스트가 있다고 해봅시다. 여기서 "배"라는 값만 지칭하고 싶다면, 인덱스 0번 행의 인덱스 1번 열의 값이라는 의미로 [0][1]을 지정하여 골라낼 수 있습니다. 다음 코드를 입력하며 중첩 리스트의 원리를 확실히 이해해봅시다.

```python filename="04-24-two_dimensional_list.py"
matrix = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9]
]

print(matrix[0])       # ➊ 인덱스 0번(첫 번째) 행 전체
print(matrix[0][1])    # ➋ 인덱스 0번 행의 인덱스 1번 열
print(matrix[2][2])    # ➌ 인덱스 2번 행의 인덱스 2번 열

matrix[1][0] = 40      # ➍ 인덱스 1번 행의 인덱스 0번 열 값 수정
print(matrix[1])
```

**실행 결과**

```text
[1, 2, 3]
2
9
[40, 5, 6]
```

❶ matrix[0]은 리스트의 인덱스 0번(첫 번째) 행을 꺼냅니다. 이때 요소 자체가 리스트이므로 값이 하나가 아니라 [1, 2, 3]이라는 리스트가 통째로 나옵니다.

❷ matrix[0]의 결과가 [1, 2, 3]이므로, 여기에 [1]을 한 번 더 붙여 matrix[0][1]로 작성하면 해당 행의 인덱스 1번(두 번째) 열에 있는 값인 2가 나옵니다. 파이썬의 인덱스는 0부터 시작하므로 matrix[0][1]은 ‘0번 행의 1번 열’이라고 읽는 것이 헷갈리지 않습니다.

❸ 같은 방식으로 인덱스 2번(세 번째) 행 [7, 8, 9]에서 인덱스 2번 열의 값인 9를 꺼냅니다.

❹ 값을 꺼낼 때와 마찬가지 방법으로 값을 수정할 수도 있습니다. 여기서는 인덱스 1번 행의 인덱스 0번 열의 값이 4에서 40으로 바뀌었습니다.

코드를 쓸 때 대괄호를 행별로 줄바꿈하여 적으면 표 형태가 눈에 잘 들어와 가독성이 높아집니다. 중첩 리스트는 성적표, 좌석 배치도, 게임판처럼 가로세로 구조를 갖춘 데이터를 다룰 때 유용하게 쓰입니다.

## 연습 01 리스트 안의 리스트를 len( ) 함수로 세면 어떻게 될까?

앞서 len( ) 함수를 사용해봤습니다. 그렇다면 len( ) 함수는 중첩 리스트의 요소 개수를 어떻게 셀까요? len( ) 함수는 바깥쪽 리스트를 기준으로 요소를 셉니다. 안쪽에 들어 있는 리스트가 아무리 길더라도, 바깥쪽에서 보면 그냥 하나의 요소로 취급합니다.

```python filename="04-25-nested_list_length.py"
nested_list = [[1, 2, 3], [4, 5], [6, 7, 8, 9]]
print(f"바깥쪽 리스트의 길이: {len(nested_list)}")
print(f"첫 번째 안쪽 리스트의 길이: {len(nested_list[0])}")
print(f"두 번째 안쪽 리스트의 길이: {len(nested_list[1])}")
print(f"세 번째 안쪽 리스트의 길이: {len(nested_list[2])}")
```

**실행 결과**

```text
바깥쪽 리스트의 길이: 3
첫 번째 안쪽 리스트의 길이: 3
두 번째 안쪽 리스트의 길이: 2
세 번째 안쪽 리스트의 길이: 4
```

[1, 2, 3]은 nested_list 입장에서 리스트이긴 하지만 인덱스가 0인 요소에 불과합니다. 그래서 len(nested_list)를 실행하면 3을 반환합니다. 만약 그 안의 리스트의 길이를 세고 싶다면 len(nested_list[0])처럼 안쪽 리스트를 먼저 꺼내 지정하면 됩니다.

> **바로 핵심 요약**
>
> - 리스트는 여러 값을 대괄호로 묶어 관리하는 자료형이며, 인덱싱과 슬라이싱으로 요소를 조회하고 더하기·곱하기 연산자로 연결 및 반복할 수 있습니다.
> - 리스트는 가변성을 가져 요소 수정(인덱싱·슬라이싱), 삭제(remove·pop), 추가(append·insert)를 할 수 있습니다.
> - len( ) 함수로 요소 개수를 세고 sort( )와 sorted( ) 함수로 정렬할 수 있습니다.
