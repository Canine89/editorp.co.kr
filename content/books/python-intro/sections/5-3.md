비교 연산자와 논리 연산자는 앞에서 살펴본 조건식에서 참과 거짓을 판단하는 데 사용하는 연산자입니다. 비교 연산자와 논리 연산자는 다소 단순한 내용처럼 느껴질 수 있습니다. 직관적으로 이해하기 쉬워서 ‘이걸 따로 시간을 내서 공부해야 하나?’라는 생각이 들 수도 있습니다. 하지만 프로그래밍에서 조건식은 프로그램의 흐름을 결정하는 중요한 요소입니다. 조금 지루하게 느껴지더라도 끝까지 잘 익혀두기 바랍니다.

> **미리 알아두세요!**
>
> - 비교 연산자는 두 값을 비교해 True 또는 False를 만듭니다.
> - 논리 연산자 and, or, not은 True와 False를 조합합니다.

## 비교 연산자 기초 연습하기

사실 비교 연산자는 이미 사용해봤습니다. 앞에서 if 문을 공부할 때 변수의 값과 25를 >= 연산자로 비교했었죠. 그때는 조건식에 자연스럽게 사용했기 때문에 따로 설명하지 않고 넘어갔습니다. 여기서는 어떤 비교 연산자가 있는지 하나씩 정리해봅시다. 비교 연산자는 두 값을 비교해 그 결과로 True 또는 False를 돌려주는 연산자입니다. 여기서 배울 기본 비교 연산자는 다음 6개입니다.

## 연습 01 여섯 가지 비교 연산자 사용해보기

외울 필요는 없습니다. 수학 시간에 배운 부등호와 거의 비슷하니까요. 다만 ‘같다’를 ==로, ‘다르다’를 !=로 표현한다는 것만 눈에 익혀두면 됩니다. 그러면 시험 점수를 저장한 score 변수로 6개 연산자를 모두 사용해봅시다.

```python filename="05-10-comparison_operators.py"
score = 85
print(score == 85)  # ➊ 같은지 비교
print(score != 85)  # ➋ 다른지 비교
print(score > 90)   # ➌ 큰지 비교
print(score < 90)   # ➍ 작은지 비교
print(score >= 85)  # ➎ 크거나 같은지 비교
print(score <= 84)  # ➏ 작거나 같은지 비교
```

**실행 결과**

```text
True
False
False
True
True
False
```

❶ score에 저장된 85와 85가 같은지 비교했습니다. 두 값이 같으므로 True가 출력되었습니다.

❷ 85와 85가 다른지 비교했습니다. 두 값이 다르지 않으므로 False가 출력되었습니다. ==와 반대로 동작한다고 생각하면 됩니다.

❸ 85가 90보다 큰지 비교했습니다. 크지 않으므로 False입니다.

❹ 85가 90보다 작은지 비교했습니다. 작으므로 True입니다.

❺ 85가 85보다 크거나 같은지 비교했습니다. 두 값이 같으므로 True입니다. >=는 '크다'와 '같다' 중 하나만 만족해도 True가 됩니다.

❻ 85가 84보다 작거나 같은지 비교했습니다. 작지도 않고 같지도 않으므로 False입니다.

> **NOTE**
>
> 초보자가 가장 많이 하는 실수가 '같다'를 비교할 때 ==가 아니라 =를 사용하는 겁니다. =는 변수에 값을 저장하는 대입

연산자이고, ==는 두 값이 같은지 확인하는 비교 연산자라는 것을 꼭 기억하세요. if score = 85:와 같이 쓰면 파이썬이 오류를 출력합니다.

name = "바로"

## 연습 03 비교 결과를 변수에 저장하기

마지막으로 하나만 더 확인해봅시다. 비교 연산자의 결과인 True, False도 그 자체가 하나의 값입니다. 따라서 바로 출력할 수도 있고 변수에 저장해 사용할 수도 있습니다.

score = 85

**실행 결과**

❶ score >= 80을 계산한 결과인 True를 is_pass 변수에 저장했습니다. 조건식의 결과가 True나 False로 평가된다는 말이 바로 이런 의미입니다.

❷ is_pass에 저장된 값을 출력했습니다. 변수에 True가 들어 있는 것을 확인할 수 있습니다.

정리하면 비교 연산자는 두 값을 비교해 True 또는 False라는 결과를 만들어내는 연산자입니다. if 문의 조건식 자리에 비교 연산자가 오는 이유도 이제 알 수 있습니다. 조건식이 True로 평가되면 해당 코드 블록이 실행되는 것이죠. 그런데 만약 ‘80점 이상이면서 90점 미만’처럼 조건이 2개라면 어떻게 해야 할까요? 이럴 때 사용하는 것이 바로 논리 연산자입니다.

## 논리 연산자 기초 연습하기

논리 연산자는 여러 조건을 조합하거나 조건의 결과를 반대로 바꿀 때 사용하는 연산자입니다. 우리말로 생각하면 아주 쉽습니다. 80점 이상이면서 90점 미만의 **‘~이면서’가 and**, 주말이거나 공휴일의 **‘~이거나’가 or**, 성인이 아니라면의 **‘~가 아니라면’이 not**입니다. 여기서 배울 파이썬의 논리 연산자는 이렇게 세 가지입니다.

- **and :** 양쪽 조건이 모두 True일 때 True
- **or :** 양쪽 조건 중 하나라도 True이면 True
- **not :** True는 False로, False는 True로 조건의 결과를 반대로 뒤집기

![](/books/python-intro/p229-155.webp)

## 연습 01 세 가지 논리 연산자 사용해보기

앞에서 사용한 score 변수를 그대로 사용해 세 가지 논리 연산자를 연습해봅시다.

```python filename="05-13-logical_operators.py"
score = 85
print(score >= 80 and score < 90)   # ➊ 두 조건 모두 만족하는지 확인
print(score >= 90 and score < 100)  # ➋ 한쪽 조건만 만족하는 경우
print(score >= 90 or score >= 80)   # ➌ 둘 중 하나라도 만족하는지 확인
print(not score >= 90)              # ➍ 비교 결과 뒤집기
```

**실행 결과**

```text
True
False
True
True
```

❶ score >= 80도 True이고 score < 90도 True입니다. and는 양쪽 조건이 모두 True일 때 True이므로 결과는 True입니다. '80점 이상이면서 90점 미만'이라는 조건을 코드로 옮긴 것이죠.

❷ score >= 90이 False입니다. and로 연결한 조건 중 한쪽이라도 False이면 전체 결과는 False가 됩니다.

❸ score >= 90은 False이지만 score >= 80은 True입니다. or는 둘 중 하나라도 True이면 결과가 True가 됩니다.

❹ score >= 90의 결과는 False입니다. 여기에 not을 사용하면 반대인 True가 됩니다. 즉 '90점 이상이 아니다'라는 뜻이 됩니다.

## 연습 02 논리 연산자를 if 문과 함께 사용하기

그러면 논리 연산자를 if 문과 함께 사용해봅시다. 장학금을 받으려면 성적뿐 아니라 출석률도 좋아야 하는 경우가 많죠. 이번에는 점수가 80점 이상이면서 출석률이 90% 이상인 학생을 장학금 대상자로 선정하는 프로그램을 만들어봅시다.

```python filename="05-14-scholarship_conditions.py"
score = 85
attendance = 95

if score >= 80 and attendance >= 90:  # ➊ 두 조건을 동시에 검사
  print("장학금 대상자입니다.")
else:
  print("아쉽지만 다음 기회에 도전해보세요.")
```

**실행 결과**

```text
장학금 대상자입니다.
```

❶ 조건식 자리에 and로 연결한 두 개의 비교식을 넣었습니다. score >= 80이 True이고 attendance >= 90도 True이므로 전체 조건식이 True가 되어 장학금 대상자로 선정되었습니다. 만약 attendance를 85로 바꾸면 and로 연결한 조건 중 한쪽이 False가 되므로 else 문의 코드 블록이 실행됩니다.

> **NOTE**
>
> 조건이 길어져서 읽기 어렵다면 (score >= 80) and (attendance >= 90)처럼 각각의 비교식을 괄호로 묶어도 됩니다.

동작은 같지만 어디까지가 하나의 조건인지 한눈에 알아보기 쉽습니다.

정리하면 비교 연산자는 두 값을 비교해 True 또는 False라는 결과를 만들고, 논리 연산자는 여러 조건을 조합하거나 결과를 반대로 바꿀 때 사용합니다. 이 두 가지를 활용하면 여러 조건이 결합된 복잡한 조건식도 표현할 수 있습니다. 이제 조건식을 만드는 도구를 모두 갖췄으니, 계속해서 다음 문법으로 나아가봅시다.

> **바로 핵심 요약**
>
> - 비교 연산자 ==, !=, >, <, >=, <=는 두 값을 비교해 True 또는 False를 반환하며, '같다'를 비교할 때는 =가 아니라 ==를 사용합니다.
> - 논리 연산자 and는 양쪽 조건이 모두 참일 때, or는 하나라도 참일 때 True가 되며, not은 참과 거짓을 반대로 바꿉니다.
> - 비교 결과는 그 자체가 하나의 값이므로 변수에 저장할 수 있고, if 문의 조건식에도 그대로 넣을 수 있습니다.
