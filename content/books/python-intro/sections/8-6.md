### 주관식 문제

08 다음은 부모 클래스의 메서드를 오버라이딩하면서 부모의 메서드도 함께 실행하는 코드입니다. 빈칸에 들어갈 코드를 쓰세요.

```python
class Animal:
  def introduce(self):
    print("저는 동물입니다.")
class Dog(Animal):
  def introduce(self):
    ____().introduce()
    print("저는 강아지입니다.")
choco = Dog()
choco.introduce()
```

**실행 결과**

```text
저는 동물입니다.
저는 강아지입니다.
```
