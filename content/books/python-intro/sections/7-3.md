함수를 제대로 사용하려면 반환이라는 고개를 넘어야 합니다. 처음에는 헷갈리기 쉬운 개념이므로 가래떡 공장 비유와 여러 연습을 통해 천천히 배워봅시다. 여기까지 잘 이해하면 함수의 기본 원리를 상당 부분 익힌 셈이니 집중해서 따라와보세요!

> **미리 알아두세요!**
>
> - 반환은 함수가 작업한 결과를 호출한 곳으로 돌려주는 것입니다.
> - 함수 안에 또 함수를 정의할 수 있고, 반환한 값이나 함수는 변수에 저장해 다시 사용할 수 있습 니다.

지금까지 함수는 어떻게 만드는지, 함수 헤더와 함수 본문은 어떻게 구성되어 있는지, 함수를 정의하고 호출하는 방법, 호출할 때마다 다른 값을 전달하기 위한 매개변수 등 함수의 기본적인 특징을 공부했습니다. 이번에는 앞서 예고한 반환을 알아볼 차례입니다.

**반환**은 처음 배울 때는 ‘별거 아닌 개념이구나’ 싶다가도 여러 함수가 서로 값을 주고받기 시작하면 조금 헷갈릴 수 있습니다. 따라서 지금부터 반환이 무엇인지 차근차근 알아보겠습니다.

## 반환이 뭔가요?

반환이란 함수가 실행된 결과로 어떤 값을 호출한 곳에 돌려주는 것입니다. 주변의 기계를 떠올려보며 반환을 이해해봅시다. 예를 들어 밥솥에 쌀과 물을 넣고 취사 버튼을 누르면 완성된 밥이 나옵니다. 이를 함수의 반환에 빗대어 정리하면 다음과 같습니다.

- **밥솥의 내솥(재료 넣는 곳) :** 매개변수
- **쌀과 물 :** 함수를 호출할 때 전달하는 인수
- **밥 짓는 과정 :** 함수 본문의 코드 블록 실행
- **완성된 밥 :** 함수가 반환한 값

![](/books/python-intro/p301-195.webp)

함수는 return 키워드를 사용해 값을 반환할 수 있습니다. 반환하는 대상은 숫자나 문자열 같은 값이 될 수도 있고, 또 리스트나 튜플, 다른 함수가 될 수도 있습니다. 또한 작업을 마친 뒤 딱히 돌려줄 값이 없을 수도 있습니다. 이때는 return을 작성하지 않아도 되며, 함수의 실행이 끝나면 파이썬은 ‘값이 없음’을 뜻하는 None을 반환합니다.

![](/books/python-intro/p301-196.webp)

### 함수는 여러 값을 반환할 수 없습니다

파이썬 함수가 반환하는 값은 언제나 하나입니다. 앞에서 살펴봤듯이 return 문을 작성하지 않은 함수도 None이라는 값 하나를 반환합니다. 그런데 여기서 많은 입문자가 헷갈립니다. **return 뒤에 여러 값을 쉼표로 나열해도 오류가 발생하지 않기 때문입니다.** 그래서 ‘함수가 여러 값을 반환할 수도 있는 것 아닌가?’라고 생각하기 쉽습니다. 하지만 실제로 여러 값을 각각 반환하는 것은 아닙니다. 파이썬은 쉼표로 나열된 값들을 튜플이라는 하나의 묶음으로 만들어 반환합니다. 즉, 여러 값이 들어 있는 것처럼 보여도 함수가 반환하는 값은 튜플 하나입니다.

말로만 들으면 와닿지 않으니 직접 확인해봅시다. 다음은 리스트 [3, 1, 4, 1, 5, 9, 2, 6]을 받아 최솟값과 최댓값을 튜플로 반환하는 함수입니다.

```python filename="07-01-get_min_max_tuple.py"
def get_min_max(numbers):
  return min(numbers), max(numbers)

result = get_min_max([3, 1, 4, 1, 5, 9, 2, 6])
print(result)
print(type(result))
```

**실행 결과**

```text
(1, 9)
<class 'tuple'>
```

return min(numbers), max(numbers)를 보면 값을 두 개 반환하는 것처럼 보입니다. 하지만 실행 결과를 보면 1과 9가 따로 나온 게 아니라 (1, 9)라는 튜플 하나로 나옵니다. type(result)의 결과가 tuple인 것을 통해서도 확인할 수 있습니다. 즉 쉼표로 나열한 두 값이 튜플 하나로 묶여 반환된 것입니다.

그렇다면 다음처럼 값을 두 개의 변수로 나눠 받는 경우는 어떻게 된 걸까요?

```python filename="07-02-unpack_min_max.py"
def get_min_max(numbers):
  return min(numbers), max(numbers)

min_val, max_val = get_min_max([3, 1, 4, 1, 5, 9, 2, 6])
print(min_val)
print(max_val)
```

**실행 결과**

```text
1
9
```

이 코드를 보면 '역시 값을 두 개 반환하는 거네!'라고 생각하기 쉽습니다. 하지만 자세히 보면 함수가 반환한 (1, 9)라는 튜플을 두 변수로 나누어 저장한 것입니다. 파이썬에서는 튜플에 담긴 값을 여러 변수에 나눠 담을 수 있습니다. 따라서 (1, 9)에서 1은 min_val에, 9는 max_val에 저장됩니다. 이것은 다음과 같은 원리입니다.

```python filename="07-03-tuple_unpacking.py"
a, b = 1, 2   # (1, 2) 튜플이 a, b로 나뉘어 담김
```

**이처럼 튜플에 담긴 값을 여러 변수로 풀어 담는 것을 언패킹**(unpacking)**이라고 부릅니다.** 정리하면 함수는 언제나 값 하나를 반환하며 return 뒤에 여러 값을 쉼표로 나열하면 하나의 튜플로 묶여 반환되고, 이를 받는 쪽에서 필요에 따라 여러 변수로 풀어 사용할 수 있습니다. 처음에는 말장난처럼 느껴질 수 있지만 이 구조를 이해하면 함수의 반환 개념이 훨씬 명확해집니다.

![](/books/python-intro/p303-197.webp)

## 헷갈리는 반환

가끔 다음과 같은 코드를 입력하고 실행하면서 '함수를 실행해서 뭔가 출력됐으니 값을 반환한 것 아닌가'라고 생각하는 경우가 있습니다. 앞에서 작성한 코드를 다시 봅시다.

```python
>>> def greet(name):
...     print(f"안녕하세요! {name} 님!")
>>> greet("요즘")
```

![](/books/python-intro/p303-198.webp)

**실행 결과**

```text
안녕하세요! 요즘 님!
```

**greet( ) 함수를 실행했을 때 인사말이 출력된 것을 보고 '인사말을 반환했다'라고 오해할 수 있습니다.** 하지만 반환은 return으로 값을 돌려주는 것으로, 화면에 무언가를 출력하는 것과는 전혀 다른 개념입니다. print( )는 값을 화면에 보여주고, return은 함수의 실행 결과를 호출한 곳으로 돌려줍니다. 따라서 화면에 무언가 출력되었다고 해서 그 값을 반환한 것은 아닙니다. 인사말을 반환하도록 바꾸려면 다음과 같이 return을 사용해야 합니다.

```python
>>> def greet(name):
...     return "안녕하세요! " + name + " 님!"
>>> print(greet("바로"))
```

**실행 결과**

```text
안녕하세요! 바로 님!
```

이제 조금 더 구체적인 예를 통해 함수와 반환을 이해해보겠습니다. 쉽게 상상할 수 있도록 가래떡 공장의 기계를 함수에 비유하며 설명하고 중간중간 코드를 작성하고 실행해보면서 함수의 반환 개념을 이해해봅시다.

## 가래떡 공장으로 이해하는 함수와 반환

예를 들어 여러분이 가래떡을 만드는 공장을 운영한다면 다음과 같은 기계가 필요할 겁니다.

![](/books/python-intro/p304-199.webp)

1. **쌀을 깨끗하게 씻는 기계 :** 쌀과 물을 넣으면 쌀을 깨끗하게 씻어 내보낸다. 2. **쌀을 찌는 기계 :** 깨끗한 쌀을 넣으면 이것을 쪄서 밥으로 만들어 내보낸다. 3. **밥을 치대는 기계 :** 밥을 넣으면 치대서 반죽으로 만들어 내보낸다. 4. **가래떡 형태로 만드는 기계 :** 반죽을 넣으면 가래떡 형태로 만들어 내보낸다.

각 기계에는 넣어야 할 재료가 정해져 있습니다. **기계 전체를 함수라고 보면 기계가 재료를 받아들이는 투입구가 매개변수이고, 실제로 투입하는 재료가 인수입니다. 기계가 작업을 마치고 내보낸 결과물이 반환값입니다.** 이제 첫 번째 단계인 '쌀을 깨끗하게 씻는 기계'를 통해 이러한 과정이 어떻게 이루어지는지 살펴봅시다.

![](/books/python-intro/p304-200.webp)

쌀을 깨끗하게 씻는 기계에는 ❶ 쌀과 물을 받는 투입구가 있습니다. 이것이 매개변수입니다. ❷ 투입구에 실제로 넣는 쌀과 물은 함수에 전달하는 인수에 해당합니다. ❸ 기계가 작업을 마친 뒤 내보내는 깨끗한 쌀은 함수의 반환값에 해당합니다. 이를 함수로 표현하면 다음과 같이 코드를 작성할 수 있습니다.

```python filename="07-04-define_wash_rice.py"
# 깨끗하게 쌀을 씻는 기계 정의
def wash_rice(rice, water):
  print(f"{rice}을 {water}로 씻고 있습니다.")
  return "깨끗한 쌀"
```

이렇게 함수를 정의했다면 실제로 기계를 가동하듯 다음과 같이 함수를 호출해봅시다.

```python filename="07-05-call_wash_rice.py"
def wash_rice(rice, water):
    print(f"{rice}을 {water}로 씻고 있습니다.")
    return "깨끗한 쌀"
# 깨끗하게 쌀을 씻는 기계 호출
result1 = wash_rice("씻지 않은 쌀", "깨끗한 물")
```

**실행 결과**

```text
씻지 않은 쌀을 깨끗한 물로 씻고 있습니다.
```

실행 결과에 보이는 ‘씻지 않은 쌀을 깨끗한 물로 씻고 있습니다.’는 wash_rice("씻지 않은 쌀", "깨끗한 물")을 호출했을 때 함수 본문의 print( ) 함수가 출력한 내용입니다. 반면 함수가 return으로 돌려준 반환값은 "깨끗한 쌀"이라는 문자열이며, 이 값은 result1 변수에 저장됩니다.

이처럼 함수는 함수 본문에서 특정 작업을 수행하고, 필요한 경우 return으로 결과를 돌려줍니다. 반환받은 값은 변수에 저장하거나 다른 작업에 다시 사용할 수도 있습니다. 주변에서 쉽게 볼 수 있는 기계를 떠올리면 이러한 함수의 흐름을 이해하는 데 도움이 됩니다. 비유를 통해 함수와 반환을 이해했으니 이제 좀 더 실용적인 실습 예제를 통해 함수와 반환을 연습해봅시다.

## 연습 02 점수를 평가하고 등급을 반환하는 함수

```python filename="07-07-evaluate_score.py"
def evaluate_score(score):

  elif score >= 80:
    grade = "B"
  elif score >= 70:

  else:

baro_math = evaluate_score(92)
```

## 연습 03 할인 가격을 계산해주는 함수

이번에는 함수가 계산 결과를 반환하고, 그 반환값을 다시 다른 함수의 입력으로 사용하는 예제를 살펴보겠습니다. 여러 함수를 연결하여 사용하는 방법을 코드로 확인해봅시다.

```python filename="07-09-calculate_discount.py"
def apply_discount(price, discount_rate):
  discount_amount = price * discount_rate
  return discount_amount

def calculate_final_price(price, discount_amount):
  final_price = price - discount_amount
  return final_price

# 바로가 구매하려는 책 가격
book_price = 20000

# 20% 할인 적용
discount = apply_discount(book_price, 0.2)
print(f"할인 금액: {discount}원")

# 최종 가격 계산
final = calculate_final_price(book_price, discount)
print(f"최종 가격: {final}원")
```

**실행 결과**

```text
할인 금액: 4000.0원
최종 가격: 16000.0원
```

첫 번째 함수 apply_discount( )는 원래 가격과 할인율을 받아 할인 금액을 계산하여 반환합니다. 두 번째 함수 calculate_final_price( )는 원래 가격과 할인 금액을 받아 최종 가격을 계산하여 반환합니다.

## 함수가 반환한 값을 다시 함수에 사용하기

함수의 반환값을 다른 함수의 인수로 바로 전달할 수도 있습니다. 예를 들어 쌀을 씻는 함수와 밥을 짓는 함수의 관계를 생각해봅시다. 쌀을 씻는 함수의 반환값인 "깨끗한 쌀"을 그대로 밥을 짓는 함수의 인수로 전달하면 자연스럽겠죠. 이처럼 함수의 반환값을 다른 함수의 인수로 사용할 수 있으므로 다음과 같이 코드를 연결하여 작성할 수 있습니다.

![](/books/python-intro/p309-203.webp)

```python filename="07-10-chain_rice_functions.py"
def wash_rice(rice):
  print(f"{rice}을 깨끗하게 씻고 있습니다...")
  return "깨끗한 쌀"

def steam_rice(rice):
  print(f"{rice}을 찌고 있습니다...")
  return "밥"

# 방법 1: 중간 변수 사용
step1 = wash_rice("씻지 않은 쌀")
step2 = steam_rice(step1)
print(f"최종 결과: {step2}\n")

# 방법 2: 함수를 직접 연결
result = steam_rice(wash_rice("씻지 않은 쌀"))
print(f"최종 결과: {result}")
```


**실행 결과**

## 함수 안에 함수를 정의하기

지금까지 만든 함수는 모두 다른 함수의 바깥에 정의했습니다. 그런데 파이썬에서는 함수 안에 또 다른 함수를 정의할 수도 있습니다. 이 책에서는 이렇게 함수 안에 정의한 함수를 안쪽 함수, 그 함수를 감싸고 있는 함수를 바깥 함수라고 부르겠습니다. 먼저 가장 단순한 형태부터 살펴봅시다.

```python filename="07-11-inner_function.py"
def outer():
  print("바깥 함수 시작")

  def inner():          # ➊ 함수 안에 정의한 함수
    print("안쪽 함수 실행")

  inner()               # ➋ 바깥 함수 안에서 호출
  print("바깥 함수 끝")

outer()
```

**실행 결과**

```text
바깥함수시작
안쪽함수실행
바깥함수끝
```

❶ def를 한 번 더 사용해서 outer( ) 안에 inner( ) 함수를 정의했습니다. 들여쓰기가 한 단계 더 들어간 것 외에는 지금까지 만든 함수와 같은 모습입니다.

❷ 안쪽 함수도 정의만 해서는 함수 본문이 실행되지 않습니다. inner( )라고 호출해야 그때 함수 본문이 실행됩니다. 실행 결과를 보면 바깥 함수가 시작하고 끝나는 사이에 안쪽 함수가 실행된 것을 알 수 있습니다.

안쪽 함수에는 눈여겨볼 특징이 두 가지 있습니다. 하나는 자신을 감싸는 바깥 함수가 가진 값을 그대로 가져다 쓸 수 있다는 것이고, 다른 하나는 일반적으로 바깥 함수 밖에서는 안쪽 함수의 이름으로 직접 호출할 수 없다는 것입니다. 다음 코드로 두 가지를 한 번에 확인해봅시다.

```python filename="07-12-inner_function_value.py"
def make_message(name):
  def build():                 # ➊ 바깥 함수가 받은 name을 사용
    return f"{name}님, 안녕하세요!"

  return build()               # ➋ 안쪽 함수를 실행한 결과를 반환

print(make_message("바로"))
print(build())                 # ➌ 바깥에서 안쪽 함수 호출 시도
```

**실행 결과**

```text
바로님, 안녕하세요!
NameError: name 'build' is not defined
```

❶ 안쪽 함수 build( )에는 name이라는 매개변수나 지역 변수가 따로 없습니다. 그런데도 바깥 함수 make_message( )가 받은 name을 그대로 가져다 씁니다. 이처럼 안쪽 함수는 자신을 감싸는 바깥 함수의 값을 참조할 수 있습니다.

❷ 바깥 함수는 안쪽 함수 build( )를 실행한 결과를 반환합니다. 따라서 "바로님, 안녕하세요!"가 출력됩니다.

❸ 반대로 make_message( ) 바깥에서 build( )를 직접 호출하면 해당 이름을 찾을 수 없다는 오류가 납니다. 안쪽 함수인 build( )는 바깥 함수 make_message( )의 안에서만 정의되기 때문이죠. 이 내용은 **07.5 함수와 스코프**에서 더 자세히 다룹니다.

여기까지만 보면 ‘굳이 함수 안에 함수를 왜 만들까’라는 생각이 들 수 있습니다. 그런데 ❷에서 안쪽 함수를 실행한 결과 대신 안쪽 함수 자체를 반환하면 재미있는 일이 벌어집니다. 바로 다음에서 확인해봅시다.

## 함수 자체를 반환할 수 있을까?

여기서 조금 낯선 이야기를 해보겠습니다. 앞에서 함수는 "밥"이나 12 같은 숫자나 문자열뿐만 아니라 함수 자체도 반환할 수 있다고 했습니다. 만약 여러분이 지금 당장 어떤 계산을 실행하려는 것이 아니라, '특정 방식으로 동작하는 함수를 하나 만들어두고 싶다'고 생각한다면 어떨까요? 이를테면 어떤 숫자를 넣어도 3을 곱해주는 함수나, 어떤 숫자를 넣어도 5를 곱해주는 함수를 만들고 싶을 수 있습니다. 두 함수는 대부분 같은 구조를 가지고 있지만 곱하는 숫자만 다릅니다. 이런 경우에는 일부 조건만 다르게 적용한 함수를 만들어주는 함수를 작성할 수 있습니다.

> **NOTE**
>
> 실생활에 비유한다면 용도에 맞는 기계를 만들어주는 기계를 생각해봅시다. 예를 들어 "보리"라고 적힌 정보를 넣으면

보리밥을 짓는 밥솥을 만들고, "쌀"이라고 적힌 정보를 넣으면 쌀밥을 짓는 밥솥을 만들어주는 기계와 비슷합니다.

일단 코드부터 작성해 실행해봅시다.

```python filename="07-13-make_multiplier.py"
def make_multiplier(n):
  def multiplier(x):
    return x * n
  return multiplier

times3 = make_multiplier(3)
times5 = make_multiplier(5)

print(times3(10))
print(times5(10))
```

**실행 결과**

```text
30
50
```

함수의 구조를 자세히 보면 make_multiplier( )의 안에서 다시 multiplier( ) 함수를 정의하고 있습니다. 그리고 반환하는 값은 어떤 계산 결과가 아니라 multiplier라는 함수의 객체입니다. 아직 객체가 무엇인지 이해가 안 될 겁니다. 객체는 다음 장에서 배울 내용이니 지금은 ‘함수 자체가 반환된다’ 정도로 이해하면 됩니다. 결과적으로 make_multiplier( ) 함수를 실행하면 전달한 인수에 따라 특정 값을 곱해주는 multiplier( ) 함수를 만들 수 있습니다. 다소 복잡하게 느껴질 수 있지만 차근차근 구조를 살펴보면 그리 어렵지 않을 겁니다.

### 함수를 반환하는 함수의 실행 과정 살펴보기

예를 들어 make_multiplier(3)을 실행하면 3을 곱해주는 함수가 만들어지는 과정을 생각해봅시다. 다음을 실행하면 어떤 일이 일어날까요?

```python
times3 = make_multiplier(3)
```

make_multiplier( ) 함수의 구조를 떠올려보면 결국은 x * 3을 계산해 반환하는 multiplier( ) 함수를 반환한다는 걸 알 수 있습니다. 그 과정을 그림으로 나타내면 다음과 같습니다.

❷ 인수 3이 함수 make_multiplier( ) 내부에 있는 매개변수 n으로 전달됩니다.

❸ 매개변수 n에 전달된 값 3은 안쪽 함수 multiplier( )의 계산(x * n)에 사용됩니다.

❹ return multiplier가 실행되면 multiplier( )를 실행한 결과가 아니라 3을 곱하는 함수 multiplier( )를 반환합니다.

## 연습 01 인사말을 만들어주는 함수를 반환하는 함수

앞에서 함수의 기초를 공부할 때 인사말을 만들어주는 함수를 만들었습니다. 이번에는 인사말의 형식을 지정하면 그 형식에 맞는 인사 함수를 만들어주는 함수를 작성해봅시다. 예를 들어 누군가에게 인사한다는 목적은 같지만 인사말은 다음처럼 달라질 수 있습니다.

- "반갑습니다! **바로님!**"
- "안녕~ **요즘아**!"

```python filename="07-14-greeting_factory.py"
def make_greeting(greeting_word):
  def greet(name):
    return f"{greeting_word} {name}!"
  return greet

formal_greeter = make_greeting("반갑습니다!")
casual_greeter = make_greeting("안녕~")

print(formal_greeter("바로님"))
print(casual_greeter("요즘아"))
```

**실행 결과**

```text
반갑습니다! 바로님!
안녕~ 요즘아!
```

make_greeting( ) 함수는 인사말을 매개변수 greeting_word로 받아 **그 인사말을 사용해 누군가에게 인사하는 안쪽 함수인 greet( )를 반환합니다.** 이렇게 반환된 함수는 각각 **formal_greeter, casual_greeter라는 변수에 저장하여 사용할 수 있습니다.** 결국 formal_greeter 변수에 저장한 함수는 "반갑습니다!"라는 인사말을 사용하고, casual_greeter 변수에 저장한 함수는 "안녕~"이라는 인사말을 사용하는 함수가 됩니다.

## 연습 02 계산기를 만들어주는 함수

이번에는 연산 종류에 따라 다른 계산을 수행하는 계산기 함수를 만들어보겠습니다. make_calculator( ) 함수는 연산자를 받아 해당 연산을 수행하는 함수를 반환합니다. 이렇게 하면 하나의 함수에서 덧셈, 뺄셈, 곱셈, 나눗셈을 수행하는 여러 함수를 만들 수 있습니다. 다음 코드로 확인해 봅시다.

```python filename="07-15-calculator_factory.py"
def make_calculator(operation):
  def calculate(a, b):
    if operation == "add":
      return a + b
    elif operation == "subtract":
      return a - b
    elif operation == "multiply":
      return a * b
    elif operation == "divide":
      return a / b
  return calculate

add_func = make_calculator("add")
multiply_func = make_calculator("multiply")

print(add_func(15, 5))
print(multiply_func(15, 5))
print(add_func(100, 25))
```

**실행 결과**

```text
20
75
125
```

make_calculator("add")를 호출하면 덧셈을 수행하는 함수가 반환됩니다. 따라서 add_func(15, 5)는 15 + 5 = 20을 계산해 반환하고, multiply_func(15, 5)는 15 × 5 = 75를 계산해 반환합니다. 한 번 만든 함수는 계속해서 재사용할 수 있으므로 add_func(100, 25)처럼 다른 숫자를 전달해 계산할 수도 있습니다.

> **바로 핵심 요약**
>
> - 반환은 함수가 작업한 결과를 호출한 곳으로 돌려주는 것입니다. 값을 명시적으로 반환할 때는 return을 사용하며, 화면에 값을 출력하는 것과 반환하는 것은 서로 다른 개념입니다.
> - 함수가 돌려주는 값은 언제나 하나이며, return 뒤에 값을 여러 개 나열하면 튜플 하나로 묶여 반환됩니다.
> - 반환값은 변수에 저장하거나 다른 함수의 인수로 전달할 수 있으며, 함수 자체를 반환할 수도 있습니다. 반환된 안쪽 함수는 자신을 정의할 때 참조하던 바깥 함수의 값을 기억할 수도 있습니다.
