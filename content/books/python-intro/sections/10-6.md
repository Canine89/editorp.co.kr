**입력과 출력**에서는 사용자가 입력한 메모를 파일에 저장하고 다시 읽는 프로그램을 만들었습니다. 이번에는 저장과 보기를 메뉴로 나누어서 새로 생기는 오류 상황에도 대비해보겠습니다. 지금까지 배운 함수, 반복문, 파일 입출력, 예외 처리를 하나로 묶어 메모장 프로그램을 더 안전하게 개선해봅시다. 앞에서 만든 프로그램에 기능을 하나씩 추가하는 과정이므로 천천히 따라와보세요!

> **미리 알아두세요!**
>
> - 잘못된 메뉴 입력과 없는 파일을 각각 알맞은 예외로 처리합니다.
> - 오류가 발생해도 프로그램을 종료하지 않고 다시 메뉴를 보여줍니다.
> - 기존 메모를 지우지 않고 새로운 메모를 이어서 저장합니다.

**입력과 출력**에서 만든 메모장 프로그램은 "끝"을 입력할 때까지 여러 줄의 메모를 받은 뒤, memo.txt 파일에 저장하고 전체 내용을 출력했습니다. 이번에는 프로그램을 메뉴 방식으로 바꾸어 한 번에 한 줄씩 메모를 저장하거나, 원할 때 저장된 메모를 확인할 수 있도록 만들겠습니다. 또한 다음과 같은 오류 상황도 처리해봅시다.

- 새로 추가한 숫자 메뉴에 문자를 입력한 경우
- 새로 추가한 보기 메뉴를 저장 전에 선택한 경우
- 아무 내용도 입력하지 않고 저장하려는 경우
- 프로그램을 다시 실행했을 때 기존 메모가 지워지는 경우

완성할 프로그램의 흐름은 다음과 같습니다.

1. 메모 저장, 메모 보기, 종료 메뉴를 출력합니다. 2. 사용자가 입력한 메뉴 번호를 정수로 바꿉니다. 3. 선택한 메뉴에 따라 메모를 저장하거나 저장된 메모를 보여줍니다. 4. 잘못된 입력이나 파일 관련 오류가 발생하면 알맞은 안내를 출력합니다. 5. 종료 메뉴를 선택하기 전까지 메뉴를 반복해서 보여줍니다.

## 메뉴 입력 오류 처리하기

먼저 숫자로 메뉴를 선택하는 코드를 작성해봅시다. 사용자가 "일"과 같이 숫자로 바꿀 수 없는 값을 입력하면 ValueError를 처리하고 다시 메뉴를 보여주도록 만들겠습니다. 코드는 비주얼 스튜디오 코드에서 .py 파일 하나를 만든 뒤, 이후 단계의 내용을 같은 파일에 계속 추가해 작성하는 것을 권합니다.

![](/books/python-intro/p487-297.webp)

> **NOTE**
>
> 실습에서 만든 memo.txt 파일이 같은 폴더에 남아 있다면 실행 결과가 책과 다를 수 있습니다. 새 폴더에서 실

습하거나 기존 memo.txt 파일을 삭제한 뒤 시작하세요.

![](/books/python-intro/p487-298.webp)

```python filename="10-19-memo_app.py"
while True:
  print("\n메모장 프로그램")
  print("1. 메모 저장")
  print("2. 메모 보기")
  print("3. 종료")
  try:
    menu = int(input("메뉴를 선택하세요: "))  # ➊ 메뉴를 정수로 변환
  except ValueError:
    print("메뉴는 숫자로 입력하세요.")         # ➋ 잘못된 입력 처리
    continue
  if menu == 3:
    print("메모장을 종료합니다.")
    break
  else:
    print("아직 준비 중인 메뉴입니다.")
```

❶ input( ) 함수로 입력받은 문자열을 int( ) 함수로 정수로 바꿉니다. 숫자 형태가 아닌 값을 입력하면 ValueError가 발생합니다.

❷ ValueError가 발생하면 안내 메시지를 출력한 뒤 continue 문을 실행합니다. continue 문이 실행되면 현재 반복의 나머지 코드를 건너뛰고 while 문의 처음으로 돌아가므로 프로그램이 종료되지 않고 메뉴를 다시 보여줄 수 있습니다.

## 메모 저장 함수 만들기

이번에는 메모 저장 기능을 함수로 만들어봅시다. 아무 내용도 입력하지 않으면 ValueError를 직접 발생시키고, 내용이 있다면 memo.txt 파일의 기존 내용 뒤에 새 메모를 추가하도록 만들겠습니다. **이 함수는 앞에서 만든 while 반복문 위에 작성하세요.**

## 예외 처리를 적용한 메모장 완성하기

까지 작성한 코드를 실행하면 메뉴에서 1이나 2를 선택해도 "아직 준비 중인 메뉴입니다."라는 메시지만 나옵니다. 함수는 만들어두었지만 아직 메뉴와 연결하지 않았기 때문이죠. 마지막 단계에서는 에서 임시로 작성해둔 else 부분을 실제 기능으로 바꿉니다. 하이라이트로 표시한 부분을 새로 추가하거나 고치세요. 그러면 다음 기능이 동작하는 메모장이 됩니다.

- menu == 1이면 save_memo( )를 호출하고, 빈 메모 때문에 발생하는 ValueError를 처리합니다.
- menu == 2이면 show_memos( )를 호출하고, 파일이 없을 때 발생하는 FileNotFoundError를 처리합니다.
- 기존 if menu == 3은 elif menu == 3으로 바꿉니다.
- 마지막 else에서는 1~3 이외의 숫자를 입력했을 때 안내 메시지를 출력합니다.

이렇게 오류가 예상되는 코드마다 try~except 문을 가까이 배치하면, 여러 오류를 하나의 큰 try로 묶지 않고 필요한 위치에서 해당 예외만 구체적으로 처리할 수 있습니다. **아마 지금까지 작성한 코드 중 가장 복잡한 편일 겁니다. 특히 파이썬에서는 들여쓰기가 코드 구조를 결정하므로 들여쓰기 위치를 주의해야 합니다. 하이라이트로 표시한 새 코드와 수정한 부분을 하나씩 확인하며 천천히 작성해보세요.**

```python filename="10-19-memo_app.py"
def save_memo():
  memo = input("메모를 입력하세요: ")
  if not memo.strip():
    raise ValueError("빈 메모는 저장할 수 없습니다.")    # ➊ 빈 메모 예외 발생
  with open("memo.txt", "a", encoding="utf-8") as memo_file:
    memo_file.write(memo + "\n")                      # ➋ 메모 이어 쓰기
  print("메모를 저장했습니다.")

def show_memos():
  with open("memo.txt", "r", encoding="utf-8") as memo_file:
    all_memos = memo_file.read()                      # ➌ 전체 메모 읽기
  print("저장된 메모 목록")
  print(all_memos)

while True:
  print("\n메모장 프로그램")
  print("1. 메모 저장")
  print("2. 메모 보기")
  print("3. 종료")
  try:
    menu = int(input("메뉴를 선택하세요: "))            # ➍ 메뉴 입력
  except ValueError:
    print("메뉴는 숫자로 입력하세요.")                   # ➎ 메뉴 입력 오류 처리
    continue
  if menu == 1:
    try:
      save_memo()
    except ValueError as error:
      print(f"입력 오류: {error}")                         # ➏ 빈 메모 처리
  elif menu == 2:
    try:
      show_memos()
    except FileNotFoundError:
      print("저장된 메모가 없습니다.")                     # ➐ 파일 오류 처리
  elif menu == 3:
    print("메모장을 종료합니다.")
    break
  else:
    print("1부터 3 사이의 메뉴를 선택하세요.")
```

이 프로그램에서는 오류가 예상되는 코드와 가까운 곳에 try~except 문을 배치했습니다. 메뉴 변환, 빈 메모, 없는 파일에서 발생하는 예외를 하나의 큰 try 문으로 묶지 않고 각각 처리하므로 어느 기능에서 어떤 예외를 예상했는지 코드만 보고도 이해하기 쉽습니다. 예외를 처리한 뒤에도 while 문은 계속되므로 사용자는 프로그램이 종료되지 않은 상태에서 다시 메뉴를 선택할 수 있습니다.
