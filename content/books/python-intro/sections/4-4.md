**딕셔너리**(Dictionary)**는 사전처럼 단어(키)로 뜻(값)을 찾는 자료형입니다.** 순번(인덱스) 대신 이름표로 데이터를 관리하므로 코드가 훨씬 읽기 쉬워집니다. 실무에서도 자주 쓰이는 자료형이니 예제를 하나씩 실행하며 확실히 익혀봅시다.

> **미리 알아두세요!**
>
> - 딕셔너리는 키와 값을 쌍으로 저장하는 사전식 자료형입니다.
> - 인덱스 대신 키로 값을 찾습니다.

딕셔너리는 여러 값을 묶어 관리한다는 점에서 리스트와 비슷하지만 키 (key)와 값(value)이라는 개념을 더해 사전과 같은 특징을 갖습니다. 사전에서 어떤 단어를 찾으면 해당 단어의 뜻이 풀이되어 있는 것처럼 딕셔너리의 key는 사전의 단어에, value는 단어의 뜻에 대응합니다.

>
> 일상에서 직관적으로 비유하기에 사전만 한 개념이 없어 사전을 예로 들어 설명

합니다.

## 딕셔너리 기초 연습하기

데이터에 숫자 대신 의미 있는 이름표(키)를 붙여 관리하는 딕셔너리는 코드의 가독성을 높여줍니다. 기본적인 생성과 조회부터 값 수정·추가, 그리고 오류 없이 안전하게 값을 꺼내는 방법까지 다양한 연습을 통해 기초를 익혀봅시다.

## 연습 01 딕셔너리 만들고 값 꺼내기

딕셔너리는 중괄호 안에 key: value 형태로 작성합니다. 기본 구조는 다음과 같습니다.

```python filename="04-32-dictionary_access.py"
student = {
    "name": "김철수",
    "age": 20,
    "major": "컴퓨터공학"
}

print(f"딕셔너리: {student}")
print(f"이름: {student['name']}")
print(f"나이: {student['age']}")
print(f"전공: {student['major']}")
```

**실행 결과**

```text
딕셔너리: {'name': '김철수', 'age': 20, 'major': '컴퓨터공학'}
이름: 김철수
나이: 20
전공: 컴퓨터공학
```

코드를 보면 중괄호 안에 "name": "김철수"와 같이 key: value 쌍을 쉼표로 구분하여 나열합니다. 이후 저장된 값인 value를 찾을 때는 "name", "age", "major"와 같이 매핑된 key를 사용합니다.

- **student['name'] :** student 딕셔너리에서 key인 'name'에 해당하는 값인 '김철수'를 찾습니다.
- **student['age'] :** student 딕셔너리에서 key인 'age'에 해당하는 값인 '20'을 찾습니다.
- **student['major'] :** student 딕셔너리에서 key인 'major'에 해당하는 값인 '컴퓨터공학'을 찾습니다.

딕셔너리의 key에는 문자열뿐 아니라 숫자나 튜플처럼 값이 변하지 않는 자료형도 쓸 수 있습니다. 반면 리스트처럼 값이 변할 수 있는 자료형은 키로 사용할 수 없습니다. 리스트가 데이터에 0, 1, 2 같은 번호표(인덱스)를 붙여 순서대로 관리한다면, 딕셔너리는 데이터에 "name", "age" 같은 이름표(key)를 붙여 관리하는 방식이라고 생각할 수 있습니다.

리스트에서는 student[0]처럼 인덱스 숫자로 접근하기 때문에 코드를 자세히 보기 전에는 어떤 데이터인지 파악하기 어렵지만, 딕셔너리는 "name"처럼 명확한 의미의 문자열을 사용합니다. 이처럼 이름표를 붙여두면 수많은 데이터 속에서도 헷갈리지 않고 원하는 값을 직관적으로 찾아낼 수 있어, 실수를 줄이고 코드의 가독성을 대폭 높일 수 있습니다.

![](/books/python-intro/p184-134.webp)

> **NOTE**
>
> 본문에서는 학습의 편의를 위해 key는 ‘키’, value는 ‘값’으로 번역하여 설명하겠습니다.

> **NOTE**
>
> 파이썬 공식 문서에서는 키로 쓸 수 있는 조건을 ‘해시 가능(hashable)하다’고 표현합니다. 그래서 리스트를 키로 쓰면

TypeError: unhashable type: ‘list’라는 오류가 발생합니다. 다만 입문하는 단계에서는 ‘값이 변하지 않는 자료형만 키가 된다’고 기억해도 큰 문제는 없습니다.

## 연습 02 딕셔너리 값 수정하기

딕셔너리는 리스트와 마찬가지로 가변 자료형이므로 내부 값을 변경할 수 있습니다. 리스트에서 인덱스를 통해 값을 수정했다면 딕셔너리에서는 키를 이용해 값을 수정할 수 있습니다. 다음 코드에서 student["age"]를 지정해 나이에 들어갈 값을 변경해봅시다.

```python filename="04-33-dictionary_update.py"
student = {"name": "김철수", "age": 20}

# 기존 값 변경
student["age"] = 21
print(f"나이 변경 후: {student}")
```

**실행 결과**

```text
나이 변경 후: {'name': '김철수', 'age': 21}
```

student["age"] = 21과 같이 대입하면, 기존 키 "age"에 매핑되어 있던 값이 20에서 21로 수정됩니다. 이해하기 어려운 코드는 아니므로 바로 다음으로 넘어가겠습니다.

## 연습 03 딕셔너리에 값 추가하기

새로운 값을 추가하는 것도 마찬가지입니다. 기존 딕셔너리에 존재하지 않는 새로운 키를 지정하고 값을 대입하면 새로운 key-value 쌍이 추가됩니다. 예를 들어 student 딕셔너리에 학점을 추가하고 싶다면 다음과 같이 코드를 작성하면 됩니다.

```python filename="04-34-dictionary_add.py"
student = {"name": "김철수", "age": 21}

# 새로운 항목 추가
student["grade"] = "A+"
print(f"성적 추가 후: {student}")
```

**실행 결과**

```text
성적 추가 후: {'name': '김철수', 'age': 21, 'grade': 'A+'}
```

실행 결과를 보면 값의 수정과 추가는 ‘키가 이미 있는 건지 아닌지’에 따라 결정된다는 것을 알 수 있습니다. 이미 존재하는 키에 값을 할당하면 기존 값이 변경되고 존재하지 않는 키에 값을 할당하면 딕셔너리에 새 항목이 추가됩니다.

## 연습 04 딕셔너리에서 키 검색하기

딕셔너리에서도 에서 배운 in 연산자를 사용할 수 있습니다. 다만 딕셔너리에서 in은 값이 아니라 키가 존재하는지를 확인해줍니다. 다음과 같이 코드를 작성하면 딕셔너리에 해당 키가 있는지 없는지를 파악할 수 있습니다.

```python filename="04-35-dictionary_key_search.py"
student = {"name": "김철수", "age": 20, "major": "컴퓨터공학"}

print("name" in student)
print("grade" in student)
```

**실행 결과**

```text
True
False
```

실행 결과를 보면 in 연산자는 키가 딕셔너리에 있으면 True를, 없으면 False를 반환합니다. in 연산자의 가장 큰 장점은 오류를 일으키지 않고 데이터의 존재 여부를 알려준다는 데 있습니다. 이 설명이 조금 의아하게 느껴질 수 있습니다. '딕셔너리에 해당 키가 있는지 없는지 검색할 때 student['name']처럼 바로 접근해도 되는 것 아닐까?'라고 생각할 수도 있기 때문입니다. 하지만 딕셔너리에 존재하지 않는 키로 직접 접근하려고 하면 실행 도중 오류가 발생해 프로그램이 강제 종료됩니다. 프로그래밍에서는 이처럼 실행 도중 발생하는 오류(예외)에 대처하는 것이 매우 중요합니다. 예를 들어 딕셔너리에 "score"라는 키가 있는지 확인하기 위해 다음 코드를 실행했다고 가정해봅시다.

```python
print(student["score"])  # 없는 키에 직접 접근하면 오류 발생
```

그러면 프로그램은 해당 위치에서 오류를 내며 이후 코드를 더 실행하지 않고 작동을 멈출 것입니다. 프로그램을 사용하던 사람 입장에서는 매우 곤란할 겁니다. 잘 실행되던 프로그램의 창이 예고도 없이 닫혀 버린다면 대개 다음과 같은 오류 때문입니다.

![](/books/python-intro/p186-135.webp)

이러한 문제를 방지하기 위해 in 연산자를 사용합니다. in을 사용하면 오류가 발생하지 않고 False를 반환하므로, 이후 흐름만 적절히 처리해주면 프로그램이 중단되지 않고 계속 실행될 수 있습니다. in을 사용하는 이유에 대한 의문이 이제 풀렸을 겁니다.

## 연습 05 값을 안전하게 꺼내는 get( ) 함수

앞서 in 연산자로 키 유무를 확인했습니다. 하지만 실제로 우리가 원하는 것은 단순히 ‘키가 있는지 확인’하는 데서 그치지 않고, ‘있다면 해당 값을 꺼내 오는 것’인 경우가 많습니다. 따라서 in으로 검사한 뒤 다시 대괄호로 접근하는 방식은 코드가 다소 번거로울 수 있습니다. 이 과정을 한 번에 처리해주는 함수가 바로 get( )입니다. get( ) 함수는 키가 있으면 해당 값을 돌려주고, 키가 없으면 오류를 발생시키는 대신 ‘값이 없음’을 뜻하는 None을 반환합니다.

```python filename="04-36-dictionary_get.py"
student = {"name": "김철수", "age": 20}
print(student.get("name"))      # ➊ 있는 키
print(student.get("score"))     # ➋ 없는 키
print(student.get("score", 0))  # ➌ 없을 때 대신 쓸 값 지정
```

**실행 결과**

```text
김철수
None
0
```

❶ "name"은 student에 있는 키이므로 값 "김철수"를 그대로 돌려줍니다.

❷ "score"는 존재하지 않는 키입니다. student["score"]로 접근했다면 오류가 나며 프로그램이 멈췄겠지만, get( ) 함수는 None을 돌려주고 매끄럽게 넘어갑니다. 바로 이 점이 앞서 이야기한 프로그램이 강제 종료되는 현상을 막아줍니다.

❸ get( ) 함수에 두 번째 인수를 전달하면 키가 없을 때 None 대신 지정한 값을 돌려줍니다. 여기서는 0을 지정했으므로 0이 나왔습니다. 점수 데이터가 없는 학생을 기본 0점으로 처리할 때처럼, 빈자리를 채워야 할 때 유용합니다.

정리하면 키의 존재 여부를 알고 싶을 때는 in을, 안전하게 값을 꺼내 오되 없어도 프로그램이 멈추지 않게 하려면 get( ) 함수를 사용하면 됩니다.

> **NOTE**
>
> None은 말 그대로 ‘값이 없음’을 뜻합니다. 에서 함수를 공부할 때 다시 자세히 다루니, 지금은 의미만 가볍게 알

고 넘어가면 됩니다.

## 딕셔너리 응용 연습하기

딕셔너리는 리스트와 마찬가지로 다른 딕셔너리나 리스트를 값으로 포함할 수 있는 자유로운 자료형입니다. 딕셔너리 다루기에 익숙해질 수 있는 실습 코드 4개를 준비했습니다.

## 연습 01 중첩 딕셔너리 사용해보기

딕셔너리는 값으로 또 다른 딕셔너리를 가질 수 있습니다. 이를 중첩 딕셔너리라고 하며, 여러 단계로 구성된 복잡한 데이터를 표현할 때 유용합니다. 코드를 실행해 그 구조를 직접 확인해봅시다.

```python filename="04-37-nested_dictionary_access.py"
students = {
    "김철수": {"age": 20, "major": "컴퓨터공학", "grade": "A"},
    "이영희": {"age": 21, "major": "경영학", "grade": "B+"},
    "박민수": {"age": 19, "major": "수학", "grade": "A+"}
}

print(students["김철수"])
print(students["김철수"]["major"])
print(students["이영희"]["age"])
```

**실행 결과**

```text
{'age': 20, 'major': '컴퓨터공학', 'grade': 'A'}
컴퓨터공학
21
```

첫 번째 출력은 "김철수" 키에 해당하는 전체 딕셔너리를 보여줍니다. 두 번째와 세 번째 출력은 대괄호를 두 번 사용해 중첩된 딕셔너리의 특정 값에 접근하는 방법을 보여줍니다. students["김철수"] ["major"]는 먼저 "김철수"를 키로 하는 값 즉, 딕셔너리 안의 딕셔너리 {"age": 20, "major": "컴퓨터공학", "grade": "A"}를 찾습니다. 그런 다음 그 딕셔너리에서 "major" 키를 찾아 "컴퓨터공학"이라는 값을 가져옵니다.

위치를 찾는 방법을 알았으니, 이번에는 그 위치의 값을 수정하거나 새로운 값을 추가해보겠습니다.

```python filename="04-38-nested_dictionary_update.py"
students = {
    "김철수": {"age": 20, "major": "컴퓨터공학"},
    "이영희": {"age": 21, "major": "경영학"}
}

# 값 수정
students["김철수"]["age"] = 21

# 새로운 키와 학생 추가
students["김철수"]["grade"] = "A"
students["최지원"] = {"age": 20, "major": "물리학", "grade": "B"}

print(students)
```

**실행 결과**

```text
{'김철수': {'age': 21, 'major': '컴퓨터공학', 'grade': 'A'}, '이영희': {'age': 21,
'major': '경영학'}, '최지원': {'age': 20, 'major': '물리학', 'grade': 'B'}}
```

이처럼 중첩 딕셔너리를 사용하면 관련 정보를 하나로 묶어 체계적으로 관리할 수 있습니다. 각 학생의 정보가 하나의 딕셔너리로 정리되어 있어 데이터를 다루기도 훨씬 편리합니다.

## 연습 02 딕셔너리에 리스트 넣어보기

딕셔너리의 값으로 리스트를 사용할 수도 있습니다. 이 방법은 하나의 키에 여러 개의 값을 연결해야 할 때 특히 유용합니다. 예를 들어 한 학생이 수강하는 여러 과목을 저장하거나, 한 회사에서 여러 직원의 이름을 관리할 때 리스트를 값으로 사용하면 편리합니다. 코드를 따라 입력하며 딕셔너리와 리스트를 조합하는 방법을 익혀봅시다.

```python filename="04-39-dictionary_list_values.py"
student_courses = {
    "김철수": ["수학", "영어", "과학"],
    "이영희": ["국어", "역사", "음악"],
    "박민수": ["수학", "물리", "화학", "생물"]
}

print(student_courses["김철수"])
print(student_courses["박민수"][1])
print(len(student_courses["이영희"]))
```

**실행 결과**

```text
['수학', '영어', '과학']
물리
3
```

첫 번째 출력은 김철수가 수강하는 모든 과목을 리스트로 보여줍니다. 두 번째 출력은 박민수의 과목 리스트에서 인덱스 1의 값인 "물리"를 가져옵니다. 세 번째 출력은 이영희가 수강하는 과목의 개수를 len( ) 함수로 계산한 결과입니다.

## 연습 03 리스트에 딕셔너리 넣기

이번에는 리스트에 딕셔너리를 넣어봅시다. 딕셔너리는 키로 값을 찾는 데 특화되어 있지만, 데이터의 형태가 일정하고 순서대로 관리해야 한다면 바깥쪽은 리스트로 묶는 편이 더 적합할 수 있습니다. 예를 들어 모든 학생의 정보가 이름, 나이, 학점으로 같은 형태라면 굳이 딕셔너리 안에 딕셔너리를 넣을 필요가 없습니다. 오히려 그렇게 구성하면 바깥쪽 딕셔너리의 키를 무엇으로 할지 고민하고 지정해야 하는 번거로움이 생깁니다.

```python filename="04-40-list_of_dictionaries.py"
students = [
    {"name": "김철수", "age": 20, "grade": "A"},
    {"name": "이영희", "age": 21, "grade": "B+"},
    {"name": "박민수", "age": 19, "grade": "A+"}
]

print(students[0])
print(students[1]["name"])
print(f"{students[2]['name']}의 학점은 {students[2]['grade']}입니다.")
```

**실행 결과**

```text
{'name': '김철수', 'age': 20, 'grade': 'A'}
이영희
박민수의 학점은 A+입니다.
```

첫 번째 출력은 리스트의 첫 번째 요소인 김철수의 전체 딕셔너리를 보여줍니다. 두 번째 출력은 인덱스로 딕셔너리를 선택한 후 그 안의 "name" 키 값을 가져옵니다. 세 번째 출력은 f-string을 사용해서 데이터를 문장으로 만드는 예입니다.

## 연습 04 딕셔너리에서 요소 삭제하기

딕셔너리에 값을 넣고 바꾸는 방법을 공부했으니 이제 값을 삭제하는 방법도 알아둘 차례입니다. 사용자가 탈퇴하거나 임시로 저장해둔 값이 필요 없어지면 딕셔너리에서 해당 항목을 지워야 합니다. 삭제하는 방법은 크게 세 가지가 있습니다.

- **del :** 파이썬 키워드 del입니다. del 딕셔너리[키] 형태로 지정하면 해당 키와 값을 함께 지웁니다.
- **pop( ) :** 키를 지정해 삭제하면서 그 값을 돌려줍니다. 없는 키를 지정하면 오류가 나지만, 기본값을 함께 전달하면 오류 없이 그 값을 대신 돌려줍니다.
- **clear( ) :** 딕셔너리의 모든 항목을 지워 빈 딕셔너리로 만듭니다.

다음 코드를 실행하며 딕셔너리에서 값을 어떻게 삭제하는지 확인해봅시다.

```python filename="04-41-dictionary_delete.py"
student = {"name": "김철수", "age": 20, "score": 95, "temp": 0}

del student["temp"]                      # ➊ 키를 지정해 삭제
print(student)

age = student.pop("age")                 # ➋ 삭제하면서 값 꺼내기
print(age)
print(student)

grade = student.pop("grade", "없음")     # ➌ 없는 키는 기본값으로
print(grade)

student.clear()                          # ➍ 전부 삭제
print(student)
```

**실행 결과**

```text
{'name': '김철수', 'age': 20, 'score': 95}
20
{'name': '김철수', 'score': 95}
```

```python
없음
{}
```

❶**del은 함수**가 아니라 **파이썬 키워드**입니다. del 딕셔너리[키] 형태로 사용하면 해당 키와 값이 함께 사라집니다. 값을 돌려주지는 않고 항목을 삭제하기만 합니다.

![](/books/python-intro/p192-136.webp)

❷**pop( ) 함수**는 항목을 지우면서 해당 값을 반환합니다. 리스트에서 배운 pop( ) 함수와 이름과 기본적인 역할은 같지만, 리스트에서는 인덱스로 항목을 삭제하고 딕셔너리에서는 키로 항목을 삭제한다는 차이가 있습니다. 여기서는 삭제한 값 20이 age 변수에 저장됩니다.

❸ 존재하지 않는 키를 지정해 삭제하려고 하면 오류가 나면서 프로그램이 멈춥니다. 이때 get( ) 함수처럼 pop( ) 함수에도 값을 하나 더 전달하면 키가 없을 때 지정한 값을 대신 돌려주고 넘어갑니다.

❹**clear( ) 함수**는 모든 항목을 삭제해 빈 딕셔너리로 만듭니다. 딕셔너리 자체가 사라지는 것은 아니므로 출력하면 { }가 나옵니다.

정리하면 항목을 지우기만 할 때는 del, 지우면서 값을 써야 할 때는 pop( ) 함수, 딕셔너리의 모든 항목을 비울 때는 clear( ) 함수를 사용하면 됩니다.

> **바로 핵심 요약**
>
> - 딕셔너리는 중괄호 안에 키: 값 쌍으로 데이터를 관리하며, 인덱스 대신 키로 값을 찾는 자료형입니다.
> - 딕셔너리는 가변성이 있어 키로 값을 수정 및 추가할 수 있고, in 연산자로 특정 키가 있는지 확인할 수 있습니다.
> - del, pop( ), clear( )로 항목을 삭제할 수 있고, 딕셔너리와 리스트를 중첩해 복잡한 데이터를 표현할 수 있습니다.
