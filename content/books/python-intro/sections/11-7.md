## 오늘의 당번 뽑고 순서 섞기

random 모듈은 숫자뿐 아니라 리스트의 요소를 고르거나 순서를 섞을 때도 사용할 수 있습니다. choice( ) 함수는 리스트에서 요소 하나를 골라 반환하고, shuffle( ) 함수는 리스트에 있는 요소의 순서를 섞습니다. 다음 코드를 11-17-duty.py 파일에 입력한 뒤 실행합니다.

```python filename="11-17-duty.py"
import random                       # ➊ random 모듈 가져오기

members = ["요즘", "바로", "하나", "두리"]

today = random.choice(members)      # ➋ 한 명 뽑기
print(f"오늘의 당번: {today}")

random.shuffle(members)             # ➌ 리스트 순서 섞기
print(f"이번 주 순서: {members}")
```

**실행 결과**

```text
오늘의 당번: 하나
이번 주 순서: ['두리', '요즘', '하나', '바로']
```

❶ 무작위 값을 다루기 위해 random 모듈을 가져옵니다.

❷ choice(members)는 리스트에서 항목 하나를 골라 반환합니다. 이 과정에서 원래 리스트의 내용이나 순서는 바뀌지 않습니다.

❸ shuffle(members)는 리스트 자체의 요소 순서를 뒤섞습니다. 값을 반환하는 것이 아니라 리스트를 직접 바꾸므로 members = random.shuffle(members)처럼 작성하면 안 됩니다.

## 생일까지 며칠 남았는지 구하기

**11.2 표준 라이브러리 활용하기**에서는 날짜를 직접 지정해 만들었지만, date 클래스의 today( ) 메서드를 사용하면 오늘 날짜를 자동으로 가져올 수 있습니다. 다음 코드를 11-18-birthday.py 파일에 입력한 뒤 실행합니다.

❸ 비교할 생일 날짜는 직접 만들었습니다. 코드에 있는 월과 일을 여러분의 생일로 바꿔서 실행해보세요.

> **NOTE**

❸ sleep(1)은 다음 코드가 실행되기까지 약 1초 동안 기다리게 합니다. 값을 0.5로 바꾸면 약 0.5초 동안 기다립니다.

## 점수의 평균과 표준편차 구하기

statistics 모듈에는 평균과 중앙값 말고도 여러 통계 기능이 있습니다. stdev( ) 함수는 값들이 평균에서 얼마나 흩어져 있는지를 나타내는 표준편차를 계산합니다. 다음 코드를 11-21-score_spread.py 파일에 입력한 뒤 실행해봅시다.

```python filename="11-21-score_spread.py"
import statistics                       # ➊ statistics 모듈 가져오기

scores = [85, 92, 78, 90, 88]

average = statistics.mean(scores)       # ➋ 평균 계산
spread = statistics.stdev(scores)       # ➌ 표준편차 계산

print(f"평균: {average}")
print(f"표준편차: {round(spread, 2)}")   # ➍ 소수점 아래 둘째 자리로 반올림
```

**실행 결과**

```text
평균: 86.6
표준편차: 5.46
```

❶ 통계 계산을 위해 statistics 모듈을 가져옵니다.

❷ mean( ) 함수로 다섯 점수의 평균을 구했습니다.

❸ stdev( ) 함수로 점수의 표본 표준편차를 구했습니다. 일반적으로 결과가 작을수록 값들이 평균 주변에 비교적 모여 있고, 클수록 넓게 퍼져 있다고 볼 수 있습니다.

❹ 계산 결과는 소수점 아래로 길게 이어질 수 있으므로 round( ) 함수를 사용해 소수점 아래 둘째 자리까지 반올림했습니다.

> **NOTE**
>
> 표준편차를 계산하는 공식을 지금 알 필요는 없습니다. 여기서는 ‘이런 통계 계산 기능도 이미 준비되어 있으므로 필요

마지막으로 표준 라이브러리와 직접 만든 패키지를 함께 사용해봅시다. datetime을 사용해 현재 시각을 문자열로 만들어주는 모듈을 패키지에 넣고, 패키지 바깥의 파일에서 가져와 호출합니다. 우선 다음 구조대로 폴더와 파일을 만듭니다.


❶ time_tools 패키지의 clock 모듈에서 now_text( ) 함수를 가져왔습니다. 패키지 이름과 모듈 이름은 점으로 연결합니다.

❷ 표준 라이브러리인 datetime은 clock.py 안에서만 사용했고, 11-22-time_app.py는 now_text( ) 함수만 호출했습니다. 이렇게 세부적인 처리 과정을 모듈 안에 분리해두면 메인 파일에서는 필요한 기능만 간단하게 호출할 수 있어 코드의 흐름을 파악하기 쉬워집니다.

> **바로 핵심 요약**
>
> - import 모듈 형태로 가져온 모듈의 기능은 모듈.이름 형태로 사용할 수 있고, from 모듈 import 이름으로 직접 가져온 이름은 모듈 이름을 붙이지 않고 사용할 수 있습니다.
> - random, datetime, time, pathlib, statistics 등은 파이썬 표준 라이브러리에 포함되어 있어 별도의 외부 패키지를 설치하지 않고 사용할 수 있습니다.
> - 직접 만든 모듈과 패키지도 import 문이나 from~import 문을 사용해 다른 파일에서 가져와 사용할 수 있습니다.
