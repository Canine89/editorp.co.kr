**흐름을 가르는 제어문**에서 사용한 except 문은 다음과 같이 예외를 처리했습니다.

> **미리 알아두세요!**
>
> - except 문에는 처리할 예외 클래스를 지정할 수 있습니다.
> - 여러 except 문을 사용하면 오류 종류마다 다르게 처리할 수 있습니다.
> - 일반적인 오류를 나타내는 예외는 Exception을 상속합니다.

```python
user_input = "abc"
try:
  number = int(user_input)
  print(f"변환 성공: {number}")
except:
  print("숫자로 변환할 수 없습니다.")
```

언뜻 보면 ‘어떤 오류가 발생해도 처리해주니 편리한 것 아닌가?’라고 생각할 수 있습니다. 하지만 try 문 안에서 여러 종류의 문제가 발생할 수 있다면 이야기가 달라집니다. 어떤 이유로 except 문이 실행되었는지 알아내기 어려워지기 때문입니다.

예를 들어 숫자로 변환하는 과정에서 발생하는 오류를 처리하려고 코드를 작성했다고 해봅시다. 그런데 실수로 변수 이름을 잘못 작성해 다른 예외가 발생하더라도 모든 예외를 한꺼번에 처리하면 똑같은 안내 메시지가 나타날 수 있습니다. 그러면 코드 작성자는 실제 문제는 변수 이름인데도 ‘숫자 변환 과정에서 문제가 생겼나?’라고 잘못 생각할 수 있습니다.

![](/books/python-intro/p468-284.webp)

![](/books/python-intro/p468-285.webp)

이럴 때는 요리할 때 사용하는 거름망을 떠올려볼 수 있습니다. 거름망으로 원하는 재료만 걸러내듯이, try 문에서 발생한 예외도 종류에 따라 골라 처리할 수 있습니다. 어떤 예외가 발생할지 예상하고 그 예외에 맞는 거름망을 준비해두는 셈입니다. 이를 위해 except 뒤에 처리할 예외 클래스를 지정합니다. 앞에서 살펴본 ValueError, TypeError, FileNotFoundError 등이 바로 예외의 종류를 나타내는 클래스입니다.

## 오류 하나만 걸러보기

다음과 같이 except 뒤에 처리할 예외 클래스를 작성하면 해당 종류의 예외만 골라 처리할 수 있습니다. 이번에는 문자열을 정수로 변환하는 과정에서 발생하는 ValueError를 처리해보겠습니다. 이때 except 문의 예외 클래스 뒤에 as와 변수 이름을 적으면 발생한 예외를 변수에 담아 출력해 구체적인 내용도 확인할 수 있습니다.

```python filename="10-07-value_error_catch.py"
user_input = "스물"
try:
  age = int(user_input)               # ➊ 오류가 예상되는 코드
except ValueError as error:           # ➋ 처리할 예외 클래스 지정
  print("나이는 숫자로 입력해야 합니다.")
  print(f"개발자 확인: {error}")        # ➌ 예외 설명 출력
```

**실행 결과**

```text
나이는 숫자로 입력해야 합니다.
개발자 확인: invalid literal for int() with base 10: '스물'
```

❶ int( ) 함수가 "스물"을 정수로 바꾸려고 하므로 ValueError가 발생합니다.

❷ except 뒤에 ValueError를 적었습니다. 따라서 try 문의 코드 블록에서 ValueError가 발생하면 해당 except 문의 코드 블록이 실행됩니다. as error를 사용했으므로 발생한 예외 인스턴스는 error 변수에 저장됩니다.

❸ error를 출력하면 오류 메시지에서 보았던 구체적인 설명을 확인할 수 있습니다.

여기서는 사용자에게 "나이는 숫자로 입력해야 합니다."와 같이 이해하기 쉬운 안내를 보여주는 방법과 error를 출력해 실제 예외의 내용을 확인하는 방법을 함께 사용했습니다. 하나의 예외를 골라 처리하는 방법을 알아봤으니 이번에는 여러 종류의 예외를 각각 다르게 처리해보겠습니다.

![](/books/python-intro/p469-286.webp)

## 여러 오류 걸러보기

이번에는 하나의 코드에서 서로 다른 예외가 발생할 수 있는 상황을 생각해보겠습니다. 요즘이가 게임 파티원들의 평균 점수를 구한다고 해봅시다.

![](/books/python-intro/p469-287.webp)

파티에 없는 이름을 사용하면 KeyError가 발생할 수 있고, 기록이 하나도 없는 파티원의 평균을 계산하려고 하면 ZeroDivisionError가 발생할 수 있습니다. 이어서 다음 코드를 실행해봅시다.

> **NOTE**
>
> ZeroDivisionError는 수를 0으로 나눌 때 발생하는 오류입니다.

```python filename="10-08-multiple_except.py"
scores = {
  "요즘이": [],
  "든든이": [80, 90, 100]
}
def show_average(name):
  try:
    member_scores = scores[name]                     # ➊ 딕셔너리 값 조회
    average = sum(member_scores) / len(member_scores)   # ➋ 평균 계산
  except KeyError:
    print(f"{name} 님은 파티에 없습니다.")              # ➌ 없는 키 처리
    return
  except ZeroDivisionError:
    print(f"{name} 님의 기록이 아직 없습니다.")         # ➍ 0으로 나누는 오류 처리
    return
  print(f"{name} 님의 평균 점수: {average}")           # ➎ 정상 결과 출력
show_average("멀리있는이")
show_average("요즘이")
show_average("든든이")
```

**실행 결과**

```text
멀리있는이 님은 파티에 없습니다.
요즘이 님의 기록이 아직 없습니다.
든든이 님의 평균 점수: 90.0
```

코드를 보면 하나의 try 문 뒤에 여러 개의 except 문이 이어져 있습니다. 이처럼 하나의 try 문에 여러 except 문을 작성하면 발생한 예외의 종류에 따라 서로 다르게 처리할 수 있습니다.

❶ scores 딕셔너리에서 name 변수에 저장된 "멀리있는이"라는 키를 찾습니다. 해당 키가 없으므로 KeyError가 발생하고, 이 오류는 except KeyError:의 코드 블록에서 처리됩니다.

❷ 파티원의 점수 합계를 점수 개수로 나눕니다. 요즘이의 기록 목록은 비어 있으므로 len(member _scores)의 결과가 0이 되고, 0으로 나누는 과정에서 ZeroDivisionError가 발생합니다. 이 예외는 except ZeroDivisionError:의 코드 블록에서 처리됩니다.

❸ KeyError가 발생했을 때는 "파티에 없다"는 안내 메시지를 출력합니다.

❹ ZeroDivisionError가 발생했을 때는 "기록이 없다"는 안내 메시지를 출력합니다.

❺ 든든이의 기록 목록에는 점수가 들어 있으므로 예외가 발생하지 않습니다. 따라서 두 except 문의 코드 블록을 모두 건너뛰고 평균을 출력합니다.

생각보다 어렵지 않죠? 예상되는 예외의 종류를 각각 지정해두면 발생한 문제에 따라 다른 메시지를 보여주거나 서로 다른 처리를 할 수 있습니다. 그런데 서로 다른 예외라도 처리 방법이 완전히 같다면 except 문을 여러 개 작성할 필요가 있을까요?

![](/books/python-intro/p471-288.webp)

## 여러 오류를 튜플로 걸러보기

만약 여러 종류의 예외를 같은 방법으로 처리하고 싶다면 예외 클래스를 소괄호로 묶을 수 있습니다.

```python filename="10-09-except_tuple.py"
numbers = [10, 20, 30]
user_input = "5"

try:
  index = int(user_input)                    # ➊ ValueError 발생 가능
  print(numbers[index])                      # ➋ IndexError 발생 가능
except (ValueError, IndexError) as error:    # ➌ 두 예외를 튜플로 묶어 함께 처리
  print(f"입력을 확인하세요: {error}")
```

**실행 결과**

```text
입력을 확인하세요: list index out of range
```

❶ user_input에 숫자 형태가 아닌 문자열이 들어 있으면 int( ) 함수로 변환하는 과정에서 ValueError가 발생합니다.

❷ 현재 입력값 "5"를 정수로 변환한 뒤 리스트의 인덱스로 사용하면 리스트의 범위를 벗어나므로 IndexError가 발생합니다.

❸ except (ValueError, IndexError)as error:처럼 두 예외 클래스를 튜플로 묶었으므로 두 예외 중 어느 것이 발생하더라도 같은 except 문의 코드 블록에서 처리합니다. user_input을 "다섯"으로 바꾸어 실행하면 이번에는 ValueError가 발생하지만 역시 같은 코드 블록이 실행됩니다.

이처럼 처리 방법이 같다면 여러 예외를 한꺼번에 묶어 코드를 간단하게 작성할 수 있습니다.

## 일반적인 예외의 부모, Exception

지금까지는 어떤 예외가 발생할지 예상하고 ValueError, IndexError처럼 구체적인 예외 클래스를 지정했습니다. 그런데 예상하지 못한 다른 예외까지 함께 처리하고 싶다면 어떻게 해야 할까요? 파이썬의 일반적인 예외 클래스 대부분은 Exception을 상속받습니다. ValueError, TypeError, IndexError, KeyError 등 지금까지 자주 살펴본 예외들도 Exception의 자식 클래스입니다.

![](/books/python-intro/p472-289.webp)

따라서 except Exception:을 사용하면 Exception을 상속받는 여러 종류의 예외를 넓게 처리할 수 있습니다. 코드를 작성하며 Exception의 역할을 알아봅시다.

```python filename="10-10-exception.py"
try:
  number = int("스물")
except Exception as error:       # ➊ 일반적인 예외의 부모
  print("오류가 발생했습니다:", error)
```

**실행 결과**

```text
오류가 발생했습니다: invalid literal for int() with base 10: '스물'
```

❶ 여기서 발생한 오류는 ValueError이지만 except Exception으로도 처리됩니다. ValueError가 Exception을 상속받은 자식 클래스이기 때문입니다. '강아지는 동물이기도 하다'와 같은 관계입니다.

다른 코드도 살펴봅시다. 이번에는 IndexError가 발생하지만 이것을 Exception으로 처리하는 코드입니다.

```python filename="10-11-exception_practice.py"
numbers = [10, 20, 30]

try:
  print(numbers[5])              # ➊ 범위를 벗어난 인덱스
except Exception as error:
  print("문제가 생겼습니다:", error)
```

**실행 결과**

```text
문제가 생겼습니다: list index out of range
```

❶ 리스트에 존재하지 않는 인덱스에 접근해 IndexError가 발생하지만 IndexError 역시 Exception을 상속받으므로 except Exception:의 코드 블록에서 처리됩니다. 코드를 numbers[5] 대신 int("스물")과 같이 바꾸어 실행하면 ValueError도 같은 except 문에서 처리되는 것을 확인할 수 있습니다.

다만 except Exception만 사용하면 예외 종류별로 처리 흐름을 나눌 수 없다는 한계가 있습니다. 따라서 예상할 수 있는 구체적인 예외는 먼저 처리하고, 필요하다면 가장 마지막에 Exception을 두어 그 밖의 일반적인 예외를 처리하는 방식을 사용할 수 있습니다. 형태로 보면 다음과 같습니다.

```python
numbers = [10, 20, 30]
user_input = "다섯"
try:
  index = int(user_input)
  print(numbers[index])
except ValueError:
  print("숫자로 입력하세요.")
except IndexError:
  print("목록의 범위를 벗어났습니다.")
except Exception as error:
  print("예상하지 못한 오류입니다:", error)
```

**실행 결과**

![실행 결과](/books/python-intro/p474-290.webp)

> **바로 핵심 요약**
>
> - except 뒤에 예외 클래스를 지정하면 해당 예외만 골라 처리할 수 있습니다.
> - except ValueError as error:처럼 작성하면 예외 인스턴스가 error 변수에 저장되므로, 이를 출력해 구체적인 오류 메시지를 확인할 수 있습니다.
> - 여러 except 문을 사용할 때는 구체적인 예외를 먼저 작성하고, 예외 처리 방법이 같다면 except (ValueError, IndexError):처럼 예외 클래스들을 튜플로 묶을 수 있습니다.
> - Exception은 일반적인 예외 클래스 대부분의 부모 클래스이므로 여러 종류의 예외를 넓게 처리할 수 있습니다.
