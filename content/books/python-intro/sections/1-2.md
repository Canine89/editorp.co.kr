보통 프로그래밍 언어는 개발자가 되기 위해 배웁니다. 이를테면 자바 같은 프로그래밍 언어는 그냥 취미로 배우지 않습니다. 특히 한국에서는 국비지원교육이라는 이름으로 학원에서 6개월 내지 1년간 전문 훈련을 받고 현장으로 가는 사람들이 많습니다. 그냥 자바를 취미로 공부하는 사람은 거의 없다고 봐도 무방합니다.

## 다양한 분야에서 사용할 수 있는 파이썬

하지만 파이썬은 조금 다릅니다. 개발자가 되기 위해 배우려는 사람도 많지만, 데이터 분석가가 되고 싶어서 배우는 사람도 있고, 인공지능에 관심이 있어 배우려는 사람도 많습니다. 그만큼 파이썬은 다양한 분야에서 사용되는 언어입니다. 다음은 파이썬으로 할 수 있는 일 중 가장 많이 언급되는 것들을 그림으로 나타낸 겁니다. 실제로는 이보다 더 많은 분야에서 파이썬을 사용합니다.

![](/books/python-intro/01.png)

이처럼 워낙 다양한 분야에서 파이썬이 쓰이니 프로그래밍을 공부해보고 싶다는 생각이 들었을 때 주변에서 '파이썬을 배워봐!'라고 하는 것이죠. 한 번 배우면 정말 다양한 분야에서 사용할 수 있을 정도로 유용하니까요. 하지만 파이썬은 이런 이유만으로 배우라고 하진 않습니다.

## 배우기 쉬운 파이썬

사람들이 '파이썬을 한 번 배워봐'라고 하는 이유는 파이썬은 타 언어에 비해 정말 배우기 쉽기 때문입니다. 물론 모든 것이 그렇듯 파이썬을 마스터한다는 건 쉽지 않습니다. 하지만 파이썬은 분명 입문하기에 가장 쉬운 언어가 맞습니다. 그 이유는 간단합니다. 파이썬의 문법은 매우 간단합니다. 파이썬 프로그래밍 세계에 첫 발을 들이면 작성하는 헬로 월드라는 프로그램을 파이썬으로 작성하면 다음과 같습니다.

```python
>>> print("Hello World")
```

이 프로그램을 실행하면 검정 화면에서 나에게 인사하듯 Hello World를 띄웁니다.

![](/books/python-intro/02.png)

이 코드는 파이썬을 전혀 몰라도 '뭔가를 프린트(print)하라는 거군'이라고 의미를 짐작하기 쉽습니다. 그리고 입력해야 할 코드의 양도 적습니다. print("Hello World")로 단 한 줄입니다. 그러면 다른 언어는 어떨까요? 예를 들어 자바라는 프로그래밍 언어는 단 한 줄의 출력을 보기 위해 다음과 같이 코드를 작성해야 합니다.

\[Note\] 자바가 부족하거나 모자란 언어라는 뜻이 아닙니다. 어디까지나 초보자 입장에서 배우기 쉽다라는 것을 설명하기 위한 예입니다.

```python
public class HelloWorld {
public static void main(String[] args) {
System.out.println("Hello World");
}
}
```

프로그래밍 언어를 처음 배우는 초보자 입장에서는 1줄의 코드와 5줄의 코드는 체감 난이도가 큽니다. 게다가 코드에 쓰인 public, class, static, System.out...과 같은 알 수 없는 용어와 중괄호들이 장벽을 느끼게 합니다. 그러면 다시 파이썬으로 돌아와 아까전 보았던 코드를 다시 보겠습니다. 파이썬은 코드만 읽어봐도 대략 무슨 뜻인지 알 수 있습니다.

```python
print("Hello World")
```

모든 파이썬의 문법이나 기법이 쉽다는 이야기는 아닙니다. 하지만 파이썬의 기초 문법은 대부분 짧고 간결하며, 직관적입니다. 물론 지금 여러분이 깊은 공감을 할 순 없을 겁니다만 파이썬의 기초 문법은 정말 배우기 쉽습니다. 이제 더는 잔소리를 하진 않겠습니다. 이 정도면 '그래 뭘 공부해도 일단 파이썬을 공부해야겠구나'라는 생각이 들었을 겁니다. 그럼 이제부터 파이썬을 공부하기 위해 필요한 실습 도구부터 준비하겠습니다. ![](/books/python-intro/03.png)
