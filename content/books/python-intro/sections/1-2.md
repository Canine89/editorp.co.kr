파이썬 공부를 시작하기 전에 프로그램과 프로그래밍 언어가 무엇인지부터 알아봅시다. 컴퓨터에게 일을 시킨다는 것이 어떤 의미인지 이해하면 앞으로의 공부가 훨씬 자연스러워질 겁니다. 부담 없이 가벼운 마음으로 시작해봅시다.

> **미리 알아두세요!**
>
> - 프로그램은 컴퓨터에게 일을 시키는 명령의 묶음입니다.
> - 프로그래밍 언어는 컴퓨터와 대화하기 위해 약속된 언어입니다.

## 프로그램이란?

우리는 이미 수많은 프로그램을 사용하고 있습니다. 스마트폰의 메신저 앱, 웹 브라우저, 게임, 계산기, 문서 편집기 모두 프로그램입니다. 겉으로 보기에는 그저 버튼을 누르고 화면을 보는 것처럼 보이지만, 내부에서는 컴퓨터가 정해진 명령을 순서대로 실행하고 있는 것이죠.

![](/books/python-intro/p036-002.webp)

예를 들어 계산기 프로그램을 사용하는 상황을 생각해봅시다. 계산기에서 을 누르고 를 누른 뒤 를 누르고 을 누르면, 8이라는 결과를 보여줍니다. 이렇게 동작하는 계산기 프로그램에는 대략 다음과 같은 명령이 들어 있다고 볼 수 있습니다.

1. 사용자가 입력한 숫자를 기억한다. 2. 사용자가 선택한 연산 기호를 확인한다. 3. 숫자를 계산한다. 4. 계산 결과를 화면에 보여준다.

> **NOTE**
>
> 실제 프로그램은 이보다 더 복잡하게

구성됩니다. 프로그램의 개념을 이해하는 데 도움이 되도록 예를 든 것이므로 가볍게 읽고 넘어가도 좋습니다.

이처럼 프로그램에는 컴퓨터가 따라야 할 명령들이 모여 있으며, 컴퓨터는 이 명령을 순서대로 실행합니다. 그렇다면 이런 명령을 어떻게 전달해야 할까요?

## 프로그래밍 언어란?

사람은 한국어, 영어, 일본어 같은 언어로 생각을 주고받습니다. 마찬가지로 컴퓨터에 명령을 전달할 때도 컴퓨터가 알아들을 수 있는 언어가 필요합니다. 이 언어를 **프로그래밍 언어**라고 합니다. 프로그래밍 언어에는 파이썬, 자바, 자바스크립트, C, C++ 등 여러 종류가 있습니다. 예를 들어 ‘화면에 Hello World를 출력하라’는 명령을 파이썬으로 작성하면 다음과 같습니다.

![](/books/python-intro/p037-003.webp)

```python
>>> print("Hello World")
```

> **NOTE**
>
> 아직 코드를 입력하는 단계가 아니므로, 눈으로 가볍게 확인만 하고 넘어가세요.

이 코드는 컴퓨터에게 ‘Hello World라는 문장을 화면에 보여줘’라고 지시하는 명령입니다. 아직 print( )가 정확히 무엇인지 몰라도 괜찮습니다. 지금은 큰따옴표 안의 문장을 화면에 보여주는 코드라고 이해하면 충분합니다. 코드를 실행하면 다음과 같은 결과를 볼 수 있습니다.

**실행 결과**

```text
Hello World
```

컴퓨터에게 시킬 일이 여러 개라면 명령도 여러 줄로 작성할 수 있습니다. 예를 들어 자기소개를 출력하는 프로그램은 다음과 같이 작성하면 됩니다.

```python
>>> print("안녕하세요.")
>>> print("저는 파이썬을 공부하고 있습니다.")
>>> print("아직은 아주 간단한 코드만 작성할 수 있습니다.")
>>> print("하지만 한 줄씩 명령을 추가하면")
>>> print("컴퓨터에게 더 많은 일을 시킬 수 있습니다.")
```

**실행 결과**

```text
안녕하세요.
저는 파이썬을 공부하고 있습니다.
아직은 아주 간단한 코드만 작성할 수 있습니다.
하지만 한 줄씩 명령을 추가하면
컴퓨터에게 더 많은 일을 시킬 수 있습니다.
```

코드와 실행 결과를 맞춰 읽어보세요. 명령을 위에서부터 아래로 차례대로 실행했다는 걸 알 수 있습니다. 첫 번째 줄의 print( )가 실행되면 첫 번째 문장이 출력되고, 두 번째 줄의 print( )가 실행되면 두 번째 문장이 출력됩니다. 그다음 줄도 같은 방식으로 차례차례 실행됩니다. 이처럼 컴퓨터는 코드의 순서를 마음대로 바꾸지 않으며, 사용자가 작성한 순서대로 하나씩 실행합니다.

![](/books/python-intro/p038-004.webp)

정리하면 프로그램은 컴퓨터가 따라야 할 명령의 모음이고, 프로그래밍 언어는 그 명령을 작성하기 위한 언어입니다. 한 줄짜리 코드든 여러 줄로 이루어진 코드든 모두 프로그램이 될 수 있습니다. 중요한 것은 컴퓨터가 이해할 수 있는 규칙에 맞게 명령을 작성해야 한다는 점입니다. 우리는 앞으로 파이썬을 사용해 컴퓨터에게 일을 시켜볼 겁니다. 그리고 이 책을 덮을 때쯤에는 여러분이 공부한 것이 단순히 파이썬이라는 프로그래밍 언어를 배우는 일이 아니라 컴퓨터 세계를 이해하는 과정이었다는 걸 알게 될 겁니다. 그럼 조금 더 나아가봅시다.

> **바로 핵심 요약**
>
> - 프로그램은 컴퓨터가 순서대로 실행하는 명령의 모음입니다.
> - 프로그래밍 언어는 그 명령을 컴퓨터가 알아들을 수 있게 작성하는 언어입니다.
> - 파이썬은 코드를 위에서 아래로 한 줄씩 차례대로 실행합니다.
