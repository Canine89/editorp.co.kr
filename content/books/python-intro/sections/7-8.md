지금까지는 함수를 직접 만들어 사용했습니다. 그런데 파이썬에는 우리가 만들지 않아도 바로 사용할 수 있는 함수가 많이 준비되어 있습니다. 이런 함수를 **내장 함수**라고 합니다. 이번 절에서는 그중 자주 쓰는 여섯 가지를 골라 연습해보겠습니다. 앞에서 이미 사용해본 함수도 있으니 가벼운 마음으로 복습하며 시작해봅시다!

> **미리 알아두세요!**
>
> - 내장 함수는 우리가 만들지 않아도 파이썬이 미리 준비해둔 함수입니다.
> - int( ), len( ), max( ), sum( ), map( ), filter( ) 함수는 자주 쓰이므로 익혀두면 좋습니다.

## int( ) : 정수로 바꿔주기

숫자처럼 보이지만 실제로는 문자열인 값이 있습니다. 예를 들어 input( )으로 입력받은 “10”이나, 따옴표로 감싼 “25”는 문자열입니다. 따라서 그대로 숫자 계산에 사용할 수 없습니다. 실제로 “10” + “5”를 하면 15가 아니라 두 문자열이 이어진 “105”가 됩니다. 이럴 때 사용하는 함수가 int( )입니다. int( ) 함수는 전달한 값을 정수로 변환해 반환합니다. 숫자로 이루어진 문자열을 정수로 바꿀 수도 있고, 실수를 정수로 변환할 수도 있죠. 실수를 정수로 변환할 때는 소수점 아래를 반올림하지 않고 0에 가까운 방향으로 버립니다. 예를 들어 int(3.9)는 4가 아니라 3이 됩니다.

```python filename="07-32-int_conversion.py"
text_number = "25"
value = 3.9

print(int(text_number) + 5)   # 문자열 "25"를 숫자로 바꿔 계산
print(int(value))             # 실수의 소수점 버리기
print("25" + "5")             # 비교용: 문자열끼리는 그냥 이어 붙음
```

**실행 결과**

```text
30
3
255
```

## len( ) : 길이나 개수를 세기

len( ) 함수는 앞에서도 사용했지만 내장 함수 중에서도 자주 사용하는 함수이므로 다시 한 번 살펴보겠습니다. 이 함수는 문자열의 길이나 리스트와 같은 자료형에 들어 있는 요소의 개수를 계산해 반환합니다. 다음 코드를 실행하며 기억을 되새겨봅시다.

```python filename="07-33-len_examples.py"
word = "파이썬"
cart = ["사과", "바나나", "우유", "달걀"]
empty = []
print(f"단어 글자 수: {len(word)}")
print(f"장바구니 개수: {len(cart)}")
print(f"빈 목록 개수: {len(empty)}")
```

**실행 결과**

```text
단어 글자 수: 3
장바구니 개수: 4
빈 목록 개수: 0
```

len(word)는 “파이썬”의 글자 수인 3을 돌려줍니다. len(cart)는 리스트 cart에 담긴 요소 4개를 세어 줍니다. 비어 있는 리스트에는 셀 것이 없으므로 len(empty)는 0이 됩니다. 이처럼 len( ) 함수는 문자열이나 여러 요소를 담는 자료형의 길이를 구할 때 유용하게 사용할 수 있습니다.

## max( ) : 가장 큰 값을 찾기

이번에는 여러 값 가운데 가장 큰 값을 찾아주는 max( ) 함수를 알아보겠습니다. max( ) 함수는 전달한 값 중에서 가장 큰 값을 돌려줍니다. 값을 쉼표로 여러 개 나열해 전달할 수도 있고, 리스트처럼 여러 값을 담은 자료형 하나를 전달할 수도 있습니다. 코드로 확인해봅시다.

```python filename="07-34-max_examples.py"
scores = [85, 92, 76, 88, 95]
print(f"최고점 : {max(scores)}")
print(f"세 수 중 최대 : {max(10, 25, 7)}")
print(f"둘 중 큰 값 : {max(50, 80)}")
```

**실행 결과**

```text
최고점 : 95
세 수 중 최대 : 25
둘 중 큰 값 : 80
```

코드에서 보듯 호출 방법은 두 가지입니다. max(10, 25, 7)처럼 여러 값을 직접 나열하거나, scores = [85, 92, 76, 88, 95]와 같이 리스트를 만든 뒤, max(scores)처럼 리스트를 전달하는 것입니다. max(scores)는 리스트 scores에 담긴 값 중 가장 큰 95를 돌려줍니다. max(10, 25, 7)은 직접 전달한 값 가운데 가장 큰 25를 돌려줍니다.

가장 큰 값을 찾는 방법을 알아봤으니 이번에는 여러 숫자를 한꺼번에 더하는 함수를 살펴보겠습니다.

## sum( ) : 모든 값을 더하기

sum( ) 함수는 리스트에 담긴 숫자를 모두 더한 합을 돌려줍니다. 리스트뿐만 아니라 튜플처럼 여러 숫자를 담고 있는 자료형에도 사용할 수 있습니다. sum(리스트) 또는 sum(튜플) 형태로 호출하며, 숫자만 더할 수 있습니다. 코드를 실행해봅시다.

```python filename="07-35-sum_examples.py"
prices = [3000, 4500, 5000]
scores = [85, 92, 76, 88, 95]
print(f"장바구니 합계: {sum(prices)}원")
print(f"총점: {sum(scores)}")
print(f"평균: {sum(scores) / len(scores)}")
```

**실행 결과**

```text
장바구니 합계: 12500원
총점: 436
평균: 87.2
```

sum(prices)는 리스트 prices에 담긴 3000, 4500, 5000을 모두 더한 12500을 돌려줍니다. sum(scores)도 같은 방식으로 다섯 과목 점수를 더해 총점 436을 구합니다. 평균을 구하려면 sum(scores)로 구한 총점을 len(scores)로 구한 과목 수로 나누면 됩니다. 따라서 평균은 87.2가 됩니다. 이렇게 sum( )과 len( ) 함수를 함께 사용하면 평균처럼 자주 필요한 값도 간단하게 구할 수 있습니다.

> **1:1 코칭 · sum( ) 함수는 더하기 시작할 값을 지정할 수도 있습니다**
>
> 

sum( ) 함수는 두 번째 매개변수에 인수를 전달하여 합계에 미리 더하기 시작할 값을 정할 수 있습니다. 예를 들어 앞에서 작성한 sum(prices)를 sum(prices, 1000)으로 바꾸면 prices의 합계인 12500에 시작값 1000을 더해 13500을 반환합니다.

지금까지 살펴본 함수들은 값을 변환하거나 개수와 합계를 구하는 비교적 단순한 함수였습니다. 이번에는 조금 다른 방식으로 동작하는 map( ) 함수를 알아보겠습니다.

## map( ) : 값을 순회하며 함수를 실행하기

map( )은 조금 독특한 함수입니다. 반복 가능한 객체에서 값을 하나씩 꺼내 지정한 함수를 적용하기 때문입니다. 이전에 반복문을 배우면서 순회에 대해 설명한 적이 있습니다. 그렇다면 ‘순회할 수 있다’는 것은 무슨 뜻일까요?

순회할 수 있는 객체란 값을 하나씩 차례대로 꺼낼 수 있는 객체를 말하며, 영어로는 이터러블(iterable)이라고 합니다. 리스트, 튜플, 문자열 등이 대표적인 이터러블입니다. 예를 들어 문자열 “가나다라”를 순회하면 “가”, “나”, “다”, “라”가 차례대로 나옵니다. map( ) 함수는 이처럼 이터러블의 값을 하나씩 꺼내 지정한 함수에 차례대로 전달하고, 그 결과를 하나씩 꺼낼 수 있는 map 객체로 반환합니다. 다음 코드를 실행하며 동작을 살펴봅시다.

```python filename="07-36-map_examples.py"
prices = [3000, 4500, 5000]   # 리스트
extra = (1000, 2000)          # 튜플

# ➊ 배달비 500원을 더하는 함수
def add_delivery(price):
  return price + 500

print(list(map(add_delivery, prices)))   # ➋ 리스트 순회
print(list(map(add_delivery, extra)))    # ➌ 튜플 순회
print(list(map(int, "123")))             # ➍ 문자열 순회
```

**실행 결과**

```text
[3500, 5000, 5500]
[1500, 2500]
[1, 2, 3]
```

❶ add_delivery( ) 함수는 전달받은 가격에 배달비 500원을 더하는 함수입니다.

❷ map(add_delivery, prices)는 리스트 prices의 값을 하나씩 꺼내 add_delivery( )에 넣어 실행합니다. 그러면 각각의 가격에 500을 더한 결과를 차례대로 얻을 수 있습니다. 그런데 map( ) 함수는 결과를 곧바로 리스트로 만들어주지 않고, map 객체를 반환하여 필요할 때 값을 하나씩 꺼내 쓸 수 있습니다. 따라서 결과를 리스트 형태로 확인하려면 list( )로 한 번 감싸줍니다. 코드에서 print(list(map(...)))처럼 map( )의 결과를 list( )로 감싼 이유가 바로 이것입니다.

❸ map(add_delivery, extra)는 같은 함수를 튜플 extra의 각 값에 그대로 적용한 것입니다. 튜플도 순회할 수 있는 자료형이므로 똑같이 동작합니다.

❹ 마지막의 map(int, “123”)도 마찬가지입니다. 문자열 “123”에서 “1”, “2”, “3”이 차례대로 꺼내져 int( ) 함수에 전달됩니다. 그러면 각각의 문자열이 숫자 1, 2, 3으로 변환되고, 이를 list( )로 감싸면 [1, 2, 3]이라는 리스트를 얻을 수 있습니다. 따라서 결과는 [“1”, “2”, “3”]이 아닌 [1, 2, 3]입니다.

> **NOTE**
>
> 이때 map( ) 함수에 함수 자체를 전달할 때는 소괄호 없이 함수 이름만 넘긴다는 점에 주의하세요. add_delivery처럼

작성하면 함수 자체가 전달되지만, add_delivery( )처럼 소괄호를 붙이면 해당 위치에서 함수를 먼저 호출하게 됩니다.

map( )이 각 값에 함수를 적용하는 역할을 한다면, 이번에는 여러 값 중 필요한 값만 골라내는 filter( ) 함수를 살펴보겠습니다.

## filter( ) : 조건에 맞는 값만 걸러내기

map( ) 함수가 각 값에 함수를 적용했다면, 때로는 값을 바꾸는 것이 아니라 조건에 맞는 값만 골라내고 싶을 때가 있습니다. 점수 목록에서 합격 점수만 고르거나 상품 목록에서 특정 조건을 만족하는 상품만 골라내는 경우가 그렇습니다. 이럴 때 사용하는 함수가 filter( )입니다. 사용 방법은 map( )과 비슷하지만 동작 방식은 다릅니다. filter( )는 전달한 함수의 결과가 참으로 판단되는 원래의 요소만 골라냅니다.

```python filename="07-37-filter_examples.py"
scores = [85, 42, 77, 30, 96]

# ➊ 람다로 60점 이상인 점수만 추출passed = list(filter(lambda score: score >= 60, scores))
print(passed)

def is_even(number):        # ➋ 짝수면 True를 돌려주는 함수
  return number % 2 == 0

evens = list(filter(is_even, scores))
print(evens)
```

**실행 결과**

```text
[85, 77, 96]
[42, 30, 96]
```

❶ lambda가 score >= 60을 계산해 True나 False를 돌려줍니다. filter( ) 함수는 True가 나온 값만 남기므로 60점 이상인 85, 77, 96만 뽑혔습니다. map( ) 함수와 마찬가지로 결과를 리스트 형태로 확인하려면 list( )로 감싸줍니다.

❷ lambda 대신 def로 정의한 함수를 전달해도 같은 방식으로 동작합니다. is_even( ) 함수의 결과로 True가 되는 42, 30, 96만 남습니다. 조건이 길거나 여러 곳에서 재사용해야 한다면 이렇게 이름 있는 함수로 만드는 편이 읽기 좋습니다.

map( )과 filter( ) 함수는 함께 기억해두면 좋습니다. map( )은 각 요소에 함수를 적용하여 그 결과를 만들고, filter( )는 조건을 만족하는 원래의 요소만 골라냅니다. 두 함수의 차이를 기억해두면 여러 데이터를 처리할 때 유용하게 활용할 수 있습니다.

> **바로 핵심 요약**
>
> - 내장 함수는 파이썬이 미리 만들어 제공하는 함수로, 따로 정의하지 않고 바로 가져다 사용할 수 있습니다.
> - int( )는 값을 정수로 바꾸고(실수는 소수점을 버림), len( )은 길이나 개수를 구하며, max( )는 가장 큰 값을, sum( )은 모두 더한 값을 돌려줍니다.
> - map( )은 순회할 수 있는 값을 하나씩 꺼내 함수에 넣어 실행하고, filter( )는 그중 조건에 맞는 값만 남깁니다. 두 함수 모두 결과를 리스트로 보려면 list( )로 감싸야 합니다.
