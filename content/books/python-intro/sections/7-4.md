이제 함수의 매개변수를 자세히 알아볼 시간입니다. 함수는 프로그래밍의 핵심 문법인 만큼, 다양한 상황에서 유연하게 사용할 수 있도록 매개변수를 다루는 다양한 방법이 마련되어 있습니다. 함수 문법은 개발자의 편의성을 높이는 방향으로 계속 발전해왔으며, 그 덕분에 매개변수 역시 상황에 맞게 여러 방식으로 다채롭게 활용할 수 있습니다.

> **미리 알아두세요!**
>
> - 매개변수는 함수가 전달받을 값을 담는 변수이고, 인수는 호출할 때 실제로 전달하는 값입니다.
> - 키워드 인수, *args, 기본값, 람다 등 다양한 사용 방법이 있습니다.

## 매개변수 순서에 따라 인수를 전달하기, 위치 인수

앞에서 매개변수는 함수를 호출할 때 전달한 값을 함수 안에서 사용할 수 있도록 받아주는 변수라고 설명했습니다. 매개변수 덕분에 같은 함수를 사용해도 전달하는 값에 따라 다른 결과를 만들 수 있어 편리하죠. 이때 매개변수의 순서에 맞춰 인수를 전달하는 방식을 위치 인수 전달이라고 합니다.

```python
>>> def introduce(name, age, city):
...     print(f"제 이름은 {name}이고, {age}살이며, {city}에
살고 있습니다.")
>>> introduce("바로", 25, "서울")
>>> introduce("요즘", 30, "부산")
```

**실행 결과**

```text
제 이름은 바로이고, 25살이며, 서울에 살고 있습니다.
제 이름은 요즘이고, 30살이며, 부산에 살고 있습니다.
```

우리는 무의식적으로 매개변수 순서에 맞춰서 인수를 전달하고 있었으니 새로울 것도 없습니다. 빨리 다음으로 넘어가봅시다.

## 매개변수 개수에 맞춰 인수를 전달하지 않으면?

그렇다면 함수를 호출할 때 매개변수의 개수와 인수의 개수가 맞지 않으면 어떻게 될까요? 예를 들어 앞에서 작성한 함수에는 매개변수가 3개 있는데 인수를 2개만 전달해봅시다.

```python
>>> introduce("바로", 25)
```

**실행 결과**

```text
TypeError: introduce() missing 1 required positional argument: 'city'
```

오류 메시지가 나타났습니다. TypeError는 여러 상황에서 발생할 수 있는 오류이지만, 여기서는 함수 호출에 필요한 인수가 부족해서 발생했습니다. missing 1 required positional argument: ‘city’는 매개변수 city에 전달할 필수 위치 인수가 하나 빠졌다는 뜻입니다. 함수가 3개의 값을 필요로 하는데 2개만 전달했기 때문에 오류가 발생한 것입니다. 이처럼 함수를 정의할 때 정한 매개변수의 개수에 따라 호출할 때 전달해야 하는 인수의 개수가 정해지므로 주의해야 합니다.

반대로 인수를 너무 많이 전달해도 오류가 발생합니다.

```python
>>> introduce("바로", 25, "서울", "학생")
```

**실행 결과**

```text
TypeError: introduce() takes 3 positional arguments but 4 were given
```

이번에는 introduce( ) takes 3 positional arguments but 4 were given이라는 메시지가 나왔습니다. 함수가 받을 수 있는 위치 인수는 3개인데 4개를 전달했다는 뜻입니다. 지금처럼 기본값이 없는 매개변수만 있는 함수를 호출할 때는 정의된 매개변수의 개수와 정확히 일치하는 개수의 인수를 전달해야 한다는 점을 꼭 기억해두세요.

![](/books/python-intro/p318-208.webp)

## 인수의 순서를 반대로 전달하면 어떻게 될까?

매개변수와 인수의 개수가 일치하면 함수 호출에 문제가 없다는 것을 알았습니다. 그렇다면 개수는 맞지만 매개변수와 인수의 순서를 바꿔서 전달하면 어떻게 될까요? 파이썬이 인수의 의미를 알아서 판단해 넣어줄까요, 아니면 작성한 순서 그대로 전달할까요? 인수의 순서가 얼마나 중요한지 코드로 확인해봅시다.

```python
>>> def introduce(name, age, city):
...     print(f"제 이름은 {name}이고, {age}살이며, {city}에 살고 있습니다.")
>>> introduce("서울", 25, "바로")
```

**실행 결과**

```text
제 이름은 서울이고, 25살이며, 바로에 살고 있습니다.
```

오류는 발생하지 않았지만 결과가 이상합니다. ‘제 이름은 서울이고’라니! “서울”이 이름으로 들어가버렸네요. 파이썬은 인수를 전달한 순서대로 매개변수에 할당합니다. 첫 번째 인수 “서울”은 첫 번째 매개변수 name에 들어가고, 두 번째 인수 25는 age에, 세 번째 인수 “바로”는 city에 들어간 겁니다. 조금 더 명확하게 문제를 확인할 수 있는 예제를 하나 더 살펴봅시다.

```python filename="07-15-discount_argument_order.py"
def calculate_discount(price, discount_rate):
  result = price - (price * discount_rate)
  return result

wrong_result = calculate_discount(0.2, 10000)
correct_result = calculate_discount(10000, 0.2)

print(f"순서를 바꾼 결과: {wrong_result}원")
print(f"올바른 순서의 결과: {correct_result}원")
```

**실행 결과**

```text
순서를 바꾼 결과: -1999.8원
올바른 순서의 결과: 8000.0원
```

할인 계산 함수에서 가격과 할인율의 순서를 바꿔 전달했더니 -1999.8원이라는 이상한 결과가 나왔습니다. 가격으로 사용해야 할 값과 할인율로 사용해야 할 값이 뒤바뀌었기 때문입니다. 올바른 순서로 10000과 0.2를 전달하면 20% 할인이 적용된 8000이라는 결과가 나옵니다.

이처럼 위치 인수는 간단하지만 순서를 정확하게 기억해야 한다는 단점이 있습니다. 그렇다면 순서를 신경 쓰지 않고도 어느 매개변수에 값을 넣을지 직접 지정할 수는 없을까요?

## 키워드 인수 알아보기

앞에서 인수의 순서를 바꾸면 예상하지 못한 결과가 나올 수 있다는 것을 확인했습니다. 파이썬에서는 이런 문제를 줄이기 위해 **매개변수 이름을 직접 지정하여 인수를 전달하는 키워드 인수**(keyword) (argument)**를 사용할 수 있습니다.** 말 그대로 매개변수를 키워드라고 생각하고 인수와 함께 사용하는 방식이죠. 예를 들어 name=”바로”처럼 매개변수 이름과 전달할 값을 함께 작성합니다. 이렇게 하면 인수를 작성한 순서와 관계없이 원하는 매개변수에 정확하게 값을 전달할 수 있습니다. 다음 코드로 확인해봅시다.

```python filename="07-16-keyword_arguments.py"
def introduce(name, age, city):
  print(f"제 이름은 {name}이고, {age}살이며, {city}에 살고 있습니다.")

introduce(name="바로", age=25, city="서울")
introduce(city="부산", name="요즘", age=30)
introduce(age=28, city="대구", name="편집자P")
```

**실행 결과**

```text
제 이름은 바로이고, 25살이며, 서울에 살고 있습니다.
제 이름은 요즘이고, 30살이며, 부산에 살고 있습니다.
제 이름은 편집자P이고, 28살이며, 대구에 살고 있습니다.
```

매개변수 이름을 명시했기 때문에 순서를 바꿔도 모두 올바른 결과가 나옵니다. 두 번째 호출에서는 city를 가장 먼저 썼지만 “부산”이 정확하게 city에 전달되었고, 세 번째 호출에서는 age를 먼저 썼지만, 역시 제대로 작동했습니다.

위치 인수와 키워드 인수를 함께 사용할 수도 있습니다. 다음 코드는 처음 두 개를 위치 인수로 전달하고, 나머지를 키워드 인수로 전달한 예입니다. 이때 일반적인 함수 호출에서는 위치 인수를 먼저 작성하고 그 뒤에 키워드 인수를 작성해야 합니다. 키워드 인수를 먼저 쓴 뒤 위치 인수를 작성하면 문법 오류가 발생하므로 주의하세요.

```python
>>> def make_profile(name, age, city, hobby):
...     print(f"{name}({age}세)는 {city}에 살며 {hobby}를 좋아합니다.")
>>> make_profile("바로", 25, city="서울", hobby="독서")
```

**실행 결과**

```text
바로(25세)는 서울에 살며 독서를 좋아합니다.
```

지금까지 다룬 함수들은 모두 매개변수의 개수가 딱 정해져 있었습니다. 하지만 상황에 따라 인수가 몇 개나 들어올지 미리 예측하기 어려울 때가 있습니다. 이어지는 내용에서 살펴봅시다.

![](/books/python-intro/p321-209.webp)

## *args 알아보기

지금까지는 함수를 정의할 때 매개변수의 개수를 정해두고, 호출할 때도 그에 맞춰 인수를 전달했습니다. 하지만 때로는 함수를 호출할 때 몇 개의 인수가 전달될지 미리 알 수 없는 상황도 있습니다. 예를 들어 여러 숫자를 더하는 함수를 만든다고 해봅시다. 어떤 때는 숫자 2개를 더하고, 어떤 때는 10개를 더해야 할 수도 있습니다. 이때 매개변수를 몇 개 만들어야 할까요?

![](/books/python-intro/p321-210.webp)

파이썬에서는 매개변수 이름 앞에 *args를 붙이면 개수에 상관없이 여러 개의 인수를 받을 수 있습니다. 인수를 몇 개 전달하든 함수가 작동하는지 코드로 확인해봅시다.

> **NOTE**
>
> *args가 아니라 *numbers와 같이 다른 이름을 매개변수 앞에 *를 붙이면 전달된 다른 매개변수에

사용해도 됩니다. 중요한 것은 이름이 아니라 앞에 붙는 *입배정되지 않은 인수가 튜플 형태로 묶여 해당 매개변수에 니다.

전달되는 원리입니다.

```python filename="07-17-variadic_add_numbers.py"
def add_numbers(*numbers):
  total = 0
  for num in numbers:
    total = total + num
  return total

result1 = add_numbers(1, 2, 3)
result2 = add_numbers(10, 20, 30, 40, 50)
result3 = add_numbers(5)

print(f"세 개 더하기: {result1}")
print(f"다섯 개 더하기: {result2}")
print(f"한 개만: {result3}")
```

**실행 결과**

```text
세 개 더하기: 6
다섯 개 더하기: 150
한 개만: 5
```

코드를 실행해보면 add_numbers(1, 2, 3)처럼 숫자 3개를 전달했을 때 함수 안에서 numbers는 (1, 2, 3)이라는 튜플이 됩니다. 따라서 for num in numbers:와 같이 반복문을 사용해 전달된 숫자를 하나씩 꺼내 더할 수 있습니다. 이렇게 *args를 사용하면 함수 호출 시 인수 개수를 미리 정하지 않아도 되므로 함수를 더욱 유연하게 사용할 수 있습니다.

> **NOTE**
>
> add_numbers(1, 2, 3, 4, 5)도 같은 방식으로 동작합니다.

![](/books/python-intro/p323-211.webp)

```python
def make_profile(name, **info):
  print(f"{name} 님의 프로필")
  for key, value in info.items():
    print(f"  {key} : {value}")
make_profile("바로", age=25, city="서울")
make_profile("요즘", age=30, city="부산", hobby="독서")
```

**실행 결과**

```text
바로 님의 프로필
  age : 25
  city : 서울
요즘 님의 프로필
  age : 30
  city : 부산
  hobby : 독서
```

## 매개변수에 전달할 인수 미리 지정해두기

지금까지는 함수를 호출할 때 매개변수에 해당하는 인수를 빠짐없이 전달했습니다. 하지만 어떤 매개변수는 대부분 같은 값을 쓰고 가끔만 다른 값을 쓰기도 합니다. 예를 들어 카페에서 음료를 주문할 때, 대부분의 사람은 기본 사이즈와 기본 샷 개수로 주문하고 특별한 경우에만 사이즈나 샷을 바꿉니다. 그런데 매번 사이즈와 샷 개수를 일일이 전달해야 한다면 번거롭겠죠. 이럴 때 함수를 정의하는 단계에서 매개변수에 기본값을 미리 지정할 수 있습니다. 기본값을 정해두면 호출할 때 해당 인수를 생략할 수 있고, 생략한 자리에는 미리 정해둔 값이 자동으로 사용됩니다. 코드로 확인해봅시다.

> **NOTE**
>
> 기본값은 매개변수=기본값 형태로 지정합니다.

```python filename="07-18-default_parameters.py"
def order(menu, size="톨", shots=2):
  print(f"주문: {menu} / {size} 사이즈 / 샷 {shots}개")

order("아메리카노")
order("라떼", "그란데")
order("아메리카노", "벤티", 3)
```

**실행 결과**

```text
주문: 아메리카노 / 톨 사이즈 / 샷 2개
주문: 라떼 / 그란데 사이즈 / 샷 2개
주문: 아메리카노 / 벤티 사이즈 / 샷 3개
```

코드를 실행해보면 order("아메리카노")처럼 음료 이름만 전달해도 잘 동작하는 것을 알 수 있습니다. 함수를 정의할 때 size와 shots의 기본값을 각각 "톨"과 2로 미리 지정했기 때문이죠. 만약 order("라떼", "그란데")처럼 함수를 호출하면 size만 "그란데"로 바뀌고 shots에는 여전히 기본값인 2가 사용됩니다. 이처럼 매개변수에 기본값을 미리 지정하면, 자주 사용하는 값은 생략하고 필요한 값만 바꿔 전달할 수 있습니다.

> **NOTE**
>
> 기본값이 있는 매개변수는 항상 기본값이 없는 매개변수보다 뒤에 와야 합니다. 따라서 def order(size="톨", menu)

처럼 쓰면 오류가 발생합니다.

여기까지 여러 방식으로 매개변수를 사용하는 방법을 알아봤습니다. 이제 잠시 방향을 바꿔, 아주 짧은 함수를 간단하게 표현하는 방법도 살펴보겠습니다.

![](/books/python-intro/p324-212.webp)

> **바로 핵심 요약**
>
> - 매개변수는 함수가 전달받을 값을 담는 변수이고, 인수는 함수를 호출할 때 실제로 전달하는 값입니다. 기본이 되는 위치 인수는 개수와 순서를 맞춰야 합니다.
> - 반면 키워드 인수는 매개변수 이름을 직접 지정하므로 순서와 상관없이 값을 전달할 수 있습니다. 또한 매개변수에 미리 기본값을 설정해두면 함수를 호출할 때 해당 인수를 생략할 수 있습니다.
> - *args는 개수가 정해지지 않은 인수를 튜플로 묶어 받고, **kwargs는 이름이 붙은 인수를 딕셔너리로 묶어 받습니다.
