### 객관식 문제

01 다음 중 실수(float)에 해당하는 값을 고르세요.

① 10 ② 3.14 ③ "3.14" ④ True

02 다음 코드의 실행 결과로 알맞은 것을 고르세요.

```python
print(7 // 2, 7 % 2, 2 ** 3)
```

① 3.5 1 6 ② 3 1 8 ③ 3 1 6 ④ 3.5 1 8

03 다음 코드의 실행 결과로 알맞은 것을 고르세요.

```python
print("10" + "20")
```

① 30 ② 1020 ③ 10 20 ④ 오류가 발생합니다

04 다음 코드의 실행 결과로 알맞은 것을 고르세요.

```python
print("파이" in "파이썬 공부 중")
```

① True ② False ③ 파이 ④ 오류가 발생합니다

05 다음 코드의 실행 결과로 알맞은 것을 고르세요.

```python
lang = "Python"
print(lang[1:4])
```

① Pyt ② yth ③ ytho ④ Pyth

06 문자열 함수에 대한 설명으로 옳지 않은 것을 고르세요.

① len( ) 함수는 문자열의 길이를 알려줍니다.

② upper( ) 함수는 모든 문자를 대문자로 바꿔줍니다.

③ find( ) 함수는 찾는 문자열이 시작하는 위치를 알려줍니다.

④ replace( ) 함수는 원래 문자열 자체를 바꿔 저장합니다.
