앞에서 식별자를 이야기하면서 스네이크 케이스와 캐멀 케이스를 이야기했습니다. 스네이크 케이스는 변수나 함수의 이름을 지를 때 사용합니다. 함수는 아직 배운적이 없지만 이름을 짓는 방법을 공부하는 김에 한 번 살펴봅시다. this\_is\_name과 같이 단어를 언더스코어 \_로 구분하여 짓습니다. 그리고 캐멀 케이스는 클래스의 이름을 지를 때 사용합니다. ThisIsName과 같이 단어를 대문자로 구분하여 짓는 방식을 말합니다. 스네이크 케이스, 캐멀 케이스라는 이름이 붙은 이유는 마치 식별자의 모양이 뱀이나 낙타 같다고 하여 붙은 이름입니다.

## 변수명에 스네이크 케이스 사용하기

다음은 변수명에 스네이크 케이스를 사용한 예입니다. 코드에서 보는 것처럼 의미 있는 단어를 언더스코어 \_로 연결했습니다.

```python
student_name = "바로"
total_score = 95
user_email = "<editor_p@example.com>"
```

```python
def calculate_average():
    pass

def get_user_info():
    pass
```
