코드를 작성하다 보면 변수나 함수에 이름을 붙일 일이 계속 생깁니다. 이름을 잘 지어두면 나중에 코드를 다시 읽을 때 의미를 한눈에 파악할 수 있죠. 파이썬 개발자들이 약속처럼 따르는 이름 짓기 관례를 알아봅시다. 강제 규칙이 아닌 권장 사항이므로 부담 없이 읽어보세요!

> **미리 알아두세요!**
>
> - 파이썬에서는 변수와 함수 이름에 스네이크 케이스를 사용합니다.
> - 클래스 이름에는 캐멀 케이스를 사용합니다.

앞서 식별자를 다루며 **스네이크 케이스**와 **캐멀 케이스**를 이야기했습니다. 스네이크 케이스는 변수나 함수의 이름을 지을 때 사용합니다. 스네이크 케이스는 this_is_name과 같이 단어 사이를 밑줄 _로 구분하여 작성합니다. 아직 함수를 배우기 전이지만 이름 짓는 방법을 공부하는 김에 함께 살펴봅시다. 반면 캐멀 케이스(정확히는 첫 글자까지 대문자로 쓰는 파스칼 케이스)는 클래스의 이름을 지을 때 사용합니다. ThisIsName과 같이 단어마다 첫 글자를 대문자로 구분하여 짓는 방식을 말합니다. 스네이크 케이스와 캐멀 케이스라는 이름은 식별자의 모양이 각각 뱀이나 낙타의 등과 닮았다고 해서 붙었습니다.

## 변수명에 스네이크 케이스 사용하기

다음은 변수명에 스네이크 케이스를 적용한 예입니다. 코드에서 보는 것처럼 의미 있는 단어를 밑줄 _로 연결했습니다.

```python
>>> student_name = "바로"
>>> total_score = 95
>>> user_email = "editor_p@example.com"
```

## 함수명에 스네이크 케이스 사용하기

함수명에 스네이크 케이스를 사용한 예도 살펴봅시다. 참고로 코드에 표시된 pass는 ‘아무 작업도 하지 않고 그냥 넘어가라’는 뜻의 키워드입니다. 아직 문법을 다 배우지 않았으므로, 지금은 함수의 이름 짓기 방식에 집중하여 보면 됩니다.
