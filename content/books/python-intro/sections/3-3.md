가장 먼저 배울 자료형은 숫자입니다. 숫자는 계산이라는 프로그래밍의 가장 기본적인 작업을 담당합니다. 수학 시간에 본 숫자 개념과 크게 다르지 않으므로 어렵지 않게 따라올 수 있을 겁니다. 파이썬에서 숫자는 정수, 실수, 복소수로 나뉩니다. 다만 복소수는 실무에서 거의 쓰일 일이 없어 표기와 자료형만 간단히 살펴보고, 정수와 실수를 중심으로 다룹니다. 다음 그림과 같이 소수점 없이 적은 8 또는 -20 같은 값을 정수, 1.5나 25.0 같은 값을 실수로 다룹니다.

> **미리 알아두세요!**
>
> - 파이썬의 숫자는 크게 정수와 실수로 나뉩니다.
> - 숫자는 변수에 저장해두고 계산에 바로 사용할 수 있습니다.

![](/books/python-intro/p108-090.webp)

숫자의 개념은 이것으로 끝입니다. 다만 파이썬에서 숫자를 다루는 방식은 조금 복잡합니다. 하나씩 천천히 알아보고 연습해봅시다.

## 숫자를 변수에 저장하기

변수에 정수를 저장하는 기본 형태부터 다시 살펴봅시다. 앞서 간단하게 다뤘던 내용이므로 복습한다는 생각으로 따라 해보세요.

```python filename="03-04-integer_variable.py"
age = 25
print(age)
```

**실행 결과**

```text
25
```

age = 25처럼 소수점이 없는 값을 넣으면 파이썬은 이 값을 정수로 인식하여 저장합니다.

```python filename="03-05-float_variable.py"
age = 25.0
print(age)
```

**실행 결과**

```text
25.0
```

반면 age = 25.0과 같이 소수점을 붙여 입력하면 정수가 아닌 실수로 취급합니다. 이처럼 숫자를 저장할 때 파이썬이 값을 정수와 실수 중 무엇으로 다루느냐에 따라 향후 연산 방식이 달라지므로, 이 차이를 유의하는 것이 좋습니다.

## 얼마나 큰 수까지 저장할 수 있을까?

그렇다면 파이썬은 얼마나 큰 수까지 저장할 수 있을까요? 최신 버전인 파이썬 3을 기준으로, 정수는 컴퓨터 메모리가 허용하는 한 얼마든지 큰 수까지 저장할 수 있습니다. 따라서 운영체제가 32비트인지 64비트인지가 파이썬 정수의 최댓값을 직접 결정하지는 않습니다. 다만 시스템 환경을 확인할 때 쓰이는 **sys.maxsize는 정수의 최댓값이 아니라, 현재 환경에서 사용할 수 있는 인덱스 크기의 상한을 나타냅니다.** 그래도 현재 환경을 기준으로 자주 쓰이는 큰 정수를 확인할 때 유용합니다. 다음 코드로 값을 출력해봅시다.

```python filename="03-06-sys_maxsize.py"
import sys
print(sys.maxsize)
```

import는 파이썬에서 필요한 기능을 불러올 때 사용하는 명령어로, sys.maxsize 값을 확인하기 위해 sys를 불러옵니다

**실행 결과**

```text
9223372036854775807
```

앞의 코드는 sys.maxsize에 저장된 값을 직접 출력한 것입니다. 이번에는 일반적인 64비트 환경에서 같은 값이 어떤 계산으로 나오는지 확인해봅시다.

```python filename="03-07-integer_max.py"
print(2**63-1)
```

**실행 결과**

```text
9223372036854775807
```

2**63-1에서 **는 거듭제곱 연산자입니다. 64비트 환경에서 2**63-1을 연산하면 9223372036854775807이라는 값이 나옵니다. 이 값이 sys.maxsize와 같게 나올 수 있지만, 이것이 파이썬 정수가 저장할 수 있는 최댓값을 뜻하지는 않습니다. 파이썬 3의 정수는 메모리가 허용하는 범위에서 이보다 큰 수도 얼마든지 다룰 수 있습니다.

## 숫자 종류 확인해보기

앞서 파이썬이 수를 저장할 때 어떤 종류로 취급할지 값을 보고 정한다고 했습니다. 그렇다면 해당 숫자를 파이썬이 실제 무엇으로 취급하고 있는지 어떻게 확인할 수 있을까요? 바로 type( ) 함수를 사용하면 됩니다. 검사할 내용을 type(12)와 같이 소괄호 안에 적어 실행하기만 하면 됩니다. 이처럼 소괄호 안에 값을 넣어 특정 작업을 실행하도록 만든 문법 구조를 함수라고 합니다. 앞서 자주 사용했던 print( ) 역시 대표적인 함수 중 하나입니다. 함수의 구체적인 개념과 활용법은 나중에 자세히 배울 예정이므로 우선은 파이썬이 숫자 데이터를 어떻게 구분하고 인식하는지 확인하는 것에만 집중합시다.

### 정수는 int

다음과 같이 type(12) 코드를 실행하면 결과로 <class 'int'>가 출력됩니다. class라는 표현과 <와 >로 감싼 형태가 어색해보일 수 있지만 핵심은 ‘int’입니다. int는 정수를 뜻하는 영어 단어 integer의 앞 세 글자를 딴 것으로, ‘인트’라고 읽습니다. 따라서 결과에 표시된 int는 파이썬이 숫자 12를 정수로 인식하고 있다는 뜻이죠.

간단히 확인만 할 때는 인터프리터 셸에서 실행해도 됩니다

```python filename="03-08-type_integer.py"
print(type(12))
```

**실행 결과**

```text
<class 'int'>
```

### 실수는 float

그렇다면 소수점이 있는 type(3.14)를 실행하면 어떻게 나올까요? 결과는 ‘float’이네요.

```python filename="03-09-type_float.py"
print(type(3.14))
```

**실행 결과**

```text
<class 'float'>
```

실수는 영어로 real number인데, 왜 파이썬에서는 real이 아니라 float이라고 부를까요? 그 이유는 컴퓨터가 실수를 표현할 때 사용하는 방식을 부동소수점(floating point)이라고 부르기 때문입니다. 여기서 ‘부동’은 부유하다, 동동 떠다닌다라는 의미로, 소수점의 위치가 고정되어 있지 않고 자유롭게 움직인다는 뜻을 담고 있습니다. 이는 실수를 가수 × 밑수(지수)로 표현하는 방식에서 떠올린 아이디어로 다음과 같이 나타낼 수 있습니다.

![](/books/python-intro/p111-091.webp)

예를 들어 123.45는 1.2345 × 10²으로 나타낼 수 있고, 12.345 × 10¹로도 나타낼 수 있습니다. 이렇게 소수점의 위치가 둥둥 떠다니듯 바뀌어도 10의 거듭제곱을 조절하면 같은 수를 표현할 수 있다고 해서 실수에 floating point라는 이름을 붙인 겁니다.

### 복소수는 complex

복소수는 실수와 허수를 합친 수로, 파이썬에서는 4 + 3j처럼 소문자 j를 붙여 나타냅니다. 보통 수학에서는 i를 사용하지만 파이썬에서는 j를 사용하는 점이 다릅니다. 예를 들어 type(4 + 3j)를 실행하여 결과를 보면 ‘complex’입니다. 복소수는 여러분이 전문 분야에서 일하지 않는 이상 거의 쓸 일이 없습니다. 복소수란 무엇인지 간단하게 확인만 하고 넘어가도 됩니다.

```python filename="03-10-type_complex.py"
print(type(4 + 3j))
```

**실행 결과**

```text
<class 'complex'>
```

지금까지 파이썬의 숫자 종류를 모두 알아보았습니다. 이제는 이 수들로 어떻게 계산하는지 배울 차례네요. 기본적인 사칙연산부터 몫, 나머지 구하기, 거듭제곱 등 다양한 계산을 해봅시다.

## 연습 01 기본 사칙연산 해보기

기본적인 사칙연산부터 시작해봅시다.

```python filename="03-11-basic_arithmetic.py"
a = 20
b = 7
print(f"{a} + {b} = {a + b}")
print(f"{a} - {b} = {a - b}")
print(f"{a} × {b} = {a * b}")
print(f"{a} ÷ {b} = {a / b}")
```

**실행 결과**

```text
20 + 7 = 27
20 - 7 = 13
20 × 7 = 140
20 ÷ 7 = 2.857142857142857
```

그렇다면 정수와 실수를 함께 더하면 어떻게 될까요? 결과가 정수로 나올까요, 아니면 실수로 나올 까요?

```python filename="03-12-int_float_add.py"
a = 20
b = 12.1

print(f"{a} + {b} = {a + b}")
```

**실행 결과**

```text
20 + 12.1 = 32.1
```

파이썬에서 정수와 실수를 더하면 정수를 실수 형태로 바꾸어 계산하기 때문에 결과는 실수가 나옵니다. 또한 파이썬의 / 연산자는 정수끼리 나누어도 실수를 반환합니다.

```python filename="03-13-mixed_number_arithmetic.py"
print(5 + 2.5)
print(10 - 3.2)
print(4 * 1.5)
print(15 / 3)       # 정수끼리 나누어도 실수를 결과로 반환
print(20 / 2.5)
```

**실행 결과**

```text
7.5
6.8
6.0
5.0
8.0
```

**특히 4 곱하기 1.5를 계산한 결과가 6이 아니라 6.0인 점에 주목하기 바랍니다.** 직관적으로 6이나 6.0이나 같아 보이지만 파이썬은 계산하는 값 중 하나라도 실수이면 결과를 실수로 돌려주므로 6.0이 됩니다.

## 연습 02 몫, 나머지 연산해보기

다음은 몫과 나머지 연산입니다. 몫은 // 연산자로 계산하고 나머지는 % 연산자로 구합니다. 몫과 나머지 연산은 조금 비중 있게 연습하겠습니다. 짝수와 홀수 판별, 자릿수 분리처럼 꽤 실용적인 작업에 자주 쓰이므로 예제로 충분히 연습해봅시다. 짝수와 홀수를 판별할 때는 2로 나눈 나머지가 0인지 아닌지만 확인하면 됩니다. 2로 나누어 나머지가 0이면 짝수, 0이 아니면 홀수입니다.

```python filename="03-14-odd_even.py"
number = 17
if number % 2 == 0:
 print(f"{number}는 짝수")
else:
 print(f"{number}은 홀수") # 여기가 출력
```

**실행 결과**

```text
17은 홀수
```

> **NOTE**
>
> if-else 문은 조건식이 맞을 때는 if 문 내의 코드 블록을 실행하고, 맞지 않을 때는 else 문 내의 코드 블록을 실행하는

유용한 구문입니다. 이 부분은 에서 자세히 배우겠습니다.

자릿수 분리의 경우 1의 자리는 10으로 나눈 나머지로 쉽게 구할 수 있습니다. 10의 자리는 10으로 나눈 몫을 다시 10으로 나눈 나머지를 구하면 되고, 세 자리 양의 정수에서 백의 자리는 100으로 나눈 몫입니다.

```python filename="03-15-digit_split.py"
number = 123
ones = number % 10 # 1의 자리는 10으로 나눈 나머지(%)
print(f"일의 자리: {ones}")
tens = (number // 10) % 10 # 10의 자리는 10으로 나눈 몫(//)을 10으로 나눈 나머지(%)
print(f"십의 자리: {tens}")
hundreds = number // 100 # 100의 자리는 100으로 나눈 몫(//)
print(f"백의 자리: {hundreds}")
# 최종 출력(f-string 사용)
print(f"분리된 숫자: {hundreds}, {tens}, {ones}")
```

**실행 결과**

```text
일의 자리: 3
십의 자리: 2
백의 자리: 1
분리된 숫자: 1, 2, 3
```

> **NOTE**
>
> 물론 반복문을 활용하면 훨씬 더 효율적으로 작성할 수 있겠지만 아직 반복문을 배우기 전이므로 이 정도로 연습만 해

보고 넘어가겠습니다.

## 연습 03 거듭제곱 연산해보기

거듭제곱 연산도 해봅시다. 거듭제곱 연산은 복잡한 계산을 하기보다는 문법의 형태를 확인하는 수준으로 간단히 연습하겠습니다.

```python filename="03-16-power.py"
# 거듭제곱 연산자 **를 사용하여 2의 3제곱 계산하기
base = 2
exponent = 3
result = base ** exponent
print(f"{base}의 {exponent}제곱: {result}")
```

**실행 결과**

```text
2의 3제곱: 8
```

> **NOTE**
>
> 아직 배운 문법이 많지 않아 지금 단계에서는 거듭제곱을 활용한 의미 있는 예제를 실습하기 어렵습니다.

이 정도까지 공부했으면 숫자 자료형의 기초는 충분히 다진 셈입니다. 이제 다음 단계인 문자열을 공부하러 넘어가 봅시다.

> **바로 핵심 요약**
>
> - 사칙연산은 +, -, *, / 연산자로 계산합니다.
> - 몫은 //, 나머지는 %, 거듭제곱은 ** 연산자로 계산합니다.
> - 정수와 실수를 함께 계산하거나 / 연산자로 나누면 결과는 실수가 됩니다.
