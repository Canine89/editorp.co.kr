## 한 개의 파일로 메모장 프로그램 만들기

이제 파이썬으로 진짜 쓸모 있는 도구를 만들 수 있습니다. 간단하지만 핵심 기능은 모두 갖춘 메모장 앱을 파이썬 파일 하나로 깔끔하게 구현해보겠습니다.

앞에서 만든 memo_project 폴더에 11-12-memo_app.py 파일을 만든 뒤 다음 코드를 입력하고 실행해봅시다. 인공지능이 코드를 대신 작성해주는 시대에 직접 타이핑하는 일이 조금 지루하게 느껴질 수도 있지만, 이번에는 코드의 구조가 어떻게 달라지는지 확인하는 과정이므로 꼭 직접 따라 입력해보기 바랍니다.

```python filename="11-12-memo_app.py"
from pathlib import Path

MEMO_FILE = Path("memo.txt")  # ➊ 메모 파일 경로


def save_memo(content):  # ➋ 저장 함수 정의
  with MEMO_FILE.open("a", encoding="utf-8") as file:
    file.write(content + "\n")


def read_memos():  # ➌ 읽기 함수 정의
  if not MEMO_FILE.exists():
    return "저장된 메모가 없습니다."
  return MEMO_FILE.read_text(encoding="utf-8").rstrip()


def main():  # ➍ 메뉴 프로그램 정의
  while True:
    print("메모장 프로그램")
    print("1. 메모 저장")
    print("2. 메모 보기")
    print("3. 종료")
    menu = input("메뉴를 선택하세요: ")

    if menu == "1":
      content = input("메모를 입력하세요: ")
      if content.strip():
        save_memo(content)
        print("메모를 저장했습니다.")
      else:
        print("빈 메모는 저장할 수 없습니다.")
    elif menu == "2":
      print("[저장된 메모]")
      print(read_memos())
    elif menu == "3":
      print("메모장을 종료합니다.")
      break
    else:
      print("1~3 중에서 선택하세요.")


if __name__ == "__main__":  # ➎ 프로그램 시작
  main()
```

❶ Path 인스턴스로 메모를 저장할 memo.txt 파일의 경로를 준비합니다. 파일이 아직 없어도 메모를 처음 저장할 때 자동으로 만들어집니다.

❷ save_memo( ) 함수는 전달받은 메모를 memo.txt 파일의 마지막 줄에 추가합니다.

❸ read_memos( ) 함수는 memo.txt 파일이 없으면 안내 문장을 반환하고, 파일이 있으면 저장된 내용을 읽어 반환합니다.

❹ main( ) 함수는 메뉴를 반복해서 보여주고 사용자가 선택한 기능을 실행합니다. 이 예제에서는 메뉴를 문자열로 입력받아 비교하므로 별도로 정수로 변환할 필요는 없습니다.

❺ 11-12-memo_app.py 파일을 직접 실행했을 때만 main( ) 함수를 호출해 프로그램을 시작합니다.

코드를 모두 작성해보니 어떤가요? 메모장 프로그램은 정상적으로 동작합니다. 하지만 한 파일 안에 메모를 저장하고 읽는 코드와 메뉴를 처리하는 코드가 함께 들어 있습니다. 만약 프로그램의 규모가 커지고 기능이 늘어나면 한 파일에 담긴 코드도 점점 길어집니다. 그러면 원하는 기능이 어디에 있는지 찾거나 특정 부분만 수정하기가 어려워져 유지보수도 복잡해집니다.

인공지능이 코드를 대신 작성하거나 수정할 때도 마찬가지입니다. 기능에 따라 파일이 잘 나뉘어 있고 각 모듈에 알맞은 이름이 붙어 있으면, 인공지능도 프로젝트의 구조와 코드의 역할을 더 쉽게 파악할 수 있겠죠. 결국 사람과 인공지능 모두 이해하기 쉬운 코드 구조가 필요한 셈입니다.

이제 프로그램의 동작은 그대로 유지하면서 메모를 저장하고 읽는 기능을 별도의 모듈로 옮겨보겠습니다.

## 저장과 읽기 기능을 모듈로 옮기기

11-12-memo_app.py와 같은 폴더에 memo_storage.py 파일을 만듭니다. 그런 다음 메모 파일 경로와 save_memo( ), read_memos( ) 함수를 11-12-memo_app.py에서 잘라내어 다음과 같이 memo_storage.py로 옮깁니다.

```python filename="memo_storage.py"
from pathlib import Path

MEMO_FILE = Path("memo.txt")  # ➊ 메모 파일 경로


def save_memo(content):  # ➋ 저장 함수 정의
  with MEMO_FILE.open("a", encoding="utf-8") as file:
    file.write(content + "\n")


def read_memos():  # ➌ 읽기 함수 정의
  if not MEMO_FILE.exists():
    return "저장된 메모가 없습니다."
  return MEMO_FILE.read_text(encoding="utf-8").rstrip()
```

❶ 메모 파일의 경로도 저장과 읽기 기능에서 사용하므로 memo_storage.py로 함께 옮깁니다.

❷ save_memo( ) 함수는 메모를 저장하는 일만 담당합니다. 01단계에서 작성한 함수의 코드는 바뀌지 않았습니다.

❸ read_memos( ) 함수도 그대로 옮겼습니다. 이제 memo_storage.py는 메모를 파일에 저장하고 읽는 기능만 담당합니다.

memo_storage.py에는 함수를 정의하는 코드만 있고 실행하자마자 출력하는 코드는 없습니다. 따라서 이 파일을 직접 실행해도 화면에는 별다른 내용이 나타나지 않습니다. 대신 다른 파일에서 필요한 함수를 가져와 사용할 수 있습니다. 이제 분리한 기능을 다시 메인 프로그램과 연결해봅시다.
