표준 라이브러리는 파이썬과 함께 제공되는 모듈과 패키지 등의 기능을 말합니다. 별도로 pip로 설치하지 않아도 import 문을 사용해 바로 가져올 수 있습니다. 여기서는 자주 사용하는 열두 가지를 골라 대표적인 기능을 하나씩 소개합니다. 더 다양한 기능이 궁금하다면 11장에서 살펴본 것처럼 파이썬 공식 문서에서 찾아보세요.

### math — 수학 계산

제곱근, 올림, 내림, 원주율 등 수학 계산에 쓰는 기능이 들어 있습니다.

```python
 import  math
print(math.sqrt(16))
print(math.ceil(3.2))
print(math.floor(3.9))
```

**실행 결과**

```text
4.0
4
3
```

### random — 무작위 값

주사위, 뽑기, 섞기처럼 무작위가 필요한 곳에 사용합니다.

```python
 import  random
print(random.randint(1, 6))
print(random.choice(["가위", "바위", "보"]))
```

**실행 결과**

```text
4
바위
```

실행할 때마다 결과가 달라질 수 있으므로 책과 다르게 나오는 것이 정상입니다.

### datetime — 날짜와 시간

날짜를 만들고 계산할 때 사용합니다.

```python
 from datetime import date, timedelta
today = date(2026, 8, 2)
print(today)
print(today + timedelta(days=7))
```

**실행 결과**

```text
2026-08-02
2026-08-09
```

### time — 시간 지연

코드를 잠시 멈추게 할 때 사용합니다.

```python
 import  time
print("시작")
time.sleep(1)          # 1초 멈춤
print("끝")
```

**실행 결과**

```text
시작
끝
```

실행해보면 두 줄 사이에 1초의 간격이 생깁니다.

### os — 파일과 폴더

현재 폴더를 확인하거나 파일이 있는지 검사할 때 사용합니다.

```python
 import  os
print(os.getcwd())
print(os.path.exists("memo.txt"))
```

**실행 결과**

```text
C:\Users\baro\Desktop\pythonstudy
False
```

폴더 경로는 여러분의 실습 위치에 따라 다릅니다.

### sys — 파이썬 자체 정보

파이썬 실행 환경이나 실행할 때 받은 값을 다룰 때 사용합니다.

```python
 import  sys
print(sys.platform)
```

**실행 결과**

```text
win32
```

윈도우는 win32, macOS는 darwin이 출력됩니다. 명령줄 인수를 담는 sys.argv도 이 모듈에 들어 있습니다.

### json — 설정과 구조가 있는 데이터

딕셔너리나 리스트를 파일에 저장할 수 있는 형태로 바꿔 줍니다.

```python
 import  json
data = {"name": "바로", "scores": [90, 85]}
text = json.dumps(data, ensure_ascii=False)
print(text)
print(json.loads(text)["name"])
```

**실행 결과**

```text
{"name": "바로", "scores": [90, 85]}
바로
```

ensure_ascii=False를 적지 않으면 한글이 알아보기 어려운 기호로 바뀝니다.

### csv — 표 형태의 데이터

엑셀에서 열 수 있는 표 파일을 만들고 읽을 때 사용합니다.

```python
 import  csv
with open("scores.csv", "w", newline="", encoding="utf-8") as file:
  writer = csv.writer(file)
  writer.writerow(["이름", "점수"])
  writer.writerow(["바로", 90])
```

**실행 결과**

```text
[파일 : scores.csv]
이름,점수
바로,90
```

newline=""는 줄 사이에 빈 줄이 생기지 않게 하는 설정입니다. csv 파일을 쓸 때는 함께 적어 준다고 생각하면 됩니다.

### re — 정규 표현식

전화번호나 이메일처럼 일정한 형식을 가진 문자열을 찾거나 검사하고, 다른 문자열로 바꿀 때 사용합니다.

```python
 import  re
print(re.findall(r"\d+", "사과 3개, 바나나 12개"))
```

**실행 결과**

```text
['3', '12']
```

### pathlib — 경로 다루기

파일 경로를 문자열이 아닌 전용 자료형으로 다룹니다. 11장에서 다뤘습니다.

```python
 from pathlib import Path
memo = Path("memo.txt")
print(memo.stem)
print(memo.suffix)
```

**실행 결과**

```text
memo
.txt
```

### statistics — 통계

평균, 중앙값 등 기본적인 통계값을 구합니다. 11장에서 다뤘습니다.

```python
 from statistics import mean, median
print(mean([80, 90, 100]))
print(median([80, 90, 100]))
```

### collections — 개수 세기

값이 몇 번씩 나왔는지 세는 Counter가 특히 유용합니다.

```python
 from collections import Counter
print(Counter("바나나"))
print(Counter(["사과", "사과", "딸기"]))
Counter({'나': 2, '바': 1})
```

**실행 결과**

```text
Counter({'사과': 2, '딸기': 1})
```

반복문과 딕셔너리로 직접 세도 되지만 Counter를 쓰면 한 줄로 끝납니다.
