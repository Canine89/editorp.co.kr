try~except 문만으로도 예외를 처리할 수 있지만, 프로그램의 정상적인 흐름과 마무리 작업을 나누면 코드의 역할을 더 분명하게 나타낼 수 있습니다. 이번에는 예외가 발생하지 않았을 때 실행할 코드와 예외 발생 여부와 관계없이 마지막에 실행할 코드를 구분하는 방법을 알아보겠습니다. 이름보다 실행되는 조건과 순서에 집중하면 어렵지 않으니, 직접 실행하며 차이를 확인해봅시다!

> **미리 알아두세요!**
>
> - else 문은 오류가 발생하지 않았을 때 실행됩 니다.
> - finally 문은 오류 발 생 여부와 관계없이 마지막에 실행됩니다.

try~except 문에는 else 문과 finally 문을 함께 사용할 수 있습니다. else 문과 finally 문은 각각 다음과 같은 역할을 합니다.

- **else 문 :** try 문의 코드 블록이 예외 없이 정상적으로 끝났을 때 실행됩니다.
- **finally 문 :** 오류 발생 여부와 관계없이 항상 마지막에 실행됩니다.

글로만 읽으면 두 문이 비슷하게 느껴질 수 있지만 실행되는 조건은 분명히 다릅니다. 계산과 딕셔너리 조회 예제를 통해 실행 원리를 확인해봅시다.

## 오류가 발생하지 않으면 실행되는 else 문

다음 코드는 전체 금액을 사람 수로 나누는 데 성공했을 때만 한 사람당 금액을 출력합니다.

```python filename="10-12-else_success.py"
total_price = 12000
people = 3
try:
  price_per_person = total_price // people  # ➊ 나눗셈 실행
except ZeroDivisionError:
  print("사람 수는 0이 될 수 없습니다.")
else:
  print(f"한 사람당 금액: {price_per_person}원")  # ➋ 정상 결과 출력
```

**실행 결과**

```text
한 사람당 금액: 4000원
```

❶ 12000을 3으로 나눌 수 있으므로 ZeroDivisionError가 발생하지 않습니다.

❷ try 문의 코드 블록에서 오류가 발생하지 않았으므로 else 문의 코드 블록을 실행해 한 사람당 금액을 출력합니다.

이 코드는 else 문의 코드를 try 문 안에 모두 넣어도 실행 결과는 같습니다. 하지만 try 문에는 예외가 발생할 가능성이 있는 코드만 작성하는 것이 좋습니다. 그리고 작업이 정상적으로 끝났을 때 이어서 실행할 코드는 else 문에 작성하면 각 코드의 역할을 더 분명하게 나눌 수 있습니다. 그렇다면 people의 값을 0으로 바꾸면 어떻게 될까요? 직접 확인해봅시다.

```python filename="10-13-else_skipped.py"
total_price = 12000
people = 0
try:
  price_per_person = total_price // people
except ZeroDivisionError:
  print("사람 수는 0이 될 수 없습니다.")  # ➊ 예외 처리
else:
  print(f"한 사람당 금액: {price_per_person}원")
```

**실행 결과**

```text
사람 수는 0이 될 수 없습니다.
```

❶ 정수를 0으로 나눌 수 없으므로 ZeroDivisionError가 발생합니다. 이에 해당하는 except 문의 코드 블록이 실행되고 else 문의 코드 블록은 건너뜁니다.

이처럼 else 문은 try 문의 코드 블록이 예외 없이 정상적으로 끝났을 때 실행됩니다. 즉 정상적으로 처리된 뒤 이어서 수행할 작업을 구분해 작성하고 싶을 때 사용할 수 있습니다. 그러면 finally 문은 어떻게 다를까요?

## 오류가 발생하거나 말거나 항상 실행되는 finally 문

finally 문의 코드 블록은 오류가 발생한 경우에도 실행되고, 오류가 발생하지 않아도 실행됩니다. 따라서 else 문과 달리 작업의 성공 여부와 관계없이 마지막에 수행해야 할 코드를 작성할 때 사용할 수 있습니다. 예를 들어 프로그램에서 사용한 자원을 정리하거나 작업이 끝났다는 사실을 기록하는 등의 용도로 활용할 수 있습니다. 다음 코드는 딕셔너리에서 두 반려동물의 나이를 차례대로 찾습니다. 조회에 성공했는지와 관계없이 마지막에는 확인을 마쳤다는 문장을 출력합니다.

```python filename="10-14-finally_flow.py"
pet_ages = {"초코": 3, "보리": 5}
pet_names = ["초코", "별"]
for pet_name in pet_names:
  print(f"이름: {pet_name}")
  try:
    age = pet_ages[pet_name]             # ➊ 나이 조회 시도
  except KeyError:
    print("나이를 찾을 수 없습니다.")      # ➋ 오류 발생 흐름
  else:
    print(f"나이: {age}살")              # ➌ 정상 실행 흐름
  finally:
    print("나이 확인을 마쳤습니다.")       # ➍ 공통 마무리 흐름
```

**실행 결과**

```text
이름: 초코
나이: 3살
나이 확인을 마쳤습니다.
이름: 별
나이를 찾을 수 없습니다.
나이 확인을 마쳤습니다.
```

❶ pet_ages 딕셔너리에서 pet_name과 같은 키의 값을 가져오려고 시도합니다.

❷ "별"이라는 키는 없으므로 KeyError가 발생하고 해당 except 문의 코드 블록에서 처리합니다.

❸ "초코"라는 키는 있으므로 예외가 발생하지 않고, else 문의 코드 블록에서 나이를 출력합니다.

❹ 두 경우 모두 마지막에는 finally 문의 코드 블록이 실행됩니다. 따라서 "나이 확인을 마쳤습니다."라는 문장은 매번 출력됩니다.

정리하면 try~except 문에 else 문과 finally 문을 반드시 사용해야 하는 것은 아닙니다. 필요한 상황에 따라 선택해서 사용하면 됩니다. 정상적으로 실행되었을 때의 작업과 예외 처리를 나눌 필요가 있을 때는 else 문을 사용하고, 성공과 실패에 관계없이 실행할 코드가 있다면 finally 문을 사용하면 됩니다.

## 실행 순서 정리하기

try~except~else~finally 문의 기본적인 실행 순서를 정리하면 다음과 같습니다.

1. try 문의 코드 블록을 먼저 실행합니다. 2. try 문에서 오류가 발생하면 일치하는 except 문을 찾아 실행합니다. 일치하는 except 문이 없다면 예외는 바깥으로 전달됩니다. 3. try 문의 코드 블록이 예외 없이 정상적으로 끝나면 else 문의 코드 블록을 실행합니다. 4. finally 문이 있다면 예외 발생 여부와 관계없이 마지막에 실행합니다.

기본적인 흐름에서는 try 문에서 시작하여 예외가 발생하면 except 문으로, 예외 없이 끝나면 else 문으로 나뉘고, 마지막에는 finally 문에서 다시 만난다고 생각하면 이해하기 쉽습니다.

> **바로 핵심 요약**
>
> - else 문의 코드 블록은 try 문의 코드 블록에서 오류가 발생하지 않았을 때 실행됩니다.
> - finally 문의 코드 블록은 오류 발생 여부와 관계없이 마지막에 실행됩니다.
> - try 문에는 오류가 예상되는 코드를 두고, else 문에는 해당 작업이 정상적으로 끝난 뒤 이어서 실행할 코드를 둡니다.
> - else 문과 finally 문은 필요한 상황에 따라 선택하여 사용합니다.
