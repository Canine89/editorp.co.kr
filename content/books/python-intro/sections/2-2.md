프로그래밍을 시작하면 가장 먼저 만나는 개념이 바로 변수입니다. 변수가 무엇인지, 왜 사용하는지 이해하면 앞으로 배울 모든 코드가 훨씬 쉽게 읽힐 겁니다. 값에 이름을 붙여 보관한다는 감만 잡으면 전혀 어렵지 않으니 가벼운 마음으로 시작해봅시다.

> **미리 알아두세요!**
>
> - 변수는 값에 이름을 붙여 보관하는 상자와 같습니다.
> - 변수를 사용하면 값을 기억하기 쉽고, 재사용하거나 수정하기도 편합니다.

![](/books/python-intro/p072-057.webp)

이제 본격적으로 파이썬 문법을 공부하겠습니다. 가장 먼저 다룰 내용은 **변수**(Variable)입니다. 사실 변수는 앞서 **파이썬 시작하기**에서 이미 사용해봤습니다. 다음 코드를 보면 기억이 되살아날 겁니다.

```python
>>> name = "바로"
```

이 코드는 name이라는 변수에 "바로"라는 문자열을 저장한 것입니다. 이처럼 값을 저장하는 행위를 ‘변수에 값을 할당한다’라고 표현합니다. 파이썬 변수에는 문자열뿐만 아니라 다양한 형태의 값을 저장할 수 있습니다. 하지만 변수에 값을 할당하는 것만으로는 화면에 결과가 출력되지 않습니다. **파이썬 시작하기**에서 해봤듯이 print( ) 함수를 사용해야 변수 안의 값을 눈으로 확인할 수 있습니다.

```python
>>> name = "바로"
>>> age = 35
>>> height = 164
>>> is_student = False
>>> print(name, age, height, is_student)
```

**실행 결과**

```text
바로 35 164 False
```

예를 들어 name = "바로"는 ‘변수 name에 "바로"라는 문자열을 할당했다’라고 하고, age = 35는 ‘변수 age에 35라는 숫자를 할당했다’라고 합니다. 할당은 다음과 같이 age라는 이름표가 붙은 상자에 35라는 값을 보관하는 모습을 떠올리면 이해하기 쉽습니다.

![](/books/python-intro/p073-058.webp)

다소 상투적인 비유이지만 변수의 기본 개념을 잡는 데는 가장 효과적인 설명입니다. 이 상자 이미지를 상상하면서 변수를 사용하는 이유와 변수의 개념을 자세히 알아봅시다.

## 변수를 사용하는 이유

변수를 사용하는 이유는 무엇일까요? 크게 3가지 이유가 있습니다.

### 값에 이름을 붙여 기억하기 쉽다

예를 들어 user_id = 12354151이라는 값이 있다면, 복잡한 숫자 12354151을 직접 외우기보다는 user_id라는 변수 이름을 사용하는 것이 더 편하겠죠. 코드에서도 마찬가지입니다. 이처럼 변수를 활용하면 복잡하거나 긴 값에 의미 있는 이름을 붙여 직관적으로 다룰 수 있어 유용합니다.

![](/books/python-intro/p073-059.webp)

```python
user_id
```

### 재사용할 수 있어 유용하다

변수에 저장한 값은 필요할 때마다 언제든 꺼내 재사용할 수 있습니다. 예를 들어 다음과 같이 코드를 작성하면 home_address에 할당한 집 주소 하나만으로 다양한 형태의 결과를 출력하여 확인할 수 있습니다.

> **NOTE**
>
> f-string은 뒤에서 자세히 배웁니다. 지금은 변수의 재사용 과정에 대해서만 확인하고 넘어갑시다.

```python
>>> home_address = "서울시 강남구 테헤란로 123"
>>> print(f"집 주소: {home_address}")
>>> print(f"택배 배송지: {home_address}")
>>> print(f"주민등록상 주소: {home_address}")
```

**실행 결과**

```text
집 주소: 서울시 강남구 테헤란로 123
택배 배송지: 서울시 강남구 테헤란로 123
주민등록상 주소: 서울시 강남구 테헤란로 123
```

만약 변수를 사용하지 않는다면 다음과 같이 print( ) 함수마다 주소를 일일이 직접 입력해야 합니다.

```python
>>> print("집 주소: 서울시 강남구 테헤란로 123")
>>> print("택배 배송지: 서울시 강남구 테헤란로 123")
>>> print("주민등록상 주소: 서울시 강남구 테헤란로 123")
```

**실행 결과**

```text
집 주소: 서울시 강남구 테헤란로 123
택배 배송지: 서울시 강남구 테헤란로 123
주민등록상 주소: 서울시 강남구 테헤란로 123
```

변수가 있을 때와 없을 때의 차이가 명확히 보일 것입니다. 변수에 값을 한 번 할당해두면 이후에는 변수 이름만 사용하여 간편하게 반복 출력할 수 있습니다.

### 수정이 용이하다

변수에 할당한 값은 언제든 한 번만 수정하여 전체 코드에 적용할 수 있습니다. 예를 들어 앞서 작성한 코드에서 주소가 변경되었다면 주소의 값만 바꾸면 되고, 나머지 코드는 건드리지 않아도 됩니다. 다음과 같이 123을 999로만 변경하면 변경된 주소가 일괄 적용됩니다. 한 번만 수정하면 나머지 코드는 손대지 않고도 주소를 다양한 방식으로 출력하는 프로그램을 그대로 사용할 수 있는 거죠.

```python
>>> home_address = "서울시 강남구 테헤란로 999"
>>> print(f"집 주소: {home_address}")
>>> print(f"택배 배송지: {home_address}")
>>> print(f"주민등록상 주소: {home_address}")
```

![](/books/python-intro/p075-060.webp)

**실행 결과**

```text
집 주소: 서울시 강남구 테헤란로 999
택배 배송지: 서울시 강남구 테헤란로 999
주민등록상 주소: 서울시 강남구 테헤란로 999
```

정리하면 **변수는 코드를 읽기 쉽고, 수정하기 쉽고, 재사용하기 쉽게 만들어주는 유용한 것입니다.** 상자에 이름표를 붙여 정리하는 모습을 상상하면 변수의 개념을 손쉽게 이해하고 기억할 수 있을 겁니다.

![](/books/python-intro/p075-061.webp)

> **바로 핵심 요약**
>
> - 변수는 값에 이름을 붙여 저장해두는 공간입니다.
> - 변수를 사용하면 코드를 읽기 쉽게 작성할 수 있고 수정과 재사용하기 편리해집니다.
> - 변수에 저장한 값은 필요할 때마다 다른 값으로 언제든 바꿀 수 있습니다.
