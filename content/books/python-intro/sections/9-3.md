print( )를 이용한 터미널 출력은 프로그램을 실행하면서 결과를 간단히 확인하기에 좋습니다. 하지만 터미널에 출력된 내용은 터미널을 끄거나, 컴퓨터를 껐다 켜면 사라지므로, 프로그램의 결과를 계속 보관하는 방법으로는 적합하지 않습니다. 그렇다면 프로그램이 만든 결과를 나중에도 다시 확인하려면 어떻게 해야 할까요? 가장 간단한 방법 중 하나는 결과를 파일로 저장하는 것입니다. 프로그램에서 처리한 결과를 파일에 기록하는 것도 출력의 한 형태이며, 여기서는 이를 파일 출력이라고 하겠습니다.

> **미리 알아두세요!**
>
> - open( ) 함수로 파일을 열고 write( )로 내용을 쓸 수 있습니다.
> - with 문을 사용하면 파일을 자동으로 닫아줍 니다.

## 파일 출력 간단하게 해보기

파이썬에서는 open( ) 함수로 파일을 열고, write( ) 메서드로 내용을 쓴 뒤, close( ) 메서드로 파일을 닫아 파일에 내용을 저장할 수 있습니다. 아마 코드를 실행하면 터미널에는 아무것도 출력되지 않을 겁니다. print( )로 화면에 값을 출력한 것이 아니라 파일을 열고 그 안에 내용을 저장했기 때문입니다. 워드 프로그램에서 문서를 작성한 뒤 파일로 저장하는 것과 비슷하다고 생각하면 됩니다.

```python filename="09-02-order_write.py"
order_file = open("order.txt", "w", encoding="utf-8")    # ➊ 주문 파일 열기
order_file.write("주문 메뉴: 아메리카노\n")                # ➋ 주문 내용 쓰기
order_file.write("결제 금액: 3000원\n")
order_file.write("배송 예정일: 내일\n")
order_file.close()                                 # ➌ 주문 파일 닫기
```

❶ open("order.txt", "w", encoding="utf-8")는 order.txt라는 파일을 쓰기 모드로 여는 코드입니다. 여기서 파일을 연다는 말은 파이썬이 해당 파일에 내용을 쓰거나 읽는 등의 작업을 할 수 있도록 준비한다는 뜻입니다. 이때 파일 이름만 지정하면 파일이 생성되는 위치는 터미널에서 파이썬을 실행한 폴더(현재 작업 폴더)입니다. 이 책의 실습처럼 코드를 저장한 폴더에서 실행하면 코드와 같은 위치에 order.txt가 생성됩니다. 해당 폴더에 order.txt 파일이 없다면 파일을 새로 만들고, 같은 이름의 파일이 이미 있다면 기존 내용을 지우고 새로 작성합니다.

> **NOTE**
>
> 세 번째 인수인 encoding="utf-8"은 파일에 문자를 저장하거나 읽을 때 글자가 깨지지 않도록 사용하는 문자 인코딩

방식을 UTF-8로 지정하는 코드입니다. 이 값을 지정하지 않으면 컴퓨터 환경에 따라 인코딩이 달라져 결과가 달라질 수 있습니다. 파일을 열 때는 항상 함께 적어준다고 생각하면 됩니다.

이때 파일을 어떤 방식으로 열 것인지 모드를 설정하는 부분이 두 번째 인수인 "w"입니다. "w"는 write를 의미하며, 파일에 내용을 새로 쓰기 위한 모드입니다. 앞서 살펴본 것처럼 같은 이름의 파일이 이미 있다면 기존 내용은 지워지고 새 내용이 저장됩니다.

❷ write( ) 메서드는 열린 파일 안에 문자열을 저장합니다. order_file.write("주문 메뉴: 아메리카노\n")처럼 쓰면 order.txt 파일 안에 주문 메뉴가 저장됩니다. 문자열 끝의 \n은 줄바꿈을 나타내는 이스케이프 시퀀스입니다. 따라서 세 번의 write( )를 실행하면서 각 문자열 끝에 \n을 넣으면 주문 메뉴, 결제 금액, 배송 예정일이 각각 다른 줄에 저장됩니다.

> **NOTE**
>
> 코드를 실행한 뒤에는 코드를 저장한 폴더를 열어 order.txt 파일이 실제로 만들어졌는지 눈으로 확인해보세요. 파일

이 보이지 않는다면 현재 작업 폴더가 어디인지 확인해보세요. 터미널의 현재 위치가 코드를 저장한 폴더와 다른 경우가 종종 있습니다.

❸ close( ) 메서드는 파이썬 코드로 열어 둔 파일을 닫습니다. 우리 눈에는 별도의 창이 열린 것처럼 보이지 않지만 open( )으로 파일을 열었다면 파일 작업이 끝나면 반드시 파일을 닫아야 합니다. 파일을 닫아야 write( )로 쓴 내용이 파일에 확실히 기록됩니다. 워드 프로그램에서 문서 작업을 마친 뒤 파일을 저장하고 종료하는 것과 비슷하게 생각하면 됩니다.

정리하면 ❶ open( )으로 파일을 쓰기 모드로 열고, ❷ write( )로 파일에 내용을 쓴 뒤, ❸ close( ) 로 파일을 닫는 것이 파일 출력의 기본 흐름입니다. 다시 말하지만 터미널에서 아무것도 보이지 않는다고 해서 당황하지 마세요. 이번에는 화면이 아니라 파일로 결과를 내보낸 것입니다.

## 파일에 내용 이어 쓰기

앞에서는 "w" 모드로 파일을 열어 내용을 저장했습니다. "w" 모드는 다음과 같은 규칙을 가지고 동작합니다.

- 파일이 없으면 새로 만들어 내용을 씁니다.
- 같은 이름의 파일이 이미 있으면 기존 내용을 지우고 새로 씁니다.

만약 기존 파일 내용은 그대로 두고, 그 아래에 새로운 내용을 덧붙이고 싶다면 어떻게 해야 할까요? 이때는 파일을 이어쓰기 모드로 열면 됩니다. 파일에 내용을 이어 쓸 때는 open( ) 함수의 두 번째 인수(모드)에 "a"를 지정합니다. 여기서 "a"는 append를 의미하며, 말 그대로 '기존 파일의 끝에 새로운 내용을 덧붙이는 모드'를 뜻합니다.

```python filename="09-04-diary_append.py"
diary_file = open("diary.txt", "w", encoding="utf-8")        # ➊ 파일을 쓰기 모드로 열기
diary_file.write("오늘의 일기\n")
diary_file.write("파이썬 파일 출력을 배웠습니다.\n")
diary_file.close()

diary_file = open("diary.txt", "a", encoding="utf-8")        # ➋ 파일을 이어쓰기 모드로 열기
diary_file.write("파일에 내용을 이어 쓰는 방법도 배웠습니다.\n")  # ➌ 내용 이어 쓰기
diary_file.close()                                            # ➍ 파일 닫기
```

**실행 결과**

```text
diary.txt 파일 내용:
오늘의 일기
파이썬 파일 출력을 배웠습니다.
파일에 내용을 이어 쓰는 방법도 배웠습니다.
```

❶ 먼저 완전히 새로운 파일을 만들어야 하므로 open("diary.txt", "w", encoding="utf-8") 를 작성해서 파일을 쓰기 모드로 열어 처음 내용을 작성합니다. 물론 open("diary.txt", "a", encoding="utf-8")와 같이 "a" 모드로 열어도 해당 파일이 없다면 새 파일을 생성해줍니다. 여기서는 "w" 모드와 "a" 모드의 차이를 명확하게 확인하기 위해 처음에는 "w" 모드로 작성했습니다.

❷ 이제 open("diary.txt", "a", encoding="utf-8")로 같은 파일을 이어쓰기 모드로 엽니다. "a" 모드에서는 기존 내용을 지우지 않고 파일의 마지막 부분에 새로운 내용을 덧붙입니다. 따라서 앞에서 저장한 다음 두 줄은 그대로 남아 있습니다.

- "오늘의 일기\n"
- "파이썬 파일 출력을 배웠습니다.\n"

❸ 파일을 "a" 모드로 연 뒤 write("파일에 내용을 이어 쓰는 방법도 배웠습니다.\n")를 실행하면 기존 내용 끝에 새로운 문장이 추가됩니다.

❹ 파일 작업이 끝났으니, close( )로 열어 둔 파일을 닫습니다.

코드를 실행한 뒤 diary.txt 파일을 열어보세요. 앞에서 작성한 내용이 그대로 남아 있고, "a" 모드에서 작성한 문장이 그 뒤에 추가된 것을 확인할 수 있습니다. 여기서 눈여겨볼 점은 "a" 모드로 쓴 내용이 기존 내용 뒤에 이어서 저장되었는지입니다.

![](/books/python-intro/p423-256.webp)

"a" 모드로 파일을 연 다음 write( ) 메서드로 내용을 쓰면 새로운 내용이 자동으로 다음 줄에 추가되는 것은 아닙니다. 줄을 바꾸려면 앞에서와 마찬가지로 write( )에 전달하는 문자열에 \n을 직접 넣어야 합니다. 또한 기존 내용의 끝에 \n이 없다면 새로 작성할 문자열의 앞에 \n을 넣어 줄을 바꿀 수도 있습니다. 다음은 새로 쓰는 문자열을 \n으로 시작하는 코드입니다. 직접 실행하며 확인해보세요.

> **NOTE**
>
> 코드는 여러분이 직접 실행해보기 바랍니다.

```python filename="09-05-memo_append_newline.py"
memo_file = open("memo.txt", "w", encoding="utf-8")
memo_file.write("첫 번째 메모")
memo_file.close()

memo_file = open("memo.txt", "a", encoding="utf-8")
memo_file.write("\n두 번째 메모")
memo_file.close()
```

지금까지는 파일을 열 때마다 마지막에 close( )를 직접 작성했습니다. 그런데 파일 작업을 할 때마다 close( )를 챙겨야 한다면 번거롭고, 실수로 빠뜨릴 수도 있습니다. 파이썬에서는 이런 불편함을 줄여주는 방법을 제공합니다.

## with 문으로 파일 자동으로 닫기

앞에서는 open( )으로 파일을 열고, write( )로 내용을 쓴 뒤, 마지막에 close( )로 파일을 닫았습니다. 하지만 매번 open( ) → write( ) → close( )의 흐름을 직접 작성하다 보면 close( )를 빠뜨릴 수도 있습니다. 이럴 때 사용할 수 있는 것이 with 문입니다. with open(...) as file: 형태로 파일을 열면 들여쓰기된 코드 블록 안에서 파일 작업을 할 수 있고, with 문을 벗어날 때 파일이 자동으로 닫힙니다. 따라서 close( )를 직접 작성할 필요가 없습니다. 코드로 확인해봅시다.

```python filename="09-06-order_with.py"
with open("order.txt", "w", encoding="utf-8") as order_file:    # ➊ 파일을자동으로 닫는 방식으로 열기
  order_file.write("주문 메뉴: 아메리카노\n")              # ➋ 파일에 내용 쓰기
  order_file.write("결제 금액: 3000원\n")
  order_file.write("배송 예정일: 내일\n")
```

**실행 결과**

```text
order.txt 파일 내용:
주문 메뉴: 아메리카노
결제 금액: 3000원
배송 예정일: 내일
```

❶ with open("order.txt", "w", encoding="utf-8") as order_file:은 order.txt 파일을 쓰기 모드로 열고, 이후 with 문의 코드 블록 안에서 파일을 order_file이라는 이름으로 사용할 수 있게 해주며, 코드 블록이 끝나면 파일을 자동으로 close( )합니다. 여기서 as order_file은 '코드 블록 안에서 열린 파일을 order_file이라는 이름으로 사용하겠다'는 뜻입니다.

❷ 이후 with 문의 코드 블록 안에서 write( )를 사용해 필요한 내용을 파일에 씁니다. 이번에는 마지막에 close( )를 직접 작성하지 않아도 됩니다.

코드를 실행한 뒤 order.txt 파일을 열어 내용을 확인해보세요. 이처럼 with 문을 사용하면 파일을 열고 작업한 뒤 닫는 과정을 with 문이 관리해주므로 close( )를 따로 작성하지 않아도 되어 편리해집니다.

![](/books/python-intro/p425-257.webp)

앞으로 파일을 다룰 때는 open( )과 close( )의 기본 흐름을 이해하되, 실제 코드에서는 with 문을 사용하는 방법도 함께 익혀두는 것이 좋습니다.

> **바로 핵심 요약**
>
> - open( )으로 파일을 열고 write( )로 내용을 쓴 뒤 close( )로 닫는 것이 파일 출력의 기본 흐름입니다.
> - "w" 모드는 파일이 없으면 새로 만들고, 파일이 있으면 기존 내용을 지운 뒤 새로 씁니다. "a" 모드는 파일의 기존 내용을 유지하면서 끝에 새로운 내용을 덧붙입니다.
> - 파일에 줄을 바꾸며 내용을 저장하려면 문자열에 줄바꿈 문자 \n을 넣어야 합니다.
> - with 문으로 파일을 열면 코드 블록을 벗어날 때 파일이 자동으로 닫히므로 close( )를 직접 작성하지 않아도 됩니다.
