내장 함수는 별도로 가져오지 않아도 바로 사용할 수 있는 함수입니다. 본문에서 이미 다룬 함수도 있고 처음 보는 함수도 있지만, 모두 외울 필요는 없습니다. '이런 함수가 있었지' 정도로 알아두었다가 필요할 때 찾아보세요. 각 함수의 예제는 그대로 입력해 실행하며 사용법을 확인할 수 있습니다.

## 숫자를 다루는 함수

### abs( )

숫자의 절댓값을 돌려줍니다. 부호를 떼고 크기만 볼 때 사용합니다.

```python
 print(abs(-5))
print(abs(3.2))
```

**실행 결과**

```text
5
3.2
```

### round( )

숫자를 반올림합니다. 두 번째 인수로 소수점 아래 자릿수를 정할 수 있습니다.

```python
 print(round(3.7))
print(round(3.14159, 2))
```

**실행 결과**

```text
4
3.14
```

에서 배운 format( )이나 f-string의 :.2f는 보여주는 모양만 바꾼 문자열을 만들지만, round( ) 는 반올림한 숫자를 돌려줍니다. 따라서 그 값을 다시 계산에 사용하면 결과가 달라질 수 있습니다.

### divmod( )

나눗셈의 몫과 나머지를 한 번에 돌려줍니다. 결과는 튜플입니다.

```python
 print(divmod(17,  5))
```

**실행 결과**

```text
(3, 2)
```

### pow( )

거듭제곱을 계산합니다. ** 연산자와 같은 일을 합니다.

```python
 print(pow(2,  10))
print(2 ** 10)
```

**실행 결과**

```text
1024
1024
```

### max( )

여러 값 중 가장 큰 값을 돌려줍니다.

```python
 print(max([3, 9, 1]))
print(max(4, 7))
```

**실행 결과**

```text
9
7
```

### min( )

여러 값 중 가장 작은 값을 돌려줍니다.

```python
 print(min([3, 9, 1]))
print(min(4, 7))
```

**실행 결과**

```text
1
4
```

### sum( )

리스트나 튜플에 든 숫자를 모두 더합니다.

```python
 print(sum([1, 2, 3]))
print(sum([1, 2, 3], 10))
```

**실행 결과**

```text
6
```

두 번째 인수는 더하기를 시작할 값입니다. 적지 않으면 0에서 시작합니다.

## 자료형을 바꾸고 확인하는 함수

### int( )

값을 정수로 바꿉니다. 실수를 넣으면 소수점 아래를 잘라냅니다.

```python
 print(int("25") + 5)
print(int(3.9))
```

**실행 결과**

```text
3
```

int(-3.9)는 -4가 아니라 -3입니다. 내림이 아니라 0에 가까운 쪽으로 잘라내기 때문입니다.

### float( )

값을 실수로 바꿉니다.

```python
 print(float("3.5"))
print(float(7))
```

**실행 결과**

```text
3.5
7.0
```

### str( )

값을 문자열로 바꿉니다. 숫자와 문자열을 이어 붙일 때 사용합니다.

```python
 print("점수: " + str(90))
```

**실행 결과**

```text
점수: 90
```

### bool( )

값이 참인지 거짓인지 알려줍니다. 0, 빈 문자열, 빈 리스트는 거짓입니다.

```python
 print(bool(0))
print(bool(""))
print(bool("파이썬"))
```

**실행 결과**

```text
False
False
True
```

### list( )

값을 리스트로 바꿉니다. 문자열을 넣으면 글자가 하나씩 나뉩니다.

```python
 print(list("파이썬"))
print(list((1, 2, 3)))
```

**실행 결과**

```text
['파', '이', '썬']
[1, 2, 3]
```

### tuple( )

값을 튜플로 바꿉니다. 요소를 추가·삭제하거나 다른 값으로 교체할 수 없는 튜플을 만들 때 사용합니다.

```python
 print(tuple([1, 2, 3]))
```

**실행 결과**

```text
(1, 2, 3)
```

### set( )

값을 집합으로 바꿉니다. 중복이 사라지므로 중복 제거에 자주 씁니다.

```python
 print(set([1, 1, 2, 2, 3]))
```

**실행 결과**

```text
{1, 2, 3}
```

### dict( )

키와 값의 짝으로 딕셔너리를 만듭니다.

```python
 print(dict(name="바로", age=25))
```

**실행 결과**

```text
{'name': '바로', 'age': 25}
```

### type( )

값의 자료형을 알려줍니다.

```python
 print(type(3.14))
print(type("파이썬"))
```

**실행 결과**

```text
<class 'float'>
<class 'str'>
```

### isinstance( )

값이 그 자료형이나 클래스로 만들어졌는지 알려줍니다.

```python
 print(isinstance(3,  int))
print(isinstance("3", int))
```

**실행 결과**

```text
True
False
```

08.2에서 상속 관계를 확인할 때 사용한 함수입니다. 자료형을 확인할 때도 그대로 쓸 수 있습니다.

## 반복할 때 쓰는 함수

### len( )

문자열, 리스트, 딕셔너리 등에 든 요소의 개수를 알려줍니다.

```python
 print(len("파이썬"))
print(len([10, 20, 30]))
```

**실행 결과**

```text
3
3
```

### range( )

정해진 범위의 숫자를 차례대로 만듭니다. for 문과 함께 씁니다.

```python
 print(list(range(1,  4)))
print(list(range(0, 10, 3)))
```

**실행 결과**

```text
[1, 2, 3]
[0, 3, 6, 9]
```

### enumerate( )

값과 함께 번호를 붙여 줍니다. 목록에 번호를 매길 때 편리합니다.

```python
 for number, fruit in enumerate(["사과", "바나나"], 1):
  print(number, fruit)
```

**실행 결과**

```text
1 사과
2 바나나
```

두 번째 인수는 시작 번호입니다. 이를 적지 않으면 0부터 시작합니다.

### zip( )

여러 리스트를 나란히 묶어 하나씩 짝지어 줍니다.

```python
 for name, score in zip(["바로", "요즘"], [90, 85]):
  print(name, score)
```

**실행 결과**

```text
바로 90
요즘 85
```

### sorted( )

정렬한 새 리스트를 돌려줍니다. 원본은 바뀌지 않습니다.

```python
 print(sorted([3, 1, 2]))
print(sorted([3, 1, 2], reverse=True))
```

**실행 결과**

```text
[1, 2, 3]
[3, 2, 1]
```

리스트의 sort( ) 메서드는 원본을 직접 정렬합니다. 원본을 지키고 싶다면 sorted( )를 쓰세요.

### reversed( )

순서를 거꾸로 뒤집어 줍니다. 결과는 list( )로 감싸 확인합니다.

```python
 print(list(reversed([1, 2, 3])))
```

**실행 결과**

```text
[3, 2, 1]
```

### map( )

모든 요소에 같은 함수를 적용한 결과를 차례대로 돌려줍니다.

```python
 print(list(map(int, ["1", "2", "3"])))
```

**실행 결과**

```text
[1, 2, 3]
```

**07.7 알아두면 좋은 파이썬 내장 함수 6가지 알아보기**에서 본 것처럼 map( )은 이터레이터를 돌려주므로 list( )로 감싸야 눈으로 확인할 수 있습니다.

### filter( )

조건에 맞는 요소만 골라냅니다. map( )이 값을 바꾼다면 filter( )는 걸러냅니다.

```python
 numbers = [1, 2, 3, 4, 5]
print(list(filter(lambda n: n % 2 == 0, numbers)))
```

**실행 결과**

```text
[2, 4]
```

에서 배운 람다와 함께 쓰면 짧게 표현할 수 있습니다.
