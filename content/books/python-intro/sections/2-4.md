## 기본 구성 요소와 관련한 용어

파이썬 코드를 만들 때 사용하는 가장 기본적인 재료들입니다. 마치 문장을 만들 때 단어, 문법, 기호가 필요한 것처럼, 프로그래밍에도 이런 기본 재료들이 있어요.

### [용어 01] 키워드, Keyword

키워드는 파이썬에서 특별한 용도로 미리 정해놓은 단어들입니다. 대표적인 파이썬 키워드는 if, for, while, def, class, import, True, False 같은 것들입니다. 보통 문법 요소로 사용하는 것들이 키워드라고 생각하면 됩니다. 현재 파이썬의 키워드는 35종이 있습니다. 참고로 키워드는 외우거나 할 필요는 없습니다. 어차피 나중에 오류가 발생하는 등의 여러 이유로 여러분이 자연스럽게 키워드라는 것을 인식하게 될 겁니다. 지금은 '아\~ 이런 키워드가 있구나'하고 눈으로 보고 넘어가도 충분합니다.

|  |  |  |  |  |  |
| :-: | :-: | :-: | :-: | :-: | :-: |
| if | while | return | try | assert | is |
| elif | break | yield | except | and | in |
| else | continue | lambda | finally | or | TRUE |
| for | def | class | raise | not | FALSE |
| None | as | del | await | from | nonlocal |
| import | global | with | pass | async |   |

예를 들어 키워드는 다음과 같이 변수명으로 사용한다던가 하면 오류가 발생합니다. 다음은 키워드 if를 변수로 사용하려고 해서 오류가 발생한 예입니다.

### [용어 02] 식별자, Identifier

식별자는 변수나 함수에 붙이는 이름을 뜻합니다. name, grade, student\_name, total\_score, MyAddress와 같이 영문자, 숫자, 밑줄만 사용해서 만들 수 있습니다. 쉽게 말해서 여러분이 앞으로 파이썬 공부를 하며 변수나 함수, 클래스에 붙일 이름이라고 생각하면 됩니다. 

\[Note\] 이때 식별자는 스네이크 케이스 또는 캐멀 케이스 방식으로 만들 수 있는데 이건 따로 알아보겠습니다.

#### 식별자 규칙 알아보기

식별자에는 규칙이 있는데 이를 어기면 문법 오류가 발생합니다. 어차피 처음에 외우기는 힘들고 오류를 만나면서 익숙해지게 되어 있습니다. 지금은 눈으로 읽어보고 넘어갑시다.

1.  사용할 수 있는 문자 : 영문 대소문자(A-Z, a-z), 숫자(0-9), 밑줄(\_)만 사용 가능
      
    1.  하지만 숫자로 시작할 수는 없음
    2.  특수 기호(@, $, %, \#, \! 등)는 사용할 수 없음
2.  시작 문자 규칙 : 대문자, 소문자, 밑줄(\_)로 시작할 수 있음
3.  대소문자 구분 : 파이썬은 대소문자를 구별, 즉, Name과 name은 서로 다른 식별자
4.  키워드 사용할 수 없음 : None, True, False, if, for, while 등과 같은 키워드는 식별자로 사용할 수 없음
5.  유니코드 지원 : 한글 등 영어 외 유니코드 문자를 사용할 수 있음, 하지만 권장하지는 않음

## 데이터와 타입 관련 용어

### [용어 05] 자료형, Data Type

## 코드 작성과 구조 관련 용어

실제 프로그램을 작성할 때 코드를 어떻게 구성하고 정리할지에 관한 개념들입니다. 컴퓨터가 이해할 수 있는 명령을 만들고, 사람이 읽기 쉽게 정리하는 방법들이에요.

### [용어 07] 문장, Statement

문장은 컴퓨터가 실행할 수 있는 완전한 명령 한 줄을 의미합니다. name = "바로"와 같이 ‘변수에 값을 저장하라’는 완전한 명령이 하나의 문장입니다. 문장들이 모여 프로그램이 됩니다.

### [용어 08] 표현식, Expression

표현식은 계산하여 하나의 값이 나오는 코드 조각을 말합니다. **\[용어 03\] 문장, Statement**와 혼동되어 설명이 좀 난해하게 느껴질 수 있으므로 예를 들어 자세히 설명하겠습니다. 예를 들어 다음은 코드 조각입니다. 즉, 표현식입니다. 

```python
  - 3 + 5라는 코드는 8이라는 값을 만들어내는 코드 조각입니다. 
  - "안녕" + "하세요"는 "안녕하세요"라는 문자열을 만들어내는 코드 조각입니다.
```

이 표현식이 문장의 일부가 됩니다. 예를 들어 name = "바로" + "님"라는 코드가 있다면,

```python
  - "바로" + "님" ← 이 부분이 표현식입니다. "바로님"이라는 문자열 값을 만드니까요.
  - name = "바로" + "님" ← 이건 문장입니다. ‘"바로님"이라는 값을 만들어 name에 저장하라’는 완전한 명령이니까요.
```

다른 예를 보겠습니다.

```python
result = 10 + 5 * 2라는 문장에서
  - 10 + 5 * 2 ← 이 부분이 표현식이고
  - result = 10 + 5 * 2 ← 전체는 문장입니다.
```

문장은 표현식을 포함할 수 있는 개념입니다. 둘은 미묘한 관계에 있으므로 미리 머릿속에 구분해두기 바랍니다.

### [용어 09] 주석, Comment

주석이란 코드 설명을 위한 메모입니다. 주석은 코드 실행에 영향을 미치지 않는 일종의 코드 포스트잇 같은 것입니다. 개발자들끼리 코드에서 메모를 통해 코드의 의미를 설명하거나 기록하는 용도로 사용하죠. 주석은 다음과 같이 한 줄 주석 또는 여러 줄 주석을 사용할 수 있습니다. 

\[Note\] 편집기에서 주석으로 만들고 싶은 줄에 입력 커서를 두거나 드래그를 한 뒤 \[Ctrl + /\]를 누르면 해당 내용을 주석으로 바꾸거나 해제할 수 있습니다.

#### 한 줄 주석 사용 예

한 줄 주석은 \# 다음에 오는 같은 줄에 있는 텍스트를 주석화하는 겁니다.

```python
# 이것은 한 줄 주석입니다
```

print("안녕하세요")  \# 코드 뒤에도 주석을 달 수 있습니다

```python
# 변수 선언
name = "바로"
age = 35  # 나이
```

#### 여러 줄 주석 사용 예

여러 줄 주석은 """와 """ 사이에 있는 모든 텍스트를 주석화하는 겁니다. 예를 보면 금방 이해할 수 있을 겁니다.

"""

이것은 여러 줄 주석입니다.

 함수나 클래스의 설명을 위해 자주 사용합니다.

docstring이라고도 부릅니다.

"""

```python
def calculate_area(radius):
    """
    원의 넓이를 계산하는 함수

    Args:
        radius (float): 원의 반지름

    Returns:
        float: 원의 넓이
    """
    return 3.14 * radius ** 2
```

그런데 하나 오해를 풀 것이 있다면 사실 """로 감싼 내용은 주석이 아니라 실제 문자열이라는 겁니다. 많은 입문서에서 여러 줄 주석을 쓰고 싶을 때 """로 감싸라고 이야기합니다. 하지만 이건 틀린 설명입니다. 여러분이 입력한 코드는 문자열을 주석처럼 쓰기 위해 편법을 쓴 것에 해당하는데, 문자열을 변수에 할당하지 않고 그냥 덩그러니 놔두었으니 만들어졌다가 바로 버려지므로 결과적으로 주석처럼 보일 뿐입니다. 그래서 원칙적으로 여러 줄 주석을 입력하고 싶다면 이렇게 해야 합니다.

```python
# 이것은
# 여러 줄에 걸친
# 주석입니다
```

## 프로그램 실행 관련 용어

프로그램을 실행했을 때 실제로 일어나는 동작들입니다. 데이터를 저장하거나 결과를 화면에 보여주는 것 같은 눈에 보이는 실질적인 작업을 말해요.

### [용어 10] 할당, Assignment

할당은 변수에 값을 저장하는 행위를 말합니다. 그래서 저장한다라는 표현을 많이 쓰기도 합니다. name = "바로"에서 할당 연산자 =를 이용해 "바로"라는 값을 name이라는 변수에 할당합니다.

### [용어 11] 출력, Output

이미 익숙한 용어입니다. 출력은 프로그램 결과를 화면에 보여주는 것을 말합니다. 파이썬 인터렉티브 셸 또는 터미널에서 print("안녕하세요")와 같은 코드를 실행하면 안녕하세요를 확인할 수 있었습니다. 출력에도 여러 가지 방식이 있는데 다음 예를 통해 이해하고 넘어가면 됩니다.

#### 한 줄만 출력하기

다음은 한 줄만 간단히 출력한 내용입니다. 이미 출력은 앞에서 해봤으니 구태여 또 설명하진 않겠습니다. 하나 달라진게 있다면 출력 결과를 주석으로 처리해서 표시하겠다는 겁니다. 이건 제가 책을 쓰기 편하기 위해 도입하는 여러분과 저만의 규칙입니다. 앞으로 간단한 출력은 구태여 줄을 바꿔서 적지 않고 주석으로 처리하고 넘어가겠습니다.

print("안녕하세요") \# 안녕하세요

#### 쉼표로 여러 개 출력하기

만약 변수의 값만 출력하고 싶다면 변수를 쉼표로 구분해서 print( )에 집어 넣으면 됩니다. 그리고 쉼표로 출력하면 출력 결과에 자동으로 띄어쓰기가 들어갑니다. 

```python
name = "바로"
age = 25
```

print(name, age) \# 바로 25

#### f-string으로 출력하기

f-string은 이미 자주 봤던 방식이죠? 변수나 표현식을 바로 print( ) 함수 한 덩이에 표현하기 좋은 방식입니다. 저는 앞으로 출력에 이 방식을 자주 사용할 겁니다.

```python
name = "바로"
score = 95
```

print(f"{name}의 점수는 {score}점입니다") \# 바로의 점수는 95점입니다
