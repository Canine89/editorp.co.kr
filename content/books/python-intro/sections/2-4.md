## 데이터와 타입 관련 용어

프로그램에서 사용하는 정보와 그 정보가 어떤 종류인지를 나타내는 개념들입니다. 숫자인지, 문자인지, 변할 수 있는 값인지 등을 구분해주는 역할을 합니다. 어떤 용어들이 있는지 살펴봅시다.

## 용어 05 자료형, Data Type

자료형은 데이터의 종류를 구별하는 방식을 말합니다. 예를 들어 문자열("안녕"), 정수(10), 실수(3.14) 등이 있습니다. 각 자료형의 상세한 문법은 뒤이어 나오는 부분에서 제대로 다룰 예정이므로 여기서는 자료형이라는 용어가 있다는 정도만 알아두고 넘어가겠습니다.

## 용어 06 상수, Constant

상수는 한 번 정하면 프로그램 실행 도중 변경할 수 없는 값을 의미합니다. 상수는 프로그래밍 언어에 따라 지원 여부가 다릅니다. 파이썬에는 상수를 지정하는 전용 문법이 따로 없어서, 언어 차원에서 값의 변경을 강제로 막기에는 한계가 있습니다. 대신 대부분의 개발자들은 '대문자로만 구성된 변수명은 상수이므로 값을 수정하면 안 된다'

> **NOTE**
>
> 프로그래머의 암묵적인

규칙으로 부족하다 싶으면 보통 라는 암묵적인 규칙을 따릅니다. 따라서 파이썬에서 값을 고정해야 하주석으로 표시합니다. 는 변수는 다음과 같이 작성하면 됩니다.

```python
# 상수 - 값이 바뀌면 안 됨

```

## 코드 작성과 구조 관련 용어

실제 프로그램을 작성할 때 코드를 어떻게 구성하고 정리할지 다루는 용어입니다. 컴퓨터가 실행할 수 있는 명령을 작성함과 동시에, 사람이 읽기 쉽게 코드를 가꾸는 다양한 방법들입니다.

## 용어 07 문장, Statement

문장은 컴퓨터가 실행할 수 있는 완결된 명령 단위를 의미합니다. name = "바로"와 같이 '변수에 값을 저장하라'는 명확한 지시가 하나의 문장입니다. 이러한 문장들이 모여 하나의 프로그램이 됩니다. 파이썬은 보통 한 줄이 한 문장이지만, 나중에 배울 제어문을 사용할 때는 여러 줄이 한 문장이 되기도 합니다.

## 용어 08 표현식, Expression

표현식은 계산되어 하나의 값으로 나오는 코드 조각을 말합니다.

**문장, Statement**와 개념이 헷갈릴 수 있으므로 조금 더 자세히 살펴보겠습니다. 예를 들어 다음과 같은 코드 조각이 바로 표현식입니다.

- 3 + 5라는 코드는 8이라는 값을 만들어내는 코드 조각입니다.
- "안녕" + "하세요"는 "안녕하세요"라는 문자열을 만들어내는 코드 조각입니다.

이 표현식은 문장의 일부가 될 수 있습니다. 예를 들어 name = "바로" + "님"이라는 코드가 있다면,

- "바로" + "님" ← 이 부분이 표현식입니다. "바로님"이라는 문자열 값을 만드니까요.
- name = "바로" + "님" ← 이건 문장입니다. '"바로님"이라는 값을 만들어 name에 저장하라'는 완결된 명령이니까요.

다른 예를 보겠습니다.

result = 10 + 5 * 2라는 문장에서

- 10 + 5 * 2 ← 이 부분이 표현식이고
- result = 10 + 5 * 2 ← 전체는 문장입니다.

이처럼 표현식은 값을 만들며, 문장은 표현식을 포함하는 더 넓은 개념이라는 것을 알 수 있습니다. 두 개념이 비슷하면서도 차이가 있는 만큼, 미리 명확하게 구분해두는 것이 좋습니다.

## 용어 11 출력, Output

이미 익숙한 용어인 출력은 프로그램 실행 결과를 화면에 보여주는 것을 말합니다. 파이썬 인터프리터 셸이나 파이썬 파일에서 print("안녕하세요")와 같은 코드를 실행했을 때 화면에 나오는 결과가 바로 출력입니다. 출력 방식은 다양하며, 다음의 대표적인 예를 통해 살펴봅시다.

#### 한 줄만 출력하기

한 줄만 간단히 출력하는 기본 사용법은 앞서 익혔으므로 재차 설명하진 않겠습니다. **한 가지 차이가 있다면, 의 일부 짧은 예제에서는 실습 코드의 실행 결과를 코드 옆에 주석 표시인 #을 붙여 구분하겠습니다. 책의 가독성을 높이고 설명을 효율적으로 진행하기 위한 약속이니 참고해주세요.**

```python
>>> print("안녕하세요") # 안녕하세요
```

#### 쉼표로 여러 개 출력하기

여러 값이나 변수를 한 번에 출력하고 싶다면 print( ) 함수 안에 쉼표(,)로 구분하여 넣으면 됩니다. 이때 쉼표로 출력하면 실행 결괏값 사이에 자동으로 공백이 들어갑니다.

```python
>>> name = "바로"

```

#### f-string으로 출력하기

f-string은 이미 자주 봤던 방식이죠? 변수와 표현식을 바로 print( ) 함수 안에서 하나의 문장으로 깔끔하게 조합하기 가장 좋은 방식입니다. 앞으로 진행할 실습에서도 이 방식을 자주 사용하겠습 니다.

```python
>>> name = "바로"
>>> score = 95
>>> print(f"{name}의 점수는 {score}점입니다") # 바로의 점수는 95점입니다
```

## 용어 12 입력, Input

입력은 사용자가 프로그램에 데이터를 전달하는 것을 말합니다. 파이썬에서는 input( ) 함수를 사용해 키보드로 값을 입력받을 수 있습니다. 예를 들어 input("이름을 입력하세요: ")와 같이 코드를 실행하면 화면에 안내 문구가 나타나고, 사용자가 입력한 값이 프로그램으로 전달됩니다. 입력 방식은 다양하며, 다음의 대표적인 예를 통해 살펴봅시다.

#### 한 줄 입력받기

사용자로부터 값을 입력받을 때는 input( ) 함수를 사용합니다. 괄호 안에 입력을 안내하는 문구를 넣으면 화면에 해당 문구가 표시되고, 사용자가 입력한 값이 프로그램으로 전달됩니다.

```python
>>> input("이름을 입력하세요: ") # 이름을 입력하세요:
```

#### 입력값을 변수에 저장하기

input( ) 함수로 입력받은 값은 변수에 저장해두었다가 다른 코드에서 사용할 수 있습니다. 이렇게 하면 사용자가 입력한 값을 원하는 곳에서 활용할 수 있습니다.

```python
>>> name = input("이름을 입력하세요: ") # 이름을 입력하세요: 바로
>>> print(f"안녕하세요, {name}님!") # 안녕하세요, 바로님!
```

#### 숫자로 입력받기

input( ) 함수로 입력받은 값은 기본적으로 문자열로 처리됩니다. 숫자로 사용하려면 int( )나 float( ) 함수를 이용해 원하는 자료형으로 변환해야 합니다.

```python
>>> age = int(input("나이를 입력하세요: ")) # 나이를 입력하세요: 25
>>> print(f"내년에는 {age + 1}살입니다.") # 내년에는 26살입니다.
```
