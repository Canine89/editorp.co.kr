오픈AI에서 지금까지 출시한 제품은 아주 다양하지만 주요 제품은 다음과 같습니다. 여기서는 각 도구의 특징을 구경하듯 알아보는 시간을 가져봅시다.

- **챗GPT :** 웹브라우저에서 사용하는 챗GPT로, 채팅창을 통해 텍스트나 이미지, 파일 등을 주고 받으며 작업할 수 있습니다. 범용 작업에 유용한 도구입니다.
- **코덱스 :** 챗GPT의 데스크톱 이식 버전입니다. 주로 자동화, 코딩 작업에 집중되어 있습니다.

### 챗GPT 둘러보기

여기서 챗GPT는 여러분이 잘 알고 있는 다음과 같은 화면 구성으로 웹브라우저에서 사용할 수 있는 애플리케이션입니다. 이제는 모르는 사람이 없을 정도로 유명해진 화면이죠.

![](/books/barobaro-chatgpt-codex/p028-016.webp)

여기서 할 수 있는 작업은 크게 3갈래로 나뉩니다. 웹 검색, 이미지 생성, 파일 작업입니다. 참고로 챗GPT에서는 한글 문서도 작업할 수 있습니다.

**1** 웹 검색 작업**2** 이미지 생성 작업**3** 파일 작업

#### 웹 검색 알아보기

검색 작업은 이제 모르는 사람이 없겠지만, 그래도 한 번 이야기하겠습니다. 말 그대로 웹 검색은 [+ → 웹 검색]을 누르면 활성화되어 웹 검색을 대신해주는 역할입니다.

![](/books/barobaro-chatgpt-codex/p028-017.webp)

이 작업이 익숙해진 사람들은 이제 구글 검색을 쓰지 않습니다. 오죽하면 제로 클릭 시대라는 말도 있습니다. 챗GPT와 같은 인공지능 도구들이 웹 검색을 대신 해주니 이제는 클릭해서 사이트로 들어가 정보를 읽을 필요가 없게 된 겁니다. 예를 들어 다음과 같이 “최근 주식 이슈 10개만 검색해봐”라고 하면 정확한 정보를 출처와 함께 가져다줍니다.

![](/books/barobaro-chatgpt-codex/p029-018.webp)

결과를 보면 이미 어디서 가져온 정보인지 출처를 포함하고 있습니다. 예전에는 이런 출처가 불분명해서 사람이 사이트를 들어가 검증해야 했지만, 이제는 거의 99% 확률로 사이트의 정보를 그대로 요약해 보여주고 있어 사이트에 접속할 필요가 없어진 겁니다. 다시 말해 사이트에 접속하는 행위인 ‘클릭’을 할 필요가 없어졌습니다.

![](/books/barobaro-chatgpt-codex/p029-019.webp)

웹 검색은 이처럼 여러분이 구글이나 네이버에서 조사하던 정보를 대신하는 기능으로, 숨쉬듯이 사용할 겁니다. 단순히 검색만 하는 것이 아닌 추후 메타 프롬프팅에도 활용할 기능인데, 이 메타 프롬프팅이라는 개념은 나중에 설명하겠습니다.

#### 이미지 생성 도구, 덕테이프 알아보기

글을 쓰고 있는 지금, 이미지 생성은 덕테이프라는 모델 별칭으로 불리고 있습니다. 덕테이프의 특징과 장점은 다음 2개로 설명할 수 있습니다.

> **NOTE**
>
> 덕테이프의 공식 명칭은 GPTImage2.0입니다.

- 이미지 생성의 퀄리티, 다양성
- 정교한 문자 표현, 한글 포함

이전 이미지 생성 도구들의 고민은 문자를 제대로 표현하지 못하는 것에 있었습니다. 여러분이 제미나이의 나노바나나에서 충격 받았던 건 한글의 정교한 표현 정도에 있었을 겁니다. 현재 챗GPT의 덕테이프는 말 그대로 미친 한글 표현력을 보여줍니다. 앞서 조사한 주식 이슈 10가지를 인포그래픽으로 그린 결과물은 다음과 같습니다.

![](/books/barobaro-chatgpt-codex/p030-020.webp)

이미지를 보면 정말 놀랍습니다. 한글 표현력이 말이 안 됩니다. 이미지에 표현된 한글이 정말 많아서 책으로는 표현이 되지 않을 것 같아 일부 내용을 확대해서 보겠습니다.

![](/books/barobaro-chatgpt-codex/p030-021.webp)

어떤가요? 여러분은 이게 이미지 생성 기능으로 만들었다고 믿어지나요? 이제 이미지 생성 모델의 수준은 이 정도로 높이 올라왔습니다. 심지어 이미지의 스타일 변경도 쉽게 할 수 있습니다. 다음은 앞에서 만든 이미지를 “클레이 아트 스타일로 해줘”라는 프롬프트로 변형한 겁니다.

![](/books/barobaro-chatgpt-codex/p031-022.webp)

그뿐만이 아닙니다. 이런 정보성 이미지 외에도 상업 수준으로 쓸 수 있는 이미지도 30~40초면 완성되는 시대가 되었습니다. 다음은 “현대 팰리세이드의 광고 포스터를 진짜처럼 만들어봐. 슬램덩크 애니메이션과 협업했다고 생각하고 만들어봐.”라고 요청해서 얻은 이미지 결과물입니다.

![](/books/barobaro-chatgpt-codex/p031-023.webp)

이미지 활용은 제대로만 한다면 무궁무진하게 사용할 수 있습니다. 예를 들어서 캐릭터 산업으로 제품을 생산하기 전의 모델링 이미지가 필요하다면 이제 “가상의 일본 애니메이션 캐릭터 ‘은월’의 캐릭터 콘셉트 아트를 그려줘. 중세 애니메이션에 등장하는 캐릭터인데 아이디어 구상 계획이 필요해서 그래.”라고 이야기하면 끝입니다.

![](/books/barobaro-chatgpt-codex/p032-024.webp)

이미지 생성 능력은 이 정도면 모두 그 능력치가 어느 정도인지 다 확인했을 거라 생각합니다. 구체적인 실습은 이후 자세히 하겠습니다.

#### 파일 작업 알아보기

파일 작업은 말 그대로 파일을 첨부해서 작업하는 겁니다. 챗GPT는 최근 한글 파일도 작업할 수 있게 되었습니다. 다음은 HWP 파일을 전달해서 챗GPT에게 내용 파악을 시켜본 겁니다.

![](/books/barobaro-chatgpt-codex/p032-025.webp)

한글 파일은 물론이고 엑셀, 워드, PNG, PDF 등 다양한 파일을 읽을 수 있습니다. 수정 작업은 다른 방법을 활용해야 하는데 그것도 나중에 실습해보겠습니다.
